# 农场建设公开化方案 · 核心层（生态种养）

> **基于**：星形结构 — 核心层（战略成本中心）
> **覆盖工作**：24项（C01-C24）
> **本文定位**：核心层所有可公开化工作的模式匹配与执行设计

---

## 第一部分：总纲

### 1.1 核心理念

核心层是农场"真实感"的物理证明。菜地在种菜、鸡在跑、堆肥在发酵——这些不是"表演给客户看的景观"，而是农场本来就每天在做的事。

公开化的目的不是"让客户来帮我们干活省人工"，而是：
- **让信任可见**：客户亲手摸到土壤、亲眼看到鸡怎么喂、亲自参与一次堆肥翻堆——"这个农场是真实的"这个结论不需要我们说出来
- **让参与成为产品**：种菜、喂鸡、捡蛋本身就有情绪价值，尤其对城市里的人——它不是"劳动"，是"另一种生活的体验"
- **让传播自然发生**：孩子在菜地里拔出一根萝卜的照片，比任何精修宣传照都有说服力

### 1.2 核心层的公开化原则

核心层有自己的特殊性，决定了它在五种模式中的使用偏好：

| 原则 | 说明 |
|:---|:---|
| 生产优先 | 核心层首先是生产单位。客户参与不能影响正常的种养节奏 |
| 安全底线 | 可公开的工作必须是"即使做错了也不会出问题"的 |
| 季节性 | 公开化的排期要跟着农事走，春夏秋冬各有侧重 |
| 品质不妥协 | 客户参与不能降低生产标准，主管需要在旁边把关 |

### 1.3 核心层五种模式的整体倾向

| 模式 | 适合核心层的什么工作 | 核心层的天然优势 |
|:---|:---|:---|
| 课程化 | 有知识含量、可讲解的工作 | 生态种养的全过程都可以变成一堂自然课 |
| 共建化 | 需要集中力量的建设工作 | 集体劳动的画面感强，做完有成就感 |
| 劳动换薪 | 日常重复的轻体力工作 | 门槛最低，任何人都能参与 |
| 认领化 | 可分割、可标记的资产 | 认领是最强的复购驱动 |
| 技能传承 | 客人比农场团队更擅长的技能 | 种了一辈子地的老客户是宝藏 |

## 第二部分：各模式详述

---

### 模式1 课程化

**定义**：将有知识含量的农事工作设计为有结构的体验活动，客户以"学习+动手"的方式参与。

**适合的工作类型**：有原理可讲、有步骤可演示、有成果可带走的工作。

#### 典型场景1：堆肥课堂（对应C20）

| 项目 | 内容 |
|:---|:---|
| 时长 | 45-60分钟 |
| 定价 | 58元/人（含材料） |
| 容量 | 6-12人 |
| 流程 | 集合（5分钟）→ 什么叫好土壤？为什么堆肥比化肥好（10分钟）→ 实地看三个不同阶段的堆肥桶，闻味道、看颜色、测温度（15分钟）→ 动手参与翻堆+添加新料（15分钟）→ 每人领一小袋成品堆肥带回家（5分钟）→ 合影（5分钟） |
| 交付 | 每人带走一袋"青松农场的堆肥"（500g，牛皮纸袋包装，贴标签） |

**情绪价值设计**：
- "原来堆肥不是把垃圾堆在一起就行了"——认知被刷新带来的满足感
- "我参与了"——从旁观者变成参与者
- 带走的那袋堆肥回家用在阳台上——每次看到都会想起在农场的这一天

**传播设计**：
- 三个不同阶段的堆肥桶摆在一起拍
- 翻堆的动作抓拍——阳光下扬起腐熟的堆肥，画面有质感
- 堆肥成品袋的设计要有颜值——客户会拍照发朋友圈

#### 典型场景2：酵素探秘（对应C21）

| 项目  | 内容                                                                                    |
| :-- | :------------------------------------------------------------------------------------ |
| 时长  | 30-40分钟                                                                               |
| 定价  | 38元/人 或 作为自然教育引流课的一个环节打包                                                              |
| 容量  | 8-15人                                                                                 |
| 流程  | 什么是酵素？为什么要做酵素？（5分钟）→ 看正在发酵的酵素桶，闻不同阶段的酵素味道（10分钟）→ 动手做一瓶自己的酵素（15分钟）→ 贴上标签写名字和日期，带走（5分钟） |
| 交付  | 每人带走一瓶自己做的酵素（1L瓶，附使用方法卡片）                                                             |

**情绪价值设计**：
- "原来厨余垃圾可以变成宝贝"——环保理念的满足感
- 做酵素的过程非常简单，成功率几乎100%
- 3个月后酵素成熟可以拿来用——等待的过程本身也是期待

#### 典型场景3：育苗/播种课堂（对应C01、C02）

| 项目 | 内容 |
|:---|:---|
| 时长 | 40-60分钟 |
| 定价 | 48元/人（含材料） |
| 容量 | 6-15人 |
| 流程 | 种子是怎么发芽的？（5分钟）→ 看农场正在育苗的苗盘（5分钟）→ 自己动手：装土→挖孔→放种→覆土→浇水→贴标签（20分钟）→ 每人带走一盘苗（10分钟）→ 合影（5分钟） |
| 交付 | 每人带走一盘自己育的苗（育苗盘+营养土+种子，附养护指南卡） |

**情绪价值设计**：
- "把种子埋进土里等它发芽"——这件事本身就让人期待
- 孩子做完了天天在家看自己的苗有没有长出来
- 等苗长大了，可以再带来农场移栽——复购理由自然产生

### 模式2 共建化

**定义**：将需要集中力量完成的建设工作设计为集体活动，客户以"一起动手"的方式参与。

**适合的工作类型**：需要体力、适合多人协作、做完有明确视觉成果的工作。

#### 典型场景：一起翻地/一起做垄（对应C22）

| 项目 | 内容 |
|:---|:---|
| 时机 | 换茬前，每季度1次 |
| 形式 | 免费/低偿（或作为长搭客户的专属活动） |
| 容量 | 10-20人 |
| 流程 | 集合分组（5分钟）→ 种植养殖主管示范翻地标准（10分钟）→ 分组开工（40-60分钟）→ 结束后一起喝杯香草茶看成果（10分钟）→ 合影 |
| 交付 | 在翻好的地头插上"XX组翻"的木牌 |

**情绪价值设计**：
- "这一片地是我们一起翻的"——集体劳动后的归属感
- 翻地的时候聊天、出汗、合作——人和人之间的距离比在餐桌上拉近得更快
- 几个月后再来农场，指着那片地说"那片地是我翻的"

#### 典型场景：集体搭架（对应C05）

| 项目 | 内容 |
|:---|:---|
| 时机 | 瓜果类开始爬藤时，每年2-3次 |
| 形式 | 免费参与，或作为长搭客户的专属活动 |
| 容量 | 8-15人 |
| 流程 | 看示范→分组搭架→完成后插上小组名牌→合影 |

### 模式3 劳动换薪

**定义**：将日常重复的轻体力工作开放给客户参与，完成后获得小额现金或农场代金券。

**适合的工作类型**：门槛低、不需要技能、做错了也不会影响生产质量的工作。

#### 适合核心层的劳动换薪项

| 优先级 | 编号 | 工作内容 | 建议薪酬 | 时长 | 说明 |
|:---:|:---|:---|:---:|:---:|:---|
| P0 | C15 | 捡蛋 | 5元/10个 | 15分钟 | 孩子最爱，捡鸡蛋这个动作本身就很有趣 |
| P0 | C14 | 喂鸡（撒玉米/倒水） | 5元/次 | 10分钟 | 简单安全，孩子独立完成 |
| P0 | C08 | 叶菜类采收 | 10元/30分钟 | 30分钟 | 门槛最低，做完还能带一把菜走 |
| P1 | C04 | 除草（指定区域） | 10元/30分钟 | 30分钟 | 需要简单区分草和菜 |
| P1 | C10 | 根茎类采收 | 15元/30分钟 | 30分钟 | 最有惊喜感的采收——挖出来才知道长了多少 |
| P1 | C13 | 种子收集 | 8元/20分钟 | 20分钟 | 坐着干的轻活，适合老人或带孩子的家长 |
| P2 | C05 | 搭架（协助） | 10元/30分钟 | 30分钟 | 需要配合种植主管，适合成人或大孩子 |

**执行方式**：
- 小黑板制度：在核心区入口处挂一块小黑板"今日劳动换薪"，写上可参与的工作和薪酬
- 初期不设预约制，随到随做
- 参与前：种植养殖主管做1分钟安全告知+操作示范
- 参与中：主管在旁边正常干活，客户有问题随时问
- 结束后：当场发现金或代金券

### 模式4 认领化

**定义**：将农场中可分割、可标记的资产开放给客户认领，客户支付年费获得专属感和持续回访的理由。

**适合的工作类型**：有明确的物理边界、可标记、不需要频繁维护的资产。

#### 认领产品设计

| 产品 | 定价 | 权益 | 目标数量 |
|:---|:---:|:---|:---:|
| 认领一棵果树 | 200元/年 | 树上挂认领人名字牌，结果期优先采摘，保底5斤水果 | 30棵 |
| 认领一只鸡 | 100元/年 | 鸡脚上戴彩色脚环（刻字），每月提供12枚鸡蛋，年底鸡归认领人 | 50只 |
| 认领一畦菜地 | 500元/年 | 菜畦边插认领人姓名牌，种植养殖主管代管，每季可采收一次 | 20畦 |

**情绪价值设计**：
- 认领一棵树——"这是我的苹果树"——孩子会问"我们的苹果长大了吗"
- 认领一只鸡——鸡脚上的彩色脚环是独一无二的
- 认领一畦菜地——农场定期在群里发"你家的菜地最近长这样"

**运营要点**：
- 果树认领：挂认领牌时拍一张照片发给客户
- 鸡认领：脚环戴上后拍视频发客户
- 菜地认领：每月更新一次菜地照片发社群
- 所有认领产品到期前1个月提醒续费

### 模式5 技能传承

**定义**：识别出客户身上有农场需要的技能，发起一次平等的价值交换。

**适合的场景**：农场团队不够擅长、但部分客户可能精通的领域。

#### 核心层适用的技能交换场景

| 客人有 | 农场需要 | 交换方式 |
|:---|:---|:---|
| 传统农法经验（种了一辈子地的老年客户） | 识别老品种、传统种植技巧、节气农谚 | 聘为银发种植顾问，交换全年免费停车+每月1次家庭招待名额 |
| 传统手工艺（编竹筐/做农具/打草绳） | 纯手工农具/容器/装饰品 | 开一次体验课，课时费归老师，农场获得课程素材 |
| 堆肥/酵素深度爱好者 | 堆肥品质评估、酵素配方优化 | 邀请作为堆肥顾问，每月来1次指导，交换储值金 |

**关键提醒**：
- 技能传承不是"省钱"的手段。它的价值在于"建立深度关系"而非"替代人工"
- 识别技能的方式：在客户的日常聊天中发现

## 第四部分：执行流程

核心层的公开化执行流程，从发现到复盘，分为6个环节。

### 4.1 发现与识别

谁来发现：种植养殖主管（日常工作中最清楚哪些工作可以开放）。

发现时机：
- 日常农事中观察到某项工作特别适合客户参与
- 客户主动问起"这个我能试试吗"——这个信号说明有公开化价值
- 季度种植计划确定时——提前规划本季度哪些环节可以设计成公开活动

### 4.2 评估与决策

发现一项可公开的工作后，种植养殖主管和运营卫星一起用决策树判断模式：

```
这项工作有知识含量吗？
  +-- 有 --> 课程化
  +-- 没有
        +-- 需要集中力量完成吗？
        |   +-- 是 --> 共建化
        |   +-- 否
        |         +-- 客人比我擅长？
        |         |   +-- 是 --> 技能传承
        |         |   +-- 否
        |         |         +-- 是日常重复的轻活？ --> 劳动换薪
        |         |         +-- 是可分割的资产？ --> 认领化
```

### 4.3 设计与发布

决策完成后，根据模式类型执行不同流程：

| 模式 | 设计负责人 | 发布时间 | 发布渠道 |
|:---|:---|:---|:---|
| 课程化 | 种植养殖主管（教案）+ 运营卫星（文案） | 提前1-2周 | 社群+小红书+朋友圈 |
| 共建化 | 运营卫星（招募）+ 种植养殖主管（现场方案） | 提前1-2周 | 社群+长搭客户群 |
| 劳动换薪 | 种植养殖主管（准备小黑板） | 当天 | 核心区小黑板 |
| 认领化 | 运营卫星（产品页面）+ 种植养殖主管（物理准备） | 长期 | 商城+社群+现场展示 |
| 技能传承 | 言渊（邀请）+ 运营卫星（记录） | 私下邀请 | 当面/微信一对一 |

### 4.4 执行与现场管理

| 要点 | 标准 |
|:---|:---|
| 安全告知 | 任何动手环节开始前，必须做1分钟安全告知 |
| 工具准备 | 提前备好足够的工具、手套、围裙 |
| 人员配置 | 课程化/共建化：种植养殖主管全程在场；劳动换薪：主管在附近即可 |
| 天气预案 | 室外活动遇雨天提前1天通知改期 |
| 拍照记录 | 每场活动安排专人拍照，重点拍"动手的瞬间"和"完成时的表情" |

### 4.5 收尾与传播

| 模式 | 收尾动作 | 传播动作 |
|:---|:---|:---|
| 课程化 | 客户带走成品+合影 | 课后2小时内发照片给客户 |
| 共建化 | 在共建成果上留名（铭牌/签名板） | 发"今天我们一起做了XX"的图文 |
| 劳动换薪 | 当场发现金/代金券+签字 | 客户自己会发朋友圈 |
| 认领化 | 挂认领牌+拍照发给客户 | 认领过程视频发社群 |
| 技能传承 | 记录交换内容+留存联系方式 | 经客户同意后发故事 |

### 4.6 记录与复盘

每月末，运营卫星汇总核心层的公开化数据：

## 第五部分：风险与合规

### 5.1 风险分级

核心层的公开化活动按风险分为三级：

| 等级 | 描述 | 涉及的工作 | 控制措施 |
|:---:|:---|:---|:---|
| 低 | 几乎无物理风险，任何年龄段可参与 | 捡蛋、喂鸡、种子收集、酵素制作 | 标准安全告知+提供手套 |
| 中 | 有轻体力劳动或简单工具使用 | 叶菜采收、根茎类采收、除草、翻地、堆肥翻堆 | 安全告知+工具使用示范+主管在场 |
| 高 | 涉及锐利工具或有较大体力支出 | 搭架、整枝、粮食采收、鸡舍修缮 | 仅限成人+1对3以内指导+配备急救箱 |

### 5.2 保险要求

核心层公开化活动覆盖在农场已有的公众责任险下。在购买/续保时需确认：
- 保险条款包含"农业体验活动"或"农事观光"类目
- 覆盖范围包含：种植区、养殖区、堆肥区、酵素制作区等所有对客户开放的区域
- 建议保额：每次事故不低于100万元

认领化产品建议在认领协议中明确：因不可抗力（病害/极端天气等）导致的认领物损失，农场不承担赔偿责任，但会优先补发同等价值的产品。

### 5.3 免责协议

课程化、共建化活动在报名时需签署电子版免责协议。劳动换薪在小黑板处提供纸质版，首次参与时签署一次即可。

免责协议要点：
- 参与者确认了解活动内容及可能的风险
- 参与者承诺在工作人员指导下操作，不擅自行动
- 未成年人需监护人全程陪同

## 第六部分：执行建议

### 6.1 从哪开始——最小可测试单元

核心层24项工作中，建议按以下顺序启动：

**第一批（第1个月内启动）：**
1. 劳动换薪小黑板上线——先放"捡蛋"(C15)和"喂鸡"(C14)两项。零成本，只需要一块小黑板+现金
2. 酵素探秘课(C21)——一堂30-40分钟的轻量课程，成本极低（一个空瓶+糖蜜+水）

**第二批（第2-3个月）：**
3. 堆肥课堂(C20)——45-60分钟，定价58元/人
4. 育苗课堂(C01/C02)——配合春季/秋季种植季推出
5. 认领果树/认领鸡上线——先推最容易的认领产品

**第三批（第3个月后）：**
6. 科普内容上线——把病虫害防治(C06)、土壤检测(C24)等做成"农场课"
7. 共建化活动——换茬时发布一起翻地/一起搭架的招募

### 6.2 每个项目启动前问自己三个问题

1. 这个活动对客户的吸引力来自哪里？（如果说不清楚，客户不会来）
2. 这个活动会影响正常生产吗？（核心层的第一优先级永远是生产）
3. 这个活动产生什么传播素材？（公开化的核心目的之一就是传播）

### 6.3 核心层公开化的节奏建议

| 阶段  |   时间   | 核心动作             | 预期效果           |
| :-- | :----: | :--------------- | :------------- |
| 起步期 |  第1个月  | 劳动换薪小黑板+酵素探秘课试跑  | 验证模式可行性        |
| 稳定期 | 第2-3个月 | 新增堆肥课堂、育苗课堂、认领上线 | 每月固定有2-3种公开化活动 |
| 成熟期 | 第3个月+  | 拓展到共建化、技能传承      | 核心层公开化成为日常表达   |
