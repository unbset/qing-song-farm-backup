[SOP编号] O-06
[SOP名称] 社群运营维护流程
[执行人] 运营卫星成员
[替代人] 言渊
[执行时间] 每日维护（30分钟）/ 每周互动（2小时）/ 每月活动（4小时）
[适用季节] 全年
[前置条件] 社群已建立（微信群/企微群）；群成员≥20人可启动正式运营
[AI接口] Hermes记录社群活跃度、成员互动数据；自动生成社群运营周报
[AI提醒] Hermes定时推送内容发布提醒、成员活跃度下降预警

---

### 一、社群基础建设

```
1. 社群定位
   - 青松农场会员群（核心群）：仅限注册会员，用于深度互动和专属福利
   - 青松农场兴趣群（开放群）：面向所有意向客户，用于活动招募和内容分享
   - B端合作群（专属群）：面向合作渠道，用于商务对接和活动协同

2. 入群规则
   - 会员群：到店消费后邀请 / 线上购买会员卡后加入
   - 兴趣群：任意渠道扫码可入
   - 入群欢迎语：自动推送（含农场简介+本月活动+群规）

3. 群规
   - 禁止广告/投票/拼团链接
   - 禁止争吵/人身攻击
   - 鼓励分享农场体验照片和视频
   - 鼓励提问和建议
```

### 二、日常运营（每日）

```
1. 早安内容发布（8:00-9:00）
   每日一条，不缺席：
   - 周一：农场一周动态预告
   - 周二：农场实拍（植物/动物/天气）
   - 周三：农事科普（种植/养殖小知识）
   - 周四：客户体验分享（精选客户照片）
   - 周五：周末活动招募
   - 周六：当日实况（直播/小视频）
   - 周日：温情内容（读书/感悟/松林故事）

2. 群内互动维护
   - 客户提问15分钟内回复
   - 客户分享内容点赞/回复（真诚互动，不敷衍）
   - 负面消息即时私聊处理，不在群内争论
```

### 三、周期性互动

```
1. 每周互动
   - 周三晚8:00：农事问答/猜品种（互动小游戏）
   - 周五：推送周末活动招募+限时优惠

2. 每月活动
   - 会员专属日（每月第一个周末）：会员专享采摘/折扣/活动
   - 线上抽奖（每月15日）：农场时令产品礼包
   - 话题征集（每月末）：下月活动你说了算

3. 每季度活动
   - 农场开放日（邀请社群成员免费参观）
   - 老客答谢会（年度消费TOP20）
```

### 四、客户分层运营

```
1. 活跃客户（近30天有互动）
   - 点赞评论，保持粘性
   - 邀请参与活动

2. 沉默客户（30天以上未互动）
   - 私聊关怀（不打搅式）："最近忙什么呢？农场新种了XX"
   - 推送专属优惠唤醒

3. 高价值客户（年消费≥3000元）
   - 一对一维护（言渊或运营卫星专人对接）
   - 新品体验优先邀请
   - 生日/节日专属问候和礼物

4. 流失预警客户（30天以上未到店+互动减少）
   - 分析原因（查看历史消费记录和反馈）
   - 推送回归优惠
```

### 五、内容素材管理

```
1. 每日拍摄素材
   - 种植区：作物生长状态、采摘实况
   - 动物区：鸡/鸭日常、捡鸡蛋场景
   - 引擎A：今日菜品、柴火灶烟火气
   - 引擎B：营地风光、帐篷布置
   - 客户体验：客户笑脸、活动花絮（征得客户同意）

2. 素材库管理
   - 所有素材按日期/板块分类存储
   - 每周精选10张照片+3条短视频存档
   - 每月整理一次素材库，删除冗余

3. 发布内容排期
   - 内容提前一周规划（在Hermes中创建内容日历）
   - 主推内容提前一天准备
   - 临时内容（天气/突发事件）灵活调整
```

### 六、社群数据分析

```
1. 每日关注
   - 新增入群人数
   - 群消息数量
   - 异常内容（投诉/争吵）

2. 每周统计（Hermes自动生成）
   - 社群活跃度（消息量/互动率）
   - 内容阅读量/点赞量
   - 活动报名转化率
   - 新客来源（社群/其他渠道）

3. 每月分析
   - 社群健康度评分
   - 客户流失率和原因分析
   - 运营策略调整建议
```

### 七、验收标准

```
□ 每日早安内容按时发送
□ 客户提问15分钟内响应
□ 每周互动活动不低于1次
□ 每月主题活动不低于1次
□ 社群活跃度月均≥30%（消息量/成员数）
□ 负面消息处理≤24小时
□ 内容素材每周更新
□ 社群数据分析周报已生成
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 群内出现负面投诉 | 立即私聊，了解情况，24小时内给答复 |
| 活跃度连续下降 | 启动唤醒活动（优惠券/专享活动） |
| 内容发布无人互动 | 调整内容方向，增加互动话题 |
| 客户私聊投诉 | 按O-05客户投诉处理流程 |
| 社群成员大量退群 | 私聊原因，分析并改进 |
| 内容素材不足 | 临时拍摄/使用历史素材/征集客户投稿 |

### 九、跨板块协作

- 社群招募活动与各板块活动排期协调（避免冲突）
- 社群中客户的消费意向即时传递给**引擎A/引擎B/核心层**
- 社群中反映的农场问题反馈至对应板块改进
- 线上招募的客户到店后由**引擎B或运营卫星**接待

### 十、客户触点

- 社群是农场与客户之间"不断线"的桥梁，到店之外的日常陪伴
- 客户在社群中看到的内容决定了下一次到店的动机
- 群内回复速度=客户感知的服务温度，不要出现"已读不回"
- 客户分享的照片是最好的内容，鼓励但不催促
