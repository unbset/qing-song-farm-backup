# 青松农场 · 移动小屋设计方案

> **工业设计文件 · 概念设计阶段**
> 项目：青松农场移动小屋（Mobile Tiny House）
> 状态：概念设计方案 V1.0
> 日期：2026-06-04

---

## 一、设计理念

### 1.1 核心命题

> **"小小的房子即可安身睡觉，何必追求豪宅？"**

移动小屋不仅是住宿产品，更是一个**观念的载体**——在城市里人们为房贷透支一生，而在松林里，一个不到10㎡的小盒子就够了。

### 1.2 三个设计约束

| 约束      | 要求                     |                  为什么 |
| :------ | :--------------------- | -------------------: |
| **可移动** | 建在拖车底盘上，可被普通车辆拖拽转移     | 规避土地性质风险；客人每次可住不同的位置 |
| **最小化** | 建筑面积≤10㎡，仅满足"睡觉+卫浴+简餐" |   与城市豪宅形成反差，承载"小屋哲学" |
| **低成本** | 全套造价控制在3-5万元以内         |           快速回本，可批量复制 |

### 1.3 "小屋哲学"——产品的精神内核

移动小屋不是一个房间，它是一个**回答**：

```
城市里的房子：300万房贷、100㎡、住两个人、大部分空间闲置
松林里的小屋：    3万造价、  8㎡、住两个人、每一个角落都用上了

问：人到底需要多大的空间才能好好活着？
答：8㎡就够了，剩下的都是欲望。
```

这个理念会印在小屋入口的内墙上，每个住进去的客人都能看到。

## 二、底盘方案（Chassis）

### 2.1 底盘选型

选用**小型平板拖车底盘**，这是整栋房子的基础。

| 参数       | 规格               |                    说明 |
| :------- | :--------------- | --------------------: |
| 类型       | 小型双轴平板拖车         | 双轴更稳定，单轴可选（更便宜但行驶晃动大） |
| 尺寸       | 2.2m（宽）× 4.5m（长） |     标准拖车宽度，城市SUV可合法拖拽 |
| 载重       | ≥3吨              |      房屋自重约1.5-2吨，留有余量 |
| 高度（底盘离地） | 0.5m             |                标准拖车高度 |
| 连接器      | 50mm球头拖车钩        |          国内普通SUV/皮卡通用 |
| 轮胎       | 185R14C 轻型载重胎    |                耐用、易更换 |
| 刹车       | 可选配电磁刹车          |          长途拖拽推荐，短途可不配 |

### 2.2 拖拽要求

| 拖拽车辆         | 是否可行 |                 说明 |
| :----------- | :--- | -----------------: |
| 普通SUV（哈弗H6等） | ✅    | 2.0T排量即可，总重不超过3.5吨 |
| 皮卡（长城炮等）     | ✅ 最佳 |            推荐，拖拽平稳 |
| 轿车           | ❌    |        不建议，制动和动力不足 |

### 2.3 转移流程

```
确定新位置 → 清理场地（平整地面）→ 用SUV/皮卡拖拽至新点位
  → 车头调正 → 卸下拖车 → 调平底盘（可调支撑脚）
    → 接水电（如该点位有接口）→ 客人入住
```

转移全过程约30分钟，两人即可完成。

## 三、建筑形态设计

### 3.1 为什么选"不对称A字框架"

考察过多种形态后，选择这个方案的依据：

| 形态 | 成本 | 空间利用率 | 趣味性 | 施工难度 | 综合评价 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 传统箱式 | ★★★★ | ★★★★ | ★ | ★★★★ | 太普通，不够有趣 |
| **不对称A字** | ★★★★ | ★★★ | ★★★★★ | ★★★ | **最佳平衡** |
| 圆顶/蛋形 | ★ | ★★★★ | ★★★★ | ★ | 造价高、施工难、拖拽不稳 |
| 三角楔形 | ★★★★★ | ★★★ | ★★★★ | ★★★★★ | 也不错，但空间略浪费 |
| 六边形 | ★★ | ★★★★ | ★★★ | ★★ | 施工复杂，不适合拖车 |

**最终选择：不对称A字框架（Asymmetric A-frame）**

### 3.2 外形描述

从正面看是一个**不对称的三角形**：
- **长坡面**（面向松林）：从屋脊延伸至接近地面，坡度约45°，主要开窗面
- **短坡面**（背向）：从屋脊短切下来，坡度约60°，开门面
- **屋脊**：偏向短坡一侧，使长坡更长、更舒展

```
         △ 屋脊（偏移）
        /|\
       / | \
      /  |  \          ← 短坡（开门侧）
     /   |   \              坡度约60°
    /    |    \
   /     |     \
  /      |      \
 /长坡面  |       \
/（开窗） |        \
/__________|_________\____  ← 底盘 2.2m × 4.5m
```

视觉效果：在松林中，三角形轮廓与松树的锥形树冠形成呼应。长坡面的大玻璃窗倒映松影，建筑仿佛从地面"长"出来。

### 3.3 尺寸参数

| 维度        | 尺寸          |               说明 |
| :-------- | :---------- | ---------------: |
| 总长        | 4.5m        |             底盘长度 |
| 总宽        | 2.4m（含屋檐挑出） | 底盘宽2.2m，屋檐各挑10cm |
| 最高点（屋脊）   | 3.5m        | 低于道路限高4.0m，可合法运输 |
| 最低点（短坡檐口） | 1.8m        |             入口高度 |
| 室内净高（最高处） | 3.0m        |             屋脊下方 |
| 室内净高（最低处） | 1.5m        | 短坡墙侧（此区域为储物/上床区） |
| 建筑面积      | 9.9㎡        |      4.5m × 2.2m |
| 总重（估算）    | 1.8吨        |          含家具，不含水 |

## 四、室内布局

### 4.1 布局策略：阁楼睡床（Loft Bed）

核心思路：**把床抬起来，释放地面空间。**

白天在地面活动、吃饭、工作；晚上爬上阁楼睡觉。8㎡的地面空间全部可用来生活，不会"一进门就是床"。

### 4.2 平面布局

```
┌────────────────────────────────────────────────┐
│                                                │
│  ┌──────┬──────────────────────┬───────────┐   │
│  │      │                      │  卫浴间    │   │
│  │ 楼梯 │   起居区（日间）      │  Composting│   │
│  │  上  │                      │  Toilet    │   │
│  │  阁  │   折叠桌             │  +         │   │
│  │  楼  │   坐垫/小沙发         │  手持花洒  │   │
│  │      │                      │           │   │
│  ├──────┤                      ├───────────┤   │
│  │ 玄关 │                      │  厨房台面  │   │
│  │ 放鞋 │                      │  洗菜池    │   │
│  │      │                      │  电磁炉    │   │
│  └──────┴──────────────────────┴─────┬─────┘   │
│                  ▲                    │         │
│              入口（短坡侧）            │ 冰箱    │
│                                      └─────────│
│          大面积玻璃窗（长坡面，面向松林）        │
└────────────────────────────────────────────────┘
                  平面俯视 2.2m × 4.5m
```

### 4.3 各功能区详解

#### ① 入口玄关（0.6m × 1.0m）
- 半室外感觉的过渡空间（门内退一步）
- 放鞋位 + 挂外套钩
- 地面用防滑材料，与室内地面有材质区分
- 门：实木门，上半部分可单独打开（荷兰门），通风又安全

#### ② 起居区（2.0m × 2.2m ≈ 4.4㎡）
- **折叠桌**：600mm × 800mm，固定在长坡面玻璃窗下方
  - 平时靠墙收拢，吃饭/工作时翻起
  - 两个人面对面坐刚好
- **地垫/坐垫**：直接坐在地台上（日式风格）
  - 地台高200mm，内部储物
- **墙面**：沿长坡面设书架/置物格
- **视觉中心**：正对大面积玻璃窗，坐在屋里看到松林

#### ③ 厨房区（1.2m × 0.6m）
| 项目 | 配置 | 说明 |
|:---|:---|---:|
| 台面 | 不锈钢或实木台面 | 600mm深，1200mm宽 |
| 水槽 | 单槽不锈钢盆 | 配手动水泵+储水桶（无自来水时可用） |
| 炉具 | 单头电磁炉 2000W | 接入市电或移动电源 |
| 冰箱 | 30L迷你冰箱 | 放食材、饮料 |
| 储物 | 台下储物柜 | 放锅具、餐具 |
| 排风 | 屋顶自然排风口 | 无油烟烹饪为主（煮面、简餐） |

#### ④ 卫浴间（1.0m × 1.0m）
| 项目  | 配置          |                 说明 |
| :-- | :---------- | -----------------: |
| 马桶  | 堆肥式干马桶      |     无需上下水，定期清理至堆肥区 |
| 淋浴  | 手持花洒 + 防水浴帘 | 地面设排水格栅，废水排至地面或收集桶 |
| 洗手台 | 迷你洗手盆       |               配小镜子 |
| 墙面  | 防水板         |           白色或木纹防水板 |
| 照明  | 防水LED灯      |                    |
| 排风  | 小型排风扇       |               通至屋顶 |

#### ⑤ 阁楼睡床（上层）
- **位置**：入口玄关 + 起居区上方
- **床尺寸**：1.5m × 2.0m（标准双人床）
- **净高**：最高处1.2m → 最低处0.8m
  - 可坐立不可站立
  - 床垫厚度100mm
- **围栏**：两侧矮围栏（防止滚落）+ 天窗（躺在床上的时候看树冠和星空）
- **楼梯**：收纳楼梯（梯子形式，下方是储物抽屉）
  - 4级台阶，每级可储物
  - 陡但省空间

### 4.4 储物系统

| 位置 | 储物内容 |
|:---|:---|
| 地台下方（2面） | 行李箱、大件物品 |
| 楼梯台阶（4个抽屉） | 衣物、日用品 |
| 阁楼床头/床尾 | 各一个开放式置物格 |
| 厨房台下 | 锅具、餐具、食材 |
| 入口墙面挂钩 | 外套、帽子、包 |
| 窗下书架 | 书、装饰品 |

### 4.5 水电系统

| 系统 | 方案 | 说明 |
|:---|:---|---:|
| 供水 | 20L便携储水桶 + 手动水泵 | 无自来水时可用，有接口时接入 |
| 热水 | 即热式电热水器（小型） | 淋浴用，功率3000W |
| 电力 | 接入农场电网（建议）+ 移动电源备选 | 每栋留市电接口 |
| 照明 | 12V LED灯带 + 2个射灯 | 低功耗，暖光 |
| 排污 | 堆肥马桶（固废）+ 灰水排放至指定区域 | 符合生态农场理念 |

```

③ 保温层安装（XPS板填充龙骨间隙）                            → 2天

⑦ 室内装修（地板、台面、卫浴设备安装）                        → 5天
⑧ 家具制作/安装（折叠桌、楼梯、阁楼床架）                     → 5天
⑨ 水电系统安装（灯具、开关、电线、水泵、热水器）               → 3天

## 六、定价与回报测算

### 6.1 定价策略

| 定价维度      | 策略       |                         依据 |
| :-------- | :------- | -------------------------: |
| 平时（周日至周四） | 199元/晚   | 潍坊市场的民宿低价段，低于城市快捷酒店但高于普通露营 |
| 周末（周五至周六） | 299元/晚   |                       旺季定价 |
| 节假日       | 399元/晚   |                   五一/十一/春节 |
| 长租（按月）    | 1,500元/月 |              适合长搭客，几乎无服务成本 |

### 6.2 回本测算

| 场景 | 年入住率 | 年收入（单栋） | 回本周期 |
|:---:|:---:|---:|---:|
| 保守 | 30%（110天） | 110×199≈21,890元 | 18个月 |
| 中性 | 45%（164天） | 164×230≈37,720元 | 11个月 |
| 乐观 | 60%（219天） | 219×250≈54,750元 | 7个月 |

> **结论：最慢18个月回本，之后就是纯利。** 如果第一批做3栋（总投资约10万），第二年即可产生正向现金流。

## 七、客群与体验设计

### 7.1 谁会来住

| 客群 | 为什么选移动小屋 | 怎么触达 |
|:---|:---|---:|
| 年轻情侣（25-35岁） | 新鲜、出片、便宜、有"野宿"的感觉 | 小红书："潍坊8㎡松林小屋仅199元" |
| 亲子家庭（体验型） | 孩子喜欢"树屋感"，大人认同极简理念 | 妈妈群："带娃住8㎡小屋，孩子说比家里好玩" |
| 城市独行客 | 追求独处、疗愈、极简 | 小红书/豆瓣："周末一个人住进松林小盒子里" |
| 长搭露营客 | 按月租比帐篷舒服，比酒店便宜 | 微信群/口碑 |

### 7.2 体验设计要点

| 触点         | 设计                                 |
| :--------- | :--------------------------------- |
| **看到的第一眼** | 三角形小屋在松林中的剪影——远看像一顶巨大的帐篷，近看是精致的木屋  |
| **推开门的瞬间** | 8㎡的空间一目了然，但完全不觉得压抑。大面积玻璃窗把松林"拉"进屋里 |
| **坐下来的感觉** | 坐在窗前的坐垫上，视线平齐松树干，光线透过树叶洒进来         |
| **爬上阁楼睡觉** | 从楼梯爬上去，躺在床垫上，抬头看天窗外的树冠和星星          |
| **晚上**     | 暖色灯光从三角窗户透出去，在松林中像一个发光的萤火虫         |
| **早上**     | 被透过松林的晨光照醒，推开门就是泥土和松针的味道           |
| **离开前**    | 在门口看到那句哲学宣言——"小小的房子即可安身睡觉，何必追求豪宅"  |

### 7.3 传播设计

移动小屋本身就是**传播杠杆**——它的外形足够独特，住进去的人**一定会拍照发朋友圈**。

| 传播点 | 内容方向 | 平台 |
|:---|:---|---:|
| "潍坊最便宜的小屋" | 199元住8㎡三角松林小屋 | 小红书/抖音 |

## 八、风险与对策

| 风险 | 概率 | 对策 |
|:---|:---:|:---|
| 拖车合法上路问题 | 中 | 1）选择符合国标的拖车底盘；2）上牌（小型旅居挂车牌照）；3）如不拖拽转移，仅场地内移动则不需要上路 |
| 冬季保温不足 | 低 | 1）XPS保温板50mm+双层玻璃；2）小型电暖器（500W）；3）被子用羽绒被 |

```
第1层 · 商业         →   单栋3-4万造价，不到18个月回本
