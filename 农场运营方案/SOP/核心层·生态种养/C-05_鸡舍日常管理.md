[SOP编号] C-05
[SOP名称] 鸡舍日常管理
[执行人] 种植养殖主管
[替代人] 言渊
[执行时间] 每天早晨 7:00-8:00 / 傍晚 17:00-18:00（夏季可调整）
[适用季节] 全年
[前置条件] 鸡舍已建成并完成消杀，鸡苗或成鸡已入场
[AI接口] Hermes记录每日产蛋量、采食量、异常情况，生成周报
[AI提醒] Hermes每日7:00推送鸡舍巡检清单；异常天气提前预警提醒关窗或通风

---

### 一、早晨巡检流程（7:00-8:00）

```
1. 检查鸡舍环境
   - 温度是否正常（小鸡30-35°C / 成鸡18-28°C）
   - 通风是否良好（氨气味是否过重）
   - 饮水器水位正常，出水口未堵塞
   - 食槽余粮情况，是否需要补充

2. 观察鸡群状态
   - 精神是否活泼，有无缩头垂翅、闭眼呆立个体
   - 粪便是否正常（绿色/红色/白色异常提示疾病）
   - 呼吸道有无异常声音（打喷嚏、呼噜声）

3. 收集鸡蛋
   - 先取蛋、后喂食，防止鸡蛋被踩碎
   - 脏蛋及时擦拭，破蛋单独存放
   - 记录产蛋数记入Hermes

4. 补充饲料和清洁饮水
   - 按Hermes推荐量投喂
   - 每周三补充保健砂/贝壳粉

5. 放鸡出栏（散养模式）
   - 确认围网完好、无缺口
   - 天敌风险排查（有无猫/鼬/鹰等痕迹）
   - 打开鸡舍小门，让鸡自由进出
```

### 二、傍晚归栏流程（17:00-18:00）

```
1. 巡查散养区
   - 检查是否有未归栏的鸡只
   - 检查围网是否有破损

2. 引导鸡只归栏
   - 投喂少量饲料引导归栏
   - 清点数量，核对与早晨是否一致

3. 舍内整理
   - 清理粪便（每2天清理一次，夏季每天清理）
   - 更换垫料（视潮湿程度，至少每周一次）
   - 检查产蛋箱清洁度

4. 夜间准备
   - 关闭鸡舍小门（防天敌）
   - 检查通风是否足够但不过量
```

### 三、每周必做事项

| 事项 | 频率 | 操作要点 |
|:---|:---|:---|
| 鸡舍全面消毒 | 每周1次 | 碘制剂或过氧乙酸喷雾，鸡只不在舍内操作 |
| 蚊虫防治 | 夏季每周2次 | 安装防蚊网，舍外灭蚊灯持续开启 |
| 驱虫 | 每月1次 | 根据Hermes提醒按量拌料 |
| 垫料更换 | 视情况 | 潮湿有异味立即更换，换下垫料进堆肥 |
| 饮水器深度清洁 | 每周1次 | 拆洗内壁，去除滑膜和藻类 |

### 四、验收标准

```
□ 鸡群精神活跃，食欲正常
□ 产蛋记录完整录入Hermes
□ 饮水和饲料充足
□ 鸡舍无异味、无渗漏
□ 围网完好，无天敌入侵痕迹
□ 当周消毒已完成
□ 粪污处理合规（进堆肥区）
```

### 五、异常处理

| 异常 | 响应 |
|:---|:---|
| 产蛋量骤降 | 检查饲料（是否变质）、饮水、光照、是否有应激源 |
| 病鸡发现 | 立即隔离，拍照记录症状录入Hermes，联系兽医 |
| 天敌入侵 | 修补漏洞，检查所有鸡只伤亡情况，加强夜间防护 |
| 持续阴雨 | 增加舍内垫料更换频率，鸡只限制在舍内活动 |
| 极端高温 | 加强通风，增加饮水器，减少投喂量 |

### 六、跨板块协作

- 向**引擎A·餐饮**提供鲜鸡蛋（每日）：种植养殖主管在8:00前将当日鸡蛋送至引擎A
- 蛋量充足时通知**运营卫星**安排客户捡鸡蛋体验
- 淘汰鸡处理提前通知引擎A调整菜单
- 鸡粪进堆肥区，与休耕期土地改良衔接

### 七、客户触点

- 客户捡鸡蛋体验（公开化：课程化/体验类）：安排固定时段，由运营卫星带领
- 客户对"散养鸡"有天然好感，鸡舍外观保持整洁，设置安全观摩区
- 可设计"鸡蛋认领"模式：客户认领一只鸡，每周收到该鸡产蛋照片和数量
