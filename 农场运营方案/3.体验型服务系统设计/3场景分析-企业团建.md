# 场景分析：企业团队建设（团建）

> **分析日期**：2026-06-02
> **基于框架**：《体验型服务系统分析框架》V2.0
> **场景概述**：15-50人企业团队来农场进行团建活动，包含用餐+团队活动
> **核心问题**：团建场景中都有哪些身份的人，分别分析他们的需求

---

## 第①层 · 人与关系

### 团建场景的特殊性

团建跟前两个场景有本质区别：

| 维度 | 亲子教育 | 四家庭聚餐 | **团建** |
|:---|:---|:---|:---|
| 来的动机 | 教育+陪伴 | 社交+吃饭 | **工作安排**——不是自愿来的 |
| 决策者 | 妈妈（使用者） | 发起妈妈（使用者） | **HR/行政（非使用者）** |
| 使用者和决策者的关系 | 同一人 | 同一人 | **分离**——安排的人和体验的人不是同一批 |
| 情绪底色 | 期待+轻度焦虑 | 放松+社交 | **中性偏负**——"周末还要搞团建" |
| 团队内部关系 | 家庭内部 | 朋友之间 | **有权力关系**——领导在不在场完全不同 |

### 角色识别

| 角色           | 定义               | 本场景中的存在意义                 |
| :----------- | :--------------- | :------------------------ |
| **购买决策者**    | 决定"去不去这里、花多少钱"的人 | HR经理/行政主管/老板本人            |
| **活动执行者**    | 具体对接、排计划、带人来的    | 行政专员/HR助理/被安排干活的人         |
| **公司领导**     | 跟队来的高层           | 有他在，所有人的自由度降一档            |
| **普通员工-积极型** | 真的想玩的人           | 约20-30%的参与者               |
| **普通员工-跟随型** | 无所谓，看氛围          | 约50-60%的参与者——**决定整体氛围的人** |
| **普通员工-抗拒型** | 不想来但没办法          | 约10-20%的参与者——最难处理但最影响口碑   |
| **附加角色**     | 司机/摄影师/家属        | 人数少但需要考虑                  |

---

### 购买决策者（HR/行政主管/老板）

```
基本画像：30-45岁 / 企业中层 / 身负"组织团建"的任务 / 可能自己也不想搞
核心动机："完成团建任务，别出事，预算内，没人投诉"
真实心理：
  ① 选错地方就是自己背锅——决策压力大
  ② 真正关心的不是"好不好玩"，是"有没有人投诉不好玩"
  ③ 预算能省就省，但不能显得抠门
  ④ 如果老板也去，压力翻倍——"老板满意比员工满意更重要"

决策方式：先框定预算和人数 → 搜"潍坊团建" → 看2-3家对比 → 打电话问详情
  → 关键决策因素：
     ① 能不能一条龙？（场地+活动+吃饭+保险都包）
     ② 有没有下雨的备选方案（这个决定了"选不选你"）
     ③ 价格按人头还是按场次
     ④ 以前有没有企业去过

最怕什么：
  ① 到了发现场地不行 → 自己决策失误
  ② 下雨没有室内方案 → 几十个人没地方去
  ③ 吃得差 → 员工嘴上不说心里骂
  ④ 员工回公司后反馈"团建好无聊" → 明年搞团建没人响应
  ⑤ 出了安全事故 → 职业生涯结束

隐藏需求：
  ① 团建结束后有照片/视频做总结汇报
  ② 能被员工说一句"这次团建还行"（不是好评，是"还行"就够了）
  ③ 明年再搞团建时不被下属翻白眼
```

### 活动执行者（行政专员/HR助理/被交办的人）

```
基本画像：25-35岁 / 执行力强但位卑 / 被安排干这件事的人
核心动机："赶紧搞定、别出错"——跟决策者不同，他更关心执行层面的顺畅度
真实心理：
  ① 对接农场时要反复确认细节，因为我承担了"落地"的责任
  ② 怕的是到了现场发现"跟我说的不一样"
  ③ 活动当天他可能比谁都累（最早到、最晚走、处理所有人的问题）
  ④ 做好了功劳是领导的，做不好锅是他的

最怕什么：
  ① 到了发现准备不足（炭不够/凳子不够/活动道具没备齐）
  ② 现场混乱没人组织
  ③ 领导不高兴

与决策者的区别：
  决策者关心"选哪家"——做选择题
  执行者关心"到了以后顺不顺"——做判断题
  决策者可能只来现场看一眼就走了，执行者从头到尾都在
```

### 公司领导

```
基本画像：40-55岁 / 企业高层 / 可能不是自愿来的 / 或者他就是那个"要求搞团建"的人
存在意义：
  ① 如果他是那个"要求搞团建的人"——他会观察活动效果
  ② 如果他是"被请来的"——他在场就是最大的不确定因素

本场景中的两种可能：

可能A：领导来参加
  员工状态：收敛——不大声笑、不放开了吃、不表达真实意见
  领导状态：要么端着，要么想表现"我跟员工打成一片"
  对设计的影响：
    ① 所有活动需要照顾到领导的参与度（不能有领导融入不了的活动）
    ② 领导在场时，服务优先级从"员工体验"变为"领导体验"
    ③ 但员工会因领导在场而不自然——这是一个结构矛盾

可能B：领导不来
  员工状态：放松——这是普通员工的真实状态
  对设计的影响：轻松很多，活动可以更"玩得开"
```

### 普通员工-积极型

```
画像：约20-30%的参与者
特征：年轻/外向/喜欢玩/平时在公司也有活力
核心动机："反正都来了，好好玩呗"
真实心理：把团建当成"免费出去玩一天"
最怕什么：无——心态好，什么活动都能参与
```

### 普通员工-跟随型

```
画像：约50-60%的参与者——**决定整体氛围的人**
特征：不突出也不抗拒 / 氛围好就玩 / 氛围差就坐着
核心动机："看大家怎么玩"——他们的投入程度完全取决于周围人的状态
真实心理：
  ① 如果有3-5个人先玩起来了，他们会加入
  ② 如果所有人都坐着不动，他们也不会动
  ③ 他们的评价决定了这次团建"好不好"的口碑——积极型和抗拒型的人数少，不足以影响整体评价

最怕什么：尴尬——"大家都在等我先动"的氛围
```

### 普通员工-抗拒型

```
画像：约10-20%的参与者
特征：不想来但没办法 / 可能平时工作忙或有家庭安排 / 觉得团建浪费周末
核心动机："赶紧搞完赶紧走"
真实心理：
  ① 不是对农场有意见，是对"团建"这件事有意见
  ② 他的负面情绪不是服务能解决的——他来之前就已经不开心了
  ③ 但他依然是客人，不能忽视

最怕什么：
  ① 被迫参加"集体游戏"
  ② 被点名、被拉上去互动
  ③ 不能自己待着

服务策略：不要试图让他"开心起来"——目标是"不要让他更不开心"
```

### 角色关系分析

| 维度 | 分析 |
|:---|:---|:---|
| 核心关系链 | **购买决策者→活动执行者→参与者**——三层传导，每层都有不同的关注点 |
| 内部权力结构 | 团建最大的变量是**领导在不在场**。在→所有设计需要分级；不在→员工体验可以更纯粹 |
| 员工的异质性 | 员工不是同一类人。20%想玩、60%随大流、20%不想来。服务设计需要覆盖三类 |
| 组织者与农场的对接 | 决策者只对接一次（预订时），执行者全程在场。农场需要识别出谁是执行者，跟他直接对接当天的所有细节 |
| 团建结束后的传播 | 员工回公司后在工作群/午餐时的评价，决定了这家企业明年还来不来。传播链是：体验→内部口碑→明年决策 |

## 第②层 · 场景

```
触发场景：
  ① 年度团建计划到了——"今年的团建去哪"
  ② 部门/公司来了新领导或新人，需要破冰
  ③ 完成了大项目，搞个团建庆祝一下
  ④ 老板突然说"周末拉出去搞搞活动"

决策方式：搜索+对比+电话确认——理性决策

决策周期：1-3周（比家庭聚餐长得多）
  ① 决策者提出→② 内部确认预算→③ 搜2-3家对比→④ 实地或电话考察→⑤ 确定

到店时间：周六或周日 9:00-10:00（客户通常希望"用满一整天"）

停留时长：6-8小时（上午活动+午饭+下午活动，约16:00-17:00结束）

季节敏感度：强——团建客户极怕下雨（几十个人的活动没有室内方案是大忌）
  春/秋：最佳
  夏：太热影响户外活动时长
  冬：只能做室内+餐饮类活动

餐饮选择：通常选择"省心"方案——包桌/自助/套餐，烧烤需要自己动手对部分客户有吸引力但对行政来说是"管理负担"
```

## 第③层 · 体验任务（四层拆解）

### 功能任务

```
购买决策者：确认场地OK、预算内、有人对接
活动执行者：确保所有人准时到、活动顺畅、准时回
公司领导：看到团队氛围好（或"完成了团建这件事"）
积极型员工：好好玩一天
跟随型员工：不尴尬就行
抗拒型员工：熬到结束
```

### 情绪任务

```
购买决策者：从"定下来的焦虑" → "没出问题的如释重负"
活动执行者：从"对接的繁琐" → "顺利结束的解脱"
公司领导：从"到了看看情况" → "还不错"或"不差"
积极型员工：从"来了" → "真挺好玩的"
跟随型员工：从"随便" → "还行，不亏"
抗拒型员工：从"烦" → "算了，也不算太差"（目标：不要更差）
```

### 社交任务

```
购买决策者：在汇报时说"这次团建去了XX农场"——需要证明材料（照片/视频）
活动执行者：发朋友圈/工作群"团建顺利完成"
公司领导：不需要
积极型员工：发朋友圈"今天团建"——展示公司福利好
跟随型员工：不一定发
抗拒型员工：不发
```

### 认同任务

```
购买决策者："我选的这个地方不错"——明年还被信任
活动执行者："我搞的这次活动还行"——不被埋怨
公司领导：不需要
积极型员工：不需要
跟随型员工：不需要
抗拒型员工：不需要
```

## 第④层 · 触点服务需求

### 触点 × 角色矩阵

| 触点 | 购买决策者 | 活动执行者 | 公司领导 | 积极型员工 | 跟随型员工 | 抗拒型员工 |
|:---:|:---|:---|:---|:---|:---|:---:|
| **1.触发** | 搜团建找到农场/被推荐 | 被分配任务 | 决策者汇报时听说 | 公司通知"本周末团建" | 同上 | 同上 |
| **2.决策** | 价格✅一条龙服务✅下雨方案✅以前案例✅ | 备选方案确认✅活动流程确认✅ | — | — | — | — |
| **3.到达** | "环境还🆗" | 跟农场对接人确认流程 | 下车看整体环境+员工反应 | "这地方不错啊" | 跟同事一起走，看环境 | "又一上午" |
| **4.活动进行中** | 看一眼就走了/全程跟 | 全场跑/处理各种问题/"XX队缺一个人你来补一下" | 参与或不参与→决定氛围 | 投入玩 | 看别人玩→决定自己玩不玩 | 站在外围/玩手机 |
| **5.服务接触** | 跟对接人保持联系 | 跟对接人反复确认时间节点 | 有人主动问候 | 问"还有什么活动" | 问"厕所在哪" | 不主动找服务 |
| **6.结束离开** | 跟对接人确认结算+下次再说 | 清点人数+确认大家都上车了 | 可能说一句"今天还行" | "下次自己来" | "终于搞完了" | "终于结束了" |
| **7.后续** | 收到照片/视频→做汇报 | — | — | 可能单独来 | — | — |

### 关键触点展开

**触点2-决策（对决策者的关键信息）**：

```
决策者需要的"一条龙"包含什么？
  ① 场地费：按人头还是按场次？含不含桌椅？
  ② 活动费：有没有破冰/团队游戏？有没有人带？
  ③ 餐费：什么标准？什么菜？
  ④ 保险：含不含意外险？
  ⑤ 下雨备选：有没有室内场地？
  ⑥ 停车：免费还是收费？车位够不够？
  ⑦ 照片/视频：活动结束有没有照片发给我？

少任何一项，决策者就要多打一个电话问。多一个电话，选你的概率就低一分。
```

**触点5-服务接触（对活动执行者的关键触点）**：

```
活动执行者是团建当天在农场最累的人。他需要：
  ① 到现场后有人接应，知道找谁
  ② 活动过程中有话事人，临时调整不需要他做决定
  ③ 有一个人从头到尾跟着他的节奏（不是"你找XX，XX在那边"）
  ④ 咖啡/水有人帮他准备好——他当天没空自己去拿

**重要判断**：活动执行者的体验决定了农场和这家企业的关系持续度。决策者明年不记得细节，但执行者记得"上次去XX农场，那个对接人挺好的/挺糟的"。
```

**触点4-活动进行中（三类员工的分化）**：

```
积极型：不需要特别设计，有活动他就会参与
  关键是：不要让他觉得"活动太幼稚"——团建活动最怕的是让员工觉得"当小孩哄"

跟随型：需要"先有人玩起来"
  设计要点：
    ① 活动从简单、低门槛的开始（不是上来就分组PK）
    ② 活动有"围观→参与"的自然过渡（先有人示范）
    ③ 他参与的时候不会成为全场的焦点（怕尴尬）

抗拒型：不要强迫他参加
  设计要点：
    ① 活动设计成"可选"而非"必选"
    ② 提供一个"不参加活动也能待着的地方"（休息区/咖啡座）
    ③ 重要的是：让他一个人待着时不觉得尴尬
```

**团建活动设计的关键原则**：

```
① 活动不是越多越好——3小时集中活动好过6小时散乱安排
② 活动之间要有"空白时间"——不然员工觉得太累
③ 核心活动不超过3个：破冰（30分钟）+ 主活动（1-1.5小时）+ 收尾（15分钟）
④ 活动难度逐步上升——不是一上来就高难度
⑤ 不搞"输了惩罚"——团建中让任何人感到"丢脸"都是失败
```

## 第⑤层 · 农场服务方案

### 团建标准套餐设计建议

团建客户的核心需求是"省心"——不需要定制，不需要讨论，给出标准选项即可。

```
建议三档标准套餐：

A档-轻量版（半天，不含餐）
  内容：场地+破冰游戏（30分钟）+2个团队游戏
  价格：68元/人
  适合：预算极紧或下午另有安排的团队

B档-标准版（全天，含午餐）
  内容：场地+破冰+2个团队游戏+自然运动会/eason活动（任选）+午餐（包桌/柴火灶）
  价格：128-168元/人
  适合：80%的团建需求——主推

C档-升级版（全天，含午+晚餐，可过夜）
  内容：B档全部+烧烤晚餐+篝火晚会+露营过夜
  价格：268-368元/人
  适合：预算宽裕或想搞"两天一夜"的团队

每档都需要备注一条：下雨备选方案（室内场地+室内活动）
```

### 到达接待

| 动作       | 执行标准                       | 负责人      |
| :------- | :------------------------- | :------- |
| 提前24小时确认 | 确认人数+时间+餐标+活动选择+天气         | 运营卫星/引擎B |
| 到店接待     | 引擎B主理人在场迎接，直接对接活动执行者       | 运营卫星/引擎B |
| 快速引导     | 引导到活动区域→告知洗手间位置→告知当天流程     | 引擎B主理人   |
| 活动物料确认   | 活动开始前全部备齐（破冰道具+游戏道具+音响+话筒） | 引擎B主理人   |

### 活动中服务

| 事项 | 标准 | 负责人 |
|:---|:---|:---|
| 活动带领 | 引擎B主理人带队，控场+节奏把控 | 引擎B主理人 |
| 服务响应 | 活动执行者有需求时3分钟内响应 | 引擎B主理人 |
| 领导关注 | 如有公司领导在场，引擎B主理人主动问候一次 | 引擎B主理人 |
| 拍照记录 | 活动中拍20-30张照片（群体照+抓拍+亮点瞬间） | 引擎B主理人（运营卫星协助） |
| 抗拒型员工的退路 | 活动区附近有休息区+饮品，不参加活动的人有地方待 | 引擎B主理人提前准备好 |

### 餐饮服务

| 场景 | 执行标准 |
|:---|:---|
| 包桌/套餐 | 提前一天确认菜单，到店时桌上已备好 |
| 烧烤/柴火灶 | 提前备好炭火/食材/工具，到店时告知"东西在哪，需要帮助喊我" |
| 特殊需求 | 素食/过敏/清真——提前问，提前备 |

### 结束收尾

| 事项 | 标准 | 负责人 |
|:---|:---|:---|
| 照片交付 | 活动结束后24小时内发送给活动执行者（含原图+精选） | 引擎B主理人（运营卫星协助整理） |
| 结算 | 提前准备好账单，结束时快速结清 | 引擎B主理人 |
| 离开送别 | 引擎B主理人在场送别，对活动执行者说一句"今天辛苦了" | 运营卫星 |
| 后续关系 | 引擎B主理人2周内跟进一次——"上次的照片还满意吗？下次有需要随时联系" | 引擎B主理人 |
| 活动执行者的特别对待 | 当天单独给活动执行者准备一瓶水/一杯咖啡——他会记住 | 引擎B主理人 |

## 第⑥层 · 能力边界

### 能做

| 事项 | 依据 |
|:---|:---|
| 15-50人的团建接待 | 场地够大，引擎A/B已有基础接待能力 |
| 标准套餐设计 | 自然运动会/四季庆典活动已有教案 |
| 下雨备选方案 | 700㎡室内餐厅可容纳50人以内的室内活动 |
| 拍照记录 | 运营卫星随手拍，不需要专业摄影 |
| 活动带领 | 引擎B主理人可带团建活动（言渊初期兼任或培训后胜任） |

### 不能做（明确放弃）

| 事项 | 原因 |
|:---|:---|
| 高难度户外拓展（高空/攀岩/水上） | 农场没有专业设施，出了事故承担不起 |
| 极端天气的户外活动 | 下雨/高温/严寒时直接建议客户选室内方案或改期，不应硬撑 |
| 让抗拒型员工喜欢团建 | 他的问题不是农场能解决的。接受"有些人就是来熬时间的" |
| 超50人的大型团建 | 当前人手和场地容量不支持。超出时可以选择推荐其他场地，而不是硬接 |
| 完全定制的团建方案 | 标准套餐3档+微调即可，不接受从零定制 |

### 差异化对比

| 对比项 | 专业拓展基地 | 农家乐 | 青松农场 |
|:---|:---|:---|:---|
| 定位 | 纯粹搞活动 | 纯粹吃饭 | 有活动、有自然、有好吃的 |
| 员工感受 | "又搞团建" | "去吃了顿饭" | "今天还挺好玩的" |
| 组织者省心程度 | 中——对接复杂 | 低——只负责吃饭 | **高——一条龙** |
| 下雨方案 | 通常有室内 | 无 | 700㎡室内餐厅 |
| 非团建时间的吸引力 | 无——不会单独来 | 低 | **高——员工可能自己带家人来** |
