# 产品分析：自然教育（自然手作卫星）

> **分析框架**：产品分析框架V4（选择性使用 + 扩展：课程体系设计 / 案例借鉴）
> **分析日期**：2026-05-29
> **分析者**：AI（多角色切换）
> **产品状态**：运营中（现有198元/一大一小含餐，客人不多）；规划中（双档调整 + 年卡体系）
> **归属板块**：自然手作卫星（费用中心）

---

## 使用说明

自然手作卫星是**费用中心**，不追求独立盈利。它的价值体现在：
- 引流（让新家庭通过自然教育首次接触农场）
- 粘性（让家庭持续回来 → 带动引擎A/B消费）
- 传播（家长发朋友圈 = 免费的获客广告）

因此分析框架对V4做了调整：弱化利润相关维度，强化**课程体系、获客与粘性**。

---

## 1. 飞轮定位

**主定位**：引流入口 + 复购锚点（双定位）

自然教育不是农场的利润来源——它是**让家庭客户"第一次来"和"一直来"的理由**。

| 产品形态          | 主定位         | 逻辑                                |
| :------------ | :---------- | :-------------------------------- |
| **引流课（68元）**  | 引流入口        | 低成本让家庭首次体验——"68元带孩子去农场玩半天，比去商场划算" |
| **深度课（198元）** | 复购锚点 + 信任引擎 | 深度体验建立信任——"这个农场做的课比我想象的用心"        |
| **节气年卡**      | 复购锚点（全年粘性）  | 一年来24次＝每个月来2次＝每次来都会在农场吃饭/消费       |

**辅助作用**：
- 传播杠杆（家长在朋友圈晒孩子的自然手作 + 农场环境——天然内容）
- 信任引擎（自然教育课程的质量本身在传递农场价值观）

## 2. 目标客群

### 核心画像

- **谁**：潍坊城区家庭，孩子3-10岁，妈妈为主要决策者（30-40岁），家庭月收入1-2万
- **教育观念**：认可"自然教育"理念，不想让孩子一直在室内和屏幕前，愿意为体验付费
- **痛点**：
  - 周末不知道带孩子去哪——去商场孩子玩游戏、去公园没什么特别的内容
  - 市面上自然教育机构太少，有的太贵（一次300-500元），有的太远
  - 买了"年卡"但机构倒闭了——对年卡有信任障碍
- **痒点**：孩子回家后兴奋地说"妈妈我今天……"——这个成就感和"我给孩子的周末安排了有意义的活动"的满足感

### 决策逻辑

```
妈妈在妈妈群/小红书看到农场自然教育 → 看到68元引流课 → 
"68元，试试也不亏" → 来了一次 → 孩子很喜欢 → 
考虑深度课或年卡 → 如果体验好 → 长期锁定
```

## 3. 课程体系设计（+扩展）

### 3.1 双档产品结构

#### A. 引流课（68元，不含餐）

| 项目   | 内容                             |
| :--- | :----------------------------- |
| 时长   | 1-1.5小时                        |
| 形式   | 单次活动，即来即走                      |
| 含餐   | ❌ 不含（家长可在中心厨房自行购买餐饮）           |
| 内容方向 | 轻体验、可带走成品                      |
| 典型主题 | "松果探索"（认识松果→捡松果→做一个小手工带走）      |
| 经营目标 | 让客户第一次来，体验满意后转化为深度课或引擎A/B消费    |
| 获客渠道 | 小红书/妈妈群/朋友圈——68元的价格足够低，不需要复杂说服 |

**为什么68元而不是更低**：
- 9.9元/19.9元吸引来的客户质量低（不尊重课程价值，客户也不珍惜）
- 68元在潍坊家庭周末消费中属于"不用思考"的价位（一顿便饭的钱）
- 定价传递信号：这不是免费赠品，这是一个认真的课程

#### B. 深度课（198元，不含餐）

| 项目   | 内容                                         |
| :--- | :----------------------------------------- |
| 时长   | 2-3小时（半天）                                  |
| 形式   | 主题式深度体验，需预约                                |
| 含餐   | ❌ 不含（建议拆掉"含餐"——因为含餐压缩了课程利润空间，也不方便想自己买吃的家长） |
| 内容方向 | 有知识浓度、有作品产出、有仪式感                           |
| 典型主题 | "松林小木匠"（用自然材料做一个木工玩具）、"小小博物学家"（标本采集+制作）    |
| 经营目标 | 建立客户对自然教育的信任——"在农场上课是有内容、有质量的"——为年卡转化铺路    |

**为什么要去掉含餐**：
- 198元含餐 → 家长会算"餐值多少钱"，课程价值被稀释
- 198元不含餐 → 家长认为"课程值198元"，去中心厨房另买吃的（又带动引擎A消费）
- 如果家长本来就是来参加课程的，多花30-50元买吃的完全不影响决策

### 3.2 二十四节气年卡方案

| 项目   | 内容                                                     |
| :--- | :----------------------------------------------------- |
| 产品名称 | "青松四季"自然年卡                                             |
| 内容   | 24个节气 × 当季主题课程（1-1.5小时/次）                              |
| 定价建议 | **1280-1680元/年**（折合53-70元/次——比引流课68元还便宜一点，有"越买越划算"的心理） |
| 含餐   | ❌ 不含                                                   |
| 有效期  | 一年（付一年锁定一年席位）                                          |
| 总场次  | 24场（每半个月一场，固定周日/周六上午）                                  |
| 缺勤处理 | 可请假3次，补课安排在下一期或材料包寄送                                   |
| 适合年龄 | 4-10岁（分4-6岁低龄组/7-10岁高龄组）                               |

**年卡的核心商业逻辑**：
- 24次来农场的固定理由 → 每次来都会产生餐饮/零售消费 → **年卡本身不赚钱，但带来24次到店机会**
- 家长买年卡不是为了"划算"，是为了"不用每周想周末去哪"

### 3.3 借鉴的国内外优秀案例

#### 案例一：日本"森のようちえん"（森林幼儿园）
- **核心做法**：不设固定教室，全年在户外。课程围绕"这个季节森林里有什么"展开，由孩子自主发现、老师引导
- **可借鉴**：节气课的核心逻辑应该是"带孩子们去发现这个节气森林里的变化"，而不是"老师站在前面讲节气"。**老师是引导者，不是讲授者**
- **具体落地**：每个节气课的第一个环节是"我们在松林里走一圈，看看和上次有什么不同"——观察变化本身就是在认识节气

#### 案例二：英国Forest School
- **核心做法**：以孩子为中心，允许"笨拙的尝试"。生火、用刀（在安全前提下）、搭棚子——让孩子做"不太危险但看起来有点冒险"的事
- **可借鉴**：198元的深度课可以偶尔加入"小冒险"元素——比如用打火石点火烤棉花糖、用锯子锯一段松木做木牌。**孩子回家后会炫耀很久**
- **安全边界**：4-6岁组不做刀具/生火类活动。7-10岁组可在员工1:3的配比下有限体验

#### 案例三：国内"大地之野"（杭州）
- **核心做法**：系统化的课程体系，从半日营到多日营。以"体验式学习"为方法论——不是"听听讲"，是"动手做"
- **可借鉴**：每个节气课必须有至少一件**可带走的作品**（松果摆件/石头画/种子玻璃瓶/小木牌）——这个作品会在客户家里的书架上放很久，每次看到都会想起农场

#### 案例四：美国Tinkergarten
- **核心做法**：户外游戏式学习。1小时的课程由4-5个游戏环节组成（探索→创造→运动→故事→分享），节奏紧凑
- **可借鉴**：68元引流课应该设计成"1小时4个环节"的快节奏体验——孩子玩得意犹未尽，家长觉得"68元值了"
- **定价策略**：Tinkergarten的"第一堂课免费+后续付费"模式可借鉴——但建议直接用68元而非全免费（筛选客户质量）

#### 案例五：国内"盖娅自然学校"（北京自然之友旗下）
- **核心做法**：以二十四节气为核心的全年课程体系，分年龄组，家长可参与可不参与
- **可借鉴**：家长参与度的设计——部分课程可以"孩子上课、家长喝咖啡"（让家长得到喘息），部分课程设计成"亲子一起完成"（适合低龄）——双轨并行

## 4. 核心体验

### 引流课（68元）

"68元，孩子在松林里做了一盏松果灯，回家挂在床头。整个过程他在找松果、在缠线、在装小灯泡——专注了一小时。我坐在旁边拍了5条视频。"

**验证**：如果结束后家长说"下次有这个还来"——体验成立。

### 深度课（198元）

"孩子在农场待了半天，回来告诉我松果里的松子是怎么出来的、什么样的树皮是老树、哪只鸡是鸡群的老大。我不确定他说的对不对，但他兴致勃勃。"

**验证**：如果孩子回家后主动跟家里人讲述在农场学到的内容——体验成立。

### 年卡

"每个月来两次农场，孩子熟路了，知道洗手间在哪、中心厨房在哪、那只鸡叫什么名字。我不需要再解释'我们去一个地方'——他可以给爷爷奶奶当导游了。"

**验证**：如果孩子第5次来的时候主动跟新来的小朋友说"我知道这里"——年卡体验成立。

## 5. 交付标准

### 触点一：报名与到达

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **员工**（自然教育老师） | 报名后发一条确认信息（"明天见！天气晴好，建议给孩子穿长裤带水壶"）——让人觉得被提前关照了 | 报名后没有声音，到现场再问 |
| **家长** | 收到确认信息+路线指引——"这个农场还挺专业" | 到了现场不知道往哪走、不知道在哪集合 |

### 触点二：课程过程中的孩子状态

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **老师** | 蹲下来和孩子平视说话、叫得出每个孩子的名字 | 站在孩子面前讲、叫不出名字、区别对待 |
| **家长** | 看到孩子专注地在做一件事——"我孩子居然能专注这么久" | 孩子不愿意参与、或者全程在跑神——家长会觉得"还不如在家里" |
| **主管** | 课程结束后，老师主动和家长沟通"今天孩子表现特别好的是……"——让家长知道老师有在关注他的孩子 | 下课了就走，没有一句反馈 |

### 触点三：课程结束的仪式感

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **老师** | 每节课结束时有一个简单的"成果展示"——孩子们拿着自己的作品站成一排，老师拍一张合影发到课程群 | "下课了，收拾一下，走了" |
| **家长** | 收到孩子的作品+合影——发朋友圈的素材齐了 | 什么都没有 |
| **主管** | 课后在课程群里发一条"今天孩子们做了什么"的文字回顾（含3-4张照片）——让没来的家长也觉得"这个课有内容" | 课程群没有内容，下次就没人看了 |

### 品质底线
- 师生比：68元引流课不超过1:8（1个老师带8个孩子）；198元深度课不超过1:5；年卡同深度课标准
- 自然老师必须提前备课（不是"今天到了再看干嘛"）——每个节气课要有教案
- 安全：松林活动前走一遍路线、清理可能的风险点（树枝/坑洼/马蜂窝等）

## 6. 定价与成本结构（△）

| 产品 | 定价 | 成本构成 | 毛利率预估 | 备注 |
|:---|:---|:---|:---|:---|
| 引流课 | 68元 | 材料费5-15元 + 老师课时费 | 60-70% | 老师工资按课时算，毛利不重要，目的是引流 |
| 深度课 | 198元 | 材料费15-30元 + 老师课时费 | 70-80% | 核心利润来源 |
| 年卡（24次） | 1280-1680元 | 折合约53-70元/次 | 与深度课一致 | 年卡本身不追求高利润，追求到店频次 |

**关于"含餐"的决定**：去掉了。理由：
1. 198元含餐→家长算"餐值50元→课程只值148元"——课程价值被低估
2. 198元不含餐→家长另花30-50元在中心厨房买吃的→带动引擎A消费
3. 自然教育课程时间（2-3小时）通常在上午→结束后家长自然选择在农场吃午餐

## 9. 增长路径

### 复购机制

| 机制 | 说明 |
|:---|:---|
| **引流课→深度课** | 引流课结束后，家长收到一条消息："下次XX节气有深度课，XX主题，今天参加的孩子优先报名" |
| **深度课→年卡** | 参加过2-3次深度课的家庭，主动推送年卡信息："您已参加过XX次，年卡特惠XX元" |
| **年卡的持续吸引力** | 节气课本身就是复购机制——每个节气内容不同，孩子不会腻。家长不续卡反而会觉得"这个节气没去可惜了" |
| **朋友圈海报** | 每节课程后，老师在群里发课程照片海报+下一节课预告——让家长持续"被看见" |

### 传播机制
- 每节课的"成果作品"是天然的传播素材（孩子拿着松果灯/草木染手帕的合影）
- 年卡家庭群本身就是一个小社群——家长在里面互相熟识后，粘性更高
- **建议：每个节气课最后一个环节设计为"作品展示+合影"——老师统一拍，发到群里，家长自行取图发朋友圈**

## 10. 决策结论

| 项目 | 内容 |

## +1 多角色验证

### 角色A：第一次来的妈妈（引流课68元）

**体验路线**：妈妈群看到农场有自然教育68元→报名→周末带孩子来→到了发现找不到集合点→找到后孩子开始活动→孩子做了松果灯→结束

**加分点**：68元的价格低于预期（"我以为至少100+")；孩子做的松果灯很可爱，发了朋友圈
**扣分点**：到了找不到集合点——第一次来的客户需要明确引导；老师带活动时中规中矩，没有特别出彩
**复购意愿**：中。会考虑下次来，但不会迫切地想来
**传播意愿**：会。发了朋友圈，但配文比较平淡
**优化建议**：**到了引导**是最优先解决的问题；**老师的感染力**决定了引流课到深度课的转化率

### 角色B：已参加过3次深度课的妈妈（年卡潜在客户）

**体验路线**：第三次来深度课 → 孩子已经认识老师了 → 课后老师说"我们有年卡，一年24个节气课" → 看了价格1280元

**加分点**：孩子喜欢这里，每次来都有新内容；孩子能叫出植物的名字了——"真的学到了东西"
**决策**：1280元算下来53元/次——"不去白不去，去了一次就够本" → 付款
**复购意愿**：年卡锁定了全年的周末安排
**传播意愿**：强。"我给孩子买了年卡"——这个消费行为本身就在传递"我们家长重视自然教育"

### 角色C：农场主管

**最大的运营现实**：自然教育需要**人**。引流课还好（一个老师+简单材料），但深度课和年卡对师资的要求高很多。如果找不到合适的自然教育老师，可以先做1-2个引流课主题，"证明这个方向的可行性"——有需求再招人，而不是先招人再等需求。

**与其他板块的联动价值**：自然教育年卡可能是所有产品中"让客户反复来次数最多"的。一年24次到店 → 每次平均消费50-100元（引擎A/B） → 24×50=1200元额外营收。**年卡客户的价值不在年卡费，在年卡外的到店消费。**
