# 场景分析：四家庭农场聚餐聚会

> **分析日期**：2026-06-02
> **基于框架**：《体验型服务系统分析框架》V2.0
> **场景概述**：4个家庭（约12-20人）相约周末来农场聚餐，主目的就是吃饭聚会、孩子们一起玩
> **核心问题**：他们如何发现农场的其他业态？是否愿意参与？

---

## 第①层 · 人与关系

### 核心洞察：这跟"一家三口来上课"是完全不同的场景

上一场亲子教育场景中，妈妈带着明确的"任务"来（让孩子学到东西），决策高度集中、时间结构化。本场景中，4个家庭的初始目的**没有任务**，就是社交+吃饭。这意味着：

1. 没有"核心体验者"——大人小孩都是平等角色
2. 决策分散——每个家庭各自决策，但群体氛围影响个体行为
3. 时间非结构化——不会按"几点到几点上课"走
4. 传播链路不同——照片发出去是"我们几个家庭聚了"，不是"孩子上了节课"

### 角色识别

| 角色               | 身份      | 本场景中的存在意义         |
| :--------------- | :------ | :---------------- |
| **发起家庭妈妈**       | 组织者     | 提议来农场、拉群、预约、付定金的人 |
| **参与家庭妈妈**       | 跟从者     | 被拉来的，带娃+带吃的+看群通知  |
| **所有爸爸们**        | 陪同+烧烤主力 | 负责生火/烤串/带孩子疯跑     |
| **所有孩子们（3-10岁）** | 自由玩耍者   | 跟朋友一起疯跑/探索/模仿     |
| **附加角色**         | 可能有     | 祖辈陪同、小婴儿          |

### 发起家庭妈妈分析

```
基本画像：30-42岁 / 与2-3个家庭妈妈是闺蜜或同班家长关系 / 有组织经验
核心动机："好久没聚了，找个地方大家都能带孩子，大人也能聊聊天"
真实心理：
  └── 组织者是"费力不讨好的角色"——她希望：
      ① 大家都满意（别有人嫌远嫌贵嫌不好吃）
      ② 自己不要太累（别从头张罗到尾）
      ③ 出了力被看到（"XX找的这个地方不错"）
决策方式：会提前搜索/问人/看评价，一旦定了就不改了
最怕什么：踩雷——"我找的地方大家说不好"
隐藏需求：她是最容易被转化为"下次单独带孩子来"的人——因为她是主动找农场的人
```

### 参与家庭妈妈分析

```
基本画像：与发起家庭妈妈同龄/同圈
核心动机："朋友叫了就来了"——没有独立搜索和决策过程
真实心理：
  ① 不用自己操心——跟着走就行
  ② 孩子有伴——自己不用全程带孩子
  ③ 见见朋友——这是核心诉求
最怕什么：无聊，或孩子无聊
注意：她没有提前了解农场有什么。她到场的全部认知来自"发起人说的"和"到了以后看到的"
```

### 爸爸们分析

```
画像差异：4个爸爸可能来自不同职业背景，但共同点是：
  ① 来之前没参与过决策——"老婆说周末去农场"
  ② 对农场的预期是"有烧烤+有地方坐"
  ③ 最理想的状态：跟朋友喝酒聊天、烤串、看孩子们在旁边玩、不用管孩子

核心动机：社交——"跟兄弟们喝一顿"
真实心理：
  ① 周末放松——不想有任务、不想被安排
  ② 能跟其他爸爸聊天是加分项（平时没机会）
  ③ 能在孩子面前表现"爸爸会生火/会烤串"是隐藏满足感

最怕什么：
  ① 被安排活动——"来都来了大家一起玩个游戏"
  ② 全程管孩子——"你老婆让你来就是带孩子你还喝什么酒"

**关键洞察**：爸爸在这场景中的满意度和消费意愿，取决于"有没有兄弟在旁边一起"。如果4个爸爸能凑在一起，他们的体验会自运转。如果只有1-2个爸爸，他们会比较无聊。
```

### 孩子们分析

```
本场景中的孩子画像与上场景不同：
  ① 不是来上课的——是来跟朋友玩的
  ② 年龄范围更宽（3-10岁混龄）
  ③ 自由时间多——课程场景50分钟，这里可能4-5小时

核心动机：跟朋友玩——"XX也来"
真实心理：只要有伴，在哪都开心。没有伴（其他家庭的孩子没来或玩不到一起），农场再好也无聊

最怕什么：没有朋友玩、被大人拉去做"有意义的活动"

**关键洞察**：孩子的满意度不取决于农场有什么设施，取决于"有没有同龄人一起"。4个家庭的好处是孩子数量够、有伴的概率高。
```

### 角色关系分析

| 维度       | 分析                                                          |
| :------- | :---------------------------------------------------------- |
| 角色间关系    | 强社交关系——家庭间是朋友/同学家长，不是陌生人                                    |
| 决策权分布    | 发起家庭妈妈有决策权（选哪里），参与家庭妈妈有否决权（太远不去/太贵不去），爸爸们不参与前期决策            |
| 到场后的权力转移 | 发起妈妈到了之后"任务完成"——主导权交给农场（农场做得好就是她选对了，做不好就是她踩雷了）              |
| 群体对个体的影响 | **这是本场景最重要的分析维度**——个体行为受群体氛围强烈影响。一个人不敢去看面包窑，但"走，我们一起去看看"就会去 |
| 服务优先级    | 不存在"核心体验者"，存在"群体体验"。让群体氛围好，每个人就都满意                          |

## 第②层 · 场景

```
触发场景：
  ① 好久没聚了，有人在群里说"周末出来聚聚吧"
  ② 几个人同时在问"去哪"，有人提议农场
  ③ 有人去过或见过别人去，发了照片到群里

决策方式：发起者先提议+发信息到群里 → 大家看价格/距离 → 投票或默认通过 → 发起者预约

决策周期：3-7天。从有人提出到确定，通常需要群内讨论2-3轮。

到店时间：周六或周日约10:00-11:00到（先到先玩，中午开烤）

停留时长：4-6小时（10:00-16:00或16:00-21:00），取决于选择午餐还是晚餐

季节敏感度：
  春/秋：最佳季节，户外烧烤+晒太阳
  夏：傍晚场更受欢迎（避开下午高温）
  冬：柴火灶+火锅是主力，室外待不了太久

初始消费预算：约100-150元/人（含餐）
```

### 场景的关键特征——"被决定的目的地"

```
这群人不是"想去农场"，是"想聚餐，最后选了农场"。

这意味着：
  ① 他们对农场的预期只有"有饭吃、有地方坐"——没有更深的预设
  ② 他们不会主动搜索"农场有什么可玩的"——除非到了以后看到了
  ③ 他们对农场其他业态的发现，取决于：
      a. 到达后是否"自然看到"（不是被推销看到）
      b. 是否"有人提议去看看"
      c. 是否"闲着也是闲着"
```

## 第③层 · 体验任务（四层拆解）

### 功能任务

```
发起家庭妈妈：找个大家都满意的地方 → 预约 → 发定位 → 到现场确认一切OK
参与家庭妈妈：跟着导航来 → 带孩子 → 跟朋友聊天 → 吃饱
所有爸爸们：生火/烤串 → 喝酒 → 聊天 → 看着孩子别出事
所有孩子们：跟朋友玩 → 吃东西 → 跑一跑 → 不无聊
```

### 情绪任务

```
发起家庭妈妈：从"找地方的压力" → "大家都说好的满足"
参与家庭妈妈：从"周末无聊" → "跟朋友见面聊聊" → "孩子有伴我也轻松"的放松
所有爸爸们：从"周末又没了" → "有酒有肉有兄弟"的快乐
所有孩子们：从"周末待在家无聊" → "跟XX一起玩"的兴奋
```

### 社交任务

```
发起家庭妈妈：在群里发照片 → "××找的地方不错，下次还来"——她需要被认可
参与家庭妈妈：发"几家聚在一起"的朋友圈 → 展示"我们有个好圈子"
所有爸爸们：发一张烧烤/篝火/干杯的照片就够了
所有孩子们：不需要社交任务
```

### 认同任务

```
发起家庭妈妈："我是会找地方、能把大家组织起来的人"
参与家庭妈妈：无
所有爸爸们："我是会烤串/会陪孩子玩的好爸爸"
所有孩子们：不需要
```

## 第④层 · 触点服务需求

### 触点 × 角色矩阵

| 触点 | 发起家庭妈妈 | 参与家庭妈妈 | 爸爸们 | 孩子们 |
|:---:|:---|:---|:---|:---|
| **1.触发** | 想聚会 → 找地方 → 想起/搜到农场 | "XX说去农场" | — | — |
| **2.决策** | 价格✅场地✅能不能容下12-20人✅有没有主食之外的吃的✅ | 看一眼价格和照片——"行" | — | — |
| **3.到达** | "我选的地方还行吧？"→观察大家反应 | "环境怎么样？"→跟群里的照片比一比 | 停车场好不好停→"这地方多大？"→"哪能烧烤？" | "XX来了吗！"→看到场地→"我们能去哪玩？" |
| **4.聚餐中** | 大家都在好好吃饭吗？有人不满意吗？ | 孩子有伴吗？我跟朋友聊上了吗？ | 火着了没？肉够不够？酒冰了没？ | 有伴→去哪里都行。没伴→无聊 |
| **5.服务接触** | 到的时候有人接待吗？加炭加菜快吗？有没有人告诉我洗手间在哪？ | 同上 | 同上 | 有人理他们吗？ |
| **6.饭后空白** | **关键触点**——吃饱了之后，大家散落在各处 | — | — | — |
| **7.离开&后续** | 大家觉得怎么样？→"下次还来吗？"→可能被问"还有什么好玩的" | 孩子开不开心→决定有没有下次 | — | "今天好玩吗？下次还来不来" |

### 关键触点展开

**触点6-饭后空白——这是全场景最重要的触点**

饭后（约13:00-14:00）到离开（约16:00-17:00）之间有2-3小时的空白时间。

```
这2-3小时决定了：
  ① 这次聚会的整体满意度（不是烧烤好不好吃——烧烤只要熟了就行，差别不大）
  ② 会不会有人产生额外消费
  ③ 会不会有下一次单独来的意愿

饭后空白期的典型状态：
  大人：吃撑了，想找个地方坐着喝茶/聊天/消食
  孩子：吃饱了坐不住，想跑想玩（但大人不想管）
  所有人：不想再被"安排"——不想参加一场"大家一起做点什么"的团建式活动
```

**饭后空白期，农场其他业态的曝光机会**：

```
此时这群人在农场里的状态：分散的、自由的、无任务的。

如果有同伴提议"那边有面包窑，去看看"，可能2-3个人会一起去。
如果有人看到鸡舍/"这里有鸡" → 孩子会跑过去 → 大人跟着走过去。
如果有人看到认领牌"这棵树被认领了" → 可能有人问一句"还能认领吗"。
如果有人坐着喝茶时翻到菜单/活动介绍页 → 可能看到"披萨DIY""自然教育课"等。

关键前提是：这些业态必须是在他自然活动范围内被"看到"的，不是被"带到"的。
```

| :---------- | :-------------------------------------- | :-- |
| 提前确认到店时间和人数 | 发起者预约时确认，到店前一天再确认一次                     | 引擎B |
| 到达时迎接       | 确认发起者身份、引导到预订区域、告知洗手间位置                 | 引擎B |
| 桌上已备好       | 餐具/炭火/菜单/酒水单——不需要人等东西                   | 引擎B |
| 自然告知农场环境    | "那边是鸡舍，孩子可以去看看。后面是松林，有吊床。面包窑在那边，下午会出面包" | 引擎B |

### 聚餐中服务

| 事项     | 标准                                | 负责人 |
| :----- | :-------------------------------- | :-- |
| 加炭加菜响应 | 农场倡导自助式。                          | 引擎B |
| 儿童区关注  | 孩子们在哪玩、安不安全，运营卫星抽空看一眼             | 引擎B |
| 拍照提醒   | 上菜/开烤/干杯时，引擎B路过时可以问一句"需要帮你们拍张合照吗" | 引擎B |

### 饭后空白期的服务方案——引导非结构化发现

**这是本场景的核心设计**。不是安排活动，是提前铺好"自然发现"的路径。

```
设计原则：
  ① 不安排活动——这个群体来不是为了被安排
  ② 不主动推销——但在他能看到的地方，自然展示其他业态
  ③ 让他自己决定去不去看——"看到了，感兴趣就过去，不感兴趣就接着坐着"
```

**三条自然发现路径**：

```
路径一：孩子驱动
  孩子在聚餐期间或饭后在农场里跑动 →
  跑到鸡舍→看到鸡/鸡舍→"妈妈有鸡！" →
  大人跟过来→看到认领牌→"这还能认领？"→扫码看详情

  触发条件：鸡舍在孩子的自然活动范围内（步行可达、无障碍、能看见）
  农场需要做的：鸡舍位置合理+认领牌显眼且有二维码

路径二：散步驱动
  大人吃完饭想走走消食 →
  走向松林/面包窑方向 →
  看到面包窑→"这还能做面包？"→看到墙上的课程表/活动列表 →
  可能产生：买两个面包带走 / 问"这个披萨DIY多少钱"

  触发条件：松林/面包窑在从用餐区到停车场的自然动线上
  农场需要做的：动线设计（不绕路自然经过）+ 信息展示（墙上/立牌）

路径三：休息驱动
  几个人坐着喝茶闲聊 →
  桌上/墙上/手边有农场的活动介绍 →
  翻看→看到"认养一棵你的果树""自然教育课"→起话题→"下次带孩子来试试"

  触发条件：信息在客人坐着的时候能被看到
  农场需要做的：每张桌上有一张活动信息卡（不是推销感，是"你在农场可以做什么"）
```

**三条路径的共同前提**：设计在客人的**自然动线**上，而不是在客人的**注意力**上。

### 从聚餐到"下次单独来"的转化设计

这比现场消费更重要。4个家庭的聚餐场景中，当场产生的额外消费（面包/咖啡）是小的，但每个人的"下次单独来"意愿是大的。

| 触发条件 | 设计动作                    | 执行人 |
| :------------- | :---------------------- | :----- |
| 孩子在农场玩得开心 | 不需要刻意设计——孩子开心是天然的       | — |
| 妈妈看到"还有这么多活动" | 每桌放一张活动信息卡，课程表/认领/生日会   | 运营卫星 |
| 爸爸觉得"这地方可以" | 让他有一段"不需要带孩子、跟兄弟待着"的时间  | 环境本身提供 |
| 发起妈妈得到"选得好"的认可 | 在结账/离开时对发起者说一句"您选的这个地方" | 运营卫星 |

**具体的转化触点——离开时**：

```
结账/收拾时，顺口带一句（不是推销语气，是"顺便告诉你"的语气）：

  对有孩子的妈妈："后面有自然教育课，下次可以单独带孩子来上"
  对爸爸："后面有窑炉面包，可以买两个带走当明天早餐"
  对所有家庭："桌上那张卡片是农场整年的活动表，感兴趣的可以拍一张"
```

## 第⑥层 · 能力边界

### 能做

| 事项 | 依据 |
|:---|:---|
| 接待12-20人的聚餐 | 引擎A餐饮已有接待能力，烧烤/柴火灶/火锅均可出餐 |
| 饭后空白期的自然发现设计 | 零额外成本——用餐区和鸡舍/面包窑/松林的动线合理即可 |
| 孩子自由玩耍的安全底线 | 农场面积够大、无危险设施，运营卫星兼顾巡视即可 |
| 信息卡/活动介绍 | 一张卡片+墙上展示，极低成本 |

### 不能做（明确放弃）

| 事项 | 原因 |
|:---|:---|
| 饭后安排集体活动 | 这群人来不是为了被安排。安排活动会破坏"朋友聚餐"的氛围 |
| 主动推销其他业态 | 这个场景的客群对"推销"极度敏感（他们聚在一起就是不想被推销），一次主动推销可能毁掉整个聚会体验 |
| 保证每个家庭都会产生额外消费 | 有些人就是来吃顿饭就走。接受这个事实 |

### 差异化对比

| 对比项 | 一般农家乐/烧烤场地 | 青松农场 |
|:---|:---|:---|
| 饭后时间 | "吃完就走"或"没地方去" | 饭后有自然可以探索的空间（鸡舍/松林/面包窑/认领区） |
| 群体氛围利用 | 不管 | 利用"有人提议一起去看看"的群体心理，设计自然动线 |
| 下次转化的意识 | 没有 | 在离开时留一个开口——"下次可以单独带孩子来上自然教育课" |
| 发起者的心理需求 | 不管 | 让发起者获得"我选的地方不错"的认可 |
