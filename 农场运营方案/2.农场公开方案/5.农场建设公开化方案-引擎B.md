# 农场建设公开化方案 · 引擎B（露营住宿）

> **基于**：星形结构 — 引擎B（利润中心）
> **覆盖工作**：14项（B01-B14）
> **本文定位**：引擎B所有可公开化工作的模式匹配与执行设计

---

## 第一部分：总纲

### 1.1 核心理念

引擎B是农场"松弛感"的来源——松林下的天幕、傍晚的篝火、挂满灯串的露营区。引擎B的公开化逻辑与核心层和引擎A都不同：

- **核心层公开化**是为了建立信任（"这个农场真的在种东西"）
- **引擎A公开化**是为了放大传播（"这个画面让人想来"）
- **引擎B公开化**是为了**创造归属感**（"这个地方有我留下的痕迹"）

露营客户是农场所有客群中"停留时间最长、情感投入最深"的群体。他们过夜、搭帐篷、在松林里度过完整的一天。引擎B的公开化核心是：让客户从"来住一晚"变成"在这个地方有我的印记"。

### 1.2 引擎B公开化的三条原则

| 原则 | 说明 |
|:---|:---|
| **住宿体验优先** | 公开化不能影响住客的安静和舒适。篝火区的共建活动不能在深夜进行，营位旁的公共区域要保持整洁 |
| **美感不妥协** | 引擎B的场景感是核心资产。公开化活动产生的"临时感"（工具乱放/材料堆积/施工围挡）必须控制，活动结束立刻恢复 |
| **自愿参与** | 露营客户中有大量"就想一个人待着"的人。引擎B的公开化活动必须是"路过看到了想参加就参加"，不强制、不打扰 |

### 1.3 引擎B五种模式的整体倾向

| 模式 | 适合引擎B的什么工作 | 引擎B的天然优势 |
|:---|:---|:---|
| 课程化 | 有知识含量的活动（夜观星空/松林导览/篝火安全课） | 露营场景本身就是沉浸式课堂的天然教室 |
| 共建化 | 设施搭建/场景布置（搭木平台/挂灯串/建篝火台） | "我们一起把这里变美"——参与者会成为场景的长期维护者 |
| 劳动换薪 | 轻体力场景维护（捡松果/清理步道/布置活动场地） | 住客吃好喝好后顺手干点活，换一杯免费啤酒 |
| 认领化 | 可标记的长周期资产（认领一棵松树/认领一个营位） | "我的营位"——归属感最强的产品 |
| 技能传承 | 露营技能/户外生活经验（资深露营客教新手搭帐篷/生火） | 资深露营客是天然的"助教" |

## 第二部分：各模式详述

---

### 模式1 课程化

**定义**：将有知识含量的露营相关活动设计为有结构的体验课程。

#### 典型场景1：松林夜观/星空导览（对应B14）

| 项目 | 内容 |
|:---|:---|
| 时长 | 45-60分钟 |
| 定价 | 38元/人（住客免费或优惠价） |
| 容量 | 10-20人 |
| 流程 | 集合发放小手电（5分钟）→ 沿松林步道慢走，听虫鸣、认植物夜间形态（20分钟）→ 走到开阔处观星，指认星座（15分钟）→ 返程路上分享感受（5分钟）→ 回到营地喝杯热茶（5分钟） |
| 交付 | 每人一张"今晚看到的星座"手绘卡片 |

**情绪价值设计**：
- "原来松林晚上这么热闹"——城市里没有的体验
- 亲子一起看星星——家庭记忆锚点
- 那些安静走路的时刻——疗愈感

**传播设计**：
- 晚上的松林+星空+手电光——画面有氛围感
- 观星环节用手机拍一张星空（或星系照片）+手指出星座的剪影
- 适合发小红书："在潍坊的松林里看到了银河"

#### 典型场景2：篝火安全小课堂（配合B05，篝火点燃前的简短讲解）

| 项目 | 内容 |
|:---|:---|
| 时长 | 10分钟（篝火点燃前） |
| 定价 | 免费 |
| 流程 | 篝火台的结构说明→松木的燃烧特性→安全距离→添柴的正确方式→点火 |
| 交付 | 参与篝火的客户掌握了正确用火知识，更安全地享受篝火 |

### 模式2 共建化

引擎B的共建化是五个模式中价值最高的。因为露营场景的设施（木平台/天幕/篝火台/灯串）有明确的"建造感"，客户参与建造后会产生强烈的归属感。

#### 典型场景1：一起搭露营平台（对应B01）

| 项目 | 内容 |
|:---|:---|
| 时机 | 新营位开发或旧平台翻新时 |
| 形式 | 免费参与（或作为长搭客户的专属活动） |
| 容量 | 8-15人 |
| 流程 | 分组（木工组/组装组/装饰组）→ 各组按图纸施工（2-3小时）→ 完成后在平台边缘刻上"XX组搭建"→ 合影 |
| 交付 | 参与者的名字刻在平台边缘或旁边立一块共建铭牌 |

#### 典型场景2：四季庆典场景共建（对应B08）

| 项目 | 内容 |
|:---|:---|
| 时机 | 每季度庆典前1天 |
| 形式 | 免费参与，参与者获得庆典优先入场权 |
| 容量 | 10-20人 |
| 内容 | 丰收节：一起堆玉米南瓜堆/挂灯笼/摆长桌；冬至节：一起搭围炉/挂松枝花环/布置篝火区 |
| 交付 | 庆典当天的照片发到群里——"这是我们一起布置的现场" |

#### 典型场景3：松林氛围布置（对应B06）

灯串悬挂、灯笼布置、夜间照明——这些工作看起来琐碎，但做起来有画面感。

| 项目 | 内容 |
|:---|:---|
| 时机 | 周末活动前或换季时 |
| 形式 | 劳动换薪或免费参与 |
| 容量 | 5-10人 |
| 流程 | 领取灯串→按规划路线在树枝间悬挂→测试亮灯→在天幕边缘挂灯笼 |
| 情绪价值 | "这里的灯有一部分是我挂的"——晚上亮起来的时候特别有成就感 |

### 模式3 劳动换薪

**定义**：将引擎B日常维护中的轻体力工作开放给客户，完成后获得小额现金或代金券。

#### 适合引擎B的劳动换薪项

| 优先级 | 编号 | 工作内容 | 建议薪酬 | 时长 | 说明 |
|:---:|:---|:---|:---:|:---:|:---|
| P0 | B07 | 活动道具制作（编拔河绳/做寻宝地图/画飞盘标靶） | 8元/30分钟 | 30分钟 | 坐着干的轻活，适合手巧的客户 |
| P1 | B06 | 松林灯串悬挂（协助挂灯/整理灯线/检查灯泡） | 10元/30分钟 | 30分钟 | 需要爬梯子（农场负责），适合有体力的客户 |
| P1 | B11 | 团建/宴会场地布置协助（铺桌布/摆椅子/插野花） | 8元/30分钟 | 30分钟 | 简单易操作，布置完自己也能享受环境 |
| P2 | B04 | 营位标识制作协助（手绘路牌/刷油漆/钉指示牌） | 10元/30分钟 | 30分钟 | 适合有绘画/手工爱好的客户 |

**特殊设计——"一杯啤酒换一次帮忙"**：
引擎B的劳动换薪可以设计得更轻松——不发现金，发"营地饮品券"。

| 工作 | 时长 | 报酬 |
|:---|:---:|:---|
| 帮挂10米灯串 | 20分钟 | 一杯精酿啤酒或特调饮品 |
| 帮忙布置5套营位桌椅 | 15分钟 | 一杯热巧克力 |
| 协助整理活动道具仓库 | 30分钟 | 两杯饮品 |

这个设计的逻辑：露营客户本身就在度假状态，现金激励不如"顺手干点活换杯喝的"来得自然。

**执行方式**：
- 服务台放一块小黑板"帮忙换杯喝的"
- 客户退房时随口问一句"走之前要不要帮我们挂几个灯笼？换杯喝的"
- 不设预约，随到随做

### 模式4 认领化

**定义**：将引擎B中可长期标记的资产开放给客户认领。

#### 认领产品设计

| 产品 | 定价 | 权益 | 目标数量 |
|:---|:---:|:---|:---|
| 认领一棵松树 | 200元/年 | 树根旁立认领人姓名牌（防腐木牌），全年免费停车，可在树下挂一个吊床（自备） | 30棵 |
| 认领一个固定营位 | 500元/年 | 营位入口挂认领人姓名牌，周末优先预留（提前24小时预约），含全年2次免费装备升级 | 20个 |

**情绪价值设计**：
- 认领松树——"那棵挂着'XX的树'的松树"——每次来都去看看
- 认领营位——"不用抢位置，那个位置永远给我留着"——归属感+便利性

**运营要点**：
- 松树认领：认领牌用防腐木+不锈钢螺丝，不损伤树木
- 营位认领：不锁定具体营位编号（避免客户非要某个位置而导致运营僵硬），而是"专属预留权"——客户提前说，引擎B主理人给留一个同等级的好位置

### 模式5 技能传承

**定义**：识别出客户身上有引擎B需要的技能，发起价值交换。

#### 引擎B适用的技能交换场景

| 客人有 | 农场需要 | 交换方式 |
|:---|:---|:---|
| 资深露营经验（搭帐篷/生篝火/户外厨艺） | 周末帮助新手露营客搭帐篷/做指引 | 当一次"营地助手"（2小时）→ 当晚免住宿费 |
| 木工技能 | 露营平台的日常维修/新设施制作 | 帮忙修缮→交换储值金 |
| 户外活动组织经验（团建教练/拓展培训师） | 周末带一场团建活动的热身/破冰 | 带一次活动→交换储值金+免费午餐 |

## 第四部分：执行流程

### 4.1 发现与识别

谁来发现：引擎B主理人。

发现时机：
- 新营位开发或设施升级前
- 有住客问"这个我能帮忙吗？"
- 季度庆典筹划阶段

### 4.2 评估与决策

引擎B决策树增加一条特殊判断：

```
这项工作会影响住客的安静和舒适吗？
  +-- 会（深夜施工/噪音大的工作）--> 安排在白天非休息时段
  +-- 不会 --> 正常开放
  +-- 继续使用通用决策树
```

### 4.3 设计与发布

| 模式 | 负责人 | 发布渠道 |
|:---|:---|:---|
| 课程化 | 引擎B主理人 | 住客群+社群+小红书 |
| 共建化 | 引擎B主理人+运营卫星 | 长搭客户群+社群 |
| 劳动换薪 | 引擎B主理人 | 服务台小黑板 |
| 认领化 | 运营卫星 | 商城+社群+现场展示 |
| 技能传承 | 言渊+引擎B主理人 | 私下邀请 |

### 4.4 执行与现场管理

| 要点 | 标准 |
|:---|:---|
| 时间控制 | 共建/劳动换薪活动需在21:00前结束，不打扰住客夜间休息 |
| 场地恢复 | 活动结束后30分钟内恢复场地原貌，工具归位 |
| 天气敏感性 | 露营区活动受天气影响大，雨天需提前通知改期 |
| 防火管控 | 篝火台搭设和点燃必须在指定区域，远离松林主干区 |

### 4.5 收尾与传播

| 模式 | 收尾动作 | 传播设计 |
|:---|:---|:---|
| 课程化（夜观） | 每人一张星座卡片+合影 | 星空的照片是天然传播素材 |
| 共建化 | 铭牌/签名+合影 | "今天我们一起建了一个平台"的图文 |
| 劳动换薪 | 一杯饮品+合影 | "在农场干活换了一杯啤酒"的轻松感 |
| 认领化 | 认领牌安装+拍照发送 | "在青松有了一棵自己的树" |
| 技能传承 | 记录技能+致谢 | 故事型内容 |

### 4.6 记录与复盘

每月末汇总引擎B的公开化数据，额外关注：

| 记录项 | 说明 |
|:---|:---|
| 共建活动次数与参与人数 | 露营平台的搭建/场景布置等活动 |
| 夜观课程场次与转化 | 参加夜观的客户中，多少人后续在引擎A/B消费 |
| 劳动换薪人次 | "帮忙换杯喝的"活动的参与情况 |
| 认领新增与续费 | 松树认领和营位认领的数据 |

## 第五部分：风险与合规

### 5.1 风险分级

| 等级 | 描述 | 涉及的工作 | 控制措施 |
|:---:|:---|:---|:---|
| 低 | 无工具/无体力风险 | 夜观课程(B14)、活动道具制作(B07) | 标准安全告知 |
| 中 | 使用简单工具/轻度体力 | 挂灯串(B06，需爬梯)、场地布置(B11) | 梯子由农场员工操作，客户只负责地面部分 |
| 高 | 涉及火源或结构搭建 | 篝火台搭建(B05)、木工施工(B01/B03) | 限成人+专业指导+灭火器在场 |

### 5.2 保险要求

引擎B的公开化活动覆盖在农场公众责任险下。注意确认：露营区的共建活动（木工/搭建）是否在保险条款涵盖的建筑类目内。

### 5.3 活动前安全Checklist

| 序号 | 检查项 | 完成打钩 |
|:---:|:---|:---:|
| 1 | 活动区域与住客休息区有物理隔离或时段错开 | - |
| 2 | 工具完好、数量足够、不适合客户的工具已锁好 | - |
| 3 | 涉及火源的活动区域已配备灭火器 | - |
| 4 | 引擎B主理人或指定员工在场 | - |
| 5 | 天气预报未来2小时无雷雨/大风 | - |
| 6 | 活动结束后场地恢复方案已明确 | - |

## 第六部分：执行建议

### 6.1 从哪开始——最小可测试单元

**第一批（第1个月内启动，零成本）：**
1. "帮忙换杯喝的"小黑板上线——在服务台放一块小黑板，列出3项简单工作，住客退房或路过时自然参与
2. 篝火安全小课堂——篝火点燃前花10分钟讲解，不增加成本，提升安全性和体验感

**第二批（第2-3个月）：**
3. 松林夜观课程——选一个周末试跑，38元/人，住客免费或优惠价
4. 松树认领上线——社群+现场展示，从长搭客户中寻找第一批认领人

**第三批（第3个月后）：**
5. 共建化活动——有新营位开发或设施升级时发布招募
6. 四季庆典场景布置——庆典前1天邀请客户共建

### 6.2 引擎B公开化的特殊节奏

| 频率 | 动作 | 谁负责 |
|:---:|:---|:---|
| 每日 | "帮忙换杯喝的"小黑板（服务台） | 引擎B主理人 |

| 每两周 | 松林夜观课程（周末排期） | 引擎B主理人 |
| 每季度 | 庆典共建活动招募 | 运营卫星 |
