[SOP编号] O-05
[SOP名称] 客户投诉处理流程
[执行人] 运营卫星成员（首问负责制）
[替代人] 言渊（升级处理）
[执行时间] 投诉发生时即时响应 → 24小时内结案 → 7天内整体复盘
[适用季节] 全年
[前置条件] 无
[AI接口] Hermes存储投诉记录和客户标签；自动统计投诉类型和趋势
[AI提醒] Hermes在投诉录入后24小时推送未结案提醒；每周推送投诉分析报告

---

### 一、投诉接收

```
1. 投诉渠道识别
   以下所有渠道收到的投诉，运营卫星成员为统一接收入口：

   □ 当面投诉（客户在现场直接提出）
   □ 电话投诉（客户致电言渊或农场电话）
   □ 微信/社群投诉
   □ 小程序/平台评价（大众点评/美团等）
   □ 第三方投诉转达（合作方转达）

2. 投诉登记
   无论何种渠道，第一时间在Hermes记录：

   - 投诉人信息（姓名/联系方式/消费时间）
   - 投诉内容（原始语句记录，不修饰）
   - 投诉板块（引擎A/引擎B/核心层/运营卫星/自然手作）
   - 投诉情绪等级（平静/不满/生气/愤怒）
   - 投诉接收人
```

### 二、现场即时处理

```
1. 当面投诉处理（7步法）

   第1步：停下手头的事，专注面对客户
   第2步：倾听完，不打断，不辩解
   第3步：共情回应："让你有了不好的体验，真的很抱歉"
   第4步：确认问题："我来确认一下，你说的是……对吗？"
   第5步：给出处理方案（权限内）
      - 轻微投诉（等太久/菜品凉了）：赠饮品/小食/折扣
      - 中度投诉（品质问题/服务失误）：免单/补偿券
      - 严重投诉（安全问题/严重失误）：免单+致歉+换人跟进
   第6步：告知处理时限："我15分钟内先给你解决XX"
   第7步：致谢反馈："谢谢你告诉我们，这对我们改进很重要"

2. 电话/线上投诉处理

   - 当天内首次回复
   - 了解经过，记录诉求
   - 告知处理时限（最迟24小时内给答复）
   - 按承诺时间内反馈处理结果
```

### 三、升级处理机制

```
1. 运营卫星权限范围
   - 直接处理：赠饮/折扣（≤50元）/重新制作/更换产品
   - 需请示言渊：免单/全额退款/公开道歉/赔偿金≥200元

2. 升级触发条件
   □ 客户情绪极度愤怒，不听解释
   □ 投诉涉及人身安全或健康问题
   □ 投诉金额超过运营卫星权限
   □ 投诉人要求见负责人
   □ 同一客户重复投诉同类型问题

3. 升级流程
   运营卫星成员记录 → 即时通知言渊 → 言渊1小时内联系客户 → 言渊24小时内出具处理方案
```

### 四、投诉结案

```
1. 结案条件
   □ 处理方案已执行
   □ 客户确认接受处理结果
   □ 客户表示"没事了"/"好的"/"谢谢"

2. Hermes结案记录
   - 处理时间
   - 处理方式（赠饮/折扣/免单/退款/道歉/其他）
   - 处理成本（金额）
   - 客户最终情绪状态（平息/满意/非常满意）
   - 投诉根本原因分析
```

### 五、投诉复盘（每周）

```
1. 每周运营卫星汇总投诉记录
   - Hermes自动生成投诉分析报告
   - 统计维度：投诉板块/投诉类型/处理成本/客户满意度

2. 周会回顾
   - 本周几起投诉，处理方式是否合理
   - 找根本原因（是人的问题/流程问题/能力问题）
   - 制定改进措施
   - 更新SOP（如需）

3. 投诉评级
   - 绿级（首次出现/偶发）：观察
   - 黄级（同类型出现2次/月）：流程改进
   - 红级（同类型出现3次+/月或涉及安全）：立即整改
```

### 六、投诉处理原则

```
1. 首问负责制
   第一个接到投诉的人负责跟进到底，不得推给他人

2. 24小时原则
   所有投诉24小时内必须有明确结果回馈给客户

3. 补偿不过度
   不过度补偿助长投诉，也不吝啬补偿损失口碑

4. 内部不追责（非恶性事件）
   员工主动报告投诉不扣绩效，隐瞒投诉追责
```

### 七、验收标准

```
□ 投诉已即时登记至Hermes
□ 客户已得到初步回应（当场或24小时内）
□ 处理方案已执行
□ 客户已确认接受
□ 结案记录已完成
□ 投诉归类和分析已录入
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户不接受处理方案 | 升级给言渊处理 |
| 投诉涉及多个板块 | 运营卫星协调各板块负责人联合处理 |
| 客户在网络平台发布差评 | 公开回复致歉 + 私信联系跟进处理 |
| 投诉涉及法律问题 | 保留证据，咨询法务，言渊负责 |
| 客户要求不合理赔偿 | 坚持原则，清晰告知服务边界 |

### 九、跨板块协作

- 投诉涉及**引擎A**：引擎A主理人参与处理
- 投诉涉及**引擎B**：引擎B主理人参与处理
- 投诉涉及**核心层**：种植养殖主管参与处理
- 升级投诉由**言渊**最终决策
- 严重投诉处理后更新相关板块SOP

### 十、客户触点

- 投诉是客户给农场的"最后一次机会"，处理得好反而能赢得忠诚客户
- 客户投诉时不是在找茬，是在表达"我原本期待更好"
- 记住客户的名字和投诉内容，他下次来时主动问一句"上次的问题后来解决了吗"，效果远超任何营销
