# 产品一：散客露营体验（模式A + 模式B）

```
使用维度：1✅ 2✅ 3✅ 4+扩展 5△ 6✅ 7✅ 8+扩展 9△ 10✅
```

## 1. 飞轮定位

**主定位**：引流入口（模式A）/ 利润中心（模式B）

双模式设计覆盖不同层级的客户：
- **模式A（9.9元/人，自带装备）**：拉低"第一次来农场"的心理门槛。9.9元看起来不像一个"消费"，更像一次"尝试"。它是整个引擎B的漏斗入口。
- **模式B（农场提供装备+食材）**：引擎B的主要收入来源。餐饮部分已在引擎A产品分析中讨论，本节聚焦获客与体验增强。

**辅助作用**：
- 模式A → 传播杠杆（低决策门槛意味着更多人愿意来，来的人多了就有更多人发朋友圈）
- 模式B → 复购锚点（服务体验好 → 成为回头客 → 升级为长搭客）

## 2. 目标客群

### 模式A——9.9元自带装备

- 画像：18-30岁，大学生/年轻上班族，经济敏感度高，自带帐篷和餐食。对"性价比"敏感
- 痛点：市区周边露营地过夜费50-100元/人，太贵；免费野地又不安全
- 痒点："9.9元就能在松林里过夜"——这个价格足够低到"不需要考虑"
- 决策逻辑：看到小红书/朋友圈有人发 → "才9.9？去一下也不亏" → 周末就来 → 体验好 → 下次升级模式B

### 模式B——农场提供装备+食材

- 画像：25-40岁，家庭或朋友团体，愿意为"方便"付费（不想自己买装备），愿意在餐饮上花钱
- 痛点：露营装备投入大（帐篷+天幕+睡袋+桌椅一套至少2000元），买回来一年用不了几次；每次露营前备装备、备食材太累
- 痒点："人到就行，什么都准备好了"——省心的露营
- 决策逻辑：想露营但没有装备 → 看到农场拎包入住式露营 → 对比价格（装备+食材≈300-500元/组）→ 比自己买装备划算 → 来

## 3. 核心体验

**模式A**：
"9.9元在松林里有一块自己的地方，搭自己的帐篷，吃自己带的泡面。听起来很便宜，但松林晚上的虫鸣和早上的鸟叫——这个体验不是钱能衡量的。"

**模式B**：
"人到就行，帐篷天幕已经搭好了、食材在中心厨房领了直接烤。不用搭帐篷、不用洗菜切菜、不用收拾装备。带一个包来，带一个包走。"

## 4. 交付标准（+扩展：获客、接待全流程、体验增强）

### 4.1 获客方式

| 渠道                | 模式A（9.9元）                                   | 模式B（拎包入住）                     |
| :---------------- | :------------------------------------------ | :---------------------------- |
| **小红书/抖音**        | ✅ 主力渠道。内容方向："潍坊最便宜的露营地""9.9元过夜"——低价本身就是爆款标签 | ✅ 内容方向："成年人的省心露营""带娃露营不用准备装备" |
| **朋友圈裂变**         | △ 自然会传播（低价+松林夜景容易出片）                        | △ 场景传播（帐篷天幕灯光+烧烤）             |
| **大众点评/美团**       | ─ 意义不大，9.9元的客单价不值得上平台                       | ✅ 可上团购套餐（装备+餐饮打包价）            |
| **本地社群**（妈妈群/车友群） | △ 适合露营爱好者群体扩散                               | ✅ 适合家庭亲子群体，妈妈群口碑传播            |
| **老带新**           | ✅ "带一个新朋友来，你本次免单"——9.9元的成本足够低，可以拿来做老带新激励    | ✅ "带新客户来，下次装备升级免费"            |

### 4.2 到店接待全流程

```
线上咨询/预约 → 到店停车引导 → 选位（模式A自选/模式B引导至已搭好的营位）→ 
入住引导（洗手间/淋浴/充电/饮用水位置说明）→ 活动时间表告知 → 自由活动 → 
夜间氛围 → 次日离店回访
```

**各环节加分/扣分标准：**

**环节一：选位/入营的第一印象**

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **员工** | 主动迎上，指引营位位置，说"这边是洗手间/淋浴/充电区，有什么事随时找我们" | 指了个方向就忙别的去了 |
| **客户** | 模式A：选好位置，松林里已经平整好了一片空地——"来了直接搭"；模式B：帐篷天幕已经搭好了、防潮垫铺好了——"放个包就能躺" | 模式A：选到的位置地上有垃圾或坑洼；模式B：帐篷是搭好的但里面潮的、或者有没清理的上一个客人的痕迹 |

**环节二：入住告知——信息透明度**

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **员工** | 给一张"入营指南"卡片：洗手间位置→淋浴时间→充电区→当日活动时间表→垃圾处理规则→篝火/用火规定→紧急联系方式 | 口头说一遍，"刚才说的你记住了吗？" |
| **主管** | 入营指南上印农场地图+活动时间表：让客户知道"接下来有什么可以玩的" | 客户来了不知道有什么活动，自己坐着玩手机 |

### 4.3 +体验增强项（主题活动设计）

**目的**：解决"吃完烤肉看完松林之后干什么"——让客户从"来了坐着"变成"来了有事做"。

**按参与方式分四类：**

#### A. 自主参与型（零人工成本，设置场地/道具即可）

| :--------- | :-------------- | :--- | :------- | :------------------------- |
| **松林飞盘**   | 飞盘5个（50元）       | 极低   | 年轻人/朋友团体 | 一块空地就能玩，1小时以上              |
| **草地羽毛球**  | 网+球拍2副（100元）    | 低    | 家庭/情侣    | 亲子互动                       |
| **吊床区**    | 吊床10个（300元）     | 一笔投入 | 所有人      | 松林里躺平——"这个太舒服了"的高频好评点，传播力强 |
| **松果收集比赛** | 无               | 零    | 亲子       | 孩子自己在松林里找松果，30分钟打发掉        |

#### B. 组织参与型（需员工组织，但同一套人工可服务多人）

| **篝火晚会**     | 中心篝火盆，到点点火，围着坐           | 柴火成本    | 所有人    | 氛围天花板         |

| **自然晨走**     | 早上7点员工带愿意早起的人走一圈"带露水的松林" | 零（员工早班） | 早起者    | 住一晚的附加价值      |

| **摄影师跟拍服务** | 待田园摄影卫星启动后对接 | — | 长期规划 |

#### D. 工作计划

**启动优先序**（按成本从低到高）：
1. **立即执行（零成本）**：松果收集比赛（孩子自己玩）、飞盘/羽毛球（购买道具一次投入）
2. **一周内执行（低人工）**：拔河比赛（排时间表）+ 篝火晚会（定柴火供应流程）
3. **两周内执行（需设计内容）**：松林夜观（员工培训一条路线+知识点）+ 自然晨走（定早上7点）
4. **一个月后评估**：吊床区（一次性投入300-500元，但评价可能最高）+ 松塔手作（需备材料）

### 4.4 离店与回访

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **员工** | 离店时问"昨晚睡得怎么样？有没有什么建议？"——临走前最后一个温暖印象 | 收了装备/退了押金就走了，没人说话 |
| **主管** | 离店后24小时内发一条微信（或系统短信）："昨晚的松林睡得好吗？欢迎下次再来" | 无跟进 |
| **客户** | 收到回访信息觉得被重视——下次还想来 | 离店后就像没来过一样 |

## 5. 定价与成本结构（△ 简写）

**模式A（9.9元自带装备）**：
- 定价逻辑：不是为了赚钱，是为了拉低首次到店门槛。9.9元不够覆盖场地维护成本（场地平整、垃圾清理、洗手间维护），差额由模式B和餐饮填补
- 经营理念：**9.9元不是价格，是获客成本**——每人补贴几块钱换来一个"第一次接触农场"的机会
- 营收预期：不重要，重要的是来的人数（转化为模式B的比例更重要）

**模式B（农场提供装备）**：
- 餐饮部分已在引擎A分析中涵盖
- 装备部分：帐篷+天幕+睡袋+防潮垫+灯——按次折旧使用
- 定价结构建议：单装备租赁（不含餐）与装备+餐饮打包价两种

# 产品二：长搭露营（年费制，100㎡小院）

```
使用维度：1✅ 2✅ 3✅ 4+扩展 5△ 6△ 7△ 8+扩展 9△ 10✅
```

## 1. 飞轮定位

**主定位**：复购锚点

长搭是"让客户长期留在农场"的产品。3600元/年的小院费用不高，但客户一旦交了年费，就会频繁来（"不来就亏了"），每次来都会产生餐饮消费。**长搭客户是农场最稳定的现金流来源**——不管淡季旺季，年费在年初就已经收了。

**辅助作用**：传播杠杆（长搭客户把小院当成自己的"第二个家"来布置，天然会在朋友圈和社交媒体展示）

## 2. 目标客群

- 画像：35-50岁，潍坊城区的稳定中产，有车。有露营基础或向往露营生活方式。工作压力大，需要一个"周末能去的地方"
- 痛点：每次露营都要带装备、搭帐篷、收装备——太累了。而且每次去都像一个"临时访客"，没有归属感
- 痒点：在农场有一个属于自己的小院——帐篷不需要收，下次来还是原样。甚至可以把小院布置成自己喜欢的样子（灯串、花、小摆件）
- 决策逻辑：来农场体验过露营 → 感觉很好但每次收拾太累 → 看到长搭选项 → 3600元/年，相当于300元/月——"一个月300元租了一个100平的小院，比去健身房划算" → 付年费 → 变成常客

## 3. 核心体验

"在松林里有自己的一个小院。上周末搭好的天幕、摆好的椅子、挂上去的灯串——这周末来的时候还是原样。不用搭、不用收、下次来它就是你的。"

## 4. 交付标准（+扩展：长搭客户的生命周期管理）

### 4.1 长搭客户的获客——靠体验转化，不靠广告

长搭不是"从外面找人来签约"的产品，而是**先通过模式A/模式B露营留住客户，客户来多了自然想升级成长搭**。

| 阶段 | 动作 | 触发条件 |
|:---|:---|:---|
| 第1-3次来 | 散客体验（模式A/B） | — |
| 第4次来 | 员工闲聊时提一句"您来得挺勤的，要不要考虑长搭？自己搭一个小院" | 客户被认出来了 |
| 第5次来 | 带客户看一眼已有的长搭区——"你看那些人，帐篷都搭好了不用收" | 客户看到实际场景 |
| 签约 | 签一年合同，划定100㎡区域 | 客户决策 |

**关键**：长搭不能主动推销，要等客户自己产生"每次收拾太累"的念头时自然引导。

### 4.2 长搭客户的日常运营

| 角色     | 加分                                                    | 扣分                            |
| :----- | :---------------------------------------------------- | :---------------------------- |
| **员工** | 定期巡查长搭区，帮客户偶尔收一下被风吹倒的东西、下雨时帮盖一下——"虽然没人说过需要，但做了客户会很感动" | 客户来发现小院被水淹了/东西被风吹乱了/隔壁搭到了自己区域 |
| **主管** | 每年组织2次长搭客户聚会（春/秋各一次），让大家互相认识——形成小社群                   | 交了钱后从不过问，一年都不说一次话             |
| **客户** | 每次来都感觉"这是我的地方"——有归属感                                  | 每次来都感觉"和散客区没什么区别"             |

### 4.3 长搭客户的续费

| 续费关键因素 | 说明 |
|:---|:---|
| 客户过去一年的使用频率 | 如果来了10次以上，续费概率高。如果只来了2-3次，续费概率低——与其挽留不如腾出位置给新客户 |
| 客户在社交媒体的分享频率 | 如果客户发了很多关于小院的朋友圈，说明他有"这是我的"的归属感——高度可能续费 |
| 主动询问 | 年费到期前1个月，主动问"明年还续吗？"——不要等到期了才问 |

## 5. 定价（△）

3600元/年，已定。评估：合理。
- 折合300元/月、10元/天
- 对比：潍坊周边长搭露营地年费通常在3000-5000元，3600元处于中等偏下
- 客户心态："一个月300元，去一次就够本了"——这个价格容易冲动决策

## 6. 增长路径（+扩展：续费与社群）

### 复购（续费）
- 使用频率是续费的最强预测指标。如果某长搭客户连续2个月没来，主动问候一次
- 年费到期前提供续费优惠（续费送等值餐饮券500元——相当于把年费拉回到3100元）

### 传播
- 长搭客户把小院当作"自己的空间"来布置，天然会在社交媒体展示
- 农场不需要激励长搭客户发帖——他们自己就会发

## 7. 决策结论

| 项目 | 内容 |
|:---|:---|
| 总体判断 | **做** |
| 优先级 | **中**（不主动拓客，从现有露营客户中自然转化。先把模式A/B跑稳再重点推长搭） |
| 启动建议 | 已有长搭客户继续维护；新长搭名额控制在现有散客露营客户的自然转化，不对外打广告。长搭区与模式A区的物理隔离完成后再扩数量 |

# 产品三：小院共创（长期储备产品）

```
使用维度：1✅ 2△ 3✅ 4+扩展 5─ 6△ 7△ 8+扩展 9─ 10✅
```

## 1. 飞轮定位

**主定位**：复购锚点（高层级）

如果长搭是"让客户来第二十次"的产品，小院共创是"让客户来二十年"的产品。

**辅助作用**：
- 传播杠杆（客户自己建小院=自己当农场代言人）
- 信任引擎（有人愿意花钱在农场建小院——这是对农场真实性的最有力背书）

## 2. 目标客群（△）

**不是"吸引很多人的产品"，是"等少数对的人"的产品。**

- 画像：认可农场理念、有审美、有动手意愿的人。年龄不限，但经济条件允许花几万块建一个小木屋或土团屋
- 触达方式：不对外宣传。等长搭客户中有人开始向往"有自己的房子"时，顺口提一句"那要不要自己建一个"

## 3. 核心体验

"在松林里有一个自己说了算的小院子。不是租的、不是临时搭的——它是我的。我可以建一座小木屋、种一圈花、搭一个户外厨房。朋友来了可以住，自己不来的时候交给农场帮忙经营。"

## 4. 交付标准（+扩展：启动策略）

### 启动原则

**先做一个样本，等人来找你。** 这个产品不做推广、不上线销售——因为需要建好一个看得见摸得着的实物，而不是计划和概念。

| 阶段 | 动作 | 时间预期 |
|:---|:---|:---|
| 样本期 | 农场自己建1-2个小院（或邀请内部员工/关系户做第一个共建者）。建好、使用、打磨 | 第1年 |
| 展示期 | 长搭客户来参观时会看到——"咦，这也是一个小院？"——形成向往 | 样本建成后 |
| 自然转化期 | 有人主动问"这个怎么弄？"——此时再推出小院共创方案 | 展示期后自然发生 |

### 合作模式（初步框架，实践中调整）

| 项目 | 内容 |
|:---|:---|:---|
| 谁建 | 共创人自己（或委托农场代建，费用自理） |
| 谁的地 | 农场提供土地（100-200㎡/院），共创人只有使用权，无产权 |
| 使用权年限 | 建议5年一签（不签永久——避免后续政策变动或农场规划调整时的纠纷） |
| 费用结构 | 方案A：年费（如3600元/年）+ 自建费用；方案B：一次性建院费（按面积算）+ 低年费 |
| 经营分成 | 共创人自己不住时，农场可对外出租，双方分成（建议农场20-30%/共创人70-80%） |
| 退出机制 | 共创人退出时：小院可转让给第三方（经农场审核）或农场以折旧价回收 |

## 5. 增长路径（+扩展：长期社群）

小院最大的价值不是"卖了几个院子"，而是**形成了一个高粘性的核心社群**：
- 小院主人们会把农场当作自己的"第二故乡"
- 他们会带朋友来→朋友也想建→自然扩大
- 小院主人在社交媒体上分享"我在乡下建了个小院"的过程——这个过程本身就是连载式的内容，传播力极强

## 6. 决策结论

| 项目 | 内容 |
|:---|:---|
| 总体判断 | **条件做**（先做样本，等人来找，不主动推广） |
| 前提条件 | 农场先建好1个样本（或内部找到第一个共建者），展示"小院是什么样" |
| 优先级 | **低**（长期储备产品，第1年重点是样本建设，第2年看效果再决定是否开放） |
| 启动建议 | 今年内建好1个样本小院（哪怕是农场自己出钱建一个木屋），让来露营的人能看到——有实物才有说服力 |

# 产品四：团建与宴会（B端客户）

```
使用维度：1✅ 2✅ 3✅ 4+扩展 5△ 6△ 7△ 8+扩展 9△ 10✅
```

> 说明：团建/宴会的**餐饮部分**已在引擎A产品分析（农村大席）中完成。本节专注**获客、接待、回访**三个引擎B主理人直接负责的环节。

## 1. 飞轮定位

**主定位**：利润中心

B端团建/宴会是农场高客单价收入来源。单场营收2000-5000元（含餐饮+场地+活动），单场毛利覆盖一周的场地运营成本。

**辅助作用**：传播杠杆（企业全员来到农场=几十个潜在的个人客户同时产生认知）

## 2. 目标客群

### 企业团建
- 画像：潍坊本地中小企业（15-40人），决策者是行政/HR（30-45岁女性）。预算敏感，人均不超过100-150元
- 决策路径：老板说"组织一次团建"→行政开始找场地→大众点评/小红书搜"潍坊团建"→看到松林农场→打电话咨询→实地看场地→报价→确认
- **获客渠道优先级**：

| 渠道 | 有效性 | 说明 |
|:---|:---|:---|
| ✅ 大众点评/美团 | 高（B端客户找场地首选平台） | 上线团建套餐（含场地+大席+活动选项），配真实环境照片 |
| ✅ 小红书搜索"潍坊团建"SEO | 中（需要内容积累） | 持续发布团建活动记录（客户授权的前提下） |
| ✅ 本地HR群/企业微信群 | 中（人脉型获客） | 运营卫星或引擎B主理人如果有本地资源，直接联系各公司行政部 |
| ✅ 已服务企业的转介绍 | 高（最精准） | 每场团建结束时问一句"有需要的话帮我们推荐一下" |
| ❌ 陌拜电话/扫楼 | 极低（不推荐） | 农场气质不适合销售式获客 |

### 宴会（寿宴/家庭聚会/同学会）
- 画像：家中有长辈过寿、同学聚会组织者、家庭聚会的晚辈。与团建不同，这类客户决策周期短（活动前1-2周才开始找场地）
- 获客方式：与团建渠道重叠，主要通过大众点评+小红书。老年人可能不会自己搜，但子女会帮他们搜

## 3. 核心体验

"这是我带同事/家人来过的最不一样的地方。不是在酒店换个厅吃饭，是在松林里摆长桌、吃大席、晚上还能围着篝火聊天。"

## 4. 交付标准（+扩展：团建接待全流程）

### 获客→接待→回访的完整流程

#### 第一阶段：咨询与报价

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **员工/主理人** | 电话/微信咨询时：先问清人数、预算、期望活动类型 → 3小时内发一份简明报价单（含场地+餐饮+活动选项+实景照片） | "你加我微信，我把资料发给你"——让客户去你资料里翻 |
| **客户**（行政） | 收到了报价单，一目了然——"这个可以直接拿去给老板看了" | 发了5条语音和3张图片，"你自己看吧" |

#### 第二阶段：实地看场地

- 看场地时，引导客户看三个地方：松林大席区（→ 布置效果）、篝火区（→ 夜间活动可能性）、天气备选方案（→ 打消下雨顾虑）
- 看场地后：当天发一条微信"今天看的那个位置还不错吧？有什么问题随时问我"——让客户觉得被重视

#### 第三阶段：活动前确认

- 活动前3天：确认人数+菜单+活动安排
- 活动前1天：发确认信息（天气预报+建议着装+导航定位+停车指引）

#### 第四阶段：活动现场

| 时间 | 动作 | 负责人 |
|:---|:---|:---|
| 客户到达前30分钟 | 场地布置完成（桌椅摆好、桌布铺好、野花摆上） | 现场员工 |
| 客户到达 | 主理人迎接，带到场地 | 引擎B主理人 |
| 活动期间 | 按预约方案执行（大席上菜/篝火/拔河等） | 现场员工 |
| 活动结束 | 主理人问"今天的活动怎么样？" | 引擎B主理人 |

#### 第五阶段：离店回访

| 角色 | 加分 | 扣分 |
|:---|:---|:---|
| **主管**（引擎B主理人） | 活动后24小时内发一条微信："今天辛苦了，同事们玩得开心吗？有什么建议随时告诉我"——附当天活动精选照片2-3张 | 无后续 |
| **客户**（行政） | 收到回访+照片→可以直接发到公司群→"今天的团建照片" | — |

## 5. 增长路径（+扩展：B端客户复购与介绍）

### 复购
- B端团建的复购逻辑不同：决策者（行政）可能会换工作、换了供应商就断了。所以维护的是"关系"而非"公司"
- 每年10月/11月（企业做下一年团建预算的时期）主动联系一次之前来过的行政："今年还有团建计划吗？"
- 每次联系不仅是问"要不要来"，而是分享农场的变化（"我们今年新做了窑炉面包/柴火灶/新的露营区"）——让客户觉得农场一直在更新

### 传播
- 团建活动结束后，给行政发送精选照片（包含"全员大合影+松林大席+篝火+精彩瞬间"）——行政会发到公司群/朋友圈
- 每场团建结束后，如果客户同意，发一条小红书（打码或肖像授权）——作为后续获客的内容素材

## 6. 决策结论

| 项目 | 内容 |
|:---|:---|
| 总体判断 | **做** |
| 优先级 | **中**（引擎B现阶段的重点是散客露营体验。团建是"有人找上门就接、没人找就不主动推"的产品） |
| 启动建议 | 大众点评上线团建套餐（含场地+大席+活动选项），配好照片即可；小红书持续发布团建活动记录（客户授权前提下）；维护好已有团建客户的关系 |
