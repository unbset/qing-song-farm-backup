### 一、活动分类

```
1. 按规模分类

   日常活动（每日/每周固定）
   - 采摘体验（季节性）
   - 捡鸡蛋（每日）
   - 农场参观（每日）

   周末活动（每周）
   - 自然手作课程
   - 面包窑体验
   - 篝火之夜（季节性）

   月度活动（每月1-2次）
   - 会员专属日
   - 农场公开日
   - 主题体验（松林音乐会/星空露营/丰收节）

   季度活动（每季度1次）
   - 大型节日活动（端午/中秋/国庆/元旦）
   - 客户答谢会
   - 公开化共建活动
```

### 二、月度排期

```
1. 排期原则
   - 日常活动不占用额外人力
   - 周末活动错开高峰时段
   - 月度活动提前30天确定
   - 避免同一天排期超过2个大型活动

2. 排期流程
   每月20日
   - 收集各板块下月活动需求和计划
   - 标注固定节日和节气节点

   每月25日
   - 制定下月活动日历
   - 确认各板块人力和资源
   - 在Hermes中发布活动排期

   每月28日
   - 启动下月首个周末活动的招募
   - 推送活动预告至社群
```

### 三、活动招募

```
1. 招募渠道

   自有渠道
   - 社群（O-06）：活动信息发布+接龙报名
   - 小程序：在线报名+支付
   - 公众号：活动推文
   - 到店推荐：客户到店时口头推荐

   外部渠道
   - 小红书/抖音：活动预告短视频
   - 大众点评/美团：活动页面
   - 合作方渠道：B端客户/社区/学校/企业

2. 招募信息模板

   标题：一句话吸引（含活动名称+日期+亮点）
   正文：
   - 活动内容（做什么/能带走什么/能拍什么）
   - 活动流程（时间线和环节）
   - 适合人群（亲子/成人/家庭）
   - 费用说明（含什么/不含什么）
   - 报名方式（链接/二维码/联系方式）
   - 截止时间

3. 招募节奏

   活动前14天：发布预告
   活动前7天：正式招募启动
   活动前3天：报名进度提醒（满额即止）
   活动前1天：确认名单 + 推送活动提醒
```

### 四、活动执行前确认

```
1. 活动前3天
   - 确认报名人数
   - 确认各板块准备情况
   - 确认物资和材料到位

2. 活动前1天
   - 发送活动提醒给已报名客户（时间/地点/注意事项）
   - 确认天气情况，备选方案提醒
   - 在Hermes中生成活动执行清单

3. 活动当天
   - 提前1小时到场布置
   - 签到准备（签到表/二维码）
   - 各环节负责人在位
```

### 五、活动后跟进

```
1. 当天
   - 活动照片整理
   - 活动参与数据录入Hermes

2. 24小时内
   - 活动照片/视频推送至参与者
   - 感谢信息发送
   - 邀请填写活动反馈

3. 7天内
   - 活动复盘（参与人数/满意度/收入/成本）
   - 推送下次活动预告
   - 未转化参与者跟进
```

### 六、验收标准

```
□ 月度排期在每月25日前完成并发布
□ 招募信息在活动前7天发布
□ 活动报名满额率≥60%
□ 活动执行按计划推进
□ 活动结束后24小时内完成照片推送
□ 活动复盘在7天内完成
□ 客户活动满意度≥4.5分
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 报名人数不足 | 加大宣传/降低价格/合并场次 |
| 活动当天天气突变 | 启动备选方案（室内/延期/取消+补偿） |
| 报名超额 | 设置候补名单/增加场次 |
| 活动冲突（多活动同时） | 优先保障高利润/高口碑活动 |
| 客户临时取消 | 候补名单替补/损失押金制度 |
| 活动物料未到位 | 替代方案/紧急采购 |

### 八、跨板块协作

- 活动排期确认：与**核心层/引擎A/引擎B/自然手作**协调
- 活动招募：与**O-06社群运营**配合推送
- 活动执行：与**G-04跨板块协调**衔接
- 活动数据：录入**G-03客户信息管理**

### 九、客户触点

- 活动招募信息的清晰度直接影响报名转化率
- 活动体验是客户对农场最直接的记忆点
- 活动后的照片/视频推送是二次传播的关键，也是客户社群分享的素材
