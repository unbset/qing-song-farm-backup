# 业务优先级矩阵

> 各业务的优先级排序与资源配置


业务优先级矩阵（四象限）

```
               盈利能力高
                     │
  B类·现金牛         │     ⭐A类·核心引擎
  长搭露营           │     餐饮矩阵
  窑炉零售           │     引流课→深度课
  手作零售           │     储值会员
 ──────────┼─────────────── 战略重要性高
  D类·培育/优化      │     C类·战略投入
  劳动换薪           │     核心层种养
  9.9露营           │     田园摄影
  社群运营           │     节气年卡
  小院共创           │     内容传播
                     │
               盈利能力低
               
```


### 精力分配

|类别|精力|优先级|考核|
|---|---|---|---|
|A类·核心引擎|**50%**|P0|利润+客流+转化率|
|B类·现金牛|**15%**|P1|维持|
|C类·战略投入|**25%**|P0-P1|战略指标（非利润）|
|D类·培育/优化|**10%**|P2-P3|有更好，没有也行|
