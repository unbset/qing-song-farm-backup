[SOP编号] B-02
[SOP名称] 散客露营退房流程
[执行人] 引擎B主理人
[替代人] 运营卫星成员（经培训后）
[执行时间] 退房日 8:00-12:00
[适用季节] 全年
[前置条件] 客户已入住；退房时间已告知（入住时已说明12:00前退房）
[AI接口] Hermes记录退房时间、客户反馈、装备归还状态
[AI提醒] Hermes 10:00推送未退房提醒，11:30推送催退提醒

---

### 一、退房前巡查（8:00-9:00）

```
1. 检查Hermes退房名单
   - 当日应退房营位数量
   - 标注有租赁装备的营位（需重点跟进）
   - 标注有额外消费的营位（需结清尾款）

2. 公共区域检查
   - 卫生间/淋浴间补充清洁
   - 垃圾站清空
   - 公共区域物资补充
```

### 二、退房办理流程

```
1. 客户退房接待
   - 引导至接待区办理退房
   - 微笑问候："昨晚休息得好吗？"

2. 租赁装备回收
   - 逐件清点归还装备
   - 检查装备是否完好（破损/污渍/丢失）
   - 损坏情况拍照记录并在Hermes标记
   - 客户签字确认归还

3. 费用结算
   - 核对住宿费用（是否已全额预付）
   - 结算额外消费（炭火/食材/饮品/装备租赁加时）
   - 押金退还（原路返回）

4. 征求意见
   - 一句话询问体验：还满意吗？有什么建议吗？
   - 记录客户反馈至Hermes
   - 邀请填写小程序评价
```

### 三、退房后检查（客户离开后）

```
1. 营位检查
   - 垃圾是否已清理（未清理的评价扣分并记录）
   - 地面有无遗留物品
   - 营位设施完好
   - 有无明火残留（重点！不可忽视）

2. 营位恢复
   - 垃圾清理
   - 地面平整
   - 设施归位
   - 如需深度维护（草皮修复/地面修整），立即安排

3. 在Hermes标记营位状态
   - "空置/可预订"或"维护中"
   - 记录退房时间和营位状况
```

### 四、后续跟进

```
1. 当日在Hermes记录
   - 客户退房时间
   - 客户反馈（原始语句记录）
   - 消费金额（住宿+附加消费）
   - 装备损耗情况

2. 离场后跟进
   - 当日发送感谢短信（含农场近期活动预告）
   - 推送社群邀请
   - 7天内推送下次活动信息
```

### 五、验收标准

```
□ 所有退房客户已办理完毕
□ 租赁装备已清点归还，损坏已记录
□ 费用已结清，押金已退还
□ 所有营位已检查并清理
□ 无明火残留确认
□ 客户反馈已录入Hermes
□ 退房营位已在系统中标记可用/维护
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 超过12:00未退房 | 致电联系，告知超时收费标准（按小时计费） |
| 装备损坏 | 按损坏程度协商赔偿，标准参照装备租赁协议 |
| 客户未自行清理营位 | 收取清理费（提前在规则中告知） |
| 营位发现明火未灭 | 立即处理，拍照记录，评估是否需要修正营位草皮 |
| 客户遗留物品 | 拍照记录，联系客户，按客户要求快递或留存 |
| 客户差评反馈 | 现场致歉 + 了解具体原因，次日由言渊回访 |

### 七、跨板块协作

- 退房营位释放后及时通知**运营卫星**，便于安排保洁和次日预订
- 退房后营位深度维护需求通知**核心层·种植养殖主管**
- 客户严重投诉上报告**言渊**，24小时内回访处理

### 八、客户触点

- 退房是客户离场前的"最后印象"，好的退房体验能对冲入住过程中的小问题
- 退房时的一句关怀（昨晚睡得好吗）比任何话术都有用
- 引导评价和复购的黄金窗口在退房后1小时内
