# 青松农场安全管理手册

> **性质**：安全管理总纲（非SOP）
> **适用对象**：全员
> **核心目标**：在3人团队+高频接触自然环境的条件下，建立一套覆盖消防/食品/活动/设施/应急的全域安全管理体系
> **关联SOP**：A-06食材安全管理、B-07露营区安全巡查、B-08篝火台与用火安全管理
> **编写日期**：2026-06-02

---

## 一、安全管理架构

### 1.1 安全第一责任人

言渊为农场安全总负责人，各板块主理人为该板块安全第一责任人。

| 板块 | 安全责任人 | 安全重点 |
|:---|:---|:---|
| 核心层·生态种养 | 种植养殖主管 | 农具安全/农药管理/动物安全/土地安全 |
| 引擎A·餐饮 | 引擎A主理人 | 食品安全/用火安全/设备安全 |
| 引擎B·露营住宿 | 引擎B主理人 | 防火安全/设施安全/夜间安全/活动安全 |
| 自然手作卫星 | 自然手作主理人 | 工具安全/材料安全/儿童安全 |
| 运营卫星 | 运营卫星成员 | 公共环境安全/巡检安全/信息安全 |
| 全员 | 所有人员 | 发现安全隐患即时上报（首问负责制） |

### 1.2 安全管理制度

1. **每日巡检制**：运营卫星按O-01每日开场巡检，发现安全隐患立即处理或上报
2. **每周自查制**：各板块主理人每周检查本板块安全状况
3. **每月联查制**：言渊每月组织一次全农场安全联合检查
4. **季度演练制**：每季度一次消防演练或应急演练
5. **事故上报制**：任何安全事故须在1小时内上报言渊

## 二、消防安全（最高优先级）

### 2.1 火灾风险评估

青松农场的火灾风险等级为**高**。原因：
- 1000+棵松树——松脂含量高，遇火极易燃烧且蔓延快
- 户外用火场景多——篝火、柴火灶、烧烤、面包窑
- 冬季干燥季节——松针堆积，一点火星即可引燃

### 2.2 防火硬件配置

| 位置      | 配备要求         |      数量       |
| :------ | :----------- | :-----------: |
| 篝火台     | 灭火器+防火水桶+防火毯 |     每处各1      |
| 引擎A厨房   | 灭火器+灭火毯      |     厨房内各1     |
| 柴火灶/烧烤区 | 灭火器+水桶       |     每处各1      |
| 面包窑区    | 灭火器          |       1       |
| 露营区公共区域 | 灭火器          |    每50米1个     |
| 停车场     | 灭火器          |       1       |
| 办公/储存区  | 灭火器          |     每房间1个     |
| 全农场     | 消防沙池         | 2处（核心区+露营区各1） |

**检查频率**：每月1日检查所有消防器材，压力不足的立即更换。

### 2.3 用火安全管理

**户外用火总原则**：

1. 风力≥6级时，禁止一切户外明火
2. 森林火险等级为高/极高时，禁止一切户外明火
3. 用火点必须与松林主干区保持≥15米安全距离
4. 每次用火必须有人在现场看守，严禁无人值守
5. 用火结束后必须确认余火完全熄灭方可离开

**各用火场景的具体安全要求**：

| 用火场景 | 安全要求                 | 关联SOP          |
| :--- | :------------------- | :------------- |
| 篝火   | 围挡内点火、专人看守、灭火后观察30分钟 | B-08篝火台与用火安全管理 |
| 柴火灶  | 固定位置、排烟正常、油锅不离人      | A-05柴火灶与烧烤协助   |
| 烧烤炉  | 烤炉在防火垫上、炭火熄灭后清理      | A-05柴火灶与烧烤协助   |
| 面包窑  | 专人操作、高温警示、儿童不可靠近     | —              |

### 2.4 松林防火专项

1. 秋季及时清理松针堆积（核心层负责，每年10月前完成）
2. 松林内禁止吸烟——设置专门的吸烟区（停车场或引擎A旁）
3. 松林内禁止私带明火（露营客户在指定区域用火）
4. 松林入口设置防火警示牌
5. 干燥季节增加松林巡逻频次

## 三、食品安全

### 3.1 食品安全责任

引擎A主理人为食品安全第一责任人，运营卫星负责每日巡检中的食品安全检查。

### 3.2 食品安全管理体系

食品安全管理的详细操作流程见SOP **A-06食材安全管理**，本手册仅列出核心原则：

**五大红线**（碰任何一条即视为严重事故）：

1. 过期食材上桌给客户食用
2. 生熟食材交叉污染
3. 客户食物中毒（无论是否责任在农场）
4. 食材储存温度不达标且未处理
5. 未留样或留样未满48小时即处理

### 3.3 食品留样制度

1. 每道菜品出餐前留样≥100g
2. 留样标注日期/时间/菜品名称
3. 留样冷藏保存48小时
4. 留样记录每日签字确认

### 3.4 过敏原管理

1. 菜单标注常见过敏原（花生/海鲜/乳制品/麸质/鸡蛋）
2. 客户询问时如实告知食材成分
3. 已知过敏客户的信息在客户档案中标注

## 四、活动与体验安全

### 4.1 客户活动安全分级

| 安全等级 | 活动类型 | 安全措施 |
|:---:|:---|:---|
| 低风险 | 参观/用餐/手作/拍照 | 常规看护，无需特别措施 |
| 中风险 | 采摘/捡鸡蛋/喂鸡/面包窑DIY | 引导+工具使用指导+儿童看管提醒 |
| 高风险 | 篝火/柴火灶/烧烤/攀爬类活动 | 专人全程看守+安全说明+防护装备 |

### 4.2 儿童安全（特别关注）

1. 儿童参加任何活动须有成人陪同
2. 儿童接触工具（剪刀/刻刀/热熔胶枪）须有导师指导
3. 篝火/柴火灶/烧烤等活动，儿童须保持≥2米安全距离
4. 农场水域（如有水塘/水池）设置围栏+警示牌
5. 建议家长为儿童购买意外保险（农场可提示但不强制）

### 4.3 活动安全告知

1. 所有付费活动开始前，向客户做1-2分钟安全说明
2. 高风险活动（篝火/柴火灶/烧烤）必须口头说明+书面提示
3. 安全说明内容包括：活动风险点、禁止行为、紧急疏散路线
4. 团建/宴会类大型活动需提前告知农场安全须知

## 五、设施与设备安全

### 5.1 设施安全检查

| 设施 | 检查频率 | 检查要点 |
|:---|:---:|:---|
| 露营区营位设施 | 每月 | 平台稳固、无松动/破损 |
| 步道/栈道 | 每月 | 无塌陷/无松动/雨后检查 |
| 围栏/围网 | 每周 | 无破损/无缺口（防动物逃逸+防野生动物进入） |
| 儿童活动区 | 每周 | 设施稳固/无尖锐边角/地面防滑 |
| 照明设施 | 每日 | 夜间照明正常 |
| 电气设备/线路 | 每月 | 无老化/无漏电/接地正常 |
| 供水设施 | 每月 | 水质检测/管道完好/冬季防冻 |

### 5.2 工具与设备安全

1. 各板块工具在使用后清洗归位
2. 锋利的工具（剪刀/刻刀/锯子）存放在儿童不可触及的位置
3. 电动工具（如有）由指定人员操作
4. 损坏工具应标记"待修"并隔离存放

## 六、应急响应

### 6.1 应急组织

```
总指挥：言渊
职责：全面指挥、对外联络、家属沟通

现场处置组：当日在场员工
职责：现场救护、人员疏散、初期灭火

通讯联络组：运营卫星成员
职责：拨打120/119、引导救援车辆、信息记录
```

### 6.2 应急预案

#### 预案A：火灾

```
1. 发现火情 → 大声呼救"着火了"
2. 初期火灾（可控）→ 就近取灭火器扑救
3. 火势失控 → 立即疏散客户至安全区域（停车场集合点）
4. 拨打119 → 告知地址+火势+被困人员
5. 言渊到场指挥
6. 引导消防车入场（运营卫星到路口接应）
7. 事后：保护现场、配合调查、48小时内完成事件复盘

疏散集合点：停车场（主）/ 引擎A前空地（备用）
```

#### 预案B：人员受伤/突发疾病

```
1. 发现有人受伤或突发疾病
2. 评估伤情/病情
3. 轻伤（擦伤/割伤/烫伤）→ 急救箱处理
4. 重伤/急症（骨折/大出血/心脏骤停/过敏休克）
   - 立即拨打120
   - 同时进行基础急救（止血/心肺复苏/保持呼吸通畅）
   - 安排人员到路口引导救护车
5. 通知言渊
6. 留存现场情况和处理记录
```

#### 预案C：食物中毒

```
1. 接到客户疑似食物中毒报告
2. 立即封存同批次食材和留样
3. 安排客户就医
4. 拨打120（如有多个客户同时出现症状）
5. 通知言渊
6. 配合卫生部门调查
7. 追溯食材源头
```

#### 预案D：恶劣天气

```
1. 关注天气预报预警信息（Hermes+气象APP）
2. 恶劣天气预警提前通知客户
3. 大风/暴雨/雷电 → 关闭户外活动，引导客户至室内或撤离
4. 露营客户 → 安排转移至安全区域或建议提前退房
5. 极端天气 → 闭园
```

#### 预案E：客户失踪/走失

```
1. 确认客户最后出现位置和时间
2. 组织在场人员搜索（农场范围内）
3. 搜索30分钟无果 → 报警
4. 联系家属
5. 配合警方搜索
```

### 6.3 急救箱配置

| 位置 | 配置标准 |
|:---|:---|
| 引擎A厨房 | 完整急救箱（含烫伤用药） |
| 引擎B接待处 | 完整急救箱（含户外急救用品） |
| 露营区公共区域 | 基础急救包 |
| 自然手作区 | 基础急救包（含创可贴/消毒用品） |
| 言渊办公室 | 完整急救箱（备用） |

**完整急救箱内容**：碘伏/酒精、创可贴（多种规格）、无菌纱布/敷料、医用胶带、弹性绷带、三角巾、一次性手套、剪刀、镊子、退热药、止泻药、抗过敏药、烫伤膏、藿香正气水、速效救心丸、冰袋。

**检查频率**：每月1日检查所有急救箱，补充消耗品、更换过期药品。

### 6.4 紧急联系方式

| 联系对象 | 号码 | 备注 |
|:---|:---|:---|
| 火警 | 119 | 报清地址+火势+联系人 |
| 急救 | 120 | 报清地址+伤情+联系人 |
| 报警 | 110 | — |
| 言渊 | 见内部通讯录 | 第一通知人 |
| 最近医院 | 见内部通讯录 | 提前确认导航地址 |

## 七、保险与责任

### 7.1 农场必须购买的保险

| 保险类型 | 覆盖范围 | 建议保额 |
|:---|:---|:---:|
| 公众责任险 | 客户在农场范围内的人身/财产损失 | ≥100万 |
| 雇主责任险 | 员工工伤 | 按法规要求 |
| 食品责任险 | 食品安全事故 | 建议附加 |

### 7.2 客户告知

1. 农场入口和活动区域张贴安全须知
2. 高风险活动开始前口头告知风险
3. 建议客户自行购买意外保险（非强制）
4. 农场不对客户因违反安全规则导致的伤害承担责任

## 八、事故报告与复盘

### 8.1 事故分级

| 级别 | 定义 | 上报时限 |
|:---:|:---|:---:|
| 一级（重大） | 人员重伤/死亡/火灾/食物中毒 | 1小时内上报言渊，24小时内完成报告 |
| 二级（较大） | 人员轻伤需就医/设备严重损坏 | 2小时内上报言渊，48小时内完成报告 |
| 三级（一般） | 轻微擦伤/设施小损坏/未遂事件 | 当日在Hermes记录 |

### 8.2 事故报告模板

每起事故（含未遂事件）应记录以下内容：

```
日期：
时间：
地点：
事故类型：
涉及人员：
事故经过：（客观描述，不推定责任）
处理过程：
处理结果：
原因分析：
改进措施：
责任人：
是否闭环：
```

### 8.3 事故复盘流程

1. 一级事故：言渊主持复盘，全员参加，形成书面整改方案
2. 二级事故：相关板块主理人主持复盘，言渊参与
3. 三级事故：当事人在晨会上简述原因和改进措施

所有事故记录存入Hermes的Incident归档，作为安全培训案例。

## 九、安全培训

### 9.1 入职安全培训

新员工入职时必须完成以下安全培训：

1. 消防器材使用方法（实操）
2. 急救箱位置和基本急救技能
3. 各板块安全风险点
4. 应急预案（五大预案的内容和职责）
5. 紧急联系方式

### 9.2 定期安全培训

| 培训内容 | 频率 | 对象 |
|:---|:---:|:---|
| 消防演练（灭火器使用+疏散） | 每季度 | 全员 |
| 急救技能（包扎/心肺复苏） | 每半年 | 全员 |
| 食品安全培训 | 每月 | 引擎A人员 |
| 户外安全培训 | 每季度 | 引擎B人员 |
| 安全事故复盘学习 | 每次事故后 | 全员 |

## 十、安全文化的日常落地

### 10.1 每日

- 晨会上通报当日的安全注意事项（天气预警/特殊活动安全提醒）
- 开场巡检的安全检查项（O-01）

### 10.2 每周

- 各板块自查本板块安全状况
- 反思：本周有没有差点出事的情况（near miss）？记录下来

### 10.3 每月

- 言渊组织全农场安全联查
- 检查消防器材和急救箱
- 月度安全记录归档

### 10.4 每季度

- 消防演练或应急演练
- 安全培训课程
