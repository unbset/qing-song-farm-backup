[适用季节] 春季生长期3-5月 / 秋季生长期9-10月

[AI接口] 每天在Hermes中记录生长状态、浇水施肥情况和病虫害观察结果
[AI提醒] Hermes每天早晨推送当日生长阶段管理重点

---

### 一、本阶段工作重点

| 维度 | 重点 | 标准 |
|:---|:---|:---|
| 浇水 | 保持土壤湿润但不积水 | 视天气2-3天一次，上午10点前完成 |
| 追肥 | 每10-15天施酵素稀释液 | 稀释比例1:100 |
| 除草 | 人工拔除，不使用除草剂 | 每周至少1次 |
| 搭架 | 蔓生品种及时搭架引蔓 | 抽蔓时立即进行 |
| 病虫害巡查 | 每天观察，早发现早处理 | 每天 |
| 间苗/补苗 | 保证合理密度 | 苗期完成 |

### 二、每日执行步骤

```
1. 早晨到农场后，先绕全部种植区走一圈（约15-20分钟）
   [客户此时：看到有人在田间巡查，会产生"这个农场有人管"的安全感]
   观察重点：
   - 土壤干湿状况 → 决定当日是否浇水
   - 叶片状态（颜色/形态/是否有异常斑） → 判断病虫害
   - 生长速度（与预期对比） → 判断肥力是否充足

2. 根据巡查结果执行当日操作
   需浇水 → 上午10点前完成浇水
   需追肥 → 按比例稀释酵素，浇施
   有杂草 → 当日拔除
   有病虫害迹象 → 按异常处理执行

3. 搭架/绑蔓
   检查已有支架是否牢固
   新抽蔓的植株及时引蔓上架

4. 在Hermes中记录当日操作
```

### 三、验收标准

```
□ 当日浇水/追肥/除草等工作已完成
□ 巡查记录已录入Hermes
□ 病虫害观察无异常，或异常已处理
□ 搭架引蔓工作跟上生长速度
□ 展示区整洁，客户可参观
```

### 四、异常处理

| 异常 | 识别方法 | 响应 |
|:---|:---|:---|
| 蚜虫 | 叶片卷曲、背面有蜜露 | 喷酵素稀释液或辣椒水，严重时用低毒生物农药 |
| 白粉病 | 叶片表面白色粉末状 | 立即移除病叶，加强通风，喷小苏打水 |
| 缺肥 | 叶片发黄、生长缓慢 | 追施酵素液，3天后观察是否改善 |
| 缺水 | 叶片萎蔫 | 立即浇水，次日检查恢复情况 |
| 涝害 | 叶片发黄、根部腐烂 | 停止浇水，松土透气，严重时挖排水沟 |

### 五、客户触点

本阶段客户可参与的活动：除草劳动换薪（15分钟8元）、搭架共建、酵素制作课
本阶段客户能看到的内容：快速生长的蔬菜、开花结果过程、搭好的整齐支架
