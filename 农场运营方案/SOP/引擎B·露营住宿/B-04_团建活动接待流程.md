[SOP编号] B-04
[SOP名称] 团建活动接待流程
[执行人] 引擎B主理人（活动全程跟进）
[替代人] 言渊
[执行时间] 活动开始前14天洽淡 → 活动前3天确认 → 活动当天全程跟进
[适用季节] 全年
[前置条件] 团建需求已确认；活动方案已通过Hermes生成并与客户确认；食材已预约
[AI接口] Hermes存储团建客户档案和活动方案模板；生成活动报价单和日程表
[AI提醒] Hermes在活动前7天/3天/1天分别推送跟进提醒和天气预警

---

### 一、接单与需求确认

```
1. 初次接洽
   - 记录客户基础信息（企业名称/人数/预算/期望日期）
   - 了解团建目的（团队融合/放松/户外体验/庆祝）
   - 了解参与者画像（年龄分布/是否有老人儿童/户外经验）

2. 方案推荐
   - 根据人数和时间推荐基础方案选项：
     半天团建（上午/下午）：采摘+柴火灶午餐+简单活动
     全天团建：松林活动+采摘+烧烤/火锅+篝火晚会
     定制团建：根据企业需求定制活动
   - 根据预算推荐餐饮方案（人均50/80/120三档）

3. 报价确认
   - 在Hermes生成报价单
   - 发送给客户确认
```

### 二、活动前准备

```
1. 活动前7天
   - 确认最终人数和活动方案
   - 收取定金（不低于50%）
   - 确认是否有特殊饮食需求（素食/过敏/忌口）
   - 向引擎A预约团餐时间和餐标

2. 活动前3天
   - 查看天气预报，准备备选方案
   - 确认活动物料清单（道具/扩音器/座椅/签到表）
   - 向核心层确认采摘区预留情况
   - 在Hermes创建团建活动日程

3. 活动前1天
   - 场地布置确认（活动区域/休息区/用餐区）
   - 物料装袋准备
   - 引擎A食材备料确认
   - 向全员通报次日团建安排
```

### 三、活动当天接待

```
1. 迎接（8:30-9:00）
   - 提前1小时到场，确认所有设施就位
   - 在停车场迎接，引导至活动集合区
   - 安排签到（企业可自行安排或由农场主持）
   - 提供欢迎饮

2. 开场（15-20分钟）
   - 农场主理人致欢迎词（时长3-5分钟）
   - 介绍农场概况和当日活动流程
   - 提醒安全事项和基础规则
   - 告知厕所/饮水/医务点位置

3. 活动分环节
   - 由引擎B主理人全程带领
   - 每个环节准时开始（控制时间节奏）
   - 灵活穿插自由活动时间
   - 核心环节设置拍照点

4. 餐饮环节
   - 引导至引擎A用餐区
   - 提前安排好座位（按企业分组）
   - 上菜节奏：先冷盘/凉菜 → 主菜 → 主食 → 甜品
   - 企业领导讲话时段预留（如需）

5. 收尾
   - 所有活动环节结束后总结
   - 合影（在农场标志性位置：松林/营地/品牌墙）
   - 引导自由活动或返程
   - 赠送伴手礼（农场时令产品）
```

### 四、活动后跟进

```
1. 当日整理
   - 场地清理，物料归位
   - 在Hermes录入活动参与人数/实际消费/异常记录
   - 拍摄的活动照片整理打包

2. 3天内跟进
   - 发送活动照片给企业对接人
   - 发送感谢信息
   - 邀请加入企业会员社群
   - 推送下次活动信息（季度答谢/新品体验）

3. 长期维护
   - 建立团建客户档案
   - 季度回访，推送新方案
   - 年框客户签约跟进
```

### 五、验收标准

```
□ 活动方案已与客户确认并签署
□ 定金已收取
□ 活动前3天一切物料准备就绪
□ 活动当天各环节准时推进
□ 客户反馈满意度≥4.5分（5分制）
□ 尾款在活动结束后当天结清
□ Hermes已完整记录客户信息和活动数据
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 活动当天下雨 | 启动备选方案（雨棚/室内活动改版） |
| 实际人数少于约定 | 按合同约定执行（通常提前48小时可免费调整） |
| 客户临时增加项目 | 评估能力和时间，可满足的加收费用，不可满足的明确告知 |
| 参与人员受伤 | 立即急救，严重者送医，记录事件 |
| 客户对方案不满意 | 现场沟通调整，能力内的满足，能力外的致歉并提供补偿 |
| 引擎A能力不足 | 提前外采或调整菜单，人数过多时加聘兼职帮工 |

### 七、跨板块协作

- 与**引擎A**：确认团餐人数/餐标/时间，提前3天锁定
- 与**核心层**：预留采摘区，准备体验物料
- 与**运营卫星**：协调人员支援，管理现场客户体验
- 与**自然手作卫星**：若方案包含手作环节，提前预约手作导师时间
- 与**言渊**：大型团建（50人以上）需言渊现场协调

### 八、客户触点

- 团建客户是B端高价值客户，一次满意的团建可带来企业年框合作
- 企业对接人是关键触点，保持专业高效的沟通语气
- 参与者的现场体验决定口碑传播，设置"值得发朋友圈"的场景
- 伴手礼不要应付，一把农场蔬菜比廉价小礼品更有记忆点
- 活动照片是二次传播的重要素材，确保每场团建都有专业拍照
