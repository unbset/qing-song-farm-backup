[SOP编号] A-02
[SOP名称] 收档流程
[执行人] 引擎A主理人
[替代人] 言渊
[执行时间] 每日营业结束后（夏季约21:00 / 冬季约20:00），预计耗时50分钟
[适用季节] 全年
[前置条件] 最后一桌客户已离开；炉灶已全部关闭
[AI接口] Hermes记录当日营业收入、食材消耗量、次日备料建议
[AI提醒] Hermes在收档时间推送检查清单；根据当日消耗自动生成次日食材采购单

---

### 一、收档执行步骤

```
1. 库房盘点
   - 清点剩余食材（可存储的/不可存储的分类）
   - 已开封食材密封冷藏，标注日期
   - 不可隔夜食材（叶菜/已切配半成品）记录量并在Hermes标记
   - 肉类/乳制品检查保质期并记录剩余量

2. 厨房清理
   - 炉灶和排烟口清洁（每日必须）
   - 操作台面消毒
   - 地面清洗（防油滑）
   - 厨余垃圾分类（厨余进堆肥区 / 油脂密封回收）

3. 餐具处理
   - 餐具清洗消毒
   - 检查破损，补充备量
   - 归位摆放整齐

4. 用餐区整理
   - 桌面/椅面清洁
   - 户外桌椅收入棚内或加盖防雨布
   - 垃圾清理，垃圾桶清洗
   - 检查客户是否有遗留物品

5. 设备关闭
   - 炉灶总阀关闭
   - 冷藏/冷冻柜确认正常运转（不关闭）
   - 排烟系统延时关闭（运行15分钟排净余烟）
   - 空调/取暖设备关闭
   - 灯光关闭（保留夜间安全灯）
```

### 二、营业数据录入

```
1. 在Hermes录入当日数据
   - 营业收入（分项：火锅/烧烤/柴火灶/饮料/其他）
   - 接待客户数
   - 食材消耗量（与库存对比）
   - 异常事件记录

2. 生成次日计划
   - Hermes根据消耗自动生成次日备料清单
   - 确认核心层食材预约（需提前告知种植养殖主管）
   - 外采清单生成
```

### 三、安全确认

```
□ 燃气总阀关闭
□ 所有电器已断电（冷藏设备除外）
□ 所有门窗已锁闭
□ 灭火器归位
□ 垃圾桶已清空
□ 无明火源
```

### 四、异常处理

| 异常 | 响应 |
|:---|:---|
| 食材库存积压 | 次日调整菜单主推消耗/员工餐消化/通知运营卫星安排加工储存 |
| 设备故障发现 | 在Hermes记录故障，晨会安排维修 |
| 客户遗留物品 | 拍照记录，在Hermes标记，联系客户次日自取或快递 |
| 当日损耗过高 | 分析原因（备料过量/保存不当/品质问题），调整次日采购量 |
| 冷藏设备异常 | 食材转移至备用冷柜，报修 |

### 五、跨板块协作

- 向**核心层**反馈当日食材使用情况，调整次日供应量
- 向**运营卫星**通报次日预计接待量，便于排班
- 向**言渊**汇报当日营业数据（Hermes自动生成）
- 剩余可食用的食材可转为员工餐

### 六、客户触点（间接）

- 收档质量影响次日开档效率和食材新鲜度
- 清洁质量反映在客户次日预约评价中
- 食材管理直接影响损耗率和利润率
