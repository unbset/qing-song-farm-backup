## obsidian-skills

`obsidian-skills` 是一个 **Agent Skill 包**，它教 AI 助手（如 Codex CLI、Claude Code）如何正确地操作 Obsidian。你装到 `~/.codex/skills/` 之后，Codex 就学会了：

| 子技能 | 作用 |
|--------|------|
| **`obsidian-markdown`** | 写 Obsidian 格式的 Markdown（`[[]]` 双向链接、`![[嵌入]]`、Callout、Properties 等） |
| **`obsidian-bases`** | 创建和编辑 Obsidian Bases（数据库视图） |
| **`json-canvas`** | 创建和编辑 Canvas 白板文件 |
| **`obsidian-cli`** | 通过 Obsidian CLI 操作 vault（插件/主题开发） |
| **`defuddle`** | 从网页提取干净 Markdown 内容 |

**简单说：** 你装好这个 skill 后，跟 Codex 说"帮我在 Obsidian vault 里创建一个笔记，加上 Callout 和 Tags"，Codex 就能写对语法、用对格式。

**`.skills\功能介绍.md`** — 一份简洁的技能介绍和运行机制文档（约950字），包含：
- 解决的问题
- 使用前提（两个文件）
- 运行机制（进入项目时、操作完成后、决策记录）
- 注意事项
- 使用示例
- 适用项目类型

**`project-knowledge-ops` 技能本体**（位于 `~/.codex/skills/`）— 包含完整的SKILL.md指令，定义了：
- 知识库读取规则
- 自动更新机制（4种触发条件 + 检查逻辑）
- 持续学习日志更新规则
- 搜索优先级策略
- 与Obsidian的联动方式
- 静默规则（不浪费token）

重启 Codex 后生效。以后用其他项目时，只需在根目录放一份 `_项目知识库.md` 就能复用。
