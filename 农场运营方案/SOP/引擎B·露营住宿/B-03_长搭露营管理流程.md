[SOP编号] B-03
[SOP名称] 长搭露营管理流程
[执行人] 引擎B主理人
[替代人] 言渊
[执行时间] 签约期：按需 / 入住期：每周巡查至少2次 / 退租期：退租当日
[适用季节] 全年（长搭合约通常3-12个月）
[前置条件] 长搭营位已划定（固定区域）；长搭协议模板已在Hermes中
[AI接口] Hermes管理长搭客户档案、合约到期提醒、费用记录
[AI提醒] Hermes在合约到期前30天/7天/1天推送续约提醒；费用逾期3天推送催缴提醒

---

### 一、长搭客户招募与筛选

```
1. 招募渠道
   - 散客转化：多次入住的散客优先推荐长搭方案
   - 社群发布：农场社群发布长搭招募信息
   - 老客推荐：现有长搭客户推荐新客（带新优惠）

2. 客户筛选
   - 面谈了解（使用目的/使用频率/是否爱惜场地）
   - 优选：长期户外爱好者/家庭客户/内容创作者
   - 慎选：频繁聚会/大量访客/有违规记录者
```

### 二、签约与收费

```
1. 合约内容
   - 营位编号和面积
   - 租期（3/6/12个月）
   - 费用（月付/季付/年付及优惠）
   - 使用规则（可携带设备/访客管理/卫生要求）
   - 退租条款和押金标准

2. 收费标准
   - 参考标准：月租=散客单次价格的8-10晚费用
   - 年付优惠：年付=10个月费用
   - 押金：1个月租金

3. 签约流程
   - 客户签署电子合约（Hermes生成）
   - 收取首期费用+押金
   - 分配营位，在Hermes标记"已租"
   - 发放长搭客户手册和营位钥匙/门禁
```

### 三、长搭期间管理

```
1. 定期巡查（每周至少2次）
   - 营位整洁度（物品堆放/垃圾/卫生）
   - 设备完好度（帐篷/天幕/电源/设施）
   - 是否存在违规行为（私搭乱建/明火/噪音）
   - 拍照记录，在Hermes填写巡查记录

2. 客户关系维护
   - 长搭客户到访时主动问候
   - 每月至少一次沟通（使用体验/需求/建议）
   - 长搭客户生日/节日发送祝福
   - 新活动/新设施优先通知长搭客户体验

3. 访客管理
   - 长搭客户可邀请访客（需提前告知引擎B）
   - 访客车辆按散客标准收费（或约定免费次数）
   - 访客人数有上限（不超过营位容量的2倍）
   - 访客需遵守农场规则（安静时间/火源管理）
```

### 四、长搭客户互动与消费引导

```
1. 互动机制
   - 长搭客户是农场的"半内部成员"，参与感越强、续约率越高
   - 邀请参加农场内部活动（采摘节/松林音乐会/手作体验）
   - 长搭客户专属活动（季度长搭聚会/烧烤之夜）
   - 建立长搭客户社群（单独群组，互通有无）

2. 消费引导
   - 引擎A用餐：长搭客户享9折
   - 引擎A食材外售：长搭客户优先预订
   - 核心层采摘：长搭客户免费体验（限本人）
   - 自然手作：长搭客户享8折
   - 邀请长搭客户参加公开化共建活动（参与感+归属感）
```

### 五、续约与退租

```
1. 续约
   - 合约到期前30天Hermes推送续约提醒
   - 引擎B主理人主动联系沟通续约意愿
   - 续约优惠（续约3个月享95折/续约6个月享9折）
   - 续约后更新合约和费用记录

2. 退租
   - 客户提前15天书面通知
   - 退租当日现场验收营位
   - 营位恢复标准：地面无损坏、垃圾已清理、设备已拆除
   - 验收合格后退还押金（扣除损坏费用）
   - 在Hermes标记营位"空置可租"
```

### 六、验收标准

```
□ 长搭合约签署完整，费用已收齐
□ 营位巡查按频率执行并记录
□ 客户关系维护动作到位（月度沟通/节日祝福）
□ 访客管理规范执行
□ 续约提醒按时推送
□ 退租验收合格，押金已退还
□ Hermes客户档案完整
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 长搭客户欠费 | 提醒→催缴→逾期15天停用营位→逾期30天解除合约 |
| 长搭客户违规（噪音/明火/私搭） | 首次警告/二次罚款/三次解除合约 |
| 长搭客户损坏设施 | 按价赔偿，从押金扣除 |
| 长搭客户长期不使用 | 主动沟通了解原因，提供转让或暂停方案 |
| 天气损坏长搭设备 | 农场提前预警通知客户处理 |
| 长搭客户要求提前解约 | 按合约条款执行（提前30天通知/扣除1个月押金） |

### 八、跨板块协作

- 长搭客户的配送需求（食材/物品）由**运营卫星**协调
- 长搭客户参加**核心层**共建活动，由运营卫星统一安排
- 长搭客户消费记录同步至**Hermes**客户档案
- 长搭客户推荐新客户，纳入**会员裂变机制**

### 九、客户触点

- 长搭客户是农场最稳定的客群，维护成本低、复购率高
- 长搭客户的"归属感"比"性价比"更重要——让他们觉得"这是我在农场的一个家"
- 长搭客户的访客是新客转化的最佳渠道，访客体验直接影响新客转化率
- 长搭客户好的续约率是农场现金流稳定的重要保障
