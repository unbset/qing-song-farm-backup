## 前置说明：田园摄影的定位

田园摄影不是农场的独立获客产品——它是**附着在其他产品之上的增值服务**。它的客户不是"专门来拍照的人"，而是"本来就在农场的人——顺便拍一组好看的照片"。

| 产品 | 拍摄场景 | 目标客户 |
|:---|:---|:---|
| 自然教育 | 孩子在松林里上课的自然抓拍 | 已在农场上课的家庭 |
| 手作体验 | 妈妈和自己的手作成品合影 | 已在做手作的妈妈 |
| 自然生日会 | 寿星+朋友+松林+蛋糕的全程记录 | 来办生日会的家庭 |
| 家庭露营 | 松林+帐篷+落日的氛围写真 | 来露营的家庭/情侣 |
| 四季庆典 | 活动现场的纪实摄影 | 来参加活动的所有客户 |

**一句话定位**：田园摄影卫星不是"开一个摄影工作室"，是**把"帮客户拍照"变成农场的一个标准服务环节。**

---

## 1. 飞轮定位

**主定位**：传播杠杆

农场的照片质量决定了农场的社交媒体传播效率。客户在农场拍到了好照片→发朋友圈/小红书→朋友看到→也想来。**田园摄影的价值核心不是卖摄影服务赚钱，是提升每一次客户体验的"出片率"——从而提升农场的整体传播效率。**

**辅助作用**：
- 利润中心（摄影服务本身有利润空间，且几乎没有物料成本）
- 信任引擎（专业照片让农场看起来"认真"——"一个连拍照都做好的农场，其他也不会差"）

---

## 2. 目标客群

### 主客群一：已在农场的客户——"顺手拍一组"

- **家庭亲子（妈妈+孩子）**：孩子在上自然教育课、或来露营、或来参加活动——抽30分钟拍一组亲子照。妈妈的心理：来都来了，顺便拍一组
- **情侣/闺蜜**：来露营或参加活动——"帮我俩拍几张"
- **寿星家庭**：办生日会时，顺带拍一组全家福

### 主客群二（来自凡朴农场的启发）：中老年女性——"专程来圆一个田园梦"

这是青松农场之前完全忽视的客群，但可能是田园摄影最大的市场。

- 画像：55-70岁，潍坊城区或下属县城。退休或接近退休，有稳定的退休金。子女已成年，有自己的社交圈（姐妹团/广场舞群/老同事群）
- 痛点：年轻时在乡村生活过，现在住在城市里，想"回去看看"但老家已变样；影楼的拍照太假、太贵、太折腾；市面上几乎没有专门为这个年龄段设计的"出片"产品
- 痒点："穿上好看的裙子、在真正的田野里拍一组不像影楼照片的照片"——发到姐妹群里，大家会问"在哪拍的"
- 决策逻辑：女儿在小红书看到农场的照片 → 转发给妈妈 → 妈妈叫上几个姐妹 → 一起来 → 拍了一组 → 发到姐妹群/朋友圈 → 其他人问"在哪" → 裂变
- 传播力：**中老年群体在微信群的传播力极强——一个人拍了，整个群都会知道。** 这个传播效率高于朋友圈。

### 次客群：专程来拍照的客户（先有摄影产品才有的客群）

- 小红书用户——看到别的农场能拍出好看的照片→"我也想去拍一组"
- 孕期妈妈——想拍一组"自然风孕照"，农场松林是天然背景
- 家有老人的家庭——想带父母出来走走、拍一组自然风全家福

### 决策逻辑

**顺手拍版**：
"来农场参加自然教育课 → 看到有跟拍服务 → 98元/组，30分钟 → '来都来了，拍一组吧' → 加一个服务 → 拍完收到照片 → 发了朋友圈"

**专门来版**：
"在小红书看到有人在农场拍了亲子照 → '好好看，在哪拍的？' → 看到是青松农场 → 预约摄影服务 + 顺便在农场待一天"

## 3. 核心体验

"在松林里拍了一组照片，没有影棚的假背景、没有僵硬的摆拍姿势。孩子在追鸡、在捡松果、在跑——摄影师在旁边抓拍。拿到照片的时候感觉不像影楼拍的那种修图修到认不出的照片，像是'我们真实的一个下午'。"

## 4. 产品设计（+扩展：拍摄服务模式）

### 4.1 三类服务模式

#### A. 跟拍陪拍（核心产品——客户在农场活动时的1小时跟拍）

| 项目 | 内容 |
|:---|:---|:---|
| 定价 | 98元/组（1小时，精修10张+原片全送）/ 188元/组（2小时，精修20张+原片全送） |
| 时长 | 1-2小时 |
| 适合场景 | 亲子游、露营、情侣周末、家庭聚会 |
| 交付 | 拍摄后5个工作日内交付精修图（电子版） |
| 预约方式 | 提前2天预约（确保摄影师有空档） |
| 拍摄风格 | 自然纪实风——不摆拍/不换装/不进影棚，在农场真实场景中抓拍 |

**为什么定价98-188元——而不是更高或更低**：
- 潍坊城区亲子摄影馆的单次拍摄通常在600-1200元（含服装+化妆+场景），但客户需要花半天时间去影楼、排队、等修片
- 农场的拍摄不需要额外去任何地方——客户本来就在农场，拍完接着玩
- 98元/1小时的价格比影楼便宜，但比"手机随手拍"贵，定位是"客户不需要犹豫的价格"

#### B. 场景服务（轻量服务——适合批量交付的场景）

| 项目 | 内容 |
|:---|:---|:---|
| 定价 | 19.9元/张（打印装框，现场取片）或 38元/组（5张电子版，拍摄+选片<15分钟） |
| 场景 | 在农场设1-2个固定的"最佳拍照点"（一棵形态好的松树下/一处自然花丛边/一个木制秋千）——摄影师定点等，客户路过排几张 |
| 适合 | 四季庆典、自然运动会等大型活动——客户人流大、不需要1小时跟拍，但想要一张"到此一游"的好照片 |
| 交付 | 现场拍→现场选→扫码下载电子版（或现场打印） |

**这个模式的商业价值**：在大型活动中，19.9元/张是几乎不需要决策的价格。如果有100个家庭到活动，10%的购买率=10组×19.9元=200元的纯增量收入（成本几乎为零），而且每张照片都是一次社交媒体的传播机会。

#### C. 内容生产服务（对内——田园摄影卫星对运营卫星的内部服务）

田园摄影卫星不仅是面向客户的摄影服务，也是**农场自己的内容生产部门**。每一组跟拍中产出的照片，精选一部分留作农场的宣传素材。

| 内部服务 | 说明 |
|:---|:---|:---|
| 客户跟拍中的内容沉淀 | 每拍一组客户，精选2-3张作为农场宣传素材（需客户授权同意） |
| 四季变化记录 | 定期拍摄农场的四季变化（同一角度不同季节），用于长期品牌建设 |
| 产品素材拍摄 | 为手作零售产品拍摄产品图 |
| 活动实拍 | 四季庆典/自然运动会的现场摄影记录 |

### 4.2 借鉴案例

#### 核心案例：成都凡朴农场——"为中老年阿姨圆一个田园梦"

凡朴农场（成都崇州）是国内田园摄影最成功的案例之一，2016年推出摄影业务，2017年爆火。它的模式和青松农场的条件高度相似——一个真实的、运营中的农场，不是人造摄影基地。

**核心数据**：
- **占地面积**：30亩（其中摄影专用区域约3-5亩，其余仍为农场正常运营）
- **目标客群**：55-70岁中老年女性——这是一个被市场忽视的蓝海群体
- **定价**：218元/人/天（含5套服装换装+专业摄影师跟拍+农家生态午餐+全天休闲体验）
- **高峰期日接待量**：400-500人
- **年收入增长**：推出田园摄影后，农场整体年收入**增长50%**
- **客流时间**：**主力集中在周一到周五的工作日**（退休群体的时间自由），完美填补了乡村旅游"周末火爆、平日冷清"的短板
- **场景设计**：法式田园、欧式苏格兰、西部牛仔、藏族雪山——不是人造影棚，是在农场真实土地上搭建的沉浸式场景
- **出片风格**：不P图（客人几乎不要求"P瘦一点"），保留皱纹、白发、雀斑——"呈现生命之美"
- **传播路径**：熟人推荐为主要获客渠道（姐妹团/老同事群/广场舞群）

**模式的核心逻辑——不是"拍照"，是"圆梦"**：
凡朴的创始人涂海霞（前媒体人）发现：55-70岁这一代女性经历了城乡巨变，内心深处有强烈的"回到乡村、找回记忆"的愿望。农场的摄影不是影楼式的服化道摆拍——**是让客人穿上衣服、拿起农具、真正在田间劳作，摄影师在旁边抓拍。** 客人不是在"演"，是在"回到过去"。

> "阿姨们也不会要求P图，这不是她们的追求。她们希望去呈现她的生命之美，所以我们基本都是出原片。"

**可借鉴的关键点**：

| 凡朴的做法 | 青松农场的可借鉴点 |
|:---|:---|
| 目标客群是55-70岁中老年女性——消费力强、社交需求强、工作日有空 | 青松农场增加这个客群定位——**不只是增收50%的潜力，还填补了工作日的营收空白** |
| 218元/人/天（含5套服装+跟拍+午餐+全天休闲）——不是"拍照"，是"一天的沉浸式体验" | 青松可以设计类似的全天体验套餐：上午换装拍照+中午农场午餐+下午自由活动（逛农场/喝茶/摘菜） |
| **工作日为主要客流时段**——退休群体的时间自由 | 这是对青松农场**最大的价值**：自然教育/手作/露营都是周末为主，田园摄影专吃工作日市场 |
| 用30亩土地（其中摄影区仅3-5亩）撬动50%年收入增长 | 青松划出3-5亩专用区域试跑，不需要大规模改造 |
| 多风格场景（法式田园/苏格兰/西部牛仔/藏族）——满足"角色扮演"的圆梦需求 | 青松不需要做那么多风格，先做1-2个和松林/田园匹配的风格（田园风+复古国风）测试市场 |
| 不P图、抓拍不摆拍——"真实"就是差异化 | 守住"真实"——不往影楼风走。客户穿农场的衣服在真实的松林/菜地/鸡舍边拍照，这个场景影楼做不出来 |
| 从小规模测试起步：3-5亩、2-3个场景、2-3套服装、摄影师兼职、与附近农家乐合作餐饮 | 青松完全可以复制这个启动路径——投入极低、验证后再扩 |
| 种子客户通过老年大学/社区活动中心招募 | 潍坊城区的老年大学/社区/广场舞群——可以快速触达种子用户 |
| 核心数据指标：客户停留时间、最受欢迎场景、服装偏好、口碑传播路径 | 青松第一期测试时重点收集这4项数据，决定是否放大 |

**对青松农场最关键的启发——客群的重新想象**：
之前设想田园摄影的客群是"亲子/情侣/妈妈"。凡朴农场证明了：

> **田园摄影最大的市场可能不是"年轻人来拍照"，而是"中老年人来圆梦"。**

这不是替代关系，是叠加关系。青松农场的田园摄影可以同时服务：
- 已有客户群体（亲子/情侣/家庭——顺手拍一组）
- 新增客户群体（中老年女性——专程来圆梦）

**如何落地中老年客群的摄影服务**：
- 不需要新增设施——松林+菜地+草地+鸡舍已经足够"田园风"背景
- 准备少量田园风服装（蕾丝长裙/花布衫/草帽/头巾）和道具（竹篮/镰刀/花束）——可租借或自带
- 定价可参照凡朴的"低门槛入场+增值摄影"模式（比如基础体验88元含服装+简餐，跟拍加120元）
- 传播途径：女儿帮妈妈发现（女儿在小红书看到→推荐给妈妈）→妈妈带姐妹团来→熟人推荐裂变

#### 案例二：日本"里山写真"——乡村摄影的审美体系

日本乡村摄影（里山写真）在过去20年形成了一种独立的审美风格：柔和的光线、自然的色彩、不以人为中心而是把人物融入环境中。拍摄地点不是"景点"，是普通的农田、村道、屋檐下。人物不直视镜头，在做自己的事（摘菜、走路、坐着喝茶）。

**可借鉴**：农场的跟拍风格应该是"里山写真"式的——**不要求客户对着镜头笑，让他们做自己的事（捡松果、喂鸡、喝香草茶），摄影师在旁边抓拍。** 客户拿到照片后发现"这张不是摆拍的，是我真的在开心的样子"——这个感知比任何修图都值钱。

#### 案例三：台湾薰衣草森林——"拍照打卡点"的设计思维

薰衣草森林在园区内设置了超过20个"拍照点"——不是那种写着"拍照点"的牌子，而是融入园区的装置：一个木质相框立在花丛中、一架不能动的白色钢琴放在草地上、一棵树上挂着的星星灯串。

每个拍照点都满足三个条件：**1）背景好看 2）不需要拍摄技巧就能出片 3）发到社交平台能一眼认出"这是薰衣草森林"**

**可借鉴**：农场不需要20个拍照点，但**需要1-2个"绝对出片"的标志性场景**。比如：一棵枝形特别好的大松树+一把木制长椅+远处能看到鸡在跑——任何人坐在那个位置上拍出来都好看。这个场景就是农场的"社交货币"。

#### 案例四：韩国"自然风儿童摄影"——妈妈们愿意付费的审美

韩国自然风儿童摄影在国内小红书有大量受众。特征：自然光、低饱和度、不过度磨皮、孩子穿日常衣服（不是换装影楼风）、场景在户外。潍坊城区拍一组这样的照片需要500-1500元，且需要专门去摄影师的"外景地"。

**可借鉴**：农场的松林本身就是一个现成的"外景地"——客户不需要多花时间去别的地方，在农场玩的过程中顺手把照片拍了。**这对妈妈来说是一个很强的不费力的决策**："反正都要来农场玩，顺便把照片拍了——省了我再单独约一次外景。"

#### 案例五：国内"自然摄影"的走红逻辑——小红书上的"农场跟拍"

在搜索小红书" 农场 跟拍"时，可以发现一个趋势：越来越多的妈妈开始找"农场跟拍"而不是去影楼。原因很简单——**影楼的背景是假的，农场的背景是真的。** 影楼的海绵石头vs农场的真实松林——前者是"拍照"，后者是"记录"。

## 5. 交付标准

### 5.1 跟拍服务全流程

| 环节 | 时长 | 加分 | 扣分 |
|:---|:---|:---|:---|
| 预约 | 提前2天 | 摄影师主动加微信，了解客户想拍什么风格、几个人、什么场景 | 只问了个时间就定了 |
| 拍摄当天到达 | 5分钟 | 摄影师在约定地点等，简单聊一下当天的光线和路线安排 | 让客户站在停车场等 |
| 拍摄中 | 1小时 | 引导自然（不是"站这里笑一个"——是"你往前走两步，回头看一下孩子"）；和孩子互动；抓拍而不是摆拍 | 让客户摆固定姿势、"笑一个"；拍出来的照片像证件照 |
| 拍摄结束 | 5分钟 | "今天拍的效果很好，我回去修一下，5天内发给您"——给客户一个确定的交付预期 | "好了"——走了 |
| 交付 | 5个工作日内 | 照片通过百度网盘/微信发给客户，精修过的照片附带一句话"最喜欢的是这张，那个瞬间特别好"——让客户觉得被真诚地对待了 | 发了一堆原片说"你挑一下我再修"——把工作转嫁给了客户 |
| 追访 | 交付后3天 | "照片还满意吗？方便的话可以发一下朋友圈或小红书" | 没有后续 |

### 5.2 品质底线

- **客户授权**：如果要把客户的照片用作农场的宣传素材，必须提前征得客户书面同意（签一个简单的授权书）。不能默认客户同意
- **交付时效**：精修照片5个工作日内交付，超出需提前告知
- **雨天备选**：阴雨天光线不够→调整为室内场景（手作工坊/中心厨房）或改期
- **照片风格统一**：田园摄影的所有作品保持统一的调色风格（自然饱和度、不过度修图），让客户一看就知道"这是农场的照片"

| 服务 | 定价 | 成本构成 | 毛利率 | 说明 |
|:---|:---|:---|:---|:---|
| 1小时跟拍（10精修+原片全送） | 98元 | 摄影师分成（按合作模式约50%=49元）+ 时间成本 | ~50% | 核心产品 |

**为什么摄影师分成是50%而非40%**：摄影师的个人技术是核心产品力，不像自然疗愈的老师可以批量替换。一个好的摄影师值得拿50%。农场提供的是客源+场地，不是核心技术。

### 5.1 营收潜力测算——凡朴模型对青松农场的适配

凡朴农场的数据：218元/人/天，高峰期400-500人/天，年收入增长50%。

青松农场如果走类似路线，保守测算：

#### 第一阶段：小规模测试（3个月内）

| 项目 | 数据 |
|:---|:---|
| 投入 | 3-5亩区域 + 2-3个场景 + 2-3套服装 + 兼职摄影师 |
| 初始投资 | 场景搭建约5000-10000元 + 服装采购约3000-5000元 |
| 日均接待 | 5-15人/天（起步期，仅靠老客户推荐） |
| 日均营收 | 218元×10人≈2180元/天 |
| 月营收 | 2180元×22个工作日≈**48,000元/月** |
| 月成本 | 摄影师分成+服装维护+午餐成本≈约50%=24,000元 |
| **月净利润** | **约24,000元** |

#### 第二阶段：稳定运营期（6个月后）

| 项目 | 数据 |
|:---|:---|
| 日均接待 | 30-50人/天（口碑裂变后） |
| 日均营收 | 218元×40人≈8720元/天 |
| 月营收 | 8720元×22个工作日≈**192,000元/月** |
| 月成本 | 摄影师2-3人分成+服装折旧+午餐成本≈40%=76,800元 |
| **月净利润** | **约115,000元/月** |

#### 对农场整体营收的影响

假设青松农场当前（不含田园摄影）的年营收为基数100%：
- 田园摄影第一年（稳定运营6个月，按月均净利8万元计算）→ 纯增量约**48万元/年**
- 如果农场当前年净利润约100万元 → 田园摄影直接带来约**48%的增长**
- **而且——这48%的增量几乎全部来自工作日。** 其他产品的营收不受影响，田园摄影是纯增量。

#### 关键变量

| 变量 | 乐观 | 中性 | 悲观 |
|:---|:---|:---|:---|
| 日均接待人数（稳定期） | 80人 | 40人 | 15人 |
| 年增营收 | +96万元 | +48万元 | +18万元 |
| 对应增长幅度 | **+96%** | **+48%** | **+18%** |

**结论**：在日均接待40人的中性预期下，田园摄影可为青松农场增收约50%。凡朴的50%增长不是神话，是一个可以复制的模型。

## 9. 增长路径

### 复购

摄影服务的复购逻辑与其他产品不同——**家庭每年拍1-2组照片是自然需求**（孩子的成长记录、家庭纪念日、季节变化）。

- 今年在农场拍了亲子照 → 明年春天再来拍一组（松林春天和秋天的背景完全不同）
- 孩子生日在农场办生日会 → 顺带拍一组生日照
- 四季庆典活动 → 每次来都可以在场景快拍点拍一张

### 传播

每一组跟拍交付给客户的照片，都是潜在的传播素材。客户把照片发到朋友圈/小红书=农场的活广告。

**传播效率公式**：
```
一组跟拍 = 1位客户发朋友圈 = 平均200位好友看到 = 假设0.5%转化率 = 1位新客户
一组跟拍的收入 = 98元
这98元不仅买了摄影服务，还买了1次精准的社交传播
```

## +1 多角色验证

### 角色A：来参加自然教育课的妈妈（顺手拍一组亲子照）

**体验路径**：带孩子来上自然教育课→下课了老师说"我们有合作摄影师，要不要给孩子拍几张"→98元/1小时→想着来都来了→拍了→5天后收到照片→发了朋友圈

**加分点**：拍摄中摄影师没有让摆固定的姿势——孩子在追鸡、在捡松果，摄影师在旁边抓拍——"这些照片就是我心目中想要的那种自然的感觉"；收到了精修图——"比我自己拍的好看太多了"
**扣分点**：如果摄影师当天状态一般，出片率和质量不稳定——"和用手机拍的区别不大"
**复购意愿**：强。"下次来露营的时候再约一组。"
**传播意愿**：强。发了9宫格朋友圈——半小时内3个朋友问"这是在哪拍的？"

### 角色B：合作摄影师（自由职业，专拍亲子/家庭）

**合作体验**：有独立客户的亲子摄影师——平时到处找外景地。和农场合作后——多了一个现成的、不用踩点的外景地。自己的客户可以带来拍（农场收场地费），农场的客户推给她拍（她拿50%）。档期自主——她想接就接，不想接不接。

**加分点**：松林的光线条件很好（尤其是下午4-5点）；农场有香草茶和面包——拍摄间隙可以歇一歇；客户转化路径顺畅——农场的客户本来就在，不需要花时间建立信任
**潜在的顾虑**：如果距离潍坊城区超过30分钟车程，摄影师每次来需要额外投入交通时间——建议在分成中考虑交通补贴或提供茶歇/简餐

### 角色C：农场主（战略视角）

田园摄影在现阶段不需要作为独立卫星来运营——它更适合作为一个"附属服务"附着在现有产品上，甚至不需要专门招人。如果能找到1位长期合作的自由摄影师，这个服务就存在了。

**真正的价值——不仅是收入，更是内容资产**：每一组跟拍产出的照片，经过客户授权后，精选入库。一年后，农场会拥有一个"真实的客户照片库"——这些照片比任何请专业模特拍的宣传照都有说服力。这才是田园摄影最大的长期价值。
