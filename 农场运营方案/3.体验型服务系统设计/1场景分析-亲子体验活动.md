# 场景分析：亲子体验活动

> **分析日期**：2026-06-01
> **基于框架**：《体验型服务系统分析框架》V2.0
> **场景概述**：一家三口（妈妈+爸爸+5-8岁孩子）周末来农场参加自然教育引流课

---

## 第①层 · 人与关系

### 角色识别

| 角色            | 身份     | 本场景中的存在意义          |
| :------------ | :----- | :----------------- |
| **核心体验者**     | 5-8岁孩子 | 这次来的主要目的对象——课是给他上的 |
| **决策者**       | 妈妈     | 决定报名、付钱、开车来的人      |
| **陪同者**       | 爸爸     | 跟着来，但他来了就是客人       |
| **附加角色（可选项）** | 爷爷奶奶   | 周末同行的常见附加成员        |

### 核心体验者分析：孩子（5-8岁）

```
基本画像：幼儿园大班到小学二年级 / 城市生长 / 每周有课外班
核心动机：不存在"动机"——是妈妈让他来的，孩子的世界只有"好玩"和"不好玩"
情绪状态：出发前被催着出门（可能不耐烦）→ 路上期待（逃离教室）→ 到了看环境决定
最怕什么：无聊、被管着、不好玩、不如在家看iPad
```

### 决策者分析：妈妈

```
基本画像：30-42岁 / 本科以上 / 体制内或企业中层的女性 / 月家庭收入1.5-3万
信息渠道：小红书"潍坊亲子"标签 + 妈妈群 + 朋友圈
消费习惯：愿意为"教育价值"付费，对"纯玩"越来越谨慎
核心动机："让孩子接触自然、学到东西"——不是为了自己
真实心理：
  └── 城市生活的愧疚感："孩子每天对着一堆电子设备，我应该带他多接触自然"
  └── 教育焦虑："别人家的孩子都在上自然课"
  └── 社交需求："约上几个妈妈一起去，孩子有伴"
情绪状态：
  └── 出发前：忙碌（收拾东西/催孩子）→ 轻度焦虑（怕迟到/怕孩子不配合）
  └── 路上：期待+轻度不确定（"不知道这个农场怎么样"）
  └── 到了以后：取决于孩子的反应——孩子开心她就开心，孩子闹她就烦躁
最怕什么：
  ① 环境脏乱差——洗手间不干净是致命伤
  ② 孩子玩不起来——花了钱孩子觉得无聊
  ③ 说好的自然教育其实是农家乐——名不副实
  ④ 价格不透明——到了发现还有各种加项
```

### 陪同者分析：爸爸

```
基本画像：30-45岁 / 上班族 / 带孩子经验通常少于妈妈 / 对"自然教育"概念无感
存在意义：妈妈开车累了需要换手 / 周末也没事干跟着来 / 负责看孩子让妈妈休息
核心动机：没有动机——他是被带来的
真实心理：
  └── 最理想的状态：找个地方坐着/喝茶/看手机/不用带孩子
  └── 最怕的状态：全程无所事事跟着走——"我为什么要来"
情绪状态：随缘——取决于有没有事干。有事干就愉快，没事干就无聊
最怕什么：全程"跟着走"——妈妈和孩子在前面上课，他在后面拎包
隐藏机会：如果这个场景中有"他能做的事"，他从陪同者→轻参与者的转化可能
```

### 附加角色分析：爷爷奶奶（可选项）

```
存在意义：周末帮忙带孩子 / 老人也想出来转转
核心动机："陪孙子/孙女"——孩子开心他们就开心
情绪状态：被动，不主动提需求，但感受直接影响家庭整体满意度
最怕什么：
  ① 没地方坐——体力跟不上
  ② 没人理——被冷落在一边
  ③ 厕所太远/太脏
隐藏机会：银发活力型消费潜力（在等候期间可能产生消费）
```

### 角色关系分析

| 维度    | 分析                                                               |
| :---- | :--------------------------------------------------------------- |
| 角色间关系 | 核心家庭（夫妻+子女），祖孙（如有爷爷奶奶）                                           |
| 决策权分布 | 妈妈100%决策权——爸爸不参与决策，爷爷奶奶无决策权                                      |
| 情绪影响链 | **孩子↔妈妈**是强耦合——孩子开心妈妈就满意；爸爸和爷爷奶奶的情绪独立，不影响核心决策但影响全家人对这次出行的整体评价    |
| 服务优先级 | P0保障孩子体验（课的质量）→ P0保障妈妈决策正确（孩子满意+环境干净）→ P1增值爸爸和爷爷奶奶的等候体验（让陪同者不无聊） |

## 第②层 · 场景

```
触发场景：
  ① 妈妈群有人发了上次去农场的照片和评价
  ② 小红书刷到"潍坊68元自然教育课"
  ③ 幼儿园同学约周末一起去
  ④ 学校布置了"亲近自然"的周末作业

决策方式：理性决策——妈妈会看完全部信息（课程内容、价格、适合年龄、真实照片、去过的人的评价）

决策周期：1-3天。不会当天决定，但决定后通常准时到。

到店时间：周六或周日上午9:30-10:00（课程通常10:00开始）

停留时长：计划2-3小时（上课1.5小时+午饭+随意逛逛），实际可能延长到4小时

季节/天气：对天气敏感——雨天来不了（户外课程），但夏天过热或冬天过冷也会影响决策
```

## 第③层 · 体验任务（四层拆解）

### 功能任务

```
孩子：上一堂好玩的课 / 动手做点什么 / 在自然里跑一跑
妈妈：让孩子安全地完成课程 / 自己也能放松一下 / 拍点照片
爸爸：没任务——他来的目的就是"不用有任务"
爷爷奶奶：找个地方坐着 / 看着孩子玩
```

### 情绪任务

```
孩子：从"又出门上课"的不耐烦 → "这个还挺好玩"的兴奋
妈妈：从出门前的忙碌焦虑 → 看到孩子开心后的放松满足
爸爸：从"周末又没了"的无奈 → "这边歇着还挺舒服"的意外好感
爷爷奶奶：从"跟着走"的被动 → "看着孙子玩得开心"的满足
```

### 社交任务

```
孩子：不需要社交任务——孩子不靠这个确认身份
妈妈：拍孩子"在自然中成长"的照片发朋友圈 / 分享到妈妈群
爸爸：无——但如果有他陪孩子玩的照片，妈妈会发
爷爷奶奶：发孙子的照片到家族群 / 退休同事群
```

### 认同任务

```
孩子：不需要——孩子不思考"我是谁"

妈妈："我是一个重视孩子自然教育的妈妈"
  └── 这是妈妈最核心的心理账户——她为这个身份付费

爸爸：没有/微妙——"我是愿意陪家人的人"
  └── 这里有一个机会：如果农场能让爸爸在等候期间有"我做了点什么"的体验，他出去可以说"周末带孩子去农场，我还在那儿烤了个面包"

爷爷奶奶："我是一个能帮上忙的爷爷奶奶"
```

## 第④层 · 触点服务需求

### 触点 × 角色矩阵

|     触点     | 孩子                   | 妈妈                                   | 爸爸                   | 爷爷奶奶（如有）              |
| :--------: | :------------------- | :----------------------------------- | :------------------- | :-------------------- |
|  **1.触发**  | —                    | 刷到课程内容/看到朋友发的照片                      | —                    | —                     |
|  **2.决策**  | —                    | 课程内容✅＋价格✅＋真实照片✅＋适合年龄✅＋安全说明✅＋去过的人怎么说✅ | —                    | —                     |
|  **3.到达**  | 看见动物/松林/大场地→兴奋       | 洗手间干净？→**生死判断** / 有人迎接吗？ / 环境跟照片一样吗？ | 停车场到门口远不远 / 有没有地方坐   | 路平不平 / 厕所在哪 / 有没有阴凉处坐 |
| **4.核心体验** | 课好不好玩？老师喜不喜欢我？能不能动手？ | 孩子投入吗？老师专业吗？环境安全吗？我能不能松口气？           | "我干嘛呢？"→**这是最大需求**   | "我坐哪？"→**这是最大需求**     |
| **5.服务接触** | 老师有没有耐心              | 有没有人跟我说"家长可以去那边休息"                   | 有没有人理我 / 有没有人告诉我能干什么 | 有没有人主动给我指个座位和倒杯水      |
|  **6.离开**  | 我做的成品 / 开不开心         | 孩子开心吗？有照片吗？有没有东西可以带走？                | "今天过得还行"             | 看着孩子开心的记忆             |
|  **7.后续**  | —                    | 收到照片 / 下次活动通知 / 孩子说"还想去"             | —                    | —                     |

### 关键触点展开

**触点2-决策（妈妈）**：
```
需要信息：
  ① 课程具体做什么（不是概念描述，是流程）
  ② 适合几岁的孩子
  ③ 多少钱、含什么、不含什么
  ④ 真实照片（不是精修图）
  ⑤ 有没有其他妈妈去过、怎么说
  ⑥ 怎么去、好不好停车

最劝退的三种情况：
  ① 页面说"自然教育"但照片是摆拍
  ② 价格不透明（到了发现还有加项）
  ③ 没写适合年龄——怕孩子去了跟不上
```

**触点3-到达（全角色）**：
```
孩子的第一反应：看有没有动物/有没有好玩的
妈妈的第一反应：看环境干不干净→**洗手间是第一站**
爸爸的第一反应：看有没有地方坐下
爷爷奶奶的第一反应：看有没有地方坐着休息

农场应准备的：
  ① 停车场到入口的步行路线清晰好走（爷爷奶奶可能走不稳）
  ② 入口处有人在等候迎接（不是"自己找过去"）
  ③ 洗手间在上课前已确认清洁
  ④ 入口处有指示：课程区↗ / 休息区→ / 洗手间←
```

**触点4-核心体验（孩子的课）**：
```
孩子的需求：
  ① 有人带着玩（不是被管着学）
  ② 能动手（不只是看和听）
  ③ 有节奏——不要全程2小时都在同一件事上
  ④ 能跑一跑（不是全程坐着）

妈妈的需求（孩子上课期间）：
  ① 有个地方坐下来看着孩子
  ② 有杯喝的
  ③ 不被打扰
```

**触点4-核心体验（爸爸的等候时间）**：
```
这是陪同者增值设计的核心场景。

等候时长：约1.5小时（一节完整的自然教育引流课）

爸爸在这1.5小时可以做什么？
  选项A：什么都不做——找一个舒服的地方坐着看手机 / 喝茶
  选项B：轻度参与——去面包窑看看 / 去鸡舍转转 / 松林里走走
  选项C：动手——体验披萨DIY / 喝杯窑炉咖啡

设计原则：
  ① 先给他"什么都不做也可以"的选择
  ② 在他坐着无聊时，有人顺手指一下"那边有面包窑，可以去看看"
  ③ 不要主动推销，不要追着他问"你要不要体验什么"
```

**触点6-离开（全角色）**：
```
孩子的离开：带走自己的手工作品 + "今天开心"的记忆
妈妈的离开：①孩子开心 ②拍了至少3张能发朋友圈的照片 ③买点农产品带走（蛋/面包）
爸爸的离开：如果有过轻度参与（比如去看了面包窑），可能会有"买两个面包带走"的冲动
所有角色的离开：扫二维码入群（运营卫星在出口处自然引导）
```

## 第⑤层 · 农场服务方案

### 课前准备（提前1天-当天早上）

| 事项        | 执行标准                | 负责人  |
| :-------- | :------------------ | :--- |
| 课程物资备齐    | 按教案清单逐项打钩           | 课程老师 |
| 洗手间检查     | 干净、有纸、无异味           | 运营卫星 |
| 休息区准备     | 松林下的桌椅擦净、水壶备好       | 运营卫星 |
| 陪同者增值信息更新 | 今天面包窑几点出面包 / 咖啡供应正常 | 运营卫星 |
| 入口指引牌确认   | 课程区↗休息区→洗手间←清晰可见    | 运营卫星 |

### 到达接待（客户到店后5分钟）

| 动作           | 执行标准                       | 负责人  |
| :----------- | :------------------------- | :--- |
| 入口迎接         | 有人在停车场出口处等待，微笑打招呼          | 运营卫星 |
| 引导停车→洗手间→休息区 | 不是"自己找过去"，是"我带您过去"         | 运营卫星 |
| 向爸爸/爷爷奶奶指路   | "那边有休息区，有茶有咖啡，还看得见孩子在哪儿上课" | 运营卫星 |
| 向妈妈确认课程信息    | 课程几点开始、几点结束、结束后可以做什么       | 课程老师 |
| 孩子与老师见面      | 老师蹲下来跟孩子打招呼，叫孩子名字          | 课程老师 |

### 核心体验执行（课程进行中）

| 事项       | 执行标准                      | 负责人     |
| :------- | :------------------------ | :------ |
| 课程执行     | 按教案走：导入→动手→探索→收尾，节奏张弛有度   | 课程老师    |
| 家长观察区有饮品 | 热水/茶/咖啡自助，不额外收费           | 运营卫星    |
| 陪同者增值引导  | 在爸爸/爷爷奶奶坐下后5分钟内，顺手指一下可选方向 | 运营卫星    |
| 拍照       | 课程中拍3-5张孩子的自然状态照片（不是摆拍）   | 运营卫星或老师 |
| 安全监护     | 老师全程在场，户外活动前做安全告知         | 课程老师    |

### 陪同者增值方案（孩子上课的1.5小时内）

| 选项 | 内容 | 成本 | 是否收费 | 需要准备 |
|:---|:---|:---:|:---:|:---|
| A. 什么都不做 | 松林休息区/茶/咖啡/看手机 | 极低 | 免费 | 桌椅+水壶 |
| B. 轻度逛逛 | 面包窑参观/鸡舍转转/松林步道 | 零 | 免费 | 知道路怎么走 |
| C. 轻度体验 | 窑炉咖啡/买两个面包 | 低 | 有消费 | 咖啡机+面包供应 |
| D. 动手参与 | 披萨DIY/烤面包体验 | 中 | 付费 | 材料备好 |

**引导方式**：
```
① 到达时指路时顺口说一句：
  "爸爸可以在那边坐着喝茶看手机，那边看得到孩子上课的区域。"
  或"那边面包窑今天在做面包，有兴趣可以去看看。"

② 坐下后5分钟，运营卫星路过时顺口带一句：
  "需要什么随时叫我，咖啡在那边自助。"
  或"后面鸡舍可以去看，鸡是散养的。"

③ 不是推销——是他在无所事事时，给他一个方向。
```

### 离开收尾

| 事项 | 执行标准 | 负责人 |
|:---|:---|:---|
| 课程收尾 | 孩子展示成品/合影/发给孩子带回家 | 课程老师 |
| 照片发送 | 课后2小时内通过微信发送给妈妈 | 运营卫星 |
| 农产品零售提示 | 在出口附近自然陈列（蛋/面包/手作），不主动推销 | 运营卫星 |
| 社群引导 | 出口处扫码入群，"以后有活动会在群里发" | 运营卫星 |
| 下一次的种子 | 结账时顺口提一句"下个月有探索营"或"后面有果树认领" | 运营卫星 |

### 附件：爷爷奶奶在场时的特别处理

| 特殊需求 | 服务标准 |
|:---|:---|
| 到达时 | 指引就近的座位（不要走太远），确认洗手间位置 |
| 等候期间 | 提供热水/茶，有屋檐或树荫的位置 |
| 孩子上课时 | 座位最好能看见孩子在哪儿 |
| 离开时 | 如有农产品（蛋/米/面），是爷爷奶奶的自然消费点 |

## 第⑥层 · 能力边界

### 能做

| 事项 | 依据 |
|:---|:---|
| 课程质量保障 | 引流课教案已开发完成，老师（言渊/自然手作主理人）有授课能力 |
| 洗手间清洁 | 已有基础设施，每天检查即可 |
| 休息区茶水 | 松林下有桌椅，热水壶/茶/咖啡成本极低 |
| 陪同者轻度逛逛 | 农场本身就有面包窑/鸡舍/松林可看，不需要额外投入 |
| 照片拍摄 | 运营卫星在课程现场顺手拍，不需要专业设备 |
| 社群维护 | 已有社群基础，运营卫星日常工作之一 |

### 不能做（明确放弃）

| 事项 | 原因 |
|:---|:---|
| 为陪同者独立开设付费活动 | 陪同者人数不固定、需求不统一，设计专门活动投入产出比不划算。用"自然引导+轻体验"替代 |
| 为爷爷奶奶提供专门服务人员 | 爷爷奶奶不是每场都有，无法配置专人。用"到达时的一次特殊指引"替代 |
| 保证爸爸一定会消费 | 爸爸的消费意愿取决于他当天的感受，不能强推。能接受"他就只是坐着喝了杯茶" |

### 差异化

| 对比项   | 其他农场/农家乐      | 青松农场（本次方案）                 |
| :---- | :------------ | :------------------------- |

**③ 体验任务中一个关键发现**：妈妈的认同任务是"我是一个重视孩子自然教育的妈妈"——她为这个身份付费，不是为"一堂课"付费。这个心理账户决定了定价和内容设计的底线。

**④ 触点的核心设计点**：陪同者的等候时间（约1.5小时）是增值空间最大的触点。设计了四个选项（从免费到付费），但不是推销——是在他无事可做时顺手指一个方向。

**⑤ 服务方案的亮点**：

- 到达时有人迎接 + 先引导洗手间 + 再引导休息区——这不是服务升级，是P0生死线
- 爸爸的等候时间设计了4个递进选项，但先给他"什么都不做也可以"的安全感
- 离开时照片已发到微信——不用客户开口要

**⑥ 能力边界**：明确放弃了"为陪同者独立开设付费活动"和"为爷爷奶奶专配服务人员"——用自然引导替代。
