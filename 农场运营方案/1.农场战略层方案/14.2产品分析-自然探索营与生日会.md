# 产品一：自然探索营（7-14岁独立营）

```
使用维度：1✅ 2✅ 3✅ 4+扩展 5△ 6△ 7✅ 8✅ 9△ 10✅
```

## 1. 飞轮定位

**主定位**：复购锚点 + 信任引擎

自然探索营是自然教育课（4-10岁）的向上延伸——孩子长大到7岁后，不再适合"带着玩"式的节气课，但家长仍然希望孩子在农场消费。自然探索营给这些"老客户"一个留下来的理由。

**辅助作用**：利润中心（独立营的客单价是自然教育的2-3倍，且家长不陪同=不需要同时服务家长，人工效率更高）

## 2. 目标客群

**直接客户：7-14岁的孩子（独立参加，家长不陪同）**

**付费决策者：家长**
- 画像：35-45岁，潍坊城区中产。孩子已经上小学，不再是"去哪玩都要陪着"的年纪
- 痛点：周末想让孩子"做点有意义的事"但又不占自己的时间；市面上的营地教育太贵（一次500+）或太远（要送到杭州/北京）
- 痒点："孩子回来自己学会了生火（在安全范围内）"——这个技能会让他在同龄人中很酷
- 决策逻辑：孩子在农场上过自然教育课（有信任基础）→ 看到新推出了大童独立营 → 价格合理（198元/半日）→ "反正他闲着也是闲着，送去吧" → 报名

**内部客户**：无

## 3. 核心体验

"没有爸爸妈妈跟着。和几个差不多大的孩子一起，在松林里找路标、用打火石点火、用树枝搭一个能挡风的小棚子。做完这些事之后，我觉得自己还挺厉害的。"

这不是"上课"，是**被允许做平时不能做的事**——用火、用工具、在树林里走一条不熟悉的路、自己决定往哪走。

### 4.4 借鉴案例

#### 案例一：英国Bushcraft——"教孩子有用的技能"

Bushcraft是全球最成熟的户外生存技能培训体系。他们的儿童课程核心理念是：**"一个孩子能独自生火，就是他独立的第一步。"** 课程内容非常实用——打火石生火、用刀削木棍、识别可食用植物、搭建遮蔽所。

**可借鉴**：探索营的"技能挑战"环节应该让孩子带走一项**可展示的技能**。孩子回家后可以向家人演示"我今天学会了打火石"——这比任何课程证书都更有说服力。7-10岁组可以从"搭建迷你遮蔽所"开始（不需要用火），11-14岁组可以挑战打火石生火。

**具体落地**：每个半日营结束时，孩子获得的"成就卡"上写的不是"参加了一次活动"，而是"完成了：定向越野✅ 搭建遮蔽所✅ 自然笔记✅"——技能导向的确认。

#### 案例二：日本"冒険教育"——"振り返り"（回顾）环节

Project Adventure（美国）的体验式教育模型被日本引入后，增加了"振り返り"（reflection）环节——每次活动结束后，孩子围坐一圈，老师引导每个人说一句"今天最难的时刻"和"今天最开心的时刻"。这个环节被认为比活动本身更重要，因为孩子在回顾中自己发现了"我克服了什么困难"。

**可借鉴**：探索营的结营分享不是走形式。老师需要会提问——不是"今天开心吗？"（回答一定是"开心"），而是"今天你遇到的最难的事情是什么？你是怎么解决的？"——这个问题会让孩子真正思考自己的经历。

**具体落地**：设计3个引导问题模板——"今天最难的是什么？""谁帮助了你？""回家后你想告诉爸爸妈妈什么？"

#### 案例三：日本"冒险教育"——"冒険"而非"危险"

日本冒险教育的核心理念是区分"危险"（hazard）和"冒险"（risk）——危险是必须消除的（塌方/坠落/毒物），冒险是孩子可以自主选择承担的（爬一棵矮树/走过一个独木桥/用火）。**教育者的职责是消除危险、保留冒险。**

**可借鉴**：探索营的设计不要为了安全把所有"冒险"元素都去掉——那就和普通游乐园没区别了。孩子在农场可以做的"适度冒险"：在松林里自己找路（而不是被老师带着走）、用打火石生火（而不是老师生了让他看）、爬一棵安全的低矮松树（树下铺软垫、老师护着）。

**具体落地**：每个活动环节标注"冒险等级"（1-3级），家长报名时能看到。"今天我们会有2级冒险活动（用打火石生火）"——这个透明信息本身就是信任的构建。

# 产品二：自然生日会（亲子生日派对）

```
使用维度：1✅ 2✅ 3✅ 4+扩展 5△ 6✅ 7✅ 8✅ 9─ 10✅
```

## 1. 飞轮定位

**主定位**：传播杠杆（一场生日会=一场小型获客活动）

自然生日会是所有产品中**单次传播效率最高的产品**。原因：
- 一场生日会来10-15个孩子 + 每人带1-2位家长 = 20-40人到店
- 这20-40人中，大部分**从未到过农场**
- 体验好的话，其中一部分会成为农场的客户

**辅助作用**：
- 利润中心（客单价980-1680元/场，成本以人工+简餐+材料为主，毛利率高）
- 复购锚点（寿星家庭来办过生日会→每年生日都会想到农场）

## 2. 目标客群

**直接客户：在农场上过课的孩子的家长（4-10岁）**
- 画像：妈妈，30-40岁，孩子4-10岁，已经通过自然教育/手作体验认识并信任农场
- 痛点：每年给孩子办生日会，在亲子餐厅办要2000-3000元、"就是换了个地方玩玩具"；在家里办太麻烦（准备食物+收拾+哄孩子）
- 痒点："在松林里办一场生日会"——这个说法本身就比"在XX亲子餐厅办生日会"有意思
- 决策逻辑：农场体验很好 → 孩子要过生日了 → "要不我们在农场办" → 问价格 → 980/1280元，比亲子餐厅便宜 → 定

**触达人群（生日会引流来的新客户）**：
- 其他来参加生日会的孩子家长——他们可能从来没听说过这个农场，但通过一场生日会完成了"首次接触"

## 3. 核心体验

寿星孩子：
"我的生日不在餐厅里过，在松林里。我和朋友们在树丛里找宝箱，然后每个人做了一个小礼物带回家。"

寿星家长（妈妈）：
"不用自己准备任何东西——场地布置好了、有老师带着玩、有简餐有蛋糕。我只需要把蛋糕拎过来、孩子全程被安排得明明白白。我在旁边坐着和其他家长聊天。"

参加生日会的孩子：
"好好玩！我也想让妈妈在这里过生日。"

## 4. 交付标准（+扩展：生日会流程设计）

### 4.1 生日会标准流程（2.5-3小时）

| 环节 | 时长 | 内容 | 加分 | 扣分 |
|:---|:---|:---|:---|:---|
| 签到与暖场 | 15分钟 | 孩子到齐后，每人发一个"森林小勇士"头带/徽章——建立临时团队感 | 每个孩子戴上头带后拍一张单人照 | 孩子干等着，有的开始跑闹 |
| 松林寻宝 | 40分钟 | 在松林划定区域内藏好"宝箱"（内含小手工材料/小零食）→孩子分组找→找到后每人获得一份 | 寻宝过程中设计了小关卡——还需要答对一个问题才能开宝箱 | 把零食撒在地上让孩子捡——太敷衍了 |
| 自然手作体验 | 40分钟 | 寿星孩子和朋友们一起做一件简单的手作（推荐：植物拓印布袋——操作简单、出片率高、成品实用、每个孩子都能带走） | 老师帮每个孩子和作品拍照——发到活动群里 | 手作太难，孩子做不出来→沮丧 |
| 蛋糕与合影 | 30分钟 | 在松林下摆好长桌→蛋糕上来→唱生日歌→寿星吹蜡烛→吃蛋糕→大合影 | 松林+长桌+蛋糕这个画面本身就很好拍。老师帮忙拍寿星家庭合影+全体孩子合影 | 在室内吃蛋糕→和在亲子餐厅一样了 |
| 自由玩耍 | 剩余时间 | 孩子们在松林里跑玩，家长坐着聊天或逛农场 | 孩子在玩，家长在松林下喝茶聊天——"这个画面太美好了" | 没有什么可玩的，孩子们开始抢玩具或拉着家长要走 |

### 4.2 套餐选择

| 套餐 | 定价 | 适合人数 | 含 | 不含 |
|:---|:---|:---|:---|:---|
| 基础版 | 980元 | 10个孩子以内 | 场地+活动（寻宝+手作）+简餐（三明治+水果+饮品）+合影 | 蛋糕自备 |
| 标准版 | 1280元 | 15个孩子以内 | 基础版内容 + 简餐升级（热食+沙拉+饮品）+装饰布置（桌子+桌布+气球+野花） | 蛋糕自备 |
| 豪华版 | 1680元 | 20个孩子以内 | 标准版内容 + 手作升级（每人做一件可带走的产品）+摄影师跟拍1小时 | 蛋糕自备 |

### 4.3 品质底线

- 寿星家长确认套餐后3天内锁定日期（不接临时加单）——生日会的准备需要时间
- 活动当天早上场地复查一遍（桌子摆好+寻宝道具藏好+手作材料备齐）
- 如果天气不好，提前和寿星家长沟通室内备选方案
- 活动结束后，给寿星家长发一个"活动精华"相册（老师手机拍的5-10张精修图）——她可以发朋友圈

### 4.4 借鉴案例

#### 案例一：美国农场生日派对——"喂动物+干草车+蛋糕"的黄金组合

美国最经典的Agritourism产品就是Farm Birthday Party。一个中型农场每年靠生日会比种地赚得还多。典型的流程：喂动物/骑小马（30分钟）→坐干草车（20分钟）→手作/游戏（30分钟）→蛋糕（20分钟）→自由玩耍。家长不需要参与任何组织，农场包办全程。

定价通常在200-500美元（约1400-3500元），不便宜但常年满订。核心原因是：**家长不是为孩子的娱乐付费，是为"自己不需要操心"付费。**

**可借鉴**：农场的生日会套餐设计应该让寿星家长**全程做客人**——"你只需要把蛋糕带来，其他的交给我们"。手作环节由自然手作卫星老师负责，简餐由引擎A负责，场地由引擎B负责。寿星家长的朋友圈文案会自动生成——"在农场办了一场生日会，我什么都没做。"

#### 案例二：丹麦森林生日会——"篝火烤面包棍"是最受欢迎的环节

丹麦森林幼儿园的生日会传统是：孩子们围坐在篝火旁，每人用一根棍子串上面团，在火上烤熟。这个环节简单到不能再简单（面团就是面粉+水+盐），但孩子们觉得"自己烤的面包是世界上最好吃的"，家长也觉得"这个场景太治愈了"。

**可借鉴**：生日会的"自由玩耍"时段，可以准备一个已点燃的小篝火盆+预调好的面团+棍子。"谁想烤面包自己去坐着烤"——不需要老师组织，孩子们自己就会围过去。成本约2元/个，效果值200元。

**具体落地**：豪华版套餐包含"篝火烤面包"环节。这个画面（孩子们围在篝火旁、自己用棍子烤面包）——10个家长有9个会拍下来发朋友圈。

#### 案例三：国内亲子餐厅生日会的"短板"——农场的优势所在

潍坊城区的亲子餐厅生日会套餐通常在2000-4000元，含场地+简餐+活动。但消费者最大的不满是："和平时去亲子餐厅没什么区别，就是换了个地方玩海洋球。"

农场的优势不是"和亲子餐厅做得一样好"，而是**"在亲子餐厅做不到的事"**：
- 亲子餐厅不能带孩子到松林里寻宝
- 亲子餐厅不能让孩子自己烤面包棍
- 亲子餐厅不能让孩子在户外跑一下午

**定价策略**：农场的生日会不需要比亲子餐厅便宜——实际上可以定同样价格（甚至更高），因为**"在松林里过生日"这个体验本身就有溢价空间。** 但为了与现有客户的信任匹配，建议定价比亲子餐厅略低（980-1680元 vs 2000-4000元），用性价比形成竞争优势。

## 7. 增长路径

### 复购（寿星家庭）

- 今年在农场办了生日会 → 明年孩子生日时，**不需要再找场地**——"去年在农场办的挺好的，今年还去"
- 年年来 → 从基础版升级到豪华版
- 对农场来说：一个寿星家庭 = 每年一笔固定收入 + 每年一次新客户获客活动

### 传播

**生日会是所有产品中传播效率最高的。**
- 寿星家长在朋友圈发"在农场给XX过了生日" → 通讯录里200+人看到 → 其中10-20个有孩子的家长会心动
- 来参加生日会的其他孩子家长回家后，孩子会说"妈妈我也想在那里过生日" → 下一个生日会客户

**一个数据模型**：
```
一场生日会（15个孩子 + 30位家长 = 45人到店）
→ 其中30人是首次到店
→ 假设转化率10% → 3个家庭成为农场新客户
→ 每个新客户年均消费500元（保守估计）
→ 一场生日会的"后续价值" = 1500元
→ 生日会本身收费1280元 + 后续价值1500元 = 2780元/场的综合价值
```

## 8. 决策结论

| 项目 | 内容 |
|:---|:---|
| 总体判断 | **做** |
| 前提条件 | 1. 内测一场（员工/熟人孩子的生日会）验证流程 2. 确定三档套餐内容和定价 3. 引擎A的简餐方案确认 |
| 优先级 | **高**（仅次于自然教育双档调整）。因为它几乎不增加固定成本、利用现有资源、且传播效率最高 |
| 启动建议 | 先不对外宣传——在自然教育/手作体验的老客户群里说一句"有需要给孩子在农场办生日会的可以私信我"→接1-2单试跑→有了案例照片后再正式上线套餐 |
| 退出条件 | 连续3次报名后因天气/人手等原因取消→暂停。首次活动出现安全事故→停办并全面复盘 |

## +1 多角色验证

### 探索营——角色A：11岁男孩

**体验路线**：妈妈帮他报名了探索营 → 到了发现都是不认识的孩子 → 有点想回家 → 开始定向越野 → 自己看地图找到第一个打卡点 → 被分到打火石组 → 第一次没打着 → 老师教了一下姿势 → 第二次着了 → 开心

**复购意愿**：强。"下次还有打火石吗？"
**传播意愿**：回家第一时间演示给爸爸看——"你看，我今天学会生火了！"
**优化建议**：下次可以让他试试难度更高的——看着火燃起来的那一刻，他会记住很久。

### 探索营——角色B：报名探索营的妈妈

**体验**：报名前担心安全问题 → 看到师生比1:5 + 生火环节1:3 → 放心了 → 把孩子送到农场 → 自己回家（或去市区逛街） → 3小时后回来接 → 孩子兴高采烈地展示"成就卡"

**复购意愿**：强。"下次全日营也报一个，我可以在市区待一天。"
**传播意愿**：发了朋友圈——"今天把他送到农场去了，我自己过了半天不用操心的日子"——这个文案的吸引力比"孩子学会了打火石"更强。

### 生日会——角色C：寿星妈妈

**体验**：在农场上过自然教育课→看到有生日会套餐→1280元/15个孩子→比亲子餐厅便宜（2000+）→预约→当天带了蛋糕来→全程在和其他家长聊天→结束后收到老师发的活动照片

**加分点**：松林寻宝时孩子们跑得很开心→"这个场面比我预想的好多了"；手作环节每个孩子做了布袋回家→"其他家长都说办得好"；最大的加分点：**她全程什么都不用管**
**复购意愿**：强。明年肯定还在这里办。
**传播意愿**：强。发了朋友圈+发到了妈妈群。3天后已经有认识的人来问"你上次办生日会的那个农场在哪？"
