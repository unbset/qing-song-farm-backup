# 社群与会员系统搭建方案

> **背景**：运营卫星尚未到岗，前期需由言渊或最低成本方式维护。
> **目标**：2年积累300名付费会员，社群作为日常触达渠道。
> **原则**：不追求"做得很重很大"，追求"一个人能维护、客户自然想加入"。

---

## 一、定位：社群和会员分别解决什么问题

|      | 社群（免费）          | 会员（付费）                   |
| :--- | :-------------- | :----------------------- |
| 目的   | 保持触达，让客户"不忘了农场" | 锁定长期关系，产生稳定复购            |
| 门槛   | 扫码入群，无需消费       | 储值500元起/年卡1280元起/长搭3600元 |
| 维护成本 | 每天5-10分钟发内容     | 每月30分钟核对权益+跟进续费          |
| 人数上限 | 不限（可多群）         | 目标300人                   |
| 核心动作 | 每周发2-3次内容       | 每月1次会员专属活动               |

**一句话**：社群是"不让客户忘了你"，会员是"让客户离不开你"。

---

## 二、社群运营——一个人每天5分钟就够了

### 2.1 社群类型

只建**一个统一群**，不按产品分群。

| 为什么不按产品分 | 一个群的逻辑 |
|:---|:---|
| 一个客户既露营又上自然课又买面包——分群他要加三个群，烦 | 一个群里发所有内容——露营的看到自然课内容→"下次带孩子试试"→自然转化 |
| 三个群需要三倍维护精力 | 一个群每天发1-2条就够了 |

### 2.2 内容节奏

| 频率 | 内容 | 谁做 | 耗时 |
|:---|:---|:---|:---|
| **每天1条** | "今天农场"——随手拍一张照片（松林/菜地/面包出炉/鸡/客人玩的样子）+一句话 | 言渊或当班员工 | 30秒拍照+10秒发 |
| **每周1条** | 本周活动预告（引流课/手作课/限时优惠） | 运营卫星负责人 | 5分钟 |
| **每两周1条** | 干货内容——节气知识/手作配方/农场故事 | 言渊或自然手作主理人 | 15分钟 |
| **每月1条** | 会员专属活动预告 | 运营卫星负责人 | 5分钟 |

**全年52周的内容节奏就是：**
- 52条"今天农场"（随手拍）
- 52条活动预告
- 24条干货（跟着节气走，正好）
- 12条会员活动预告

**不需要排期表，不需要专门的内容日历**。每天拍一张照片发群里，这个动作就够了。

### 2.3 入群入口

| 触点 | 动作 | 话术 |
|:---|:---|:---|
| 客户第一次到店（停车/签到） | 展架上放群二维码，"扫码入群领一份松林探索地图" | 给一个即时的利益，不是"欢迎入群" |
| 自然教育课后 | "今天的课程照片会发到群里，您加一下群" | 照片驱动——家长为了看到自己孩子的照片会扫码 |
| 收银台 | "群里每周有福利活动，扫码入群" | — |
| 线上预约确认 | 确认信息里附群二维码 | — |

## 三、会员体系设计——三级递进

### 3.1 三级会员

| 级别     | 名称       | 门槛           | 权益                    | 2年目标 |
| :----- | :------- | :----------- | :-------------------- | :--- |
| ⭐ 入门   | **储值会员** | 储值500元起      | 餐饮9.5折+优先订位+生日赠礼+入群   | 185人 |
| ⭐⭐ 核心  | **节气年卡** | 1280-1680元/年 | 24次节气课+消费9折+专属活动+优先报名 | 80张  |
| ⭐⭐⭐ 深度 | **长搭小院** | 3600元/年      | 100㎡小院使用权+自由出入+免费停车   | 35人  |

### 3.2 储值会员为什么是第一抓手

节气年卡1280元决策门槛高（客户要先参加过自然教育、认可价值才会买）。长搭3600元门槛更高。**储值500元是"不需要犹豫"的价格**——一家人在农场吃一顿饭+买点东西就花了，充500元还能打折。

**储值会员的增长路径**：
```
客户第一次来 → 社群（免费）→ 来了2-3次后 → 
"经常来可以充点钱，充值500打9.5折" → 储值会员 → 
储值余额用完了 → 续充（习惯已养成）
```

### 3.3 会员权益的"成本 vs 感知价值"

| 权益 | 你的成本 | 客户感知价值 | 说明 |
|:---|:---|:---|:---|
| 餐饮9.5折 | 让利5% | "省钱" | 推荐放第一位 |
| 优先订位 | 零成本 | 节假日不用抢位置 | 推荐放第二位 |
| 生日赠礼（一块手工皂） | 约5元 | "好用心" | 低成本高感知 |
| 会员专属活动 | 按次算成本 | "比普通客户多一个特权" | 每月1次，成本100-200元 |
| 免费参加1次手作体验（储值1000元） | 材料费约10元 | "价值100+" | 促进从500升级到1000 |

## 四、客户从"第一次来"到"成为会员"的完整路径

```
第一次到店（9.9元露营/68元引流课/来吃饭）
    │
    ├──→ 扫码入群（免费社群）
    │      │
    │      ├──→ 在群里看到农场日常内容
    │      ├──→ 看到活动预告→再次到店
    │      │
    │      └──→ 来了3次以上后，收银台推荐储值
    │             │
    │             └──→ 储值500元 → 入门会员
    │                      │
    │                      ├──→ 储值用完后→续充
    │                      ├──→ 有孩子且多次参加自然教育课→推年卡
    │                      └──→ 常来露营→推长搭
    │
    └──→ 直接充值（意向强烈的客户）
```

**关键转化节点**：
- 从"第一次到店"到"入群"：转化率目标≥70%（靠扫码给即时利益驱动）
- 从"入群"到"储值"：转化率目标≥15%（靠"来了几次后收银台说一句"）
- 从"储值"到"年卡/长搭"：转化率目标≥10%（靠产品力自然推动）

## 五、一个人怎么维护——每天/每周/每月的工作清单

### 每天（5分钟）

| 时间 | 动作 | 耗时 |
|:---|:---|:---|
| 任何时候 | 拍一张"今天农场"的照片发群里 | 30秒拍照+10秒发 |
| 收工前 | 核对当天有没有新入群的客户→备注"来源"（第一次来→什么活动来的） | 5分钟 |

### 每周（30分钟）

| 时间 | 动作 | 耗时 |
|:---|:---|:---|
| 周一 | 本周活动预告发群里 | 5分钟 |
| 周一 | 上周新增客户备注更新 | 10分钟 |
| 周一 | 群里回复上周遗留的未回复消息 | 5分钟 |
| 周五 | 周末活动提醒+天气提醒 | 5分钟 |
| 周末 | 如本周有会员到店→微信群发一条生日/问候 | 5分钟 |

### 每月（1小时）

| 时间 | 动作 | 耗时 |
|:---|:---|:---|
| 月初 | 储值余额到期提醒→发微信给快用完的客户 | 20分钟 |
| 月初 | 节气年卡下期课程预告+报名接龙 | 10分钟 |
| 月中 | 长搭客户续费提醒（到期前1个月） | 10分钟 |
| 月末 | 本月新增会员数+到店次数统计→记录 | 20分钟 |

**初期只有言渊一人时，能做多少做多少。** 上面是"理想状态"，做不到也别焦虑。**每天拍一张照片发群里——这个动作坚持住了，社群就不会死。**

运营卫星负责人到岗后，以上工作全部移交给他/她。言渊只需要在拍照时顺手发一张到群里——1分钟的事。

## 六、工欲善其事——必要的工具

| 工具 | 用途 | 月费 | 说明 |
|:---|:---|:---|:---|
| 微信（个人号+群） | 社群运营 | 免费 | 尽量用个人号建群，不要用企业微信（个人号更亲切） |
| 腾讯文档/飞书 | 客户信息表 | 免费 | 姓名+微信+电话+来源+到店次数+消费记录+标签 |
| 收银系统（收钱吧/微信商家等） | 所有收入的统一入口 | 约0.3-0.6%费率 | 已有 |
| 微店/小程序商城 | 零售产品线上销售 | 免费/低费 | 运营卫星负责人到岗后搭建 |
| 微信标签 | 客户分组管理 | 免费 | 在微信通讯录给客户打标签——"自然教育""露营""储值会员" |

**不做的事**：不采购CRM系统（初期用腾讯文档就够了，客户量1000以上再考虑）、不做积分体系（复杂度高但转化效果不确定）、不做付费社群（社群的目标是"保持触达"，不是"靠社群赚钱"）。

## 七、300会员目标的拆解

| 阶段 | 时间 | 重点动作 | 新增会员 | 累计 |
|:---|:---|:---|:---|:---|
| 积累期 | 第1-3个月 | 社群建立+每天拍照发群+储值会员起步 | 15-20人 | 20人 |
| 增长期 | 第3-6个月 | 自然教育引流课扩量→转化储值→节气年卡推出 | 30-40人 | 60人 |
| 爆发期 | 第6-12个月 | 年卡扩售+生日会+探索营→多产品线转化 | 50-60人 | 120人 |
| 成熟期 | 第12-24个月 | 口碑裂变+田园摄影新客群+周年活动 | 180人 | 300人√ |

**从KPI倒推**：
- 第1年目标120人（储值60人+年卡15张+长搭25人+其他）
- 第2年目标新增长180人（储值125人+年卡65张+长搭10人）
- 平均每月新增储值5-10人 → 只需要每周有1-2个客户选择储值

**这个目标不需要大量推广，只需要：**
1. 客户体验好（产品分析已覆盖）
2. 客户来了之后有人推一把储值（"经常来可以充点钱"——收银台说一句就行）
3. 社群不断提供回来的理由（"今天农场"每天1张照片）

**不做的事：** 不买CRM系统（腾讯文档够用）、不作积分体系（复杂度高效果不确定）、不做付费社群（社群的目的是"保持触达"，不是"靠社群赚钱"）。
