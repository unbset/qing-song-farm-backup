
## 农场建设公开化方案（框架）

### 五种互动模式

| 模式         | 本质           | 适合什么工作       |
| :--------- | :----------- | :----------- |
| **① 课程化**  | 把劳动包装为教育产品   | 有知识含量、可讲解的工作 |
| **② 共建化**  | 把建设包装为集体活动   | 需要集中力量完成的建设  |
| **③ 劳动换薪** | 把日常维护开放为轻体验  | 日常重复性轻体力工作   |
| **④ 认领化**  | 把农场资产分割为个人专属 | 可分割、可标记的资产   |
| **⑤ 技能传承** | 客人擅长的→农场需要的  | 需要专业技能但自己不会的 |

### ⑤技能传承具体怎么用

不是让客人来干活，是**识别出客人身上有农场需要的技能，然后发起一次交换**。

匹配示例：

|客人有|农场需要|交换方式|
|---|---|---|
|木工技能|户外长椅/木牌/指示牌|教一堂木工课→全年免费停车|
|摄影技能|菜品/场景/活动照片|拍一组宣传照→无限量面包供应|
|绘画技能|路牌/菜单/活动海报|画一批标识→家庭套餐免单|
|花艺技能|入口花境/餐桌花|设计并打理花境→储值卡|
|水电技能|灌溉系统/户外照明|帮忙检修→储值金|
|老人传统手艺|编竹篮/做酱菜|开一次课+做样品→课时费+成品带走|

**关键**：不是"我需要帮忙"，而是"你有的本事在这里有用武之地"。


### 选择优先级：五个模式哪个优先

```
这个工作有知识含量吗？
  ├── 有 → ①课程化（最安全、有收入、可做品牌）
  └── 没有
        ├── 需要集中力量完成吗？
        │   ├── 是 → ②共建化（低成本建设+深度关系）
        │   └── 否 → 客人比我擅长？
        │         ├── 是 → ⑤技能传承
        │         ├── 否 → 是日常重复的轻活吗？        
        │         │   ├── 是 → ③劳动换薪
        │         │   └── 否
        │         │         └── 是可分割的资产吗？
        │         │               ├── 是 → ④认领化
        │         │               └── 否 → 不做
```

### 农场建设公开化方案 · 结构设计

**第一部分：总纲**

| 节 | 内容 |
|:---|:---|
| 1.1 核心理念 | "农场每一件必须干的事，都是与客人建立关系的机会"——用一两句话说清楚为什么要做这件事 |
| 1.2 五种模式总览 | 课程化、共建化、劳动换薪、认领化、技能传承——每种模式一句话定义+一张对比表 |

**第二部分：各模式详述（每种模式独立一节）**

每节包含：
- 模式定义和适合的工作类型
- 典型场景（2-3个具体例子）
- 运营流程（从发现机会→设计互动→执行→收尾，谁做什么）
- 定价/交换原则（多少钱、怎么换）
- 情绪价值设计（客人参加这个会感受到什么）
- 传播设计（这个活动天然产生什么传播素材）
- 风险点与控制

**第三部分：农场工作 × 互动模式对照总表**

列所有必须做的工作，按核心层、引擎A、引擎B、运营卫星分四个表。标注工作内容，频次，难度，是否有故事可讲，是否长期存在等。

同一件工作，**根据客户的需求深度**，从轻参与到深参与，可以设计成不同模式。在匹配模式中，将每个工作项用五种进行模式评估，标记哪些组合值得尝试，并进行情绪价值光谱分析。同样的工作，不同的设计方式，提供的情绪价值完全不同。



**第四部分：执行流程**

| 节           | 内容                                  |
| :---------- | :---------------------------------- |
| 4.1 发现与识别   | 谁（通常是运营主管+各板块主理人）在日常工作中发现"这个工作可以开放" |
| 4.2 评估与决策   | 用决策树判断用哪种模式（参考之前画的那棵决策树）            |
| 4.3 设计与发布   | 招募信息怎么写、发在哪（朋友圈/社群/小黑板）、流量转换分析      |
| 4.4 执行与现场管理 | 活动现场谁负责、物资清单、安全告知                   |
| 4.5 收尾与传播   | 活动结束后做什么（证书/铭牌/照片/朋友圈总结）            |
| 4.6 记录与复盘   | 每次活动记录什么数据、谁来复盘                     |

**第五部分：风险与合规**

| 节                  | 内容                    |
| :----------------- | :-------------------- |
| 5.1 风险分级           | 每类活动的风险等级（低/中/高）和控制措施 |
| 5.2 保险要求           | 公众责任险覆盖范围，活动是否需要额外投保  |
| 5.3 免责协议           | 标准化免责条款模板             |
| 5.4 活动安全 checklist | 活动前必须确认的事项清单          |

**第六部分：执行建议**
对方案执行的具体建议
每个项目启动前问自己三个问题
如何设计最小可测试单元


**第七部分：附录**

- 招募文案模板（不同模式的文案范例）
- 免责协议模板
- 活动记录表模板
- 铭牌/证书模板
