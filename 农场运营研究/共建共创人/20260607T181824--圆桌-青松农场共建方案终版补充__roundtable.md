## 议题

针对终版共建方案，五位代表各提出2-3条改善意见，言渊逐条裁定。

---

## 裁定结果

### 一、运营与财务（石嫣）

| 编号 | 改善意见 | 裁定 | 终版表述 |
|:---|:---|:---:|:---|
| S1 | 院子分批交付（原建议8个月完成） | ✏️修改 | **2个月内完成全部50个院子交付**，按签约顺序分批 |
| S2 | 消费金不清零，可转赠直系亲属 | ✅同意 | 首年5000消费金**永久有效**，未用完自动结转，**可转赠直系亲属**使用 |
| S3 | 院子代管服务（50-100元/月，付费可选） | ✅同意 | 农场提供**可选院子代管服务**（除草/水电巡检/通风），收费50-100元/月 |

### 二、情感与仪式（陈晓卿）

| 编号 | 改善意见 | 裁定 | 终版表述 |
|:---|:---|:---:|:---|
| C1 | 立牌仪式——共建者亲手钉铭牌，拍照存档 | ✅同意 | 院子交付当天举行**立牌仪式**：共建者亲手将铭牌钉在院门口松树上，农场拍摄两张照片（举锤+铭牌特写），一张给共建者，一张留存农场共建者墙 |
| C2 | 院子日志——每院一本手写记录本 | ⏸️暂留 | 暂不纳入方案正文，保留为未来可选项 |
| C3 | 50年后一封信——言渊手写，封存 | ⏸️暂留 | 暂不纳入方案正文，保留为未来可选项 |

### 三、价值与权益（江南春）

| 编号 | 改善意见 | 裁定 | 终版表述 |
|:---|:---|:---:|:---|
| J1 | 消费金永久结转——用不完不清零 | ✅同意 | 同S2——消费金**永久有效**，自动结转 |
| J2 | 终身9折覆盖团建/大席等大额消费 | ✏️修改 | **仅限共建人本人及其直系家属消费**享有终身9折。**不覆盖**团建、农村大席、商业活动等非个人消费场景。需在协议中**明确注明适用范围** |
| J3 | 旺季提前7天优先预约权 | ✅同意 | 共建者在法定节假日及暑期（7-8月）享有**提前7天优先预约权**（小院续租/活动/课程），7天后开放散客 |

### 四、社群与长期（藤田和芳）

| 编号 | 改善意见 | 裁定 | 终版表述 |
|:---|:---|:---:|:---|
| T1 | 共建者轮值制度——每季度2-3人列席运营复盘会 | ✅同意 | 每季度邀请**2-3位共建者轮值列席**农场运营复盘会，听取经营数据和下季计划，可提问建议，不参与投票 |
| T2 | 《共建者通讯》季刊——纸质+电子 | ⏸️暂留 | 暂不纳入方案正文，保留为未来可选项（当前团队精力有限） |
| T3 | 共建者引荐权——退出名额由现有共建者引荐填补 | ✅同意 | 若共建者退出产生空缺，现有共建者享有**优先引荐权**。被引荐人经农场+共建者群体审核通过后加入，引荐人获非金钱奖励（如院子续租9折→8折） |

### 五、风险与边界（塔勒布）

| 编号 | 改善意见 | 裁定 | 终版表述 |
|:---|:---|:---:|:---|
| N1 | 撤回权公式化——可退金额精确计算 | ✅同意 | 可退金额 = 15000元 - 消费金已使用额度 - 实物已领取价值（蔬菜5元/斤、鸡80元/只）- 院子已使用月份×300元/月。**公式写入协议** |
| N2 | 不可抗力条款——灾/疫/政策写清处理方式 | ✅同意 | 因自然灾害、疫情封控、政策变化等不可抗力导致权益无法兑现的：权益自动暂停不视为违约，暂停期间权益相应延长。极端情况（农场严重损毁无法经营）下身份处理方式另见条款 |
| N3 | 休眠唤醒机制——12月无活动主动联系 | ✅同意 | 共建者连续**12个月无任何活动记录**，农场主动联系一次确认状态。①回应"暂时来不了但不想退出"→身份保留，院子可转租（收益归原共建者）；②不回应或主动放弃→按撤回权处理 |

## 终版共建方案（含改善意见整合版）

### 基本参数

| 项目 | 数值 |
|:---|:---|
| 招募人数 | 50人 |
| 投资金额 | 1.5万元/人 |
| 总融资 | 75万元 |
| 共建者身份 | 终身（与农场同寿，30年租约期） |
| 年续费 | 无 |

### 完整权益清单

| 序号 | 权益 | 详细说明 |
|:---|:---|:---|
| ⭐ | **终身共建人铭牌** | 独立前置。院子交付当天举行立牌仪式——共建者亲手将铭牌钉在院门口松树上，农场拍摄举锤照+铭牌特写照，一张给共建者，一张留存共建者墙。只要农场存续，名字永远在。 |
| ① | **松林小院1年使用权** | 松林中圈约100㎡，通水电。共建者自主装修/使用。**2个月内全部50个院子交付完成**，按签约顺序分批。1年到期可续租（标准价9折），可转让（约束见下条）。到期不续：东西可带走，不带走农场任意处置。农场提供**可选院子代管服务**（50-100元/月）。 |
| ② | **小院转让权** | 仅小院使用权可转让，收益归共建者。约束：限直系亲属或农场审核通过；转让时重新建联；禁加价；使用须与农场调性一致（休闲/种植/手作/小聚），禁纯商业经营/破坏环境/破坏调性，违规农场有权收回。 |
| ③ | **首年消费金5000元** | **永久有效**，未用完自动结转，可拆分使用，**可转赠直系亲属**。 |
| ④ | **终身9折** | **仅限共建人本人及其直系家属**全场消费终身9折。**不覆盖**团建、农村大席、商业活动等非个人消费场景。协议中明确注明适用范围。 |
| ⑤ | **100斤蔬菜+4只散养鸡** | 当季产出，农场配送或自提 |
| ⑥ | **全年2次共创人聚会** | 农场统一组织 |
| ⑦ | **共建者基金投票权** | 农场年收入2%注入共建者专属基金，共建者投票决定用途 |
| ⑧ | **第一年末撤回权** | 可退金额 = 15000 - 消费金已用额度 - 实物已领价值（蔬菜5元/斤、鸡80元/只）- 院子已用月份×300元/月。**公式写入协议**。铭牌保留，后续权益终止。 |
| ⑨ | **年度共建日** | 每年至少参与一次共建活动（帮厨/除草/拍照/写文等） |
| ⑩ | **旺季优先预约权** | 法定节假日及暑期（7-8月）享有提前7天优先预约权（小院续租/活动/课程） |
| ⑪ | **共建者轮值** | 每季度2-3人轮值列席农场运营复盘会，听经营数据和计划，可提问建议，不投票 |
| ⑫ | **共建者引荐权** | 空缺名额由现有共建者优先引荐，被引荐人经农场+共建者审核通过后加入，引荐人获续租折扣升级（9折→8折） |
| ⑬ | **不可抗力条款** | 自然灾害/疫情/政策导致权益无法兑现：自动暂停不视违约，暂停期权益延长；极端情况另见条款 |
| ⑭ | **休眠唤醒** | 连续12月无活动记录→农场主动联系。回应保留→身份续存，院子可转租（收益归己）；不回应或放弃→按撤回权处理 |
| ⑮ | **其他活动权益** | 视农场组织的活动而定 |

### 财务测算（更新）

| 项目 | 单人成本 | 50人合计 | 类型 |
|:---|:---:|:---:|:---|
| 铭牌+立牌仪式 | ≈50元 | 2500元 | 一次性 |
| 院子基建（通水电+围栏） | 300元 | 1.5万 | 一次性（农场固资） |
| 首年消费金5000（食材成本约40-50%） | 2000-2500元 | 10-12.5万 | 长期（永久有效，成本分散） |
| 终身9折（限个人及家人） | 利润率减少约2-3% | 长期影响 | 长期 |
| 蔬菜+鸡 | 约820元 | 4.1万 | 年度 |
| 聚会 | 约200元 | 1万 | 年度 |
| 代管服务 | 收入项（可选） | 收入项 | 可选收入 |
| 共建者基金 | 年收入2% | 视收入 | 年度 |
| **首年预估总成本** | **约3370-3870元/人** | **约16.9-19.4万** | |
| **农场实收** | **1.5万/人** | **75万** | |
| **首年可支配（用于运营启动）** | | **约55.6-58.1万** | |

> 消费金从1年有效期改为永久有效——成本并非集中在首年，而是分散到后续年度，实际首年现金支出更少。

## 开放问题（更新）

1. 院子转让审核的具体标准和拒绝转让的情形
2. 不可抗力极端情况（农场严重损毁）下身份处理的具体条款
3. 共建者基金的投票权重和通过门槛
4. 共建日的记录方式和缺席处理
5. 院子使用规范违规的判定→警告→整改→收回流程
6. 50个院子的选址和建设排期（2个月内完成的具体计划）
7. 共建者协议的完整法律文本定稿
