# 青松农场供应链管理策略方案

> **性质**：策略设计（非SOP）
> **适用对象**：言渊 + 各板块主理人
> **核心目标**：在"3人团队 + 生态种养 + 体验优先"的前提下，建立一套能指导日常采购决策的供应链策略
> **编写日期**：2026-06-02

---

## 一、整体供应链结构

核心（生态种养）产出 → 客户体验优先分配 → 引擎A餐饮分配
外部采购 → 批发市场为主渠道 → 尽量减少库存
两类供应链在引擎A汇合，补充自产不足的部分

---

## 二、自产 vs 外采策略

### 2.1 品类策略总表

| 品类                | 策略        |   目标自给率   | 理由                    |
| :---------------- | :-------- | :-------: | :-------------------- |
| 叶菜类（生菜/菠菜/油菜/小青菜） | 优先自产      |    70%    | 生长周期短，客户辨识度高，引擎A用量稳定  |
| 鸡蛋                | 优先自产      |    70%    | 散养鸡画面感强，客户触点高，蛋品品质可感知 |
| 香草类（薄荷/罗勒/迷迭香）    | 优先自产      |    90%    | 占地少、产量高、易种植，几乎可全覆盖    |
| 番茄/辣椒/茄子          | 旺季自产/淡季外采 | 50%（全年加权） | 挂果期长但冬季需大棚            |
| 玉米/南瓜/根茎类         | 体验导向自产    |   不计自给率   | 主要为客户体验，产量随缘          |
| 米面粮油              | 全部外采      |    0%     | 非农场擅长领域               |
| 猪肉/牛肉/鸡肉          | 全部外采      |    0%     | 养殖投入大、周期长             |
| 木炭/柴火/调料/一次性用品    | 全部外采      |    0%     | 成本敏感型物资               |
| 露营装备/手作材料         | 全部外采      |    0%     | 按需采购                  |
|                   |           |           |                       |

### 2.2 自给率70%的执行路径

第1年目标：叶菜+鸡蛋自给率达到30%（翻地+种叶菜+30只蛋鸡）
第2年目标：叶菜+鸡蛋自给率达到50%（稳定轮作+蛋鸡扩到60只）
第3年目标：叶菜+鸡蛋自给率达到70%（稳定体系+蛋鸡扩到100只+大棚补充冬季产出）

不自产不代表降低品质标准——外采食材同样需验收合格。

## 三、多通道分配策略

### 3.1 分配优先级

第一优先：客户体验通道
- 客户采摘（劳动换薪/付费采摘）
- 展示台陈列（"今日自产"信任展区）
- 认领地块客户

第二优先：引擎A通道
- 当日菜单食材
- 加工储存（做酱/做干/冷冻）

第三优先：其他通道
- 堆肥/酵素原料（仅限不可食用部分）
- 员工餐

### 3.2 执行规则

- 体验区不断供：客户采摘区始终保留充足挂果，引擎A缺货也不动用
- 展示台"永远有"：哪怕每天只放5颗番茄+3个鸡蛋，只要每天有
- 引擎A先用次级品：外观最好的留给客户体验和展示，品相稍次的供引擎A
- 引擎A缺口外采：不因自产不够而削减菜单
- 季节性过剩：优先加工储存（番茄酱/泡菜/冷冻），其次社群通知会员采摘

### 3.3 每日分配流程

每日早晨采收时按以下顺序：
1. 查看Hermes当日预约情况（客户采摘预约数+引擎A预约人数）
2. 预留体验区所需量（比预约多备20%）
3. 预留展示台（少量但必须有）
4. 剩余部分供应引擎A
5. 引擎A缺口通知外采
6. 自产过剩通知运营卫星安排加工储存或社群推送

## 四、季节性平衡策略

### 4.1 四季供应特征

| 季节 | 自产供应量 | 主要自产品类 | 外采压力 |
|:---|:---:|:---|:---:|
| 春季（3-5月） | 低到中 | 叶菜、香草 | 中等 |
| 夏季（6-8月） | 高 | 叶菜、番茄、辣椒、茄子、玉米、蛋 | 低 |
| 秋季（9-11月） | 中到高 | 第二茬叶菜、南瓜、根茎、蛋 | 中 |
| 冬季（12-2月） | 低 | 大棚叶菜（如有）、蛋 | 高 |

### 4.2 淡季应对

- 提前11月确定冬季供应商和价格（锁定价格防涨价）
- 冬季菜单调整为外采可稳定供应的品类为主
- 秋季过剩的根茎类（南瓜/红薯/土豆）储存供冬季使用
- 冬季提高外采肉类比例，下调叶菜比例
- 展示台保持"有"——冬季展示大棚叶菜或储存根茎即可

### 4.3 旺季加工储存

夏季/秋季过剩处理：制番茄酱、晒辣椒干、制果酱、剥粒冷冻、香草烘干
加工储存量占过剩量的比例不超过50%（留出客户体验和引擎A加量的空间）

## 五、损耗控制策略

### 5.1 损耗率目标

| 损耗类型 | 定义 | 目标损耗率 |
|:---|:---|:---:|
| 采收损耗 | 采收过程中损坏/遗漏 | 不超过3% |
| 储存损耗 | 储存过程中变质/过期 | 不超过2% |
| 加工损耗 | 切配过程中去皮去根等 | 不超过5%（边角料做堆肥） |
| 餐前损耗 | 备了但没卖出去的 | 不超过5% |
| 综合供应链损耗率 | 从采收到消费的总损耗 | **不超过8%** |

### 5.2 损耗控制策略

- 按需采收：不提前大量采收，根据当日需求决定采收量
- 先进先出（FIFO）：外采食材标注日期，先入库先使用
- 边角料循环：蔬菜边角料做堆肥或酵素，不可食用的做鸡饲料，蛋壳晒干做钙肥
- 按预约备料：引擎A根据Hermes预约数据备料，非周末按基础量备
- 损耗记录：每次损耗在Hermes记录（品种/数量/原因），月度分析调整备料策略

## 六、供应商管理原则

### 6.1 供应商选择原则

| 原则 | 说明 |
|:---|:---|
| 就近优先 | 潍坊本地供应商优先，缩短运输距离 |
| 稳定性优先于最低价 | 能稳定供货的优于单次最低价 |
| 品质可验 | 接受到货验收标准，不合格可退换 |
| 账期友好 | 优选接受月结的供应商 |

### 6.2 供应商分级

A级供应商（核心供应商）：供应米面粮油/肉类/大宗食材
- 要求：月结+送货上门+品质保证
- 数量：同品类保留1家主供+1家备用

B级供应商（补充供应商）：供应调料/一次性用品/特殊食材
- 要求：价格合理+可小批量采购
- 数量：按需，不固定

C级供应商（临时应急）：临时缺货补充
- 渠道：本地批发市场/社区超市
- 要求：能当天到货即可

### 6.3 比价原则

- 常规采购（每月固定）：每季度比价一次，比价不少于2家
- 大宗采购（单次1000元以上）：每次比价不少于2家，言渊审批
- 紧急采购（当日缺口）：不用比价，迅速补货，事后记录原因和金额

### 6.4 成本敏感型物资降本策略

| 物资 | 降本策略 |
|:---|:---|
| 木炭 | 季度初一次采购一个季度的量，锁定价格，按消耗采购不囤积 |
| 柴火 | 与本地木材加工厂/园林公司合作回收废弃木料；核心层修剪枝条自用 |
| 调料/一次性用品 | 统一品牌规格集中采购；选用中档品质（太低影响体验，太高增加成本） |
| 露营装备 | 优先维护延长寿命（B-06物资管理）；大件装备批量采购谈折扣 |
| 手作材料 | 优先使用核心层自产自然材料，外购材料控制单次课程成本率不超过20% |

## 八、与现有体系的衔接

- A-03备料与切配：每日备料量参考"体验优先、引擎A其次"分配原则
- A-06食材安全管理：外采食材验收标准纳入食品安全管理体系
- B-06露营区物资管理：消耗品补货线参考"尽量减少库存"原则
- H-02手作材料管理：材料采购优先使用核心层自产自然材料
- C-00年度种植日历：种植品种参考引擎A需求+客户体验需求双向平衡
- G-01财务管理：采购成本按板块归集，月度分析食材成本率
