### 一、课程分类与开发

```
1. 课程分类

   自然手作类（可带走作品）
   - 植物拓染（春季/夏季）
   - 松果手作（秋季/全年）
   - 草木染（夏季/秋季）
   - 竹编/草编（全年）
   - 木工小件（全年）
   - 蜂蜡蜡烛/香皂（全年）

   农事体验类（与核心层协作）
   - 堆肥体验课（休耕期）
   - 种子球制作（春季）
   - 扦插/育苗体验（春季/秋季）
   - 酵素制作（全年）

   食物手作类（与引擎A协作）
   - 面包窑烤面包（全年）
   - 手工豆腐/豆花（全年）
   - 果酱/泡菜制作（丰收季）
   - 柴火灶烹饪体验（全年）

2. 课程开发流程
   a) 发现课程灵感（客户需求/季节素材/农场资源）
   b) 设计课程方案（时长/流程/材料/定价）
   c) 试做验证（自己先做一遍，确认可行）
   d) 编写课程教案（步骤/要点/话术）
   e) 材料清单确认和备料
   f) 上架到课程目录
```

### 二、课程定价与时长

```
1. 定价策略

   入门体验课（45-60分钟）
   - 适合初次体验、低龄儿童
   - 定价：38-58元/人
   - 作品：简单可带走

   深度体验课（90-120分钟）
   - 适合亲子/成人/手作爱好者
   - 定价：68-128元/人
   - 作品：完整可带走+知识讲解

   系列课程（4次/期）
   - 适合深度爱好者
   - 定价：198-298元/期
   - 内容：系统学习+进阶技巧

2. 折扣策略
   - 会员享8折
   - 团建客户享7折（10人以上）
   - 长搭客户享8折
   - 两人同行享9折
```

### 三、课程执行流程

```
1. 课前准备（提前1天）
   - 确认预约人数
   - 准备材料包（每人一份，多备2份）
   - 场地布置（桌椅/工具/展示样品）
   - 准备展示样品（让客户看到成品效果）

2. 课程开场（5分钟）
   - 自我介绍
   - 介绍今天要做的作品
   - 展示成品效果
   - 告知时长和流程

3. 教学过程
   - 分步骤演示（做一个步骤，学员跟一个步骤）
   - 每个步骤讲解要点和技巧
   - 巡场指导（关注进度慢的学员）
   - 鼓励创意（不要求完全和样品一致）

4. 收尾（5分钟）
   - 帮助完成最后步骤
   - 拍照留念（客户与作品合影）
   - 作品包装（方便带走）
   - 收集反馈
```

### 四、课后工作

```
1. 材料整理
   - 剩余材料归位
   - 工具清洗归位
   - 场地清理

2. 客户跟进
   - 在Hermes记录参与客户
   - 推送课程照片给客户（24小时内）
   - 邀请加入手作兴趣群
   - 推送下期课程预告

3. 课程复盘
   - 记录课程执行情况（准时/参与度/问题）
   - 收集客户反馈
   - 优化课程方案
```

### 五、课程质量标准

```
1. 学员能完成一件可带走的作品
2. 课程时长控制在实际预约时间的±10%以内
3. 教学节奏让不同年龄/能力的学员都能跟上
4. 有拍照环节（客户与作品合影）
5. 课后客户满意度≥4.5分
6. 课程材料损耗率≤10%
```

### 六、验收标准

```
□ 课程方案已完成并审核
□ 课前材料已备齐（每人一份+备用2份）
□ 展示样品已准备
□ 课程按时开始/结束
□ 每位学员完成作品并带走
□ 客户合影已拍摄
□ 客户反馈已收集
□ Hermes课程记录已更新
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 学员进度慢跟不上 | 一对一帮助或简化步骤 |
| 材料不足 | 临时调整方案，用替代材料 |
| 作品制作失败 | 帮助补救，重新制作或换成其他作品 |
| 低龄儿童无法完成 | 家长协助或提供简化版 |
| 客户对作品不满意 | 了解原因，赠送材料回家重做 |
| 预约人数不足（≤2人） | 合并时段或取消（提前48小时通知） |

### 八、跨板块协作

- 农事体验类课程：与**核心层**协作（材料/场地/知识内容）
- 食物手作类课程：与**引擎A**协作（使用厨房设备/食材）
- 团建客户的课程需求：与**引擎B**对接
- 课程招募：与**O-06社群运营**配合宣传
- 课程材料采购：提报**运营卫星**统一采购

### 九、客户触点

- 自然手作是农场"带得走的回忆"，作品是客户回家后持续感受农场温度的物品
- 教学过程中"鼓励创意"比"教得标准"更重要——让客户有成就感
- 拍照环节不可省略，客户与作品合影是社群传播的最佳素材
