# 自然体验板块：产品扩展建议

> **背景**：自然手作卫星现有2个产品线（自然教育 + 手作体验）。以下为可补充的产品方向，供评估。
> **筛选标准**：与现有产品不冲突、能复用农场资源、有明确的目标客群。

---

## 一、补齐年龄缺口——7-14岁大龄儿童与青少年

自然教育的课程（4-10岁）覆盖了学龄前和小童，但**7-14岁的大童/青少年目前是空白**。他们的需求和4-6岁孩子完全不同——他们不需要"带着玩"，需要"有点挑战"的事。

### 推荐方向：自然探索营

| 项目 | 内容 |
|:---|:---|:---|
| 定位 | 深度课形态，半日/全日独立营（孩子独立参加，家长不陪同） |
| 定价 | 198-298元/半日，398-598元/全日 |
| 目标客群 | 7-14岁，父母愿意为"让孩子独立做一件事"付费 |
| 内容示例 | 松林定向越野（指南针+地图+打卡点）、野外生火与防火教育、用自然材料搭建遮蔽所、自然笔记+标本采集 |
| 与现有产品的关系 | 与自然教育共享教案体系，只是内容深度和难度不同 |
| 启动成本 | 极低——不需要新设施，只需设计路线+培训老师+安全预案 |

### 推荐方向：暑期独立营（3天2夜/5天4夜）

如果7-14岁的独立营跑通了，可以升级为多日营。这是自然体验板块**客单价最高的产品**，按天收费500-800元/天，3天营就是1500-2400元/人。

但这是重运营产品——需要住宿、全天看护、餐饮、活动设计。建议不着急，等自然教育和探索营跑稳了再考虑。

---

## 二、补齐大人需求——没有孩子的成年人

现有产品（自然教育+手作体验）的客群是**"带有孩子的家长"**。但农场有不少客户是没有带孩子、自己来的成年人。他们来农场做什么？目前除了露营和吃饭，没有别的选择。

### 推荐方向：成人自然疗愈

| 项目 | 内容 |
|:---|:---|:---|
| 定位 | 引流产品（轻量、低门槛、有传播力） |
| 定价 | 68-128元/人/次 |
| 目标客群 | 25-45岁，工作压力大，想找个地方"静一静"的成年人 |
| 内容示例 | **松林正念行走**（Slow walk in the forest，导师引导呼吸+感知，全程静默）——这在日本叫森林浴（Shinrin-yoku），有成熟的理论体系；**树下颂钵疗愈**（找个松树下，颂钵+引导冥想）；**森林瑜伽/八段锦**（早晨或傍晚，松林里的晨练） |
| 特别价值 | 这些活动几乎零成本——不需要材料、不需要复杂设施，导师+松林空地即可 |
| 与人手的关系 | 不需要专门招人。如果自然手作卫星主理人本身有正念/瑜伽基础，直接带；如果没有，找潍坊城区的瑜伽老师合作（分成制，老师带队，农场提供场地和客户） |

### 推荐方向：自然摄影工坊

| 项目   | 内容                                                                    |     |
| :--- | :-------------------------------------------------------------------- | :-- |
| 定位   | 引流+传播产品                                                               |     |
| 定价   | 88-168元/人/次                                                           |     |
| 目标客群 | 喜欢拍照的年轻女性、妈妈群体（想要"拍出好看的照片发朋友圈"）                                       |     |
| 内容   | 手机摄影技巧（在松林里怎么构图、怎么利用光线、怎么拍出氛围感）→ 导师带在农场里走一圈拍一组照片 → 每个人产出3-5张可以发朋友圈的照片 |     |
| 特别价值 | 这个产品本身就是"如何为农场拍照"的培训——客户上完课发朋友圈的照片质量高了=农场的传播质量高了                      |     |

## 三、补齐"亲子一起做"的场景

自然教育是"孩子上课"（家长在旁或做手作），手作体验是"妈妈自己做"。但**缺少一个产品是家长和孩子一起参与的**。

### 推荐方向：自然运动会（季节性产品）

| 项目   | 内容                                                                     |     |
| :--- | :--------------------------------------------------------------------- | :-- |
| 定位   | 引流+事件型产品（不是每周都有，是季节性大活动）                                               |     |
| 定价   | 家庭套票：68元/组（含3-4个项目）                                                    |     |
| 目标客群 | 所有家庭                                                                   |     |
| 内容示例 | 松果投掷比赛、拔河（已有）、草地接力跑、树叶辨识寻宝、亲子两人三足。积分制——完成所有项目后换一个小奖品（比如一块手工皂小样/一个窑烤面包） |     |
| 组织方式 | 一个季度一次（春/秋各一次，避开夏冬极热极冷）。提前1-2周在社群预告，当天分时段场次（2小时/场）                     |     |
| 价值   | 不靠这个赚钱，靠"营造热闹气氛"——满草坪的家庭跑来跑去=最好的活广告                                    |     |

## 四、补齐"仪式感"——自然生日会/自然派对

现有产品缺少一个**"客户可以邀请别人来"**的场景。

| 项目 | 内容 |
|:---|:---|:---|
| 定位 | 高客单价+传播力极强的锚点产品 |
| 定价 | 980-1680元/场（含场地+活动+简餐，约10-15个孩子） |
| 目标客群 | 已经在农场上过课的家庭（有信任基础）→ 孩子生日时自然想到"在农场办" |
| 内容 | 松林寻宝游戏 → 自然手作（每人做一个小作品带走）→ 松林下吃蛋糕 → 自由跑玩 |
| 传播价值 | **每一位来参加生日会的孩子和家长，都是第一次接触到农场的潜在客户。** 假设一场10个孩子，每人带父母2人 = 30个准客户到店。一次生日会=一场小型引流活动 |
| 人手的限制 | 不必专门安排人员。自然手作卫星主理人带手工环节，引擎A负责简餐（三明治+水果+饮品），引擎B提供场地和布置 |

## 五、补齐"全年节奏"——四季庆典

| 项目  | 内容                                                                                                                                   |     |
| :-- | :----------------------------------------------------------------------------------------------------------------------------------- | :-- |
| 定位  | 大型引流活动（一年4次，作为农场的自然节庆）                                                                                                               |     |
| 定价  | 免费/低票价入场（靠餐饮和零售赚回）                                                                                                                   |     |
| 内容  | **春季：开耕节**（核心区开耕仪式+种下第一粒种子+手作种子球体验） **夏季：夏至萤火虫之夜**（如果有的话）/ **星空露营节**（引擎B联动） **秋季：丰收节**（掰玉米比赛+南瓜雕刻+大席长桌宴） **冬季：冬至围炉节**（篝火+热红酒+松枝花环手作） |     |
| 价值  | 一年4次固定事件 = 4次客户"即使没有特别理由也会关注农场"的理由。庆典本身就是内容素材——小红书/抖音各发一次，全年获客                                                                       |     |

## 六、扩展建议的优先级排序

| 优先级 | 产品 | 理由 |
|:---|:---|:---|
| **P0** | 自然探索营（7-14岁独立营） | 填补年龄缺口，深化自然教育体系，启动成本极低 |
| **P0** | 自然生日会 | 现有客户内部的自然裂变，"一场生日会=一场小型引流活动" |
| **P1** | 成人自然疗愈（森林浴/瑜伽） | 零启动成本，填补"没带孩子来的成年人"的空白 |
| **P1** | 自然摄影工坊 | 既引流又教会客户拍照=提升农场传播质量 |
| **P2** | 四季庆典（春耕/秋收/夏夜/冬至） | 大型活动需整体协调各板块，建议自然手作卫星跑稳后再推 |
| **P2** | 自然运动会 | 季节性，安排一次试试效果再决定是否常态化 |

---

## 七、一句话总结

现在的产品线（自然教育+手作体验）覆盖了**4-10岁孩子**和**妈妈**。扩展的方向是向上和横向：

```
向上补年龄：7-14岁 → 自然探索营 → 暑期独立营
横向补人群：成年人 → 森林浴/摄影
向上补场景：亲子一起 → 自然运动会/生日会
拉高拉节奏：全年 → 四季庆典
```
