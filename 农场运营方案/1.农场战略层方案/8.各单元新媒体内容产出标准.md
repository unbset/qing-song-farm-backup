# 各单元新媒体内容产出标准

> **更新日期**：2026-05-29（基于流量漏斗模型V1的重订）
> **前提确认**：各主理人负责自己板块的自媒体，农场有统一账号。不设独立内容部门。
> **核心变化**：漏斗模型显示月需总曝光约50万次，原每周1条的频率不足以支撑。
> **原则**：在不影响主业的前提下，提升内容产出频次和质量。不求爆款，求持续稳定。

---

## 一、内容分工体系（谁负责漏斗的哪个环节）

从流量漏斗模型得出的结论：各单元内容在不同漏斗阶段发挥不同作用，不能"各发各的"。

```
曝光层（月需50万+）
  ├── 引擎A（餐饮）——烟火气吸引泛流量，让人"想来吃"
  ├── 引擎B（露营）——场景感吸引精准流量，让人"想来住/玩"
  └── 言渊/运营卫星——品牌深度内容，建立认知
      ↓
预约层（月需到店400+人）
  ├── 引擎B（露营）——活动/团建/长搭的直接预约转化
  ├── 自然手作卫星——课程预约的直接转化
  └── 所有内容——每条内容必须包含"到店理由"
      ↓
消费层（月需首次消费260+人）
  ├── 引擎A（餐饮）——到店后的消费转化
  └── 引擎B（露营）——到店后的消费转化
      ↓
复购层（月需复购40+人）
  └── 种植养殖——信任背书：让客户相信这里好，愿意再来
      ↓
会员层（月需新增会员10-12人）
  └── 言渊/运营卫星——深度内容转化高价值会员
```

## 二、各单元内容产出标准

### 引擎A（餐饮主理人）

**漏斗定位**：农场流量入口——承担最大的曝光任务

**账号定位**：农场的"烟火气"——让人看了就想来吃。

| 项目 | 原标准 | 新标准 | 说明 |
|:---|:---|:---:|:---|
| **频次** | 每周≥1条 | **每周≥2条** | 餐饮内容是最容易吸引泛流量的类型，承担50%的曝光任务 |
| **平台** | 未指定 | **以抖音为主+小红书同步** | 抖音适合烟火气内容爆发，小红书适合精准获客 |
| **内容方向** | 窑鸡/备菜/日常 | **增加2个方向** | 见下方内容矩阵 |
| **"到店理由"** | 无要求 | **每条必须有** | 见下方标注 |
| **拍摄方式** | 手机横屏15-60秒 | 不变 | |
| **发布账号** | 个人号首发+主号转载 | 不变 | |
| **耗时控制** | ≤20分钟/周 | ≤30分钟/周 | 新增1条约加10分钟 |

**内容矩阵（每周2条搭配）**：

| 类型 | 占比 | 目的 | 示例 | 平台侧重 |
|:---|:---:|:---|:---|:---:|
| A类：出餐过程/成品特写 | 50%（每周1条） | 曝光引流，引发食欲 | 窑鸡出炉瞬间、大锅卤沸腾、披萨拉丝 | 抖音 |
| B类：客户就餐场景 | 25%（每2周1条） | 营造氛围，驱动预约 | 柴火灶前一家人在炒菜、篝火旁吃烧烤 | 抖音+小红书 |
| C类：食材故事 | 25%（每2周1条） | 信任背书，为复购埋种 | 今天用的菜是从菜地现摘的 | 小红书 |

**每条内容的"到店理由"四要素**（必须包含，文字或口播均可）：
1. 我们在哪（地址/导航关键词）
2. 有什么（产品/价格区间）
3. 怎么约（是否需要提前预约/电话/私信）
4. 什么时候来（营业时间/最佳时段）

### 引擎B（露营住宿主理人）

**漏斗定位**：流量入口+预约转化主力

**账号定位**：农场的"松弛感"——松林下的时光。

| 项目 | 原标准 | 新标准 | 说明 |
|:---|:---|:---:|:---|
| **频次** | 每周≥1条 | **每周≥2条** | 露营内容是预约到店转化率最高的内容类型 |
| **平台** | 未指定 | **抖音+小红书并重** | 小红书适合露营地推荐类内容，抖音适合场景氛围 |
| **内容方向** | 松林晨光/篝火/团建花絮 | **增加活动预告和客户见证** | 见下方内容矩阵 |
| **"到店理由"** | 无要求 | **每条必须有** | 见下方标注 |
| **拍摄方式** | 手机横屏15-60秒 | 不变 | |
| **发布账号** | 个人号首发+主号转载 | 不变 | |
| **耗时控制** | ≤20分钟/周 | ≤30分钟/周 | 新增1条约加10分钟 |

**内容矩阵（每周2条搭配）**：

| 类型 | 占比 | 目的 | 示例 | 平台侧重 |
|:---|:---:|:---|:---|:---:|
| A类：场景氛围 | 50%（每周1条） | 曝光引流 | 松林晨光、傍晚篝火、星空帐篷 | 抖音 |
| B类：客户体验/活动花絮 | 25%（每2周1条） | 社交裂变+预约转化 | 团建队游戏、长搭客户小院生活、自然运动会片段 | 抖音+小红书 |
| C类：活动预告/招募 | 25%（每2周1条） | 直接转化预约 | 四季庆典报名、周末活动安排 | 小红书+朋友圈 |

**额外要求**：有客户自发拍摄内容时（团建、生日会、聚会），请客户授权后转载——这类内容天然带有社交裂变属性。

### 种植养殖主管（到岗后）

**漏斗定位**：信任背书——不追求曝光量，但内容质量要求更高

**账号定位**：农场的"真实感"——菜是怎么长的、鸡是怎么养的。

| 项目 | 原标准 | 新标准 | 说明 |
|:---|:---|:---:|:---|
| **频次** | 每周≥1条 | **每2周≥1条** | 核心内容不追求量，追求"每一条都值得看" |
| **平台** | 仅在主号发布 | **仅在主号发布** | 核心内容的价值是信任背书，不是独立引流 |
| **内容方向** | 蔬菜生长/鸡群/酵素/堆肥 | **增加"前后对比"类内容** | 见下方说明 |
| **拍摄方式** | 手机横屏15-60秒 | **鼓励30-90秒，展示完整过程** | 信任内容需要时间建立真实感 |
| **耗时控制** | ≤10分钟/周 | ≤15分钟/2周 | |

**为什么降低频次？**
- 漏斗模型显示核心内容的职责不是曝光，而是**提高复购转化率**
- 低频高质的内容比高频低质的信任背书更有效
- 每个月能拍到1-2条真正"有意思"的素材（比如：第一批鸡下蛋了、酵素对比实验、菜地30天变化）比每周凑1条强

**内容方向建议**：
- 生长记录类：同一块菜地每周拍一次，最后剪成"30天从荒地到满园"的延时
- 对比类：使用酵素和不使用酵素的植物对比（真实可信）
- 日常类：捡鸡蛋、翻堆肥、收割蔬菜——越简单越真实

### 自然手作卫星（主理人到岗后）

**漏斗定位**：精准获客+体验转化

**账号定位**：农场的"成长感"——孩子的自然课堂。

| 项目 | 标准 |
|:---|:---|
| **频次** | **每周≥2条**（课程日必发1条+1条预告/花絮/知识分享） |
| **平台** | **小红书为主**（妈妈群体的核心决策平台）+ 抖音辅助 |
| **内容方向** | 见下方内容矩阵 |
| **"到店理由"** | 每条必须有课程价格+适合年龄+报名方式 |
| **拍摄方式** | 手机拍摄，竖屏为主（小红书竖屏流量更高） |
| **发布账号** | 自然手作个人号首发，主号转载 |
| **耗时控制** | ≤30分钟/周 |

**内容矩阵**：

| 类型 | 占比 | 目的 | 示例 |
|:---|:---:|:---|:---|
| A类：课程花絮 | 50% | 精准获客——让妈妈看到"我的孩子也能这样" | 孩子做手工皂的专注瞬间、完成作品的成就感 |
| B类：知识分享 | 25% | 建立专业信任 | "为什么推荐用松针纯露替代花露水"、"节气与食物的关系" |
| C类：报名预告 | 25% | 直接转化 | 周末课程安排、名额剩余、早鸟价 |

---

### 运营卫星/言渊

**漏斗定位**：品牌深度+会员转化——全漏斗串联

**账号定位**：农场的"理念层"——为什么做这件事。

| 项目 | 原标准 | 新标准 | 说明 |
|:---|:---|:---:|:---|
| **频次** | 每周≥2条 | **每周≥2条** | 保持不变 |
| **平台** | 未指定 | **微信生态（视频号+公众号+朋友圈）为主** | 深度内容的传播不在曝光量，在信任度 |
| **内容方向** | 课程花絮+理念分享+季节变化 | **增加"农场日记"系列** | 见下方说明 |
| **发布账号** | 主号+卫星个人号 | 不变 | |

**"农场日记"系列**（建议每周固定1条）：
- 每周1条"青松农场这周发生了什么"——把各单元的内容串起来
- 形式：图片+文字（朋友圈/公众号）或1-2分钟视频（视频号）
- 内容：这周的亮点瞬间+下周预告+一个"本周特别感谢"（可以感谢某位客户/员工/帮了大忙的人）
- 目的：让关注者形成"每周必看"的期待感，建立长期信任

## 三、内容产出的协调流程（更新版）

**每周一上午：各单元在群里发本周内容计划**

```
言渊：我周三拍"农场日记"——这周讲酵素
餐饮：周二拍窑鸡 + 周六拍柴火灶客户
露营：周三拍松林晨光 + 周五发周末活动预告
手作：（到岗后）周六有课会拍花絮
核心：（到岗后）周四拍酵素翻桶进度
```

**为什么改到周一上午？**
- 原方案是周日晚10点→改为周一上午，因为周一大家精力最好，周末刚过也有素材可回顾
- 周一发计划还有一个作用：**哪个单元没发计划，运营卫星可以即时提醒**

**内容排雷规则**：
- 同一天不出现两个单元发同类型内容（比如周一全是吃的）
- 同一周内不出现某个单元连续两周只发同一类内容
- 活动预告类内容需提前至少3天发布（不要今天发今天报名）

## 四、内容的标准和底线（保持不变）

**必须做到的底线**：
- 不摆拍、不用剧本、不讲假话。客户一眼能看出是不是演的
- 不提前吹核心的东西（核心还没建好时，不在内容里暗示"我们有生态种养"）
- 不发与农场无关的内容

**新增一条底线：**
- **每条内容必须包含"到店理由"四要素**（在哪、有什么、怎么约、什么时候来）

**不要求的**：
- 不要求专业剪辑、不要求统一风格
- 不要求固定发布时间（忙的时候晚发一天没关系）
- 不要求每个视频都加话题标签

## 五、数据反馈机制

每周一发计划时，各单元同步上周的数据：

```
餐饮：上周发了2条，曝光共2.3万，私信咨询5人
露营：上周发了2条，曝光共1.8万，预约到店8组
```

**数据来源**：各平台后台即可查看，不需要第三方工具。
**目标**：不是考核KPI，是让每个人都感受到"发了有用"——看到自己发的内容带来了预约和数据增长，才有持续的动力。

当某个单元的曝光连续3周下降时，言渊或运营卫星需要介入一次——不是追责，而是一起看看内容方向是否需要调整。

## 六、频率调整原则

以上频率标准是"漏斗模型需最低量"，实际运营中允许以下调整：

| 情况 | 调整方式 |
|:---|:---|
| 本周有活动/课程 | 可降至1条（活动/课程本身的内容产出已覆盖曝光需求） |
| 本周极端忙碌（节假日高峰期） | 可跳过1周，但需在可预见的间隙补上 |
| 连续两周未达标 | 运营卫星介入——不是追责，是排查"为什么没时间拍了" |
| 农场整体进入淡季 | 频率可下调至每周≥1条，但内容质量要提上来 |
