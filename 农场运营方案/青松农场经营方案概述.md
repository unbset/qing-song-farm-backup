## 一、农场基本面

### 1.1 基础信息

| 项目 | 内容 |
|:---|:---|
| 位置 | 潍坊城区半小时车程 |
| 面积 | 120亩（建设用地3亩+农用地20亩+林地约97亩） |
| 核心资产 | 1000+棵百年油松，已生长13年（合同期剩余33年） |
| 前期投入 | 约400万元（基础设施：水电燃气、硬化路面、700㎡餐厅、住宿建筑均已建成） |
| 当前状态 | 引擎A（餐饮）+引擎B（露营住宿）+自然手作卫星已运营，有稳定客流基础；核心层（生态种养）尚未启动，主理人待招 |

### 1.2 油松资源的独特价值

农场最大的自然禀赋是1000+棵油松，这是同行很难短期复制的核心差异。松树的利用价值贯穿农场多个业务板块：

| 用途 | 对应产品 |
|:---|:---|
| 景观 | 松林露营、松林野餐、松林步道 |
| 护肤 | 松针纯露 |
| 手作 | 松塔香、松针皂、松针编织、松针洗发液 |
| 饮食 | 松针茶、松花粉（仅油松和马尾松可食用） |
| 园艺 | 松针土（腐殖土原料） |

## 二、经营哲学——农场的底层逻辑

### 2.1 农场真正经营的是什么

表面上看，农场在做餐饮、露营、亲子、教育、摄影。但这些都只是**表现形式**。

农场真正经营的是：**城市人与自然之间被割裂的关系的修复。**

城市人缺少的不是一颗白菜或一顿饭，而是：
- 对食物来源的知情权
- 与自然节律同步的踏实感
- 亲手触摸泥土的肉身记忆
- 让孩子知道"食物从哪里来"的教育场景

因此，**农场卖的不是产品、服务或体验，而是"另一种生活的真实样本"。**

### 2.2 一个关键区分：真实 vs 情绪

农场经营中天然包含情绪价值——放松、治愈、陪伴。但**情绪是真实体验的自然结果，而非产品本身。**

| | 情绪作为产品 | 真实作为产品 |
|:---|:---|:---|
| 逻辑 | 不断换新场景刺激客户 | 扎根于客观的物质生产 |
| 结果 | 永远在重新获客 | 客户因信任而复购 |
| 类比 | 网红店速生速死 | 百年老店慢慢生长 |
| 竞争对手 | 商场、火锅店、电影院、短视频 | **没有竞争对手**——城市的番茄不好吃，手机里种不出真的菜 |

### 2.3 第一性原理

经过剥离测试（逐一剥离田园摄影、农产品销售、教育手作、餐饮露营，最后剥离种养循环），得出农场不可剥离的内核是：**这块土地上持续进行的生态生产过程。**

因此，农场经营的第一性原理表述为：

> **以生态系统的持续生产为基础，以客户的深度参与为核心机制，实现人与自然之间长期关系的建立与价值交换。**

这个原理的三个维度不可分割：

| 维度 | 内容 | 为什么不可删除 |
|:---|:---|:---|
| **基础** | 生态系统的持续生产 | 这是"农场"二字的物理前提 |
| **机制** | 客户的深度参与 | 信任建立的唯一有效路径 |
| **目的** | 人与自然的长期关系 | 区别于一次性消费场所的根本 |

**判断任何决策的最高标准**：这项决策是在增强还是在消耗农场的生态资产？

### 2.4 核心价值观

**正心正事，修己及人**——这八个字是农场所有决策的依据。

- **正心**：做事之前审视发心，不藏私心、不自欺欺人
- **正事**：如实还原事情本身应有的价值，不走捷径割韭菜
- **修己**：每个人成为各自领域的专家，竞争力来自理解深度而非营销技巧
- **及人**：把客户当作家人，己所不欲勿施于人

## 三、星形结构——组织与业务架构

### 3.1 架构总览

```
1个核心（战略成本中心）
└── 生态种养 · 客户参与体系 · 劳动换薪

2个引擎（利润中心）
├── 引擎A：餐饮（室内餐+室外矩阵+窑炉产品+野餐篮+农村大席）
└── 引擎B：露营住宿（散客露营+长搭小院+团建+四季庆典）

N个卫星（保障中心）
├── 自然手作卫星（自然教育+手作体验+探索营+生日会+成人疗愈）
├── 运营卫星（公共环境+安全品牌内容+CRM+零售+行政）
└── 田园摄影卫星（项目制，合作模式）
```

### 3.2 三层的关系

| 层 | 角色 | 考核 | 核心逻辑 |
|:---|:---|:---|:---|
| **核心** | 信任底座 | 不考核利润，考核土壤健康度+展示丰富度+客户触达率 | 核心越强，所有上层业务越强 |
| **引擎** | 造血器官 | 自负盈亏 | 把核心的真实产出转化为现金流 |
| **卫星** | 扩音器 | 考核获客+传播 | 让更多人走进农场，提供升级路径 |

**一句话概括**：核心决定能走多远，引擎决定能不能活，卫星决定能长多大。任何一层的扩张都不能以牺牲核心为代价。

## 四、双飞轮加速——增长引擎

### 4.1 飞轮一：信任复利环

```
卫星做内容 → 吸引客户到店 → 客户亲眼验证核心 → 信任建立 → 引擎消费 
    → 收入回流核心 → 核心更强（更多品种/更好展示/客户参与区） 
    → 信任更深 → 传播更猛 → 更多客户到店
```

**加速判断标准**：如果一个客户今年来了两次，第二次看到的东西比第一次多、感受比第一次深，这个环就在加速。

### 4.2 飞轮二：客户结构优化环

客户的逐级升级路径：

```
首次到店（体验引擎A/B）
  → 参加引流课（对核心产生兴趣）
    → 认养一只鸡/租长搭位（周期性回访）
      → 参与劳动换薪（在核心有"自己的东西"）
        → 成为农场常客/带朋友来（主动传播）
```

**每一级升级的价值变化**：

| 客户类型 | 年到店频次 | 人均年消费 |
|:---|:---:|:---:|
| 一次性散客 | 1次 | 200-400元 |
| 餐饮常客 | 2-3次 | 600-1,200元 |
| 自然体验常客 | 3-5次 | 800-2,000元 |
| 认养客户 | 4-6次 | 1,000-2,000元 |
| 长搭客户 | 月2-4次 | 3,000-6,000元 |
| 劳动换薪参与者 | 高频 | 高粘性 |

**核心结论**：把一个一次性散客升级为认养客户，比拉3个新散客的总价值更大。

### 4.3 公开化运营机制——双飞轮的加速器

公开化运营机制替代了早期方案中单一的"劳动换薪"概念，升级为覆盖农场全部87项工作的系统化运营框架。它不是一项独立业务，而是贯穿5个板块、嵌入所有业务单元的信任建设与获客工具。

#### 五种互动模式在飞轮中的角色

| 模式 | 在飞轮中的角色 | 对应客户升级阶段 |
|:---|:---|:---|
| **课程化** | 知识入口——让客户在"学东西"的过程中建立对核心的认知和信任 | 首次到店→参与引流课 |
| **劳动换薪** | 轻参与通道——零门槛的劳动体验让客户获得"我在农场出了力"的参与感 | 引流课后→动手体验 |
| **共建化** | 归属创造——让客户在建设成果上留下自己的印记，产生"这有我一份"的情感 | 体验后→深度绑定 |
| **认领化** | 财产关系——让客户与农场的具体资产（果树/鸡/菜地）建立专属关系 | 绑定期→周期性回访 |
| **技能传承** | 关系深化——将客户擅长的技能与农场的需求做交换，从消费者升级为共建者 | 老客户→深度关系 |

#### 飞轮加速的完整路径

```
内容获客 → 客户到店
  → 课程化（第一次建立认知和信任）
    → 劳动换薪（低成本让客户上手，获得参与感）
      → 共建化（在建设成果上留名，产生归属）
        → 认领化（与具体资产建立财产关系，周期性回访）
          → 技能传承（从消费者升级为共建者，主动传播）
            → 回流核心（客户升级带来的收入+信任+传播，让核心持续增强）
```

每一级升级对应一个公开化模式，5种模式形成一条从轻到深、逐级递进的客户关系深化链。公开化运营机制的核心价值，就是**把"一次性客人"逐级升级为"在农场有印记的人"**。

## 六、AI经营系统——Hermes

### 6.1 定位

不是"自动经营农场"，而是"降低经营复杂度，辅助长期经营决策"。AI的职责是：**记录→整理→复盘→分析→提醒→协助规划**。最终经营决策由人类完成。

### 6.2 系统架构

```
人类CEO（言渊）
  └── Hermes（统一协调入口）
       ├── 调度层：任务分发+记忆写入审批
       ├── 推理层（gbrain）：策略推理+方案对比+联网调研+风险评估
       └── 存储层（hindsight）：长期知识存储+SOP+经验沉淀
```

**核心规则**：推理层不存储，存储层不分析。gbrain产出的思考结果不自动存，需要沉淀时必须经Hermes审批后写入hindsight。

### 6.3 五顶帽子

| 帽子 | 职责 |
|:---|:---|
| CEO | 战略分析、经营复盘、风险提醒 |
| COO | 日常运营协调、排班、任务追踪 |
| CRM | 客户记忆、复购提醒、生日/节气问候 |
| Content | 内容选题、文案辅助、发布计划 |
| Finance | 收支记录、成本分析、现金流预警 |

### 8.3 公开化——信任建设的加速器

公开化是青松农场经营体系中一个独立的、系统性的战略模块，已完成完整的方案设计。

#### 8.3.1 核心理念

> **把农场每一件必须做的事，变成与客人建立关系的机会。**

农场每天发生大量"有内容、有画面、有故事"的环节——菜在长、鸡在跑、面包在窑炉里烤、灯串在松林里挂。过去这些环节只在"后场"发生，客人看不到。公开化的目的就是把它们拉到"前台"，让客人看见、触摸、参与。

**公开化的三大价值**：

| 价值 | 说明 |
|:---|:---|
| **建立信任** | 让客户亲眼看到、亲手摸到农场的真实运作 |
| **放大传播** | 每个参与环节都是客户的"朋友圈素材" |
| **创造归属** | 客户有了"我参与过""我有印记"的情感连接 |

#### 8.3.2 五种互动模式

所有可公开化的工作，按以下5种模式组织：

| 模式 | 本质 | 适合什么工作 | 客户心理 |
|:---|:---|:---|:---|
| **课程化** | 将劳动包装为教育产品 | 有知识含量、可讲解的工作 | "学到了+带走了" |
| **共建化** | 将建设包装为集体活动 | 需要集中力量完成的建设 | "有我的印记" |
| **劳动换薪** | 将日常维护开放为轻体验 | 日常重复性轻体力工作 | "赚了杯啤酒" |
| **认领化** | 将资产分割为个人专属 | 可分割、可标记的资产 | "这是我的" |
| **技能传承** | 客人擅长的转为农场需要的 | 农场需要但自己不擅长的技能 | "我的本事有用" |

#### 8.3.3 全板块覆盖——87项工作×81项可公开

覆盖5个板块共87项日常工作，其中81项可设计为公开化活动（6项因安全/效率/体验原因不公开）。

| 板块 | 工作项数 | 可公开 | 主要模式 |
|:---:|:---:|:---:|:---|
| 核心层（生态种养） | 24 | 21 | 课程化15+共建化5+劳动换薪8+认领3+技能3 |
| 引擎A（餐饮） | 17 | 17 | 课程化11+共建化2+劳动换薪4+认领2+技能3 |
| 引擎B（露营住宿） | 14 | 14 | 课程化6+共建化7+劳动换薪4+认领2+技能4 |
| 自然手作卫星 | 19 | 19 | 课程化19+共建化1+劳动换薪2+认领1+技能4 |
| 运营卫星 | 13 | 10 | 课程化7+技能3+财务透明2 |
| **合计** | **87** | **81** | **课程化58+共建化15+劳动换薪18+认领8+技能17** |

|:---|:---|:---:|

#### 8.3.5 公开化方案的体系结构

公开化方案由6个文档组成，形成"1本总册统领+5本分册落地"的完整体系：

- **总册**：农场建设公开化方案（总册）—— 7个部分，包括执行体系、风险框架、落地路线图、附录
- **分册**：核心层/引擎A/引擎B/自然手作卫星/运营卫星—— 各板块的详细匹配表+执行流程+附录

#### 8.3.6 公开化与农场运营的关系

公开化不是"附加在运营方案之上的额外工作"，而是**嵌入到每一个运营环节中的视角**：

```
运营方案决定"要做什么"（种菜/做面包/搭平台）
公开化方案决定"这些事怎么让客人看到、参与、记住"
两者咬合运作，不是先后关系，而是同一件事的两个面
```

公开化的底线是"不影响生产"。农忙时可以不公开，先保证农场活着。

#### 8.3.7 三阶段落地路线图

| 阶段 | 时间 | 核心动作 |
|:---|:---:|:---|
| 启动期 | 第1-30天 | 劳动换薪小黑板就位；选1个课程化活动试跑；建立每日内容习惯 |
| 扩展期 | 第31-90天 | 各板块≥3个常态项目；跨板块联动活动上线；认领化产品上线；固定课表成型 |
| 成熟期 | 第91天-1年 | 固定课表+月历稳定运行；内容品牌化；公开化制度文档化 |

**一句话总结公开化的意义**：公开化不是"搞活动"，是把成本变成资产、把后台变成前台、把一次性客人变成"在农场有印记的人"。

## 九、风险与挑战

### 9.1 核心风险

| 风险 | 可能性 | 影响 | 应对 |
|:---:|:---:|:---:|:---|
| **核心投入被挤占**（致命风险） | 中高 | **极高** | 核心预算作为每月固定项优先划出，不可挪用；言渊有一票否决权 |
| **种植养殖主管招不到** | 中高 | 高 | 从退休农技员中找；降级为种植顾问+帮工执行；言渊自己带 |
| **内容获客波动大** | 高 | 高 | 分散渠道（抖音+小红书+视频号+朋友圈）；持续积累老带新；按保守预期排人力 |
| **飞轮加速前6个月无可见效果、团队信心动摇** | 中 | 中 | 提前管理预期；选"客户自发拍照率"和"老带新占比"两个先行指标；至少运行6个月再看数据 |
| **主理人没有动力帮别人做转化** | 中 | 中 | 初期不设强制考核；言渊月度复盘时自然问一句形成习惯 |
| **运营主管招不到** | 中 | 高 | 放宽行业经验要求，核心看执行力和细心程度 |
| **首年人工成本超出现金流** | 中 | 中 | 自然手作主理人延后到岗（节省前2-3个月工资） |

### 9.2 结构性风险的深层解释

最重要的一个风险需要单独说明：**"核心优先"的原则需要持续的纪律来维护。**

核心是战略成本中心，不直接产生利润。当现金流紧张时，砍核心预算是最容易、最不影响本月利润的选择。但核心一旦被削弱：展示变差→客户信任下降→复购下滑→引擎收入减少→更没钱给核心——这是星形结构崩盘的最短路径。

**防范措施**不是一个流程或工具，而是言渊本人的认知和坚持。

### 9.3 外部风险

| 风险 | 说明 |
|:---|:---|
| 短视频流量不稳定 | 抖音/小红书算法变化影响内容曝光，需分散渠道+老带新互补 |
| 天气依赖 | 农场客流天然受天气影响，需靠旺季利润弥补淡季亏损 |
| 竞争对手模仿 | 可以模仿产品（面包窑/松林露营），但模仿不了信任和时间积累 |
| 食品安全事件 | 引擎A的餐饮环节需严格把控，保险配置必须到位（公众责任险+食品安全险） |
| 人员流失 | 核心岗位人员（种植养殖主管、运营主管）是关键依赖，需提前储备候选和交接机制 |

> **一句总结**
