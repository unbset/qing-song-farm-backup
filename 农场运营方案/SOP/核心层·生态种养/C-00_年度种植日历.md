## 一、全年种植节奏总览

青松农场所处潍坊地区（暖温带季风气候）的农事节奏分为4个阶段：

| 阶段 | 月份 | 农事重点 | 客户可看到的 | 客户可参与的 | 生产约束 |
|:---:|:---|:---|:---|:---|:---|
| 春播期 | 2-3月 | 育苗、播种、翻地、施底肥 | 新翻的土地、育苗盘、刚出苗的嫩叶 | 育苗课堂、播种体验 | 早春地温低，不耐寒品种需保护地 |
| 生长期 | 4-5月 | 浇水、追肥、除草、搭架、病虫害防治 | 生长中的蔬菜、开花、搭好的架子 | 除草劳动换薪、搭架共建、酵素制作课 | 病虫害高发期，部分区域禁入 |
| 采收期 | 5-6月 / 9-10月 | 采收、供应引擎A、客户采摘体验 | 成熟的果实、采收场景 | 采摘体验、割麦/掰玉米/挖花生 | 采收高峰人员紧张，需提前协调引擎A |
| 休耕期 | 11-2月 | 堆肥制作、土壤改良、工具维护、来年规划 | 堆肥区、休整的土地 | 堆肥课堂、土壤检测课 | 低温期生长缓慢 |

## 二、推荐种植品种与安排

### 2.1 品种选择原则

```
① 优先选择潍坊本地适生品种（抗病强、管理成本低）
② 兼顾生长周期，确保全年各阶段有东西可看
③ 优先供应引擎A常用食材（叶菜类、根茎类、香草类）
④ 预留客户体验品种（易成活、有采收成就感）
```

### 2.2 分季品种表

| 季节  | 推荐品种              |   生长周期   |  预期采收  | 用途           | 客户体验价值          |
| :-- | :---------------- | :------: | :----: | :----------- | :-------------- |
| 春播  | 小白菜、油菜、生菜、茼蒿      |  25-35天  |  4-5月  | 引擎A供应 + 客户采摘 | 生长快，客户每次来都能看到变化 |
| 春播  | 番茄、黄瓜、辣椒、茄子       |  60-80天  |  6-8月  | 引擎A供应 + 客户采摘 | 花果期观赏价值高        |
| 春播  | 豆角、丝瓜、苦瓜          |  50-70天  |  6-8月  | 引擎A供应        | 需搭架，搭架共建活动      |
| 春播  | 玉米                |  70-90天  |  7-8月  | 客户体验         | 掰玉米是高人气体验项目     |
| 春播  | 花生                | 100-120天 |  8-9月  | 客户体验         | 挖花生适合亲子         |
| 夏播  | 秋白菜、萝卜、胡萝卜        |  60-80天  | 10-11月 | 引擎A供应 + 客户采摘 | 秋收体验            |
| 夏播  | 菠菜、香菜、小葱          |  30-40天  | 10-11月 | 引擎A供应        | 生长快，填补秋收后的展示空白  |
| 全年  | 香草类（薄荷/紫苏/罗勒/迷迭香） |   多年生    |  全年可采  | 引擎A + 手作材料   | 可闻可摘可入菜         |
| 全年  | 食用花卉（金盏花/旱金莲/琉璃苣） | 多年生/一年生  |  全年可采  | 手作材料+装饰      | 拍照场景            |

## 三、各阶段关键工作清单

### 3.1 春播期（2-3月）

**必须完成的工作**：

| 工作内容   | 标准                   | 最迟完成时间 |
| :----- | :------------------- | :----: |
| 翻地     | 深度20-25cm，清除杂草和石块    |  2月中旬  |
| 施底肥    | 腐熟堆肥或酵素渣，用量按Hermes计算 |  2月下旬  |
| 育苗     | 西红柿/辣椒/茄子等先育苗，小白菜等直播 |  3月上旬  |
| 早春叶菜播种 | 小白菜/油菜/生菜            |  3月上旬  |
| 搭建保护地  | 早春气温不稳时，需简易拱棚防寒      |  3月上旬  |

### 3.2 生长期（4-5月）

**必须完成的工作**：

| 工作内容 | 标准 | 频次 |
|:---|:---|:---:|
| 浇水 | 见干见湿，不积水 | 视天气，通常2-3天一次 |
| 追肥 | 酵素稀释液或堆肥浸出液 | 每10-15天一次 |
| 除草 | 人工拔除，不使用除草剂 | 每周 |
| 搭架 | 豆角/黄瓜/西红柿等及时搭架 | 抽蔓时 |
| 病虫害巡查 | 每日观察，发现异常立即记录 | 每天 |
| 间苗/补苗 | 保证合理密度 | 苗期 |

### 3.3 采收期（5-6月 / 9-10月）

**必须完成的工作**：

| 工作内容 | 标准 | 频次 |
|:---|:---|:---:|
| 采收 | 按各品种成熟标准采收，不过熟 | 每天或隔天 |
| 供应引擎A | 采收后立即通知引擎A主理人，确认接收 | 每次采收 |
| 客户采摘区管理 | 预留客户采摘区，标牌清晰 | 每次客户到访前 |
| 采收后记录 | 记录品种、产量、品质、采收时间 | 每次采收 |
| 下一季种植准备 | 采收后清理地块，准备下一季种植 | 采收完成后 |

### 3.4 休耕期（11-2月）

**必须完成的工作**：

| 工作内容 | 标准 | 频次 |
|:---|:---|:---:|
| 堆肥制作 | 收集落叶/秸秆/厨余，堆制 | 集中制作 |
| 土壤改良 | 施有机肥/绿肥，翻压入土 | 11-12月 |
| 工具维护 | 清洁/修理/保养所有农具 | 每年一次 |
| 来年计划制定 | 复盘当年成效，制定下年计划 | 1月 |
| 冬修共建 | 鸡舍修缮/围栏维护/设施加固 | 按需 |

## 五、与前一年度的衔接

```
每年1月制定本年度计划时需参考：
  ① 上一年度种植记录（品种表现、产量、问题）
  ② 上一年度引擎A的食材使用数据（哪些品种用量大、哪些浪费多）
  ③ 上一年度客户参与数据（哪些公开化活动报名多）
  ④ 当前土地状态（连作障碍考虑、需轮作的品种）
```

**执行步骤**：

```
1. 每年1月第1周：种植养殖主管查看上一年度记录，起草本年度计划
2. 每年1月第2周：种植养殖主管与引擎A主理人沟通，确认引擎A今年的食材需求
3. 每年1月第3周：种植养殖主管与运营卫星沟通，确认公开化课程和活动的种植需求
4. 每年1月第4周：言渊审核确认全年计划，录入Hermes
5. 每月25日：种植养殖主管根据天气和实际生长情况，微调下月计划
6. 每月28日：更新后的计划同步至引擎A和运营卫星
```

## 六、异常处理

| 异常情况 | 响应 |
|:---|:---|
| 极端天气（倒春寒/冰雹/暴雨） | 立即检查保护地设施，必要时抢收可采收的作物，在Hermes中记录损失 |
| 突发病虫害 | 立即隔离，拍照上传Hermes确认，按C-02异常处理执行 |
| 引擎A临时增加食材需求 | 评估当前可采收量，无法满足时提前告知引擎A外采补充 |
| 客户体验计划与生产冲突 | 优先保障生产，在Hermes中标记"该时段客户禁入"，通知运营卫星调整公开化计划 |

### 七、客户触点

- 年度种植日历是客户在农场全年体验的"底层时间轴"，什么季节来能看到什么、能摘什么、能做什么
- 公开化运营中，将种植日历转化为"农场四季体验日历"展示给客户，帮助客户规划到访时间
- 播种/生长期/采收期各阶段的客户参与机会（课程化/共建化/劳动换薪）均以本日历为基础排期
- 认领地块的客户可查看自己地块在全年种植日历中的位置和进度
