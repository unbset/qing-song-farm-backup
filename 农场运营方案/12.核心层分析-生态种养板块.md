## 1. 定位与价值

### 在星形结构中的角色

**核心不是"卖菜卖鸡"的生意，而是整个农场真实性的地基。**

| 表象角色      | 实际价值                    |
| :-------- | :---------------------- |
| 引擎A的食材供应商 | 但这不是核心存在的理由——去批发市场买菜更便宜 |
| 农场的景观资源   | 但这不是核心存在的理由——种草更省事      |

**核心存在的唯一理由：它是农场"真实"的物理证明。**

- 当客户走进松林，看到菜地里有人在拔萝卜——他"知道"这个农场在种东西
- 当客户看到灶台上的蔬菜是刚从那片地里摘的——他"相信"这个农场是真实的
- 当一个品牌说"从农场到餐桌"——大多数时候客户不信。但当客户亲眼看到菜地连着厨房的时候，他不需要"信"——他看到了

**所以核心的价值不体现在它的产出的市场价格上，而体现在它对农场整体信任资产的贡献上。**

### 在飞轮中的位置

```
  核心层（生态种养）
    │
    ├──→ 引擎A（餐饮）：提供看得见来源的食材
    ├──→ 引擎B（露营）：提供"在菜地旁边吃火锅"的体验场景
    ├──→ 自然手作卫星：提供"拔根萝卜带回家种"的手作素材
    └──→ 劳动换薪：提供让客户参与种养的机会
    │
    └──→ 信任资产 ↑ （所有板块最终都在消费这个信任）
```

## 2. 种养规划

### 核心原则

1. **先做视觉丰富的，再追求产出。** 来访客人第一眼看到的区域，要种"好看、容易被认出"的作物——不是产量最高的，而是客户一眼能认出来的（番茄、草莓、向日葵、玉米）
2. **优先种引擎A需要的。** 引擎A（餐饮）用量大的食材优先种（叶菜、香草、番茄、辣椒、鸡蛋），用量小或不易储运的大宗食材继续外部采购
3. **量力而行，不贪多。** 第一年集中精力做好1-2个品类，积累经验后再扩展

### 建议的种养品类

#### 第一优先级（当年见效，视觉丰富，引擎A直接需求）

| 品类 | 原因 | 种植规模建议 | 引擎A用途 |
|:---|:---|:---|:---|
| 叶菜类（生菜/菠菜/油菜/小青菜） | 生长周期短（30-45天），客户来了就能看到 | 2-3畦轮种，保证每周有产出 | 柴火灶炒菜、火锅涮菜、大席配菜 |
| 番茄（大番茄+小番茄） | 辨识度高，客户一眼认出 | 1畦 | 沙拉、大席配菜；小番茄做茶歇/野餐篮 |
| 辣椒/茄子/菜椒 | 生长周期适中，挂果期长 | 1畦 | 柴火灶炒菜、大席配菜 |
| 香草类（薄荷/罗勒/迷迭香/紫苏） | 占地小，产量高，视觉好闻 | 1个香草床 | 窑炉面包（迷迭香）、饮品（薄荷）、烤肉佐料 |
| **散养蛋鸡（30-50只）** | 鸡蛋是引擎A刚需；鸡在松林里跑的画面本身就有传播力 | 小型鸡舍+围栏 | 早餐蛋、大席煎蛋、面包蛋液、野餐篮白煮蛋 |

#### 第二优先级（需稍长周期，丰富展示面）

| 品类 | 原因 | 建议 |
|:---|:---|:---|
| 玉米（甜玉米/糯玉米） | 夏季视觉高耸，客户有"掰玉米"的体验需求 | 1畦，不追求产量，追求"观赏+体验" |
| 南瓜/冬瓜 | 秋季视觉丰富，适合做秋季主题 | 种在边缘区域，不占好地 |
| 果树（葡萄/无花果/枣树） | 长期投资，3年后有产出 | 第1年先种，不指望当年结果 |
| 散养鸡（扩展到100只+） | 鸡蛋供应稳定后可以卖活鸡/白条鸡给引擎A | 视第一年运营情况决定 |

#### 第三优先级（备选，不着急）

| 品类             | 原因                        |
| :------------- | :------------------------ |
| 根茎类（胡萝卜/土豆/红薯） | 生长期长，视觉在地下，展示价值低。但红薯可以做窑烤 |
| 豆类（四季豆/豌豆）     | 有一定展示价值，但产量和引擎A需求不明确      |
| 其他禽类（鸭/鹅）      | 散养鸡跑通后再考虑                 |

### 季节轮作示意

| 季节 | 主要产出 | 看点 |
|:---|:---|:---|
| 春季（3-5月） | 叶菜、香草、草莓（如有） | 万物生长，油菜花开 |
| 夏季（6-8月） | 番茄、辣椒、茄子、玉米、散养蛋 | 满畦挂果，最丰富的季节 |
| 秋季（9-11月） | 南瓜、玉米、红薯、第二茬叶菜 | 收获感，适合劳动换薪的"掰玉米""挖红薯" |
| 冬季（12-2月） | 温室/大棚叶菜（如有）、散养蛋 | 展示面最少的季节，靠鸡和温室体现活力 |

## 3. 产出与供应

### 供应路径

```
核心（生态种养）
  │
  ├── 每日采收（员工早上完成）
  │     │
  │     ├──→ 引擎A中心厨房：当日食材送达，中心厨房根据菜单分配
  │     │     ├── 叶菜→火锅、柴火灶
  │     │     ├── 番茄/辣椒→大席、炒菜
  │     │     ├── 香草→面包、烤肉、饮品
  │     │     └── 鸡蛋→全日供应
  │     │
  │     ├──→ 现场展示台：留出一部分摆放在中心厨房/展示区
  │     │     └── 写个牌子"今日自产：XX斤番茄、XX个鸡蛋"
  │     │
  │     └──→ 劳动换薪：留出可供客户参与采收的区域
  │
  └── 供应不上的食材 → 外部采购补充（不设"必须用自产的"这条红线）
```

### 供应原则

| 原则 | 说明 |
|:---|:---|
| **核心优先供展示，引擎优先供产量** | 展示面上必须时刻有东西（哪怕就几株番茄），引擎A的需求靠量产满足 |
| **不设"全部自产"的目标** | 核心一开始不可能满足引擎A的全部食材需求，外部采购正常进行。自产食材是"加分项"不是"必须项" |
| **展示台上的东西不追求多，追求"永远有"** | 哪怕每天只在展示台上放5颗番茄+3个鸡蛋+一把香草——只要每天都有，客户就相信这个农场在种东西 |

## 4. 展示与信任

### 展示触点设计

| 触点位置             | 展示内容                   | 加分                                     | 扣分                        |
| :--------------- | :--------------------- | :------------------------------------- | :------------------------ |
| **从停车场到中心厨房的路上** | 核心区入口，客户第一眼看到菜地        | 菜畦整齐、有牌子写着"今日XX正在生长"                   | 菜畦里长草了、或者什么也没种，光秃秃的       |
| **中心厨房/室外餐区旁边**  | 展示台：今日自产食材 + 农田到餐桌的关系牌 | 展示台上的番茄还带着泥、鸡蛋壳上还沾着草——"这是今天早上刚摘/刚捡的"   | 展示台是空的、或者放着从批发市场买回来的菜冒充自产 |
| **各区域之间的动线上**    | 从A区走到B区的路上能看到菜地/鸡舍     | 散养鸡在松林里跑、菜畦里有人在浇水——"活的"展示              | 鸡舍区域气味不佳，路过要屏住呼吸          |
| **厕所/洗手区**       | 香草展示                   | 几盆薄荷摆在洗手台，"采一片搓一搓，闻闻味道"——"这真的是农场"的最后一击 | 什么都没有                     |

### 信任构建的关键时刻

| 客户阶段 | 信任里程碑 | 核心的配合动作 |
|:---|:---|:---|
| 第一次来 | "这个地方真的有在种东西" | 核心区入口一眼能看到有内容的菜地 |
| 第二次来 | "上次那样菜还长在那里"——持续感 | 核心区有持续维护，每次来都有变化 |
| 第三次来 | "我能不能也种点什么？"——参与感 | 劳动换薪开放种养参与 |

## 5. 劳动换薪接口

核心层是劳动换薪**最天然的载体**。原因：
- 种养工作有明确的成果（拔出来的萝卜、摘下来的番茄）——客户做完有成就感
- 种养工作不要求技能——老人、小孩、城市白领都能做
- 客户参与种养的过程本身就是最好的展示（"那个人在拔萝卜"→其他人看到了也想试）

### 可开放的劳动项目

| 项目 | 适合人群 | 时长 | 难度 | 换薪标准（参考） |
|:---|:---|:---|:---|:---|
| 采收叶菜（拔/剪/装筐） | 成人、老人 | 20-30分钟 | 极低 | 10-15元/次 |
| 采摘番茄/辣椒 | 成人、亲子 | 20-30分钟 | 低 | 10-15元/次 |
| 捡鸡蛋 | 亲子（孩子最爱） | 10分钟 | 极低 | 5-10元/次 |
| 浇水 | 成人 | 15-30分钟 | 极低 | 10元/次 |
| 除草 | 成人（体力活） | 30分钟+ | 低 | 15-20元/次 |
| 松土/翻地 | 成人（体力活） | 30分钟+ | 中 | 20元/次 |
| 喂鸡撒玉米 | 亲子 | 10分钟 | 极低 | 5元/次 |

### 组织方式

- **小黑板制**：在核心区入口放一块小黑板，写上今天可参与的项目 + 所需人数 + 薪酬
  - 示例：*"今日劳动换薪：摘番茄（需2人，10元/次，约30分钟）——已预约：空缺"*
- **预约制（会员）**：会员客户提前一天预约，核心主理人安排工作内容
- **不预约（散客）**：散客到现场看到小黑板有兴趣，现场参与

## 6. 协作关系

| 协作方 | 配合什么 | 谁主导 |
|:---|:---|:---|
| **引擎A（餐饮）** | 每日从核心领用食材（中心厨房→采收区） | 引擎A主理人发起领用需求，核心主理人安排采收 |
| **引擎B（露营住宿）** | 向露营客户宣传核心区的参观/劳动换薪 | 引擎B主理人推荐，核心主理人接待 |
| **自然手作卫星** | 从核心获取手作材料（松果、植物染材料、干花干草） | 自然手作卫星发起 |
| **运营卫星** | 核心区的线上内容制作（菜地/鸡舍/劳动换薪的画面） | 运营卫星拍摄制作 |
| **劳动换薪（贯穿机制）** | 核心提供劳动项目→客户参与→运营卫星记录薪酬 | 核心主理人安排工作，运营卫星记录 |

## 7. 考核标准

**核心不考核利润。** 以下三项是核心的考核指标：

### 指标一：土壤健康度（年度）

| 项目 | 采集方式 | 目标 |
|:---|:---|:---|
| 土壤有机质含量 | 第三方检测（第1年做一次基线，以后每年做一次） | 逐年提升 |
| 蚯蚓密度 | 挖土观察（每季度一次，同一区域） | 逐年增加 |
| 不使用化肥农药的持续年数 | 记录 | 持续 |

### 指标二：展示丰富度（月度）

| 项目 | 采集方式 | 目标 |
|:---|:---|:---|
| 核心区当日可见作物品种数 | 员工每日记录拍照 | 每个季节≥5种可见作物 |
| 展示台"今日自产"的每日更新率 | 观察记录 | 每日都有展示品 |
| 散养鸡/禽类的存栏量 | 计数 | 始终有 |

### 指标三：客户触达率（月度）

| 项目 | 采集方式 | 目标 |
|:---|:---|:---|
| 进入核心区的客户人数（核心区入口有计数器） | 人工计数器/目测 | ≥当天到店客户的30% |
| 参与劳动换薪的核心区项目人次 | 小黑板记录 | 每月≥20人次 |
| 停留在核心区拍照的客户占比 | 员工观察 | ≥进入核心区客户的50% |

## 8. 风险评估

| 风险类别 | 风险描述 | 概率 | 影响 | 应对 | 剩余风险 |
|:---|:---|:---|:---|:---|:---|
| **运营风险** | **没有主理人**——这是最现实的障碍。生态种养需要有人每天照料（浇水/采收/喂鸡），不可能靠"顺便" | **高** | **极高** | 分阶段：第一阶段（找到主理人之前）只种最容易活的品类（叶菜+香草），由引擎A员工兼管浇水；第二阶段找到主理人后再扩品类 | **当前不可承受**——必须先解决主理人问题 |
| 运营风险 | 种了没人看，被虫/鸟/鼠吃了，或被客户误踩了 | 中 | 中 | 核心区设围栏+标识（"生长中，请勿进入"）、物理防护网 | 可承受 |
| 运营风险 | 散养鸡跑了/被黄鼠狼咬了/死了 | 中 | 中 | 围栏+夜间归笼+养狗（如有） | 可承受 |
| 品牌风险 | 客户看到核心区种得不好（菜枯了/地荒了/鸡脏了）——不但没有建立信任，反而建立了不信任 | 中 | 高 | 不做超出能力的展示——宁可种少点种好点、也不多种多荒。展示区只保留最有信心的品类 | 可承受 |
| 财务风险 | 生态种养的产出价值远低于投入成本（种子+肥料+围栏+人工），经济账算不过来 | 高 | 中 | 这本来就是战略成本中心——不要求经济账平衡。但投入应有上限（建议第一年核心投入不超过农场总固定投入的10%） | 可承受 |

## 10. 分阶段计划

### 第一阶段：信心验证期（找到主理人之前）

| 时间 | 动作 | 目标 |
|:---|:---|:---|
| 第1-3个月 | 整理核心区场地（翻地/做畦/围栏/路径硬化） | 让客户一眼能看到"这里有一片地在种东西" |
| 第1-3个月 | 种植叶菜+香草（最容易活的品类），由引擎A员工兼管浇水 | 展示台上有东西 |
| 第1-3个月 | 购置小型鸡舍+围栏，引进30只蛋鸡 | 松林里有鸡在跑——这个画面很重要 |
| 第3-6个月 | 一边运营一边找主理人 | — |
| 同时 | 设置展示台+标识牌+劳动换薪小黑板（哪怕只有"浇水"一个选项） | 让客户知道"这里可以参与" |

**第1阶段交付标准**：客户来了能看到菜地+散养鸡+展示台+劳动换薪小黑板。**不需要丰盛，需要"有"。**

### 第二阶段：稳定运营期（主理人到岗后）

| 时间 | 动作 | 目标 |
|:---|:---|:---|
| 第7-12个月 | 主理人根据客户反馈和引擎A需求调整种养品类 | 产出开始覆盖引擎A的部分需求（目标：叶菜和鸡蛋自给率达到30%） |
| 第7-12个月 | 劳动换薪常态化运营（每周至少3个可参与项目） | 每月劳动换薪参与≥20人次 |
| 第7-12个月 | 组织1-2次客户参与的种植活动（如"一起种番茄"） | 增强客户参与感 |
| 第12个月 | 做年度土壤检测，对比基线 | 土壤健康度变化 |

### 第三阶段：展示成熟期（第2年起）

| 动作 | 目标 |
|:---|:---|
| 根据第一年经验，保留受欢迎的品类、淘汰无人问津的 | 形成稳定的四季轮作计划 |
| 核心区参观引导动线成熟（客户从停车场→核心区→中心厨房是一条完整的动线） | 客户自然走入核心区，不需要专门引导 |
| 核心成为农场的"信任引擎"而不是"菜地" | 客户离开时带走的不仅是照片，还有"这个农场真的在种东西"的印象 |

## +1 多角色验证

### 角色A：首次到店的年轻情侣

**体验路线**：停好车 → 往中心厨房走 → 路上看到一片菜地 → 看到有牌子写着"今日自产" → 看到几只鸡在松林里跑 → 走到中心厨房看到展示台上有带着泥的番茄

**感受**：
- "这个农场居然真的有菜"——这个"居然"就是信任的起点
- 看到鸡在跑→掏出手机拍视频→"你们还养鸡？"
- 看到展示台上的番茄+"今日自产"的牌子→"那我们今天吃的菜是不是就是这里的？"——这个问题的答案是"是"的时候，信任就建立了

**如果核心区没种好**：路过看到菜地荒着、或者种了但稀稀拉拉 → "这个农场就是做个样子" → 信任坍塌。

### 角色B：带着孩子来的妈妈

**体验路线**：孩子看到鸡在跑→"妈妈鸡！"→停下来看→看到有人在拔萝卜→"我也想拔"→参与劳动换薪

**感受**：孩子拔出一根萝卜的那一刻，"这个钱花得值"——这个体验比任何课程都有价值。
**建议**：核心区可以做一件事——孩子参与劳动换薪后，给他们一个"今日小农夫"的贴纸或小卡片。成本几乎为零，但孩子会记住。

### 角色C：农场主管

**最大的实际困难**：核心层是最"不紧急"也最难看到短期成果的板块——它不像引擎A那样每天有现金进账，也不像引擎B那样有客户反馈。在没有主理人的情况下，它很容易被"先放一放"。但一旦放久了，展示面没了，农场的"真实性"就塌了。

**建议**：即使没有找到主理人，第一阶段（翻地+种叶菜+养鸡+设展示台）也要推进——不是为了产出，是为了**让客户和团队看到"这个地方在被维护"**。一个空的菜地和一个有叶菜的菜地，给客户的心理暗示完全不同。

---
**一个关键判断：**  
核心层是所有板块中最容易被"先放一放"的——没有每日现金流，没有客户投诉，不做也不会马上有事。但菜地空两周，农场的"真实性"就空了两周。即使没有主理人，第一阶段（翻地+种叶菜+养鸡+设展示台）也得推进——不是为了产出，是为了让客户看到"这个地方在被维护"。
