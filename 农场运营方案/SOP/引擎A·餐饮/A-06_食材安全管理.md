### 一、食材入库安全标准

```
1. 食材验收安全要求
   □ 叶菜类：无黄叶、无腐烂、无虫害
   □ 根茎类：无发芽（尤其土豆）、无腐烂、无黑心
   □ 瓜果类：无霉斑、无软烂、无异常气味
   □ 肉类：色泽正常、无粘液、无酸臭味
   □ 禽蛋：无裂纹、晃动无声、清洁
   □ 乳制品：包装完好、冷藏运输、在保质期内
   □ 干货：无霉变、无虫蛀、包装密封

2. 验收不合格食材处置
   - 品控不合格：退回供应商或做堆肥
   - 包装破损：立即换装或优先食用
   - 临期食品：标注"临期优先使用"标签
```

### 二、储存安全管理

```
1. 温度监控
   - 冷藏柜：温度0-4°C（每日检查2次，记录在Hermes）
   - 冷冻柜：温度-18°C以下（每日检查1次）
   - 常温储存：温度15-25°C，湿度60%以下

2. 储存原则
   - 生熟分离（生肉、熟食、蔬菜分区存放）
   - 密封覆盖（所有食材密封或覆膜）
   - 离地存放（食材不直接接触地面，货架离地≥15cm）
   - 先进先出（入库食材标注日期，先入库的先使用）

3. 禁止混放
   - 肉类与蔬菜分柜存放
   - 生食与熟食分柜存放
   - 有异味食材（洋葱/大蒜）密封后放入
```

### 三、加工安全标准

```
1. 个人卫生
   □ 操作前洗手消毒
   □ 穿戴围裙和工作帽
   □ 手部有伤口时戴一次性手套
   □ 操作不佩戴首饰/手表

2. 工用具管理
   □ 刀具砧板生熟分开（色标管理：红色=生肉/绿色=蔬菜/蓝色=熟食）
   □ 抹布分类使用（一擦一消毒）
   □ 操作台每2小时消毒一次

3. 加工过程安全
   □ 肉类彻底解冻（冷藏解冻，不室温解冻）
   □ 蔬菜充分清洗（浸泡10分钟以上）
   □ 加热食品中心温度≥75°C
   □ 已加工食材2小时内未使用必须冷藏
```

### 四、出餐安全

```
1. 出餐前检查
   □ 菜品无异物、无异常色泽
   □ 菜品温度达标（热菜≥60°C/冷菜≤10°C）
   □ 餐具清洁无破损
   □ 菜品留样（每道菜留样100g，冷藏保存48小时）

2. 过敏原管理
   - 菜单标注常见过敏原（花生/海鲜/乳制品/麸质）
   - 客户询问时如实告知食材成分
```

### 五、临期与过期管理

```
1. 每日检查
   - 冰箱/货架所有食材生产日期和保质期
   - 临期食材（保质期剩余≤2天）标注"优先使用"

2. 过期食材处理
   - 过期食材立即下架
   - 记录过期品种和数量至Hermes
   - 分析过期原因（备料过多/周转慢/品类选择问题）
   - 过期食材做堆肥或妥善丢弃（不可送人或喂动物）

3. 损耗控制目标
   - 食材损耗率≤5%
   - 核心层食材损耗率≤3%
```

### 六、清洁消毒周期

| 项目 | 频率 | 方式 |
|:---|:---|:---|
| 刀具砧板 | 每次使用后 | 清洗+消毒水浸泡 |
| 操作台 | 每2小时 | 清洗+消毒喷雾 |
| 冰箱内部 | 每周1次 | 除霜+清洗+消毒 |
| 排烟系统 | 每月1次 | 拆卸清洗 |
| 地面 | 每日 | 清洗+消毒水拖地 |
| 垃圾桶 | 每日 | 清洗+消毒 |

### 七、验收标准

```
□ 所有食材入库前已验收合格
□ 冷藏/冷冻温度达标并记录
□ 食材储存符合生熟分离/密封/离地标准
□ 刀具砧板色标管理执行到位
□ 无过期食材在库
□ 留样完整（每道菜100g/48小时）
□ 损耗率在控制目标内
□ 清洁消毒按频率执行并记录
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 冷藏设备故障 | 食材转移至备用冷柜，报修 |
| 停电 | 减少开关冰箱次数，优先使用易腐食材 |
| 发现过期食材 | 下架销毁，分析原因并调整备料量 |
| 客户投诉食品安全 | 立即封存同批次食材，留样送检（如需） |
| 食材变质 | 追溯同批次，全部下架，调整供货商 |
| 虫害/鼠害发现 | 全面消杀，封存所有暴露食材 |

### 九、跨板块协作

- 食材品质问题反馈**核心层·种植养殖主管**改进种植/养殖方式
- 食材安全管理纳入**运营卫星**的每日巡检内容
- 食品安全事件升级至**言渊**处理
- 公开化运营中向客户展示食材安全管理记录（增加信任）

### 十、客户触点

- 食材安全客户看不见，但一旦出问题就是致命打击
- 在公开化展板展示食材安全管理记录（每日温度记录/食材来源追溯），增加透明度和信任
- 过敏原标注是对客户的尊重，尤其是有儿童的家庭
