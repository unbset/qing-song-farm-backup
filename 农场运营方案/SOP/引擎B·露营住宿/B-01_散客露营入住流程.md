[SOP编号] B-01
[SOP名称] 散客露营入住流程（旺季/淡季两版）
[执行人] 引擎B主理人
[替代人] 言渊 / 运营卫星成员（经培训后）
[执行时间] 旺季 14:00-20:00 / 淡季 14:00-18:00
[适用季节] 全年（旺季：5-10月 / 淡季：11-次年4月）
[前置条件] 客户已通过小程序/社群/合作平台预约并支付；Hermes已记录预约信息
[AI接口] Hermes管理预约系统，自动发送入住指南；入住后创建客户档案
[AI提醒] Hermes每日13:00推送当日入住名单和客户偏好；恶劣天气提前预警建议改期

---

### 一、入住前准备（13:00-14:00）

```
1. 核对当日入住名单
   - 查看Hermes当日预约客户清单
   - 了解客户类型（散客/家庭/情侣/长搭客）
   - 特殊需求标记（宠物/儿童/生日/纪念日）

2. 场地检查
   - 预约营位已清理（杂草/垃圾）
   - 营位地面平整，无积水
   - 电源接口可用（若提供）
   - 公共区域（卫生间/淋浴间/洗漱区）清洁并备好物资
   - 指引标识清晰（从停车场到营位的方向）

3. 物资准备
   - 入住包准备（营位卡/地图/规则须知/紧急联系方式）
   - 租赁装备检查（帐篷/睡袋/天幕/桌椅）——逐件确认无损
   - 公共区域补货（卫生纸/洗手液/垃圾袋）
```

### 二、旺季入住流程（5-10月）

```
当日预约量大，客流量高，需高效处理

1. 到达迎接
   - 客户车辆到达停车场时引导停车
   - 问候并确认预约信息（姓名/手机号）
   - 核销预约码

2. 快速入住办理
   - 交付入住包（内含：营位地图 + 营位编号手环 + 规则须知 + 紧急电话）
   - 简要说明营位位置（地图标注，不陪同前往——旺季由客户自行前往）
   - 指明卫生间/淋浴间/水源位置
   - 提醒引擎A餐饮营业时间和点餐方式

3. 租赁装备交付（如需）
   - 客户在接待处领取已预约的装备
   - 当面清点数量并签字确认
   - 告知归还时间和地点

4. 入住后跟进
   - 17:00巡查各营位，确认已搭建完成
   - 询问是否有额外需求（炭火/冰块/食材补充）
```

### 三、淡季入住流程（11月-次年4月）

```
当日预约量小，可提供更精细的服务

1. 到达迎接
   - 客户车辆到达时到停车场迎接
   - 问候并确认预约信息
   - 提供热饮（姜茶/热茶）——给客户的冬季暖身迎接

2. 全程陪同办理
   - 陪同客户步行至营位
   - 现场介绍营位设施和使用方法
   - 确认防风/防寒措施（周边遮风情况）
   - 提供额外保暖用品建议

3. 租赁装备交付（如需）
   - 陪同送至营位并协助搭建
   - 检查和演示使用方法（炉具/取暖设备）

4. 入住告知
   - 引擎A冬季营业时间（可能结束较早）
   - 取暖设备安全提醒
   - 夜间温度告知，建议添衣
```

### 四、通用入住告知内容

```
每位客户入住时需告知以下内容（旺季口述要点，淡季详细说明）：

□ 卫生间和淋浴间位置及使用时间
□ 用水点和取电点位置
□ 垃圾投放规定（垃圾分类、投放点）
□ 夜间安静时间（22:00后）
□ 火源管理（篝火区使用规则、禁止私自生火）
□ 紧急事故联系人（言渊电话）
□ 次日退房时间（12:00前）
□ 引擎A早餐供应时间
□ 引擎B主理人联系方式
```

### 五、验收标准

```
□ 入住前营位已清理完毕，设备检查合格
□ 客户预约信息已核验
□ 入住告知已完成（口头+书面）
□ 入住包已交付
□ 租赁装备（若有）已清点交付
□ Hermes已确认入住状态
□ 入住后30分钟内无客户投诉或求助
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户未预约到店 | 有空营位时即时办理，无营位时推荐引擎A用餐或下次预约 |
| 营位被占/重复预约 | 优先升级至更好营位，致歉并提供补偿（赠送饮品或折扣券） |
| 恶劣天气预警 | 提前联系客户建议改期，不同意改期的提供安全庇护方案 |
| 客户要求特殊营位 | 在能力范围内调整，超出范围的明确告知并提供替代方案 |
| 装备租赁发现损坏 | 先提供替代装备，损坏件标记维修 | 
| 旺季多组客户同时到达 | 快速办理组排队，每组办理不超过5分钟 |

### 七、跨板块协作

- 向**引擎A**通报入住人数和用餐需求（团餐预订提前一天确认）
- 向**运营卫星**通报次日或当日的退房情况和营位释放信息
- 向**言渊**通报入住率异常（过高或过低需调整策略）
- 长搭客入住提前报备，签约流程参照B-03长搭露营管理

### 八、客户触点

- 入住体验是露营板块的"第一印象"，直接影响客户在农场的停留时间和复购率
- 旺季追求效率（不让人等），淡季追求温度（让人觉得被照顾）
- 入住时赠送农场即时蔬菜或鸡蛋，是低成本高感知的好做法
