## 画像一：周末散客情侣/年轻夫妇

### ① 人（Who）

| 维度 | 描述 |
|:---|:---|
| **年龄** | 25-35岁 |
| **群体** | 情侣 / 新婚夫妇 / 无孩年轻夫妻 |
| **职业** | 潍坊城区白领、事业单位、自由职业 |
| **收入** | 两人月收入合计1-2万 |
| **交通工具** | 自驾（30分钟车程） |
| **信息渠道** | 小红书、抖音、朋友圈 |
| **消费习惯** | 周末有固定外出消费预算500-1000元 |
| **自然经验** | 对农业无认知，偶尔去采摘园 |

### ② 为什么来 & 情绪状态

| 维度 | 描述 |
|:---|:---|
| **核心动机** | "找个不一样的地方过周末"——不是想来学东西，是想要换环境 |
| **表层需求** | 拍照好看、环境舒服、能吃顿好的 |
| **真实心理** | 工作日被KPI和通勤消耗，渴望"周末两天的另一种活法" |
| **情绪状态** | 周五晚疲惫，周六上午刚睡醒的松弛感，带着期待但也带着怀疑（"别再踩雷了"） |
| **害怕什么** | 踩雷——"照片看着好看，到了发现不过是个土院子" |

### ③ 场景（Context）

| 触发场景 | 周五晚上刷小红书看到"潍坊周边最美松林" / 朋友推荐"那家面包窑不错" |
|:---|:---|
| **决策方式** | 随手决策——刷到了、觉得不错、发消息问对象"明天去？"→"行啊" |
| **决策窗口** | 极短——从看到到达定不超过30分钟 |
| **计划vs冲动** | 冲动型居多，80%出发前没有详细计划，看到什么玩什么 |
| **结伴方式** | 两人同行，偶尔约另一对一起（4人） |
| **停留时长** | 3-5小时（中午到，下午走，不住宿） |

### ④ 体验任务（JTBD）

| 任务类型 | 具体任务 | 对应的农场工作 |
|:---|:---|:---|
| **功能任务** | 吃一顿有特色的午餐 / 在自然环境中待一会儿 | 引擎A餐饮体验 |
| **情绪任务** | "从城市节奏切换到自然节奏"——需要过渡感 | 到达时的氛围设计 |
| **社交任务** | 拍出"我们过了一个好周末"的照片发朋友圈 | 场景出片点设计 |
| **认同任务** | "我们是有生活品味的人"——选择小众、真实的去处 | 农场的调性传达 |

### ⑤ 体验链关键触点

| 触点 | 核心需求 | 设计要点 |
|:---|:---|:---|
| 触发 | 内容吸引——"看起来真的不错"而不是"看起来像网骗" | 红薯/抖音内容用真实场景（面包出炉/松林光影/刚出锅的菜），不用精修 |
| 决策 | 快速确认"值不值得去" | 价格透明（菜单/价目）、路好找（导航指引）、没隐形消费 |
| 到达 | "到了，比预期的好还是差？" | 停车场到主入口的30米步道是第一印象——看到松林/闻到面包香/听到鸡叫 |
| 体验 | 自由+惊喜——不需要全程被安排 | ①到店先逛一圈（自发路线）②看到面包窑冒烟自己过去看 ③午餐是亮点 ④有个随手能参与的小事（喂鸡/捡蛋） |
| 服务 | 不打扰但需要时有人 | 不用全程陪同，但问路/点餐/问活动时响应快 |
| 离开 | 带走点什么 | ①照片（手机里至少有3张能发的）②面包（顺手买一个带走）③"下次可以试试露营"的念头 |
| 后续 | "还会不会再来" | 结账时运营卫星加微信→拉入社群→下次活动预告 |

### ⑥ 与生产的关系

| 维度 | 描述 |
|:---|:---|
| **关系深度** | 第一层——"看到了" |
| **对生产的价值** | 直接消费引擎A/B，是现金流的核心贡献者 |
| **升级路径** | 多次到访后可能升级为"自然体验常客"或"亲子教育型"（有孩子后） |
| **不宜做的事** | 不要强推课程化/认领化，不要推销，不要让他们觉得"这是来干活的地方" |

## 画像二：亲子教育型妈妈

### ① 人（Who）

| 维度 | 描述 |
|:---|:---|
| **年龄** | 30-42岁 |
| **群体** | 妈妈+3-12岁孩子（主要），偶尔爸爸陪同 |
| **职业** | 偏体制内/教育/医疗/企业中层的女性 |
| **教育水平** | 本科及以上 |
| **家庭月收入** | 1.5-3万（潍坊中上水平） |
| **信息渠道** | 小红书"潍坊亲子"、妈妈群、朋友圈 |
| **消费习惯** | 愿意为"教育价值"付费（一节课200-300元不犹豫），对"纯玩"付费越来越谨慎 |
| **自然经验** | 去过采摘园、去过农场、有一定的自然教育认知 |

### ② 为什么来 & 情绪状态

| 维度 | 描述 |
|:---|:---|
| **核心动机** | "让孩子知道食物从哪里来"——不是为了自己，是为了孩子 |
| **表层需求** | 有孩子能玩的项目、安全、卫生、有教育意义 |
| **真实心理** | ①城市生活的愧疚感——"孩子每天对着iPad，我应该带他多接触自然" ②教育焦虑——"别人家的孩子都在上自然课" ③社交需求——"约上几个妈妈一起去，孩子有伴" |
| **情绪状态** | 周末早上匆忙（催孩子出门/准备东西）→ 路上期待但也焦虑（怕孩子不感兴趣/怕环境太脏）→ 到了以后取决于孩子表现 |
| **害怕什么** | ①脏、乱、差 ②孩子玩不起来 ③"说是自然教育，其实就是农家乐" ④花了钱没学到东西 |

### ③ 场景（Context）

| 触发场景 | ①妈妈群有人发了上次去的照片 ②小红书刷到"68元自然课" ③幼儿园同学约周末一起 ④学校布置了"亲近自然"的作业 |
|:---|:---|
| **决策方式** | 理性决策——会看完所有图片/评价/价格，可能还会问去过的人 |
| **决策周期** | 1-3天——不会当天决定，但决定后一般会准时来 |
| **计划vs冲动** | 计划性消费，通常会预约 |
| **结伴方式** | ①单独带娃 ②2-3个妈妈拼团一起来（孩子有伴） |
| **停留时长** | 2-4小时（半天），不常过夜 |

### ④ 体验任务（JTBD）

| 任务类型 | 具体任务 | 对应的农场工作 |
|:---|:---|:---|
| **功能任务** | 孩子能在安全环境下玩/学 / 有适合孩子的活动 / 有吃午饭的地方 | 自然教育课/手工课/餐饮 |
| **情绪任务** | 自己放松半天——孩子有人带、自己不用盯 | 课程期间妈妈可以在松林喝茶聊天 |
| **社交任务** | 拍孩子"在自然中成长"的照片发朋友圈 / 分享到妈妈群 | 课程中安排拍摄环节 |
| **认同任务** | "我是一个重视孩子自然教育的妈妈" | 课程的设计感和教育内容的专业性 |

### ⑤ 体验链关键触点

| 触点 | 核心需求 | 设计要点 |
|:---|:---|:---|
| 触发 | "这个看上去是真的自然教育，不是农家乐挂个名" | 内容突出"真实的农场场景"（孩子在菜地/在鸡舍/在做手工） |
| 决策 | ①有明确的课程内容介绍 ②知道适合几岁 ③知道多少钱 ④知道安不安全 | 页面信息：课程流程+适合年龄+价格含什么+安全说明 |
| 到达 | ①好停车 ②洗手间干净（核心决策点） ③有人迎接指路 | 洗手间是第一印象——脏了就输了；有人在门口打招呼 |
| 体验 | ①孩子有专人带（有老师） ②活动真实、不糊弄 ③妈妈有地方待 | 课程化活动是核心——老师质量决定一切；妈妈休息区放松林里的桌椅 |
| 服务 | 对孩子的耐心和亲和力 | 老师需要喜欢孩子、有幼儿互动经验——这是亲子教育型的生死线 |
| 离开 | ①孩子开心 ②有带走的成果（手工作品/蔬菜/照片） ③下次还来 | 课程结束合影+发给妈妈；有成品带回家（手作/摘的菜） |
| 后续 | 运营卫星私信发照片 → 群内下次活动预告 → 推荐深度课/生日会 | 课后48小时内发照片；群内定期推活动 |

### ⑥ 与生产的关系

| 维度 | 描述 |
|:---|:---|
| **关系深度** | 第二层——"学到了" |
| **对生产的价值** | 是自然手作卫星的收入主力，也是深度课/探索营/生日会的核心转化源 |
| **升级路径** | 引流课（68元） → 深度课（198元） → 探索营（398-598元） → 生日会（980-1680元） → 认养/年卡 |
| **不宜做的事** | 不要有安全漏洞（孩子在，安全是底线）；不要让孩子觉得无聊（失去一个妈妈=失去一个妈妈群） |

## 画像三：银发活力型退休人群

### ① 人（Who）

| 维度 | 描述 |
|:---|:---|
| **年龄** | 55-70岁 |
| **群体** | 退休女性为主（占比约70%），部分夫妻同行 |
| **职业背景** | 退休教师/公务员/企业管理人员/医生 |
| **收入** | 退休金稳定（潍坊中上水平3000-6000元/月），有一定积蓄 |
| **交通工具** | 自驾（较多）、公交/打车（部分） |
| **信息渠道** | 微信朋友圈、微信群（广场舞群/退休同事群/老年大学群）、抖音 |
| **消费习惯** | 节俭但愿意为"有意义的体验"花钱，价格敏感但重品质 |
| **自然经验** | 可能有农村生活经历，对农业有情感记忆 |

### ② 为什么来 & 情绪状态

| 维度 | 描述 |
|:---|:---|
| **核心动机** | "找点事干、有人说话、别闲着"——退休后时间太多，需要填充 |
| **表层需求** | 来农园转转/拍拍照/摘点菜/做做手工 |
| **真实心理** | ①怕孤独——退休后社交圈缩小，想找人说话 ②怕没用——想证明自己还能干 ③念旧——可能从小在农村长大，来农场是重温记忆 ④爱美——拍照发朋友圈被点赞是重要心理奖励 |
| **情绪状态** | 平日（周中）比较空闲，周末容易感觉孤单；来农场时心情愉快，喜欢热闹 |
| **害怕什么** | ①太远、交通不方便 ②活动太累（体力跟不上） ③觉得自己是"老年人"不被欢迎 ④价格太贵 |

### ③ 场景（Context）

| 触发场景 | ①朋友在群里发了去农场的照片 ②看到"田园摄影"的宣传 ③女儿推荐"妈你去转转" ④看到有手作课/采摘活动 |
|:---|:---|
| **决策方式** | 信息确定性需求强——会问清楚"多少钱、多远、有没有午饭、要不要预约" |
| **决策周期** | 2-5天，通常会约朋友一起去 |
| **计划vs冲动** | 半计划——会提前约好人，但对具体玩什么不预设 |
| **结伴方式** | 2-4人结伴为主，很少独自来；周中为主要出行时间 |
| **停留时长** | 半天到一天，几乎不过夜 |

### ④ 体验任务（JTBD）

| 任务类型 | 具体任务 | 对应的农场工作 |
|:---|:---|:---|
| **功能任务** | 有地方逛/有东西看/有简单的事做/有饭吃 | 田园摄影/采摘/手作/餐饮 |
| **情绪任务** | "今天过得挺充实"——创造被填满的不是虚度的一天 | 半天的活动节奏别太空 |
| **社交任务** | 拍照片发朋友圈收获点赞——"退休生活很精彩" | 出片点设计（松林/花境/面包窑/篝火台） |
| **认同任务** | "我是有活力的、跟得上时代的老年人" | 活动设计要"适老"但不"显老" |

### ⑤ 体验链关键触点

| 触点 | 核心需求 | 设计要点 |
|:---|:---|:---|
| 触发 | "适合我们去"——看到同龄人的照片 | 内容中要有银发客群的真实照片，不要只有年轻人和孩子 |
| 决策 | ①路好不好找 ②贵不贵 ③累不累 ④有没有人带 | 价格透明+体力说明（"走路不多"）；建议预留电话咨询渠道 |
| 到达 | ①好停车 ②有引导标识 ③有人打招呼 | 停车场到大门的距离不能太远；工作人员看到老年人主动打招呼 |
| 体验 | ①有人带着走、有人讲解 ②可以动手（但不能太累）③可以拍照 | 田园摄影是核心；配合轻量手作（驱蚊膏/松塔香/花束） |
| 服务 | 耐心、耐心、耐心——对老年人的慢节奏要包容 | 说话大声一点、慢一点、有问必答；不要表现出不耐烦 |
| 离开 | ①照片 ②买点农产品带走（蛋/面包/手作）③"下次还来" | 运营卫星帮忙拍照并发给他们；农产品的零售展示要显眼 |
| 后续 | 社群维护（发活动预告）+ 节日问候 +"上次照片"提醒 | 银发客群的复购率高但需要持续维护 |

### ⑥ 与生产的关系

| 维度 | 描述 |
|:---|:---|
| **关系深度** | 第一至二层——"看到了"到"参与了" |
| **对生产的价值** | ①填补周中客流空白（工作日的主力） ②田园摄影的核心客群 ③农产品零售的好客户 |
| **升级路径** | 周中一日游 → 多次来 → 可能介绍子女来（亲子教育型入口） → 少量升级为认养 |
| **不宜做的事** | ①不要安排体力消耗大的活动 ②不要让他们觉得被当作"老年人特殊对待" ③不要让他们觉得冷清 |

## 画像四：内容创作者型博主/KOC

### ① 人（Who）

| 维度 | 描述 |
|:---|:---|
| **年龄** | 22-35岁 |
| **群体** | 潍坊本地小红书/抖音博主（粉丝5000-5万）、探店博主、生活方式博主 |
| **职业** | 自媒体/自由职业/副业探店 |
| **收入** | 不稳定，主要靠探店置换和广告 |
| **交通工具** | 自驾，通常会带拍摄设备 |
| **信息渠道** | 同行推荐、接到探店邀请、自己刷到想去拍 |
| **消费习惯** | 愿意为"出片"付费，但对体验要求高——不好拍的地方不会第二次去 |
| **自然经验** | 对农场无特殊情感，这是"内容选题"而非"休闲去处" |

### ② 为什么来 & 情绪状态

| 维度 | 描述 |
|:---|:---|
| **核心动机** | "我需要内容素材"——来拍东西的，不是来玩的 |
| **表层需求** | 场景好看、有特色、有话题度 |
| **真实心理** | ①粉丝增长焦虑——"这条内容能不能爆" ②同质化焦虑——"别人都拍过了我还能拍什么" ③希望被区别对待——"我是博主，给我好一点的待遇" |
| **情绪状态** | 工作状态——在拍的时候很专注，不拍的时候会迅速评估"值不值得推荐" |
| **害怕什么** | ①"实际和照片不一样"——拍了不出的片 ②没有特色——"这种地方到处都有" ③被同行比下去 |

### ③ 场景（Context）

| 触发场景 | ①农场主动邀请探店 ②看到同城博主发了 ③搜索"潍坊周边拍照"发现 ④朋友推荐 |
|:---|:---|
| **决策方式** | 功利决策——"这个地方能产出什么内容"决定去不去 |
| **决策周期** | 很快——约时间、当天来、当天走 |
| **计划vs冲动** | 有明确拍摄计划，但具体的取景点到现场再找 |
| **结伴方式** | ①独自（带三脚架） ②带摄影师朋友 ③情侣博主一起拍 |
| **停留时长** | 1-3小时（拍够了就走，不等吃饭） |

### ④ 体验任务（JTBD）

| 任务类型 | 具体任务 | 对应的农场工作 |
|:---|:---|:---|
| **功能任务** | 找到3-5个值得拍的场景 / 光线好 / 没人打扰 | 场景设计/拍摄路线规划 |
| **情绪任务** | "这个地方拍出来一定好看"——创作兴奋感 | 场景的视觉冲击力 |
| **社交任务** | 产出内容→涨粉→接广告→持续做博主 | 这是他们的生计——内容质量很重要 |
| **认同任务** | "我是能发现好地方的博主" | 独特的、别人没拍过的角度 |

### ⑤ 体验链关键触点

| 触点 | 核心需求 | 设计要点 |
|:---|:---|:---|
| 触发 | "这个有话题"——面包窑/松林/篝火台/柴火灶 | 提供一个别人没拍过的角度（建议农场的"后台"内容——堆肥/酵素/鸡舍等） |
| 决策 | ①远不远 ②让不让拍 ③收不收费 | 对博主免门票/免停车；提前告知可以拍哪些区域 |
| 到达 | ①第一眼就好看 ②光线好（建议上午或傍晚来） | 入口处的松林光影是最好的第一印象 |
| 体验 | ①3-5个出片点分布清晰 ②有"时间感"的场景（四季不同） | 出片点：松林光影/面包窑/柴火灶/菜地/鸡舍/篝火台 |
| 服务 | ①告诉他哪里好拍 ②不打扰他创作 ③需要什么随时说 | 运营卫星在现场："那边光线更好"；提供一杯水/咖啡 |
| 离开 | ①拍了满意的素材 ②"值不值得在内容里推荐" | 不要催他走；走时问一句"拍得怎么样" |
| 后续 | ①产出内容时@农场 ②可能会再来（换季节/换活动） | 运营卫星跟进："内容发了吗？@我们一下~" |

### ⑥ 与生产的关系

| 维度 | 描述 |
|:---|:---|
| **关系深度** | 第零层——"来取材的"，与生产本身无关 |
| **对生产的价值** | ①传播杠杆——一条优质内容可能带来几十个到店客户 ②公信力背书——博主推荐比广告可信 |
| **升级路径** | 博主 → 如果体验好 → 可能带朋友来 → 可能升级为"技能传承"对象（摄影师→帮农场拍宣传照） |
| **不宜做的事** | ①不要收费 ②不要限制拍摄 ③不要刻意摆拍（博主需要"自然地拍出好照片"） |

## 画像优先级矩阵

按"客户价值（现金流+传播）"和"与农场核心的匹配度"两个维度排出优先级：

```
                             高匹配度
                                │
            内容创作者型         │  亲子教育型 ★★★★
              (传播高/收入低)    │  (收入高/匹配高)
                                │
       低价值 ────────────────┼──────────────── 高价值
                                │
            银发活力型           │  深度归属型 ★★★★
              (收入中/潜力大)    │  (收入稳/传播高)
            疗愈独行型           │  城市逃离型
              (低价值/差异化)    │  (现金流主力)
                                │
                             低匹配度
```

**优先排序**：
1. **亲子教育型** — 最高匹配度，最高收入潜力，最好升级路径
2. **深度归属型** — 稳定现金 流+最强传播，但数量有限
3. **城市逃离型** — 现金流主力，量大但单次价值低
4. **内容创作者型** — 传播杠杆极高，不收费但要维护好关系
5. **银发活力型** — 周中客流的主力，潜力待挖掘
6. **疗愈独行型** — 方向有价值，但当前市场规模不确定
7. **团建B端** — 单次量大但复购率低，可作为淡季补充
8. **自然探索型** — 本质是"孩子的体验"，客户的付费人是家长（亲子教育型），不单独列为优先获客方向
