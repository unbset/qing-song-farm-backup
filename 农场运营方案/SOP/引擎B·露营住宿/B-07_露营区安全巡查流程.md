[执行人] 引擎B主理人
[替代人] 运营卫星成员（经培训后）
[执行时间] 每日 21:00（夜间首次巡查）/ 23:00（二次巡查）/ 次日7:00（晨间巡查）
[适用季节] 全年
[前置条件] 当日有客入住
[AI接口] Hermes记录每日巡查结果和异常；自动生成安全巡查周报
[AI提醒] Hermes在巡查时间推送巡查清单；恶劣天气推送加强巡查提醒

---

### 一、晨间安全巡查（7:00-7:30）

```
1. 营位区巡查
   - 检查各营位过夜情况（帐篷状态、有无异常）
   - 检查有无明火残留（重点！）
   - 检查有无垃圾遗留
   - 检查设施是否完好（桌椅/遮阳设施）

2. 公共区域巡查
   - 卫生间/淋浴间清洁度和设施完好
   - 公共照明是否正常关闭（日间省电）
   - 步道有无障碍物

3. 外围巡查
   - 围栏/围网完好（防野生动物进入）
   - 入口门禁正常
   - 监控设备正常运转（如有）
```

### 二、夜间安全巡查（21:00 / 23:00）

```
1. 首次巡查（21:00）

   消防安全
   □ 各营位无违规用火
   □ 篝火台已按规定使用（仍在燃烧的需有人看守）
   □ 灭火器材在位有效

   秩序安全
   □ 音响音量在规定范围内
   □ 无酗酒闹事情况
   □ 无陌生人员进入营区

   设施安全
   □ 公共照明正常
   □ 供水/供电无异常
   □ 卫生间/淋浴间夜间照明正常

2. 二次巡查（23:00）

   □ 各营位已安静（无喧哗）
   □ 所有篝火/炭火已熄灭
   □ 公共区域灯光已调暗
   □ 入口已关闭
   □ 全营区无异常声响/光线
```

### 三、恶劣天气专项巡查

```
1. 强风预警（风力≥6级）
   - 检查各营位帐篷稳固性
   - 提醒客户加固风绳
   - 收起遮阳伞/天幕
   - 检查是否有高空坠物风险

2. 暴雨预警
   - 检查排水沟畅通
   - 检查营位有无积水风险
   - 提醒客户将物品离地存放
   - 准备庇护所（如有需要安排转移）

3. 雷电预警
   - 提醒客户远离高大树木
   - 提醒客户收起金属杆/天线
   - 切断不必要的户外电源
   - 密切监测天气变化

4. 高温预警（≥35°C）
   - 检查公共区域防暑物资（急救箱/藿香正气水）
   - 提醒客户注意防暑
   - 确保供水点正常
```

### 四、月度安全专项检查

```
1. 消防设施检查（每月1日）
   □ 灭火器压力正常
   □ 灭火器未过期
   □ 消防通道畅通
   □ 应急灯/疏散指示正常

2. 电气安全检查（每月1日）
   □ 户外电源箱无漏电/进水
   □ 线路无老化/破损
   □ 接地保护正常

3. 设施结构检查（每月1日）
   □ 营位平台/木结构稳固
   □ 围栏/围网无破损
   □ 步道无塌陷
   □ 标识牌牢固
```

### 五、安全事故应急响应

```
1. 火灾
   - 立即呼叫所有人员疏散
   - 使用灭火器扑救（初期火灾）
   - 拨打119（火势失控时）
   - 通知言渊

2. 人员受伤
   - 评估伤情
   - 轻伤：急救箱处理
   - 重伤：拨打120，通知言渊
   - 保护现场（如需）

3. 失踪/迷路
   - 确认最后出现位置
   - 组织人员搜索
   - 报警（搜索30分钟无果）

4. 恶劣天气突发
   - 立即通知所有客户转移至安全区域
   - 停止户外活动
   - 启动庇护所方案
```

### 六、验收标准

```
□ 每日夜间巡查按时完成并记录
□ 晨间巡查无明火残留
□ 安全设备在位有效
□ 无安全事故发生
□ 恶劣天气预警已及时响应
□ 月度安全专项检查已执行
□ Hermes巡查记录完整
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 发现客户违规用火 | 立即制止，没收火源，口头警告 |
| 客户醉酒闹事 | 劝告→隔离→报警（必要时） |
| 设施损坏存在安全隐患 | 围挡停用→张贴警示→报修 |
| 发现野生动物进入 | 驱离→修补入口→加强巡查 |
| 监控设备故障 | 记录→报修→加强人工巡查 |
| 客户深夜未归 | 联系确认安全 |

### 八、跨板块协作

- 安全巡查发现的设施问题即时通知**运营卫星**安排维修
- 安全隐患整改纳入**晨会（G-02）**通报
- 严重安全事故升级至**言渊**处理
- 安全巡查记录在公开化运营中展示（透明化安全承诺）

### 九、客户触点

- 客户可能看不到巡查过程，但能感受到安全感
- 夜间巡查不打扰客户（轻声、不照向帐篷内部）
- 恶劣天气的提前预警和关怀是建立信任的关键时刻
