# 农场建设公开化方案 · 引擎A（餐饮）

> **基于**：星形结构 — 引擎A（利润中心）
> **覆盖工作**：17项（A01-A17）
> **本文定位**：引擎A所有可公开化工作的模式匹配与执行设计

---

## 第一部分：总纲

### 1.1 核心理念

引擎A是农场"烟火气"的来源。窑炉在烧、柴火灶在冒烟、面包刚出炉的热气、大席摆满一桌的排面——这些不是"餐厅后厨的秘密"，而是农场最生动的可见面。

引擎A公开化的核心逻辑与其他板块不同：
- **核心层公开化是为了建立信任**（"这个农场真的在种东西"）
- **引擎A公开化是为了放大传播**（"这个画面让人想来"）

引擎A的公开化不是"让客户帮忙做饭"，而是"让做饭的过程本身成为风景和内容"。

### 1.2 引擎A公开化的三条原则

| 原则 | 说明 |
|:---|:---|
| **出餐优先** | 公开化不能影响出餐效率和品质。高峰时段（午餐/晚餐）不开放任何互动，只能安排在备餐时段或低峰期 |
| **天生出片** | 引擎A大部分的公开化价值在于"拍出来好看"。设计任何公开环节时都要先问：这个画面值得拍吗？ |
| **体验可复制** | 引擎A的公开化活动必须标准化，确保换一个人执行体验也不掉线。不像核心层可以随性一些，餐饮环节涉及食品安全 |

### 1.3 引擎A五种模式的整体倾向

| 模式 | 适合引擎A的什么工作 | 引擎A的天然优势 |
|:---|:---|:---|
| 课程化 | 有知识含量、可讲解的加工过程（面包窑建造/食材加工/发酵熬酱） | "从原材料到食物的转化过程"本身就有完整的故事线 |
| 共建化 | 需要集中力量完成的设施建设（建面包窑/建户外厨房） | 客户参与建一个自己以后能用的窑——归属感极强 |
| 劳动换薪 | 备餐环节中的重复轻体力工作（穿肉串/分装蔬菜/打包野餐篮） | 工作内容简单干净，在中心厨房附近进行，安全可控 |
| 认领化 | 可长期标记的产品（认领一棵烘焙用的果树/认领一个窑炉的命名权） | 适用场景有限，但认领窑炉的"窑主"概念有差异化 |
| 技能传承 | 客人擅长的烹饪技能/传统食谱/烘焙经验 | 每位客人都有自己的"拿手菜"——这是最好的内容素材 |

## 第二部分：各模式详述

---

### 模式1 课程化

**定义**：将有知识含量、可演示的餐饮相关工作设计为体验活动，客户以"学习+动手+品尝"的方式参与。

**适合的工作类型**：有制作过程可展示、有技巧可教学、成品可直接食用的工作。

#### 典型场景1：面包窑建造课（对应A01）

面包窑不是每天建，但建的过程是引擎A最值得深度开发的课程化产品。它兼具"建造的成就感"和"烤出面包的实用性"。

| 项目 | 内容 |
|:---|:---|
| 形式 | 系列课程（3-4次课，每周一次，从打地基到开窑烤第一批面包） |
| 定价 | 单次168元/人，全套520元/人（含所有材料+每次的午餐） |
| 容量 | 8-12人/次 |
| 课程安排 | 第1课：窑基与耐火层——了解面包窑的原理，动手砌窑基（3小时） |
| | 第2课：窑体与保温层——耐火泥+沙+稻草的配比，亲手糊窑体（3小时） |
| | 第3课：烟道与装饰——烟道走向设计，窑体外立面装饰（3小时） |
| | 第4课：开窑仪式——学习生火控温，烤第一批面包，开窑庆祝（4小时） |
| 交付 | 每位参与者获得"面包窑共建人"证书，开窑后一年内享受面包9折 |

**情绪价值设计**：
- "这个窑有我亲手砌的一块砖"——参与建窑的客户以后来农场都会去看看"自己那个窑"
- 第四课开窑时，自己烤的面包从自己建的窑里拿出来——双重成就感
- 系列课程意味着客户连续四周都来——粘性极高

**传播设计**：
- 每一课的过程都拍成短视频——"从零开始建一个面包窑"系列
- 开窑仪式的画面——窑火打开，面包夹出，热气腾腾——最佳传播素材
- 结课时的大合影+证书颁发——客户会发朋友圈

#### 典型场景2：食材加工课（对应A06）

腌制、发酵、熬酱、风干、熏制——这些食材加工过程有知识含量、有动手乐趣、成品还能带走，是最适合课程化的引擎A工作。

| 项目 | 内容 |
|:---|:---|
| 产品线 | 做辣酱课（88元/人，带走2瓶）、腌咸菜课（68元/人，带走1坛）、熬果酱课（78元/人，带走2瓶）、做泡菜课（88元/人，带走1坛）、腊肉/香肠制作课（128元/人，带走1串） |
| 时长 | 1-1.5小时 |
| 容量 | 6-12人 |
| 通用流程 | 介绍食材来源和选择标准（5分钟）→ 演示关键步骤（10分钟）→ 客户动手操作（40-60分钟）→ 封装/贴标（10分钟）→ 合影（5分钟） |
| 交付 | 客户带走自己做的成品，贴上"青松农场+制作日期+制作人"标签 |

**情绪价值设计**：
- "以后吃的辣酱是我自己做的"——日常生活中的小骄傲
- 做完了带回家，家里人吃到的时候会说"这是你自己做的？"
- 季节限定（春天的香椿酱、夏天的番茄酱、秋天的桂花酱、冬天的腊肉）——每个季节来一次

**传播设计**：
- 熬酱时锅里冒泡的特写——视觉+嗅觉的想象
- 成品瓶子的颜值决定传播力——标签设计要好看
- 客户回家后开瓶吃的时候拍了发——"上次在农场做的辣酱，今天开了"

#### 典型场景3：窑炉面包的"出炉时刻"（对应A08，免费观赏）

这不是一门收费课，而是一个"免费观赏环节"，但它可能是引擎A传播价值最高的公开化设计。

每天一炉面包出炉时，员工吆喝一声"面包好啦！"。这个动作本身是免费的，但效果极好。

| 项目 | 内容 |
|:---|:---|
| 时间 | 上午10:00-11:00（第一炉），下午视情况 |
| 形式 | 免费观赏，客户可围观面包出炉全过程 |
| 流程 | 员工打开窑门→用长铲夹出面包→放在晾架上→面包还在冒热气→客户可以拍照→切一片试吃（免费或极低价） |
| 定价 | 围观免费，试吃2元/片（或随餐饮赠送） |

**情绪价值设计**：
- "刚出炉的面包"——这个体验在城市里几乎不存在了
- 面包的香味+窑炉的热气+员工夹出面包的动作——三感叠加

**传播设计**：
- 面包出炉的瞬间拍下来发抖音/小红书——"每次出炉都是这个感觉"
- 客户自己拍的面包热气视频发朋友圈——最好的免费广告

### 模式2 共建化

**定义**：将需要集中力量完成的餐饮设施建设工作设计为集体活动，客户以"一起建造"的方式参与。

#### 典型场景1：一起建户外厨房（对应A02）

| 项目 | 内容 |
|:---|:---|
| 时机 | 户外厨房搭建/升级时，一次性活动 |
| 形式 | 免费/低偿参与，共建完成后举办一场"开灶宴" |
| 容量 | 10-15人 |
| 流程 | 分组（木工组/泥工组/装饰组）→ 各组按图纸施工（2-3小时）→ 完成后一起用这个厨房做一顿饭庆祝（1小时） |
| 交付 | 参与者的名字刻在户外厨房的铭牌上 |

### 模式3 劳动换薪

**定义**：将餐饮备餐环节中的重复轻体力工作开放给客户，完成后获得小额现金或代金券。

#### 适合引擎A的劳动换薪项

| 优先级 | 编号 | 工作内容 | 建议薪酬 | 时长 | 条件 |
|:---:|:---|:---|:---:|:---:|:---|
| P0 | A10 | 烧烤食材包打包（穿肉串/分装蔬菜/配调料包） | 12元/30分钟 | 30分钟 | 在中心厨房操作台进行，干净卫生，员工在旁边指导 |
| P1 | A14 | 野餐篮打包（食物组装/分层摆放/插卡片/装篮） | 8元/篮 | 15分钟 | 适合孩子操作，做完有成就感 |
| P1 | A15 | 面包切片包装贴标签 | 5元/10个 | 15分钟 | 简单重复，适合家长带孩子一起做 |
| P2 | A16 | 加工品装瓶/封口/贴标 | 8元/30分钟 | 30分钟 | 按批次进行，配合课程化批量生产 |

**执行方式**：
- 中心厨房外设一块小黑板"今日厨房助手"
- 参与时间限制在低峰期（上午9:00-11:00，下午14:00-16:00），高峰期不开放
- 参与前：洗手+戴围裙+戴帽+口罩（食品安全标准）
- 参与中：在中心厨房员工的指导下操作，不接触生肉等高风险食材
- 不适合儿童独立完成（涉及刀具/炉火），但穿肉串和打包野餐篮可在家长陪同下参与

**限制条件**（引擎A劳动换薪特有的边界）：
- 每天限3人次参与（不影响正常备餐节奏）
- 禁止接触：生肉/刀具/炉火/热油
- 参与前必须签署食品安全告知书

### 模式4 认领化

**定义**：将引擎A中可长期标记的资产开放给客户认领。

引擎A适合认领的资产较少，但有差异化价值。

#### 认领产品设计

| 产品 | 定价 | 权益 | 目标数量 |
|:---|:---:|:---|:---:|
| 认领一棵面包果树（窑炉旁边的果树） | 300元/年 | 树上挂认领牌，每年收获季的果实优先供应窑炉面包，认领人获得"该果树果实制作的面包"全年8折 | 10棵 |
| 认领一次窑炉的"窑主"身份 | 500元/年 | 窑炉上刻认领人名字（铭牌），全年面包9折，每年可预约一次"用这个窑烤自己的东西" | 5个名额 |

### 模式5 技能传承

**定义**：识别出客户身上有引擎A需要的技能，发起价值交换。

#### 引擎A适用的技能交换场景

| 客人有 | 农场需要 | 交换方式 |
|:---|:---|:---|
| 独家拿手菜/祖传食谱 | 餐厅菜单的差异化菜品 | 教一次农场厨师做这道菜→菜品在菜单上标注"由XX提供配方"→该客户全年在引擎A用餐8折 |
| 烘焙经验（尤其窑炉/柴火烘焙） | 窑炉面包的品质提升和品种开发 | 定期来做技术指导→交换储值卡 |
| 传统面点手艺（做馒头/花卷/包子/饺子） | 早餐/简餐产品的开发 | 开一次体验课（客户教，农场出场地和材料）→课时费归老师 |

## 第四部分：执行流程

引擎A的公开化执行流程沿用核心层设定的6环节框架，但有几处关键差异。

### 4.1 发现与识别

谁来发现：引擎A主理人（厨师或餐饮主理人）。

发现时机：
- 备餐时发现"这个环节客人肯定感兴趣"
- 有客户围观厨房操作时——这个信号说明有公开化价值
- 季节食材变化时——推出新的食材加工课

### 4.2 评估与决策

引擎A的决策树增加了两条特殊判断：

```
这项工作可以对外公开吗？
  +-- 涉及食品安全吗？（生肉处理/未消毒器具/高温操作）
  |   +-- 是 --> 不开放
  |   +-- 否 --> 继续评估
  +-- 会影响出餐效率吗？
  |   +-- 会 --> 仅在低峰期开放
  |   +-- 不会 --> 正常开放
  +-- 继续使用通用决策树判断模式
```

### 4.3 设计与发布

| 模式 | 负责人 | 注意事项 |
|:---|:---|:---|
| 课程化 | 引擎A主理人（内容）+ 运营卫星（发布） | 标清楚是否含餐、是否可带走成品 |
| 共建化 | 引擎A主理人+运营卫星 | 提前确认材料清单和工具安全 |
| 劳动换薪 | 引擎A主理人（排班）+运营卫星（小黑板） | 每天限量，低峰期开放 |
| 认领化 | 运营卫星 | 主要在店内展示+社群发布 |
| 技能传承 | 言渊+引擎A主理人 | 私下邀请，不在公开渠道发布 |

### 4.4 执行与现场管理

引擎A的特有执行要求：

| 要点 | 标准 |
|:---|:---|
| 食品安全 | 所有参与客户必须洗手+戴围裙+戴帽。接触食材前完成卫生准备 |
| 分区管理 | 劳动换薪在"备料区"进行，与"烹饪区"和"清洗区"物理隔离 |
| 时间限制 | 高峰期（11:00-13:00, 17:00-19:00）不开放任何公开化活动 |
| 人员配置 | 课程化活动需引擎A主理人或指定员工全程陪同，不可让客户单独操作 |
| 过敏告知 | 任何涉及食材的活动必须提前告知客户：本场活动涉及哪些常见过敏原 |

### 4.5 收尾与传播

引擎A的传播价值在所有板块中最强，收尾环节要尤其重视"传播引导"。

| 模式 | 收尾动作 | 关键传播引导 |
|:---|:---|:---|
| 课程化（食材加工课） | 成品贴标+合影 | "和你的辣酱拍一张"——客户会发朋友圈 |
| 课程化（面包窑建造课） | 每次课后拍进度照 | "窑炉建造第X周"系列内容 |
| "出炉时刻" | 员工吆喝+让客户拍照 | 不主动推销，让客户自发拍 |
| 劳动换薪 | 发薪酬+拍"今日厨房助手"照 | 孩子穿着小围裙的照片——家长必发 |
| 共建化 | 铭牌安装+开灶宴 | "我们一起建的厨房开火了" |

### 4.6 记录与复盘

每月末运营卫星汇总引擎A的公开化数据。引擎A需要额外关注两个特有指标：

| 记录项 | 说明 |
|:---|:---|
| 课程化场次与收入 | 本月开了几堂食材加工课、报名人数、课程收入 |
| "出炉时刻"曝光量 | 客户自发发布的内容数量（可在小红书/抖音搜索品牌名统计） |

## 第五部分：风险与合规

### 5.1 风险分级

| 等级 | 描述 | 涉及的工作 | 控制措施 |
|:---:|:---|:---|:---|

### 5.2 特殊：食品安全告知书

引擎A的劳动换薪和课程化活动，在参与前需签署食品安全告知书（比核心层的免责协议多两条）：

1. 参与者确认无传染性疾病、无开放性伤口
2. 参与过程中遵守卫生规范（洗手/穿戴/不随意触摸非操作区）
3. 如有不适（咳嗽/打喷嚏/皮肤破损）主动告知工作人员

### 5.3 保险要求

引擎A的公开化活动覆盖在农场已有的公众责任险下。需额外确认：
- 保险条款包含"食品体验活动"类目
- 覆盖范围包含中心厨房的客户参与区域
- 食品安全的特殊考虑：如果客户参与制作的食品被客户自己带走食用后出现问题，责任界定需在参与协议中明确

## 第六部分：执行建议

### 6.1 从哪开始——最小可测试单元

引擎A的公开化启动顺序建议：

**第一批（第1个月内启动，零成本）：**
1. "出炉时刻"标准化——每天面包出炉时员工吆喝一声，让客户围观拍照。零成本，只需要一个动作和意识
2. 展示台升级——A03和A04合并为一个动作：中心厨房门口摆一张小桌，放上当天核心层送来的蔬菜+鸡蛋+采购食材对比，配一块小黑板"今天从地里到厨房"

**第二批（第2-3个月）：**
3. 烤箱食材加工课上架——先推"熬果酱"课，夏季应季，成本低（水果+糖+瓶子），成品好看
4. 劳动换薪小黑板上线——先从"面包切片包装"(A15)和"野餐篮打包"(A14)开始，简单安全

**第三批（第3个月后）：**
5. 面包窑建造系列课——如果有新建/改造窑炉的计划，提前招募
6. 其他食材加工课（做辣酱/腌咸菜/做泡菜）——按季节推出

### 6.2 引擎A公开化的特殊节奏

引擎A有一个天然优势：**每天都有出餐，每天都有内容素材**。不需要像核心层那样等换季。

| 频率 | 动作 | 谁负责 |
|:---:|:---|:---|
| 每日 | "出炉时刻"（上午窑炉出品时） | 窑炉负责人 |
| 每周 | 劳动换薪小黑板更新（2-3次/周，低峰期） | 引擎A主理人 |
| 每两周 | 食材加工课开课（按季节主题） | 引擎A主理人+运营卫星 |
| 每季度 | 共建活动（换季时设施维护/升级） | 引擎A主理人+言渊 |

### 6.3 每个项目启动前问自己三个问题

1. 这个活动是否影响出餐效率？（高峰期绝对不能开放）
2. 这个活动的画面值不值得拍？（引擎A的核心价值是传播）
3. 客户参与后会产生"下次还想来"的念头吗？
