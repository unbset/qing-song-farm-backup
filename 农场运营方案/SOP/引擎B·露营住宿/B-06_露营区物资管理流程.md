[SOP编号] B-06
[SOP名称] 露营区物资管理流程
[执行人] 引擎B主理人
[替代人] 运营卫星成员
[执行时间] 每周盘点1次（周一上午）/ 每次出入库即时记录
[适用季节] 全年
[前置条件] 物资台账已在Hermes建立
[AI接口] Hermes管理物资台账，记录出入库流水，自动生成补货清单
[AI提醒] Hermes在物资库存低于安全线时推送补货提醒；每月推送物资损耗分析报告

---

### 一、物资分类与台账

```
1. 物资分类

   固定设施类
   - 帐篷（自有/租赁用）
   - 天幕、桌椅
   - 睡袋、防潮垫
   - 照明设备（营灯/头灯/灯串）
   - 炉具/卡式炉
   - 公共设施（卫生间/淋浴间/洗漱台配件）

   消耗品类
   - 卫生纸、洗手液、洗洁精
   - 垃圾袋、一次性手套
   - 炭火、柴火、点火器
   - 急救箱耗材
   - 驱蚊用品

   租赁物资类
   - 帐篷套装（帐篷+睡袋+防潮垫）
   - 天幕套装
   - 烧烤炉租赁
   - 户外电源/充电宝
```

### 二、入库管理

```
1. 新物资入库
   - 登记至Hermes台账
   - 填写：物资名称/规格/数量/入库日期/供应商/采购价格
   - 实物贴标签（编号/入库日期）
   - 分类存放至对应储物区

2. 物资验收
   - 数量核对（与采购单一致）
   - 质量检查（新品无损坏/功能正常）
   - 不合格品拒收或退换
```

### 三、出库与使用记录

```
1. 租赁出库
   - 客户租赁时在Hermes记录：
     客户姓名/营位号/租赁物资/数量/租赁时间/押金
   - 客户签字确认
   - 归还时核对数量+检查状态

2. 消耗品领用
   - 公共区域消耗品按需补充（不单独记录每次领用）
   - 大额消耗品（炭火/柴火）每次出库在Hermes记录

3. 内部使用
   - 员工因公使用物资在Hermes登记
   - 员工个人使用按成本价购买
```

### 四、库存盘点

```
1. 每周盘点
   - 周一上午盘点所有物资
   - 核对Hermes台账和实物数量
   - 记录盘盈/盘亏

2. 月度盘点
   - 每月最后一天全面盘点
   - 分类统计损耗率
   - 生成补货清单

3. 库存安全线
   物资	安全库存量	补货触发线
   卫生纸	20卷	≤5卷
   洗手液	5瓶	≤2瓶
   炭火	50kg	≤20kg
   柴火	100kg	≤50kg
   垃圾袋	100个	≤30个
   急救耗材	1套备用	已使用即补
   驱蚊用品	10瓶	≤3瓶
```

### 五、物资维护与报废

```
1. 租赁物资维护
   - 每次归还后检查清洁
   - 帐篷：晾晒后收纳（防霉）
   - 睡袋：清洗后晾晒（每月至少清洗一次）
   - 天幕：检查有无破损，有破损的修补或报废

2. 固定设施维护
   - 营位设施每月全面检查
   - 灯具/电源/淋浴设备每季度保养

3. 报废标准
   - 帐篷：破损面积≥10cm或无法修复
   - 睡袋：拉链损坏+填充物结块
   - 天幕：多处漏水或撕裂
   - 炉具：阀门损坏或漏气
   - 报废物资在Hermes标记"已报废"，备注原因
```

### 六、验收标准

```
□ 物资台账完整，出入库记录及时
□ 库存量在安全线以上
□ 租赁物资归还后已检查清洁
□ 周盘点已完成，盘盈/盘亏已处理
□ 消耗品备量充足（不低于安全线）
□ 报废物资已标记并处理
□ 月度损耗分析报告已生成
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 物资损耗率异常高 | 排查原因（客户使用不当/质量差/管理漏洞） |
| 物资被盗 | 记录并报警，加强夜间巡查 |
| 客户损坏租赁物资 | 按标准赔偿（正常磨损不计） |
| 消耗品断货 | 紧急外采，运营卫星协助 |
| 库存与台账不符 | 重新盘点，找出差异原因 |

### 八、跨板块协作

- 物资采购清单提报**运营卫星**统一采购
- 消耗品补充纳入**O-01每日开场巡检**检查项
- 报废物资中可再利用的（如旧帐篷布）移交**自然手作卫星**做改造材料
- 大额物资采购报**言渊**审批

### 九、客户触点

- 物资齐全是露营体验的"隐形保障"，客户可能不会注意到，但物资短缺时一定会投诉
- 租赁物资的清洁度和完好度直接影响客户对露营品质的判断
- 消耗品充足（卫生纸/洗手液）是基础服务，断供是严重失误
