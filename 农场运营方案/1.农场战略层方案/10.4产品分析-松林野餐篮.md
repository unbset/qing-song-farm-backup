# 产品分析：松林野餐篮

> **分析框架**：产品分析框架V4

---

## 1. 飞轮定位

**主定位**：传播杠杆

松林野餐篮是三个室外餐饮产品（柴火灶/火锅/烧烤）之外的一个轻量补充——它不需要客户动手做任何事，拎了就走、找个松林空地坐下就吃。它的画面感极强（松林+野餐篮+花格布），天然的社交媒体素材。

**辅助作用**：
- 利润中心（食材成本可控，无需人力服务）
- 引流入口（"拎了就走"的低决策门槛，适合首次到店的轻度体验客户）

---

## 2. 目标客群

### 主客群：不想动手又想亲近自然的"轻体验"客户

- 画像：25-35岁情侣，或2-4个闺蜜结伴的年轻女性群体。拍照意愿强，对"出片率"有要求
- 痛点：想野餐但自己准备太麻烦（买菜、洗切、装篮、带餐具、吃完收拾）；去市区野餐营地太商业化了
- 痒点："到松林里坐下就吃，不用准备不用收拾，还能拍出好看的照片"——这个画面本身就让人向往
- 决策逻辑：在小红书/朋友圈看到野餐篮的照片 → "这个好，不用自己带东西" → 周末来 → 到中心厨房直接买一个拎走 → 找个松林空地铺开吃

### 次客群：带孩子家庭的快速午餐方案

- 画像：带孩子来的家庭，孩子饿了但大人不想在餐厅等上菜
- 痛点：孩子饿了就要马上吃，等不了
- 痒点：买了直接拿走、孩子先吃着、大人慢慢逛
- 决策逻辑：孩子喊饿 → "买个野餐篮吧，那边松林里坐下吃" → 买了 → 孩子边吃边玩

### 内部客户：无。直接面向外部消费者。

---

## 3. 核心体验

"到中心厨房拎一个篮子就走，在松林里找个空地铺开坐下就吃。不用排队点菜、不用等人上菜、不用自己带任何东西、吃完了篮子一收放到回收处——全程零负担。"

对比室外散客餐饮矩阵的三个产品：
- 柴火灶：需要动手炒 → 适合社交展示型客户
- 火锅：需要点火涮 → 适合有"坐下来慢慢吃"意愿的客户
- 烧烤：需要自己烤 → 露营客户首选
- **松林野餐篮：什么都不用做，拎了就吃 → 适合最懒的那群人**

## 4. 交付标准

### 触点一：从中心厨房拿到野餐篮的第一眼

| 角色     | 加分                                          | 扣分                  |
| :----- | :------------------------------------------ | :------------------ |
| **员工** | 把篮子递过来说"里面有湿巾和垃圾袋，吃完把篮子放到回收处就行"——引导了完整的操作流程 | "要个篮子吗？"——问完就不管了    |
| **主管** | 篮子的外观本身就是一个产品——藤编篮+棉麻布+牛皮纸包装，视觉上"可出片"       | 塑料袋或一次性餐盒凑一起，看着就不想吃 |
| **客户** | "哇这个篮子好好看"——还没吃就想拍照了                        | "就这个？"——预期和实物差距大    |

### 触点二：打开篮子时的惊喜感

| 角色     | 加分                                        | 扣分              |
| :----- | :---------------------------------------- | :-------------- |
| **员工** | 每样食物独立牛皮纸包，附一张手写风格的小卡片（"野餐愉快"+"松林建议拍照位置"） | 所有东西塞在一个塑料袋里    |
| **主管** | 打开篮子的过程本身就是一个"开箱体验"——分层摆放，视觉有层次感          | 打开乱糟糟的，食物和餐具混一起 |
| **客户** | "这个好精致"——拍照欲望被触发                          | 不想拍了，直接吃吧       |

### 触点三：吃完后的收尾

| 角色     | 加分                                       | 扣分                 |
| :----- | :--------------------------------------- | :----------------- |
| **员工** | 回收处准备了清水洗手，顺便问一句"吃得怎么样？下次可以试试柴火灶"——跨产品引流 | 没有回收处提示，客户不知道篮子往哪放 |
| **主管** | 篮子可重复使用（客户可选择带走或退还押金退回），退还的篮子消毒后复用       | 一次性包装，用完就扔         |
| **客户** | 吃完把垃圾一收放回收处，轻松走人——"真的什么都不用管"             | 垃圾不知道扔哪，拎着油乎乎的篮子走  |

### 品质底线
- 篮子外观必须"可出片"（藤编/竹编篮+棉麻内衬+牛皮纸包装）
- 所有食物独立包装，不串味，不易漏油
- 每篮附：湿巾、垃圾袋、一次性手套
- 篮子提供两种方式：带走（含篮子费）或退还（押金制，篮子消毒后再用）
- 回收处设洗手池+纸巾

## 8. 增长路径

### 复购机制
- 菜单按季节轮换：春季（草莓/青团）、夏季（水果杯/冷面）、秋季（葡萄/板栗）、冬季（热饮+暖食版）
- 推出"打卡收集"：松林里有3个推荐野餐点，每个点有不同标识，集齐3个点的照片发小红书可换一份饮品
- 会员储值：充值200送一个野餐篮

### 传播机制
- **这个产品的核心传播价值不在食物本身，在"场景"。** 松林+藤编篮+花格布+阳光透过松针洒下来——这个画面不需要任何拍摄技巧
- 在松林里设置2-3个"最佳野餐拍照位"（用木桩或石板简单标示，不破坏自然感）
- 鼓励客户发小红书，带话题#松林野餐 #青松农场

### 衍生可能
- 季节限定版：圣诞野餐篮（热红酒+姜饼）、春游野餐篮（青团+野花束）
- 情侣约会版：野奢篮+松林散步路线推荐卡
- 企业团建版：批量定制（运营卫星对接B端客户）

## 10. 决策结论

| 项目 | 内容 |
|:---|:---|
| 总体判断 | **做** |
| 前提条件 | 1. 篮子和包装设计方案确定（运营卫星负责视觉，引擎A负责内容）2. 三款菜单试做一遍，确认出餐流程和成本 3. 松林野餐区域和拍照位的清理 |
| 优先级 | **高**。野餐篮是入场门槛最低的产品（客户不需要任何技能，拎了就走），适合作为"首次到店客户的第一个产品"。它同时承担引流和传播的双重角色，性价比高 |
| 启动建议 | 先推经典款（轻食篮，68元）+ 亲子篮（98元），野奢篮（158元）作为第2批上线。首批试跑2周，观察销量和客户反馈后再决定是否加推野奢篮 |
| 退出条件 | 连续1个月日均销量<5篮→暂停；食材损耗率超过30%→重新评估备货量；如果篮子供不应求→追加采购即可，不构成退出 |

## +1 客户视角验证（AI多角色模拟）

### 角色A：两个闺蜜（25岁，小红书活跃用户）

**体验路线**：在小红书搜"潍坊周末去哪"→看到有人发松林野餐的照片→周末开车过来→到中心厨房看到展示柜里的篮子→选了经典款→找了一块松林空地铺开→拍照→吃→走

**加分点**：看到篮子实物"好好看"——马上掏手机拍照；打开篮子发现每样东西独立包装、还有一张小卡片——"这个农场好用心"
**扣分点**：如果当天松林地上有没清理的垃圾——拍照需要避开，体验打折扣
**复购意愿**：强。下次换野奢篮试试，再拍一组。
**传播意愿**：强。当场发了小红书，"潍坊终于有像样的野餐地方了"。
**优化建议**：松林野餐区域每天早上的垃圾清理是底线工作——一个烟头就能让客户的照片废掉。

### 角色B：带孩子的一家三口（孩子4岁）

**体验路线**：周末来农场玩 → 到了午餐时间孩子开始闹饿 → 大人不想等上菜 → 看到亲子野趣篮 → 买了直接走到松林里铺开吃

**加分点**：孩子看到迷你汉堡+鸡翅马上安静了——"不用等，直接吃"；里面配了湿巾和围兜——"农场连这个都想到了"
**扣分点**：如果当天没有亲子篮只有经典款——孩子不爱吃三明治，大人还要再想办法
**复购意愿**：中。下次还会考虑，但如果有其他选择（火锅/柴火灶）可能会换个体验。
**传播意愿**：中。会在妈妈群推荐，但不会单独发朋友圈。
**优化建议**：亲子篮里加一个"找松果"小任务卡——让孩子吃完在附近找3个松果，找到后去中心厨房换一颗糖或小贴纸。零成本，但孩子会记住这个农场。

### 角色C：独自来长搭的客户（自由职业者）

**体验路线**：周中到长搭位工作 → 中午饿了不想离开座位太久 → 去中心厨房看到有野餐篮 → 买了拎到长搭位边干活边吃

**加分点**：不用离开工作区太久，直接拎过来就能吃
**扣分点**：经典款三明治的量对成年人来说偏少（1-2人份的"2人"是女生饭量）——一个成年男性可能不够
**复购意愿**：中。会回购，但可能会同时加一份中心厨房的其他成品。
**传播意愿**：不。不会为了野餐篮专门发什么。
**优化建议**：经典款可以考虑出单人份（38-45元/篮，一人食分量），更适合长搭客户的工作日午餐场景。

### 角色D：农场主管（运营视角）

**最大盲点发现**：野餐篮看起来"很简单，就是打包食物"，但实际上它有三个产品中**最依赖跨部门协作**的：引擎A负责出餐，运营卫星负责包装设计（篮子+卡片+视觉风格），现场需要维护松林区域卫生。任何一个环节掉链子，产品体验都会毁掉。建议在正式上线前，三个负责人坐在一起对一遍流程。

**跨产品引流价值**：野餐篮最大的价值可能不是它自己赚了多少钱，而是它作为一个"低门槛入口"，让首次到店的客户以一个轻松的姿势进入农场——先试野餐篮（68元），满意了下次来试柴火灶（120元+），再下次来露营住宿（过夜）。**野餐篮是引擎A的"漏斗产品"**。
