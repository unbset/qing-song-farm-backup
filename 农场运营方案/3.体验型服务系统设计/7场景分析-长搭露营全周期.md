# 场景分析：长搭露营（关系型客户全周期）

> **分析日期**：2026-06-02
> **基于框架**：《体验型服务系统分析框架》V2.0
> **场景性质**：关系型服务——非一次性体验，是年度持续关系
> **核心问题**：长搭客户的决策过程是怎样的？签约后农场如何与长搭者互动？农场如何与长搭者带来的客人互动？

---

## 一、本场景的特殊性

长搭露营跟前五个场景有本质区别——它不是一个"场景"，是一段**持续1年以上的关系**。

| 维度   | 前五个场景       | **长搭露营**                    |
| :--- | :---------- | :-------------------------- |
| 时间跨度 | 一次到访（4-8小时） | **1年（续约可能3-5年）**            |
| 客户关系 | 交易/活动参与者    | **"小院的主人"——有财产关系**          |
| 消费方式 | 单次付费        | **年费3600元+日常消费**            |
| 服务模式 | 触点式的单次服务    | **持续的关系维护**                 |
| 客户角色 | 客人          | **半个主人**                    |
| 分析单位 | 一个场景        | **三个阶段的连续分析：决策→签约后日常→客带到访** |

## 第①层 · 人与关系

### 角色识别

| 角色 | 定义 | 存在意义 |
|:---|:---|:---|
| **长搭决策者** | 付3600元年费的人 | 做购买决策的核心人物 |
| **长搭使用者（家庭）** | 实际使用小院的家庭全员 | 配偶+孩子，他们的满意度影响续约 |
| **长搭者带来的客人** | 被邀请来玩的亲友 | 长搭者的"显摆对象"——**农场获取新客户的核心入口之一** |
| **农场（引擎B）** | 服务提供方+关系维护方 | 维护小院+协调公共空间+关系管理 |

---

### 长搭决策者

```
基本画像：35-50岁 / 家庭月收入2万以上 / 潍坊城区居民 / 有车 / 有家庭有孩子
核心动机："在城外有一个属于自己的院子"

真实心理（深度访谈推导）：
  ① 城市生活的压迫感——"我想有一个周末可以不用待在城里的地方"
  ② 对"拥有"的渴望——不是去住酒店/民宿，是"我的地方"
  ③ 对家人补偿——"周末带孩子去农场玩"比"周末带孩子去商场"更让父母觉得自己是好父母
  ④ 面子的成分——"我在XX农场有个院子"是一个社交货币

情绪状态：不是冲动消费——3600元需要一段时间的心理建设

最怕什么：
  ① 交了钱发现使用率很低——"一年去不了几次，亏了"
  ② 小院环境维护不好——"我的院子长草了/漏水了/被人动了"
  ③ 农场的服务和承诺不一致——"交钱前说得好听，交钱后没人管了"

关键洞察：长搭客户的决策不是"理性计算"，是"情感冲动+理性说服自己"的混合体。
  情感层面："我想要一个属于我的院子"
  理性层面："3600元一年，一个月300，周末来几次就值了"
  两者缺一都签不了——纯情感冲动会在付款前退缩，纯理性计算会觉得不如去住酒店。

续约的关键：不是"小院本身怎么样"，是"去年我用了多少次、每次的感受怎么样"。
  使用率<6次/年 → 续约意大降（"划不来"）
  使用率>12次/年 → 续约意愿高（"值了"）
```

### 长搭者的家庭（配偶+孩子）

```
配偶：
  ① 通常不是决策者，但有一票否决权——"花3600买这个，你确定？"
  ② 如果她/他觉得农场环境好、孩子开心，会支持续约
  ③ 如果她觉得"就是个院子，没什么特别的"，续约时会说"今年别续了"

孩子：
  ① 孩子的态度直接影响使用率——"爸爸，我们去农场吧"就是最好的续约保障
  ② 如果有同龄玩伴（其他长搭家庭的孩子），使用率会大增
```

### 长搭者带来的客人

```
画像：长搭者的朋友/同事/亲戚 / 跟长搭者年龄收入相仿 / 有家庭
到访动机：被邀请的——"周末去我的院子玩"

客人的真实心理：
  ① 好奇——"听说他花3600在农场租了个院子，去看看什么样"
  ② 社交——朋友邀请，不去不好
  ③ 隐性的对比——"如果他选的这个地方不错，可能我也搞一个"

客人的服务体验决定了他会不会成为下一个长搭者：
  ── 好体验 → 可能问"这个怎么租的？多少钱？"
  ── 一般体验 → "挺好的"然后没了
  ── 差体验 → 不会当面说，但会劝退他自己

客人对长搭者的影响：
  ① 如果客人觉得"这个地方不错" → 长搭者面子上有光 → 更愿意再来
  ② 如果客人觉得"就这？" → 长搭者感到尴尬 → 使用率下降
```

## 二、第一阶段：决策过程分析

### 决策流程（长周期，非冲动消费）

```
阶段一：接触与感知（1-6个月）
  ① 听说过农场（内容/朋友/路过）
  ② 可能参加过一次以上活动（聚餐/亲子课/露营）
  ③ 对农场有初步印象

阶段二：认知深化（1-3次到访）
  ① 观察到其他长搭小院——"那家人是有自己院子的"
  ② 产生概念——"还能在农场租个院子？"
  ③ 开始注意到长搭的信息（公众号/现场展示）

阶段三：考虑与犹豫（1-4周）
  ① 主动询问长搭价格和条件
  ② 心理计算——3600元/年vs预期使用频率
  ③ 与配偶商量——"你觉得呢？"
  ④ 犹豫点：怕花钱了用不上 / 怕服务不好 / 怕老婆不同意

阶段四：决策与签约
  ① 通常需要一次"临门一脚"——看到别人在院子里烧烤/看到一家人玩得很开心/孩子说"我们也租一个吧"
  ② 签约付款
  ③ 选位

总时长：从第一次感知到签约，通常3-8个月。
```

### 决策过程中的关键触点

| 触点         | 客户的真实问题        | 农场该做的                        |
| :--------- | :------------- | :--------------------------- |
| **第一次听长搭** | "这个东西是干什么的？"   | 现场有显眼的长搭展示牌：小院照片+价格+权益       |
| **第一次考虑**  | "3600值不值？"     | 提供清晰的权益清单+已长搭客户的真实反馈（不是广告文案） |
| **与配偶商量**  | "你觉得呢？"        | **配偶在农场时有好的体验**——这是续约的隐形战场   |
| **临门一脚**   | "别人都在用，我也想试试"  | 长搭区域保持活跃——有人在用=最好的广告         |
| **签约时**    | "不会交完钱就没人管了吧？" | 签约即建立关系——不是"交钱走人"，是"欢迎回家"    |

### 长搭定价的心理账户

```
3600元/年的决策不是"我每月花300"，是"我要不要为一个院子花3600"。

两种心理计算方式：
  感性计算：3600元 = 一年的"城外小院" × 周末归属感
  理性计算：3600元 ÷ 12个月 = 300元/月 ÷ 4周末 = 75元/周末

  感性驱动签约，理性说服自己。
  农场的任务是：情感上让人想要，理性上让人觉得值。
```

## 三、第二阶段：签约后的互动分析

### 签约后的关键时间节点

**定位**：农业续约率的行业数据——大多数流失发生在签约后前3个月（"沉默期"）。

| 时间节点 | 长搭者的心理状态 | 农场的标准动作 | 负责人 |
|:---:|:---|:---|:---|
| **签约当天** | 兴奋+期待+"我的院子" | 挂牌仪式（写入协议是流程，但让客户感受到仪式感）+拍照发给TA+"欢迎成为农场主人" | 引擎B主理人 |
| **第1周** | 新鲜感最高 | 不需要特别做什么——客户会自己来 | — |
| **第1个月** | 新鲜感维持 | 发一次环境照片/小院状态 | 引擎B主理人 |
| **第2个月** | 新鲜感开始消退 | "最近怎么没来？"的问候 / 农场有什么新活动的推送 | 引擎B主理人 |
| **第3个月** | ⚠️ 流失高风险期 | 主动邀请参加一次农场活动（免费的） / 或告知"你的小院旁边新种了花" | 引擎B主理人 |
| **第6个月** | 习惯期 | 推送当季活动/通知邻居变动/询问使用感受 | 引擎B主理人 |
| **第9个月** | 续约犹豫期开始 | "您的租期还有3个月，有什么需要改进的吗？" | 引擎B主理人 |
| **第11个月** | 续约决策期 | 推送续约方案/老客户优惠/提前锁定下一年 | 引擎B主理人 |

### 长搭者的日常服务触点

```
长搭者的日常需求跟"来消费的客人"不同：
  ① 他不是来"被服务"的——他是来"用他的院子"的
  ② 他需要的是：小院干净、设施正常、公共区域可用
  ③ 他不需要：全程被关注、被问候——但需要：有问题的时候有人回应

日常服务原则：
  ── 常态隐身（不打扰），需要时出现（有响应）
  ── 小院维护主动做，不在客户要求下才做
  ── 公共区域的维护质量直接影响长搭者的续约判断

具体要求：
  ① 小院定期检查（每周至少1次）：清洁/设施/绿植状态
  ② 长搭者到店时确认：不需要全程陪同，但见面打个招呼
  ③ 长搭者有问题时：响应速度不超过15分钟（线上或现场）
  ④ 长搭者离开后：不需要做什么，但下次来之前确认小院已整理
```

### 长搭者的"主人意识"培养

```
长搭者的续约率不取决于"小院的硬件条件"，取决于"我在这里有没有归属感"。

培养归属感的具体动作（低成本高效果）：
  ① 小院门口挂一块属于TA的牌子——"XX家的院子"（签约当天挂好）
  ② 农场有活动时，给长搭者一个"优先通知"（不是群发，是单独发）
  ③ 长搭者连续3周没来，发一条"最近忙什么呢？小院旁边的花开得很好"
  ④ 长搭者带客人来时，引擎B主理人认识他、叫得出他的名字
  ⑤ 年底/续约时送一个小礼物——成本低于50元但代表"我们记得你"

这些动作的成本极低，但它们回答了一个核心问题：
  "农场还记得我吗？"
```

## 四、第三阶段：长搭者带客到访的互动分析

### 这个场景的特殊价值

长搭者带客到访是**农场获取新客户的最高效渠道之一**：

```
获客成本：零（农场不需要做任何推广）
信任度：极高（朋友推荐 > 广告 > 内容）
转化率：高（看到朋友真实在使用，比看到广告有说服力）
```

### 带客到访的场景分析

```
触发场景：
  ① 长搭者的朋友/同事说"周末不知道去哪"
  ② 长搭者想展示自己的院子——"去我的院子烧烤"
  ③ 长搭者的孩子在农场玩得很开心，想带自己的朋友来

角色：
  ① 长搭者 — 主人角色，主动介绍/带领
  ② 客人 — 被邀请者，好奇+对比
  ③ 农场 — 让长搭者"有面子"的后盾

客人的体验链：
  ① 被邀请（收到长搭者的邀约）
  ② 到农场（第一印象决定评价）
  ③ 进入小院（"这就是他的院子"）
  ④ 使用设施（烧烤/坐坐/农场逛逛）
  ⑤ 离开时（"这个地方还可以"）
  ⑥ 后续（可能会问"多少钱"）
```

### 农场对客人的互动原则

```
核心原则：让长搭者"有面子"，让客人"有好感"。

具体怎么做：
  ① 长搭者带客到店时，不需要特别的服务升级——把长搭者当作主人对待，客人自然能感受到氛围
  ② 如果长搭者带客在农场公共区域活动（面包窑/鸡舍/松林），客人的体验跟普通客人一致
  ③ 如果客人主动问起长搭的事——由长搭者自己介绍，农场不在旁边"推销"
  ④ 如果客人单独找到农场问（比如去洗手间路上看到长搭展示牌）——正常介绍即可

   不要做的事：
     ① 在长搭者带客时，主动向客人推销长搭产品——这是越界
     ② 让客人感受到"我是被推销对象"
     ③ 让长搭者觉得农场在"挖他的客"

   正确的做法：
     客户之间的推荐应该由客户自己完成。农场的作用是：把他的院子维护好，让他的客人在农场有好的自然体验。
```

### 客人→长搭者的转化路径

```
自然路径（不刻意推动）：

  ① 客人在农场度过愉快的一天
  ② 客人看到长搭小院的生活状态（有人在烧烤/孩子们在玩/大人在聊天）
  ③ 客人问长搭者"这个多少钱？怎么样？"
  ④ 长搭者介绍自己的体验（好的和不好的）
  ⑤ 如果长搭者说"挺好的"——客人可能会来问农场
  ⑥ 如果长搭者说"一般"——客人的兴趣到此为止

  农场唯一能做的是：让长搭者自己在第三步说"挺好的"。
  而不是跳过第三步，试图直接在第六步接住客人。
```

## 第⑤层 · 农场服务方案

### 长搭产品运营的核心工作

```
长搭不是"卖了一块地"，是"经营了50个（目标）-100个小院社区"。

核心工作分三块：

一、小院硬件维护（每周执行）
  ① 每周至少1次小院巡检：清洁/设施/绿植/供水供电
  ② 发现问题的处理时效：24小时内响应，72小时内解决
  ③ 换季维护：冬季保温/夏季遮阳

二、关系维护（常态执行）
  ① 新签约：挂牌+拍照+欢迎仪式
  ② 每月：至少1次主动触达（不一定是私信——可能是农场新动态推送）
  ③ 每季：活动优先通知（长搭者优先报名权）
  ④ 年底：续约提醒+老客户福利

三、社区氛围营造（长期）
  ① 长搭者之间的社交引导（公共烧烤区/社区活动/节假日布置）
  ② 长搭者与农场的身份认同设计（"我是农场主人"的标识/权益）
  ③ 长搭者的归属感设计（访客制度/小院个性化装饰许可/长期投入的回报感）
```

### 长搭者的服务分级

| 服务类型 | 内容 | 频次 | 负责人 |
|:---|:---|:---|:---|
| **被动服务** | 响应长搭者的维修/清洁/使用问题 | 按需（响应<15分钟） | 引擎B主理人 |
| **主动维护** | 小院巡检+公共区域清洁+设施维护 | 每周至少1次 | 引擎B主理人 |
| **主动触达** | 农场动态推送/活动优先通知 | 每月1-2次 | 引擎B主理人 |
| **关系维护** | 沉默唤醒（连续3周没来）/生日/节日 | 按节点 | 引擎B主理人 |
| **续约前维护** | 提前3个月的满意度回访+提前1个月的续约推送 | 年两次 | 引擎B主理人 |

### 长搭者带客互动的标准

| 场景 | 标准 | 负责人 |
|:---|:---|:---|
| 长搭者带客到店 | 正常欢迎，认识长搭者、跟客人打招呼 | 引擎B主理人 |
| 客人在公共区域 | 跟普通客人一致对待 | 引擎B主理人 |
| 客人问长搭产品 | 正常介绍，不主动追单 | 引擎B主理人 |
| 长搭者主动推荐朋友 | 给推荐人（长搭者）一定的推荐奖励（延长期限或代金券） | 言渊/引擎B主理人 |
| 长搭者离开后 | 检查小院状态，恢复清洁 | 引擎B主理人 |

## 第⑥层 · 能力边界

### 能做

| 事项 | 依据 |
|:---|:---|
| 50个小院的日常维护 | 当前小院数量有限，引擎B主理人每周巡检可行 |
| 长搭者的关系维护 | 非大批量时，引擎B主理人个人关系可覆盖 |
| 长搭者带客的自然接待 | 不需要额外投入，纳入日常运营即可 |

### 不能做（明确放弃）

| 事项 | 原因 |
|:---|:---|
| 保证每个长搭者使用率>12次/年 | 使用率由客户自身的频率决定，农场无法控制。但可以通过主动推送活动信息来提高 |
| 替长搭者管理客人的服务体验 | 客人的体验一半由长搭者决定（他选的地方/他的招待），农场无法代劳 |
| 保证长搭者带客转化为新客户 | 推荐由客户之间的信任完成，农场介入会破坏信任链 |

### 长搭与农场整体业务的关系

```
长搭不是引擎B的"一个产品"，是农场所有业务的"关系锚点"：

  ① 从现金流看：3600元/年×50人=18万/年稳定收入，不依赖天气和季节
  ② 从传播看：每个长搭者是农场的编外推荐员——他带客、他发朋友圈、他介绍
```
