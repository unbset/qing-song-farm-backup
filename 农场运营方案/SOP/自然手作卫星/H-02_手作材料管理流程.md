### 一、材料分类与台账

```
1. 材料分类

   自然材料类（农场自产）
   - 松果、松枝、松针
   - 树叶、花草
   - 木块、竹片、藤条
   - 石头、沙土
   - 种子、果壳

   手作耗材类（外购）
   - 颜料（丙烯/水彩/植物染料）
   - 胶水/热熔胶棒
   - 麻绳/棉线/毛线
   - 蜡/皂基/精油
   - 布料/毛毡
   - 画框/底板

   工具类
   - 热熔胶枪、剪刀、刻刀
   - 锤子、钳子、锯子
   - 画笔、调色盘、印章
   - 磨具、模具
```

### 二、自然材料采集

```
1. 农场自采
   - 核心层种植区：植物标本、落叶、修剪的枝条
   - 松林区：松果、松针、枯枝
   - 收割季：麦秆、玉米皮、玉米芯

2. 采集原则
   - 不破坏生态环境（每棵树的松果采集量≤1/3）
   - 不采集活体植物
   - 采集后及时晾晒/干燥处理

3. 处理标准
   - 松果：晒干→除虫（密封冷冻48小时）→分类
   - 树枝：修剪→晾干→去刺
   - 花草：压制干燥→封存
   - 材料入库前必须做除虫处理
```

### 三、材料入库与储存

```
1. 入库登记
   - 名称/规格/数量
   - 来源（自采/外购/捐赠）
   - 入库日期
   - 储存位置

2. 储存标准
   - 自然材料：阴凉干燥通风，防虫防霉
   - 颜料/胶水：密封常温，远离儿童
   - 工具类：分类挂放，每月检查
   - 易燃材料（蜡/酒精）：远离火源

3. 保质期管理
   - 自然材料：标注采集日期，超过1年清理
   - 颜料：标注开封日期，干结的废弃
   - 胶棒/胶水：标注保质期
```

### 四、材料出库与消耗

```
1. 每次课程出库
   - 根据预约人数准备材料包
   - 每人一份+备用2份
   - 在Hermes记录出库品种和数量

2. 消耗标准
   - 单次课程材料成本控制在课程定价的20%以内
   - 自然材料消耗不计算成本（但记录用量）
   - 工具类损耗按实际损坏记录

3. 回收利用
   - 未使用的材料归库
   - 可回收材料（布料头/纸张）分类回收
   - 不能用的材料做堆肥或丢弃
```

### 五、库存管理

```
1. 安全库存标准

   材料	安全库存量	补货触发线
   松果	200个	≤50个
   热熔胶棒	100根	≤30根
   丙烯颜料（各色）	10瓶/色	≤3瓶
   麻绳	50米	≤10米
   蜡/皂基	5kg	≤2kg
   画框/底板	30个	≤10个

2. 盘点周期
   - 每次课程后：清点剩余材料
   - 每周：全面盘点
   - 每月：损耗分析+补货清单

3. 补货流程
   - 自然材料：核心层采集+运营卫星协助
   - 外购材料：提报采购清单→运营卫星统一采购
   - 大额采购（单次≥500元）报言渊审批
```

### 六、验收标准

```
□ 材料台账完整（入库/出库/库存）
□ 自然材料已除虫处理
□ 材料储存符合标准（阴凉/干燥/安全）
□ 库存量在安全线以上
□ 每次课程出库已记录
□ 每周盘点已完成
□ 损耗率在合理范围内
□ 补货清单已及时提交
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 自然材料发霉/虫蛀 | 废弃处理，追查储存问题 |
| 材料库存不足 | 紧急补货或调整课程方案 |
| 材料品质不合格 | 退货/更换供应商 |
| 工具损坏 | 维修或报废更新 |
| 材料浪费严重（单次损耗率>15%） | 分析原因，优化课程设计 |
| 供应商断货 | 寻找替代材料或替代供应商 |

### 八、跨板块协作

- 自然材料采集：与**核心层**协作（修剪枝条/采收剩余物）
- 材料采购：提报**运营卫星**统一采购
- 废弃材料：可堆肥的送**核心层**堆肥区
- 特殊材料需求（如面包窑用柴）：与**引擎A**协调

### 九、客户触点

- 材料的品质和安全（尤其儿童接触的颜料/胶水）直接影响客户信任
- 自然材料本身是农场的"特色竞争力"——城市里买不到的松果、松枝
- 材料的"故事"（这松果来自哪棵松树）是课程体验的一部分
