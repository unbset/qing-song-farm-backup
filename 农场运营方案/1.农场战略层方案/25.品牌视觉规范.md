# 青松农场品牌视觉规范

> **性质**：品牌视觉设计指导手册
> **适用**：平面设计、空间设计、内容物料、线上传播
> **核心品牌资产**：青松农场、1000+棵松树、生态真实感、正心正事修己及人
> **当前状态**：视觉规范已定稿，Logo及VI应用物料待设计执行
> **编写日期**：2026-06-02

---

## 一、品牌核心

### 1.1 品牌定位（一句话）

> 在城市与自然之间，搭建通往真实生活的桥梁。

### 1.2 品牌调性

| 维度 | 调性定位 | 说明 |
|:---|:---|:---|
| 气质 | **真实、质朴、温暖、有力** | 不是精致田园风，不是网红打卡风，是"真的有在种东西"的真实感 |
| 语言 | **真诚、直接、有温度** | 不说大词、不堆砌、像朋友介绍自家院子一样说话 |
| 视觉 | **自然、克制、有细节** | 色彩来自土地和松林，不过度设计，让素材本身说话 |
| 情绪 | **踏实、放松、治愈** | 不是刺激性的兴奋，是"终于可以喘口气"的松弛 |

### 1.3 品牌关键词

```
松林 · 土地 · 节气 · 真实 · 劳作 · 连接 · 慢 · 生长
```

## 二、Logo设计指引

### 2.1 Logo核心元素

青松农场的Logo应包含以下核心元素（由设计师完成具体设计）：

| 元素                | 必要性 | 设计方向                    |
| :---------------- | :-: | :---------------------- |
| 松树图形              | 必选  | 简洁、有识别度的松树剪影或抽象松形，非写实手绘 |
| "青松农场"文字          | 必选  | 中文名称，字体选择见下方字体规范        |
| "QINGSONG FARM"英文 | 可选  | 辅助识别，字体权重低于中文           |
| slogan            | 可选  | "在自然中，过一段真实日子"（辅助使用）    |

### 2.2 Logo设计原则

1. **不复杂**：松树图形不超过3个层次，能在1cm见方上仍可识别
2. **不网红**：不使用手绘水彩风、ins风、森系等流行风格——农场要的是"能存在10年"的Logo
3. **有辨识度**：即使去掉文字，只看到松树图形就知道是青松农场
4. **单色可用**：Logo必须是单色版本也能完整表达的图形

### 2.3 Logo应用规范

| 应用场景 | Logo版本 | 说明 |
|:---|:---|:---|
| 白色背景 | 彩色标准版 | 松树绿+大地棕 |
| 深色/绿色背景 | 白色反白版 | 单色反白 |
| 印刷小尺寸（<2cm） | 简化版 | 仅保留松树图形+中文名称 |
| 头像/图标 | 松树图形版 | 仅保留松树图形 |

### 2.4 Logo禁用规则

❌ 不要改变Logo颜色
❌ 不要给Logo加阴影或立体效果
❌ 不要在Logo上叠加其他图形
❌ 不要拉伸或压缩Logo比例
❌ 不要将Logo放在复杂背景上

## 三、色彩体系

### 3.1 主色调

| 色块 | 色值 | 命名 | 使用场景 |
|:---|:---|:---|:---|
| ■ | #3A6B35 | **松林绿** | Logo主色、品牌主色、标题文字、重点元素 |
| ■ | #8B7355 | **大地棕** | Logo辅助色、副标题、边框、木质标签 |
| ■ | #F5F0E8 | **米白** | 背景色、纸张色、信息卡片底色 |

松林绿来自农场松针的颜色，大地棕来自土地的颜色，米白来自阳光照在松林地面的颜色。这三种颜色构成了品牌的视觉根基。

### 3.2 辅助色

| 色块 | 色值 | 命名 | 使用场景 |
|:---|:---|:---|:---|
| ■ | #C4A882 | **麦秆黄** | 标签/标注/高亮/季节性点缀 |
| ■ | #D46A4A | **番茄红** | 采摘/餐厅/季节性促销（慎用、小面积） |
| ■ | #5A7A4A | **苔藓绿** | 辅助绿色、板块区分 |
| ■ | #4A6B8C | **天空蓝** | 少数线上用途（头像/图标辅助） |

### 3.3 色彩使用原则

1. 松林绿+大地棕+米白 三种主色覆盖80%以上的视觉面积
2. 辅助色使用面积不超过视觉总面积的15%
3. 番茄红仅用于餐饮和采摘相关场景，不可用于全场通用
4. 不使用荧光色、高饱和色

### 3.4 色彩搭配示例

| 场景 | 背景色 | 文字色 | 点缀色 |
|:---|:---|:---|:---|
| 菜单/宣传单 | 米白 | 松林绿（标题）+ 大地棕（正文） | 番茄红（价格） |
| 展板/指示牌 | 大地棕 | 米白（文字） | 松林绿（图形） |
| 社群海报 | 米白 | 松林绿（标题） | 麦秆黄（活动信息） |
| 小程序/线上 | 米白 | 松林绿 | 松林绿 |

## 四、字体规范

### 4.1 品牌字体（待选择）

品牌字体由设计师根据以下要求选择或设计：

**中文标题字体**
- 要求：有力、不花哨、有手写感的克制
- 方向参考：思源宋体/Noto Serif SC（粗体）/ 或定制书法体
- 禁用：瘦金体、少女体、卡通体

**中文正文字体**
- 要求：清晰、自然、易读
- 方向参考：思源黑体/Noto Sans SC / 阿里巴巴普惠体
- 禁用：宋体（正文太小不易读）

**英文字体**
- 要求：与中文字体协调，不抢戏
- 方向参考：与中文同系品牌无衬线体

### 4.2 排版层级

```
一级标题（品牌标语/大标题）
  字体：品牌标题体
  字号：视使用场景定
  字重：Bold/Heavy

二级标题（板块标题/活动标题）
  字体：品牌标题体或同系字体
  字号：一级标题的60-70%
  字重：SemiBold

正文
  字体：品牌正文字体
  字号：便于阅读的最小尺寸
  字重：Regular

辅助信息（时间/价格/备注）
  字体：品牌正文字体
  字号：正文的80%
  字重：Light/Regular
```

### 4.3 排版原则

1. 标题与正文行距保持1.5-1.8倍
2. 段落间留白＞行距
3. 一行不超过25个字（纸质）/ 不超过15个字（海报）
4. 不堆叠字体样式（不同时使用两种以上字体）

## 五、摄影与图片风格

### 5.1 摄影调性

| 方向 | 要拍 | 不要拍 |
|:---|:---|:---|
| **真实感** | 带着泥的蔬菜、刚摘下的番茄、沾着草屑的鸡蛋 | 精修摆拍、过度调色、滤镜过重 |
| **自然光** | 清晨的阳光穿过松林、傍晚的篝火 | 闪光灯直打、棚拍感 |
| **人物** | 客户在自然状态下的笑、孩子在菜地跑 | 僵硬摆拍、过度引导的"假笑" |
| **季节感** | 春天的嫩芽、夏天的番茄、秋天的落叶、冬天的霜 | 不分季节的千篇一律 |

### 5.2 图片处理原则

1. 色调以暖调为主（不冷、不灰）
2. 饱和度不过度提升（接近肉眼看到的真实色彩）
3. 不过度裁剪（保留环境感）
4. 不添加大面积文字遮挡（文字放在图片留白处）
5. 不加水印（品牌感靠图片本身传递，不靠水印）

### 5.3 必拍的品牌资产画面

这些画面是青松农场的品牌视觉资产，应持续拍摄和积累：

```
● 松林全景（四季各一张标准视角）
● 菜地里的作物（生长中 + 采收时）
● 散养鸡在松林里跑
● 从田地到餐桌的链条（摘→洗→炒→上桌）
● 客户参与劳动（拔萝卜/掰玉米/捡鸡蛋）
● 柴火灶/篝火的烟火气
● 孩子在农场自由跑动的瞬间
● 农场的晨光/晚霞/雨/雪
```

## 六、空间视觉

### 6.1 整体空间调性

1. **"被维护的自然"**——不是野地，也不是花园。能看出有人在打理，但不刻意
2. **材质优先选用自然材质**：木头、石头、麻绳、陶罐、铁艺（不使用塑料感强的装饰）
3. **标识手写化**：价格牌、指引牌、今日推荐等，优先使用手写黑板或木牌，不大量使用印刷品

### 6.2 标识系统

| 标识类型 | 材质 | 字体/样式 | 位置 |
|:---|:---|:---|:---|
| 农场入口招牌 | 木质/石刻 | 品牌Logo+名称 | 主入口 |
| 指引牌 | 木质 | 手写或印刷 | 各路口 |
| 板块标识牌 | 木牌+金属 | 板块名称+简图 | 各板块入口 |
| 菜品/价格牌 | 小黑板/木牌 | 手写粉笔/油漆字 | 引擎A、采摘区 |
| 安全警示牌 | 金属/亚克力 | 红底白字 | 篝火/柴火灶/水域 |
| 劳动换薪小黑板 | 黑板 | 粉笔手写 | 核心区入口 |

### 6.3 空间色彩控制

- 建筑/设施主色：大地棕系（木质）+ 米白（墙面）
- 点缀色：松林绿（标识/装饰）
- 不使用：鲜艳的塑料色（红/蓝/黄塑料棚、彩色遮阳伞等）

## 七、应用场景

### 7.1 印刷物料

| 物料 | 色彩 | 字体 | 要点 |
|:---|:---|:---|:---|
| 菜单 | 米白底+松林绿+大地棕 | 品牌字体 | 简洁，标注食材来源（自产/本地） |
| 名片 | 米白底+松林绿Logo | 品牌字体 | 正面中文+反面英文（如需要） |
| 宣传单页 | 米白底+实拍照片 | 品牌字体 | 照片为主，文字为辅 |
| 包装袋/盒 | 牛皮纸色+松林绿印刷 | 品牌字体 | 极简Logo+名称 |
| 伴手礼标签 | 大地棕或米白 | 品牌字体 | 手写感 |

### 7.2 线上传播

| 平台 | 视觉风格 | 要点 |
|:---|:---|:---|
| 小红书 | 实拍照片+自然色调 | 不加过度滤镜，文字简洁 |
| 微信公众号 | 米白底+松林绿标题 | 图文为主，留白充足 |
| 社群朋友圈 | 实拍为主 | 每天一张农场实拍，不制作海报 |
| 小程序 | 品牌色为主 | 干净简洁，功能优先于设计 |

### 7.3 文创周边（远景）

品牌成熟后可开发的周边产品，均以"真实"和"实用"为导向：

```
● 帆布袋（Logo+松树剪影）——实用
● 种子纸明信片（种下去能长出植物）——有内容
● 节气手帕（印有农场节气日历）——有记忆
● 自制果酱标签（印有Logo的牛皮纸标签）——产品载体
```

不做：冰箱贴、钥匙扣、书签等"为了做周边而做"的无意义产品。

## 八、品牌语调

### 8.1 语言风格

| 场景 | 风格 | 示例 |
|:---|:---|:---|
| 社群日常 | 朋友聊天 | "今天地里番茄熟了，摘了几个，炒了吃，真香" |
| 活动招募 | 真诚邀请 | "周末来掰玉米吧，地里那茬再不来就老了" |
| 客户服务 | 温暖直接 | "这事儿是我们没做好，给你添麻烦了" |
| 品牌宣传 | 克制自信 | "我们不是网红农场，我们真的在种东西" |
| 客户回复 | 尊重亲切 | "张姐，你上次说的那个问题，我们改了" |

### 8.2 禁用词汇

❌ "沉浸式"、"打卡"、"网红"、"仙境"、"绝美"、"必去"
❌ 夸张的营销词汇
❌ 自己给自己贴"有机"、"生态"等标签（让客户自己说）
❌ 过度承诺的表述

## 九、品牌视觉的执行与维护

### 9.1 品牌资产清单

| 资产 | 状态 | 负责人 |
|:---|:---:|:---|
| Logo（标准版/反白版/简化版/图形版） | 待设计 | 设计师 |
| 品牌色卡（Pantone/CMYK/HEX/RGB） | 本文已定义 | — |
| 品牌字体（标题体+正文字体） | 待选定 | 设计师+言渊 |
| 品牌摄影素材库 | 持续积累 | 运营卫星 |
| 品牌物料模板（菜单/名片/海报等） | 待制作 | 设计师 |
| 品牌语调指南 | 本文已定义 | — |

### 9.2 品牌一致性检查

所有对外发布的视觉物料，在发布前应经过以下检查：

```
□ 色彩是否符合品牌色体系
□ 字体是否符合品牌字体规范
□ Logo使用是否符合规范（版本正确/无变形/位置正确）
□ 图片风格是否符合品牌调性（真实/自然光/暖调）
□ 文字语气是否符合品牌语调（真诚/直接/有温度）
□ 整体感觉是否"像一个农场该有的样子"
```

### 9.3 品牌视觉的维护原则

1. **一致性优先于创意**——每一份物料都在为品牌积累认知，不一致就是消耗品牌资产
2. **品牌感觉优先于设计技巧**——设计再好看，如果看起来不像"青松农场"，就是失败的设计
3. **素材说话优先于设计炫技**——一张好的实拍照片远胜于精心设计的合成图
4. **品牌规范不是束缚**——规范是让团队不用每次从零开始思考一套"看起来像青松农场的方案"
