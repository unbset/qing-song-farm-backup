### 一、入住后的主动服务

```
1. 入住后1小时
   - 巡查营位区，确认客户已安顿好
   - 主动上前询问"还有什么需要的吗"
   - 确认帐篷/设备无问题

2. 入住后关键时段服务
   17:00-18:00（傍晚时段）
   - 提醒引擎A晚餐时间和点餐方式
   - 询问是否需要篝火/烧烤预约
   - 提醒夜间温度，建议准备保暖衣物

   20:00-21:00（夜间服务）
   - 巡查营位区灯光/安全
   - 提醒安静时间（22:00后）
   - 询问是否需要热水/充电等
```

### 二、客户服务需求响应

```
1. 常见服务需求及标准响应

   □ 需要额外毯子/枕头
   → 15分钟内送达

   □ 需要充电/电源
   → 指引公共充电区或提供充电宝

   □ 需要热水
   → 指引热水供应点或送热水至营位

   □ 需要炭火/柴火补充
   → 10分钟内送达

   □ 需要清洁营位
   → 30分钟内安排

   □ 需要医疗帮助
   → 第一时间到场，提供急救箱，严重者送医

2. 服务时限标准
   - 紧急需求（医疗/火灾/安全）：5分钟内到场
   - 一般需求（物资补充/清洁）：15分钟内响应
   - 非紧急咨询（活动/周边）：30分钟内回复
```

### 三、公共区域服务

```
1. 卫生间/淋浴间
   - 每2小时巡检一次（记录在Hermes）
   - 卫生纸/洗手液/擦手纸随时补充
   - 淋浴间热水温度稳定（夏季35-40°C/冬季40-45°C）
   - 地面防滑垫在位，无积水

2. 公共洗漱区
   - 热水供应正常
   - 镜子/台面清洁
   - 垃圾桶未满溢

3. 公共休息区
   - 座椅/桌子归位
   - 遮阳伞状态正常
   - 公共读物/桌游整洁
```

### 四、露营氛围营造

```
1. 白天氛围
   - 背景音乐（轻音乐/自然白噪音，音量适中）
   - 营地布置整洁有序
   - 指引标识清晰

2. 傍晚氛围
   - 灯光点亮（营区/步道/公共区域）
   - 篝火台准备就绪（如需）
   - 引擎A晚餐开放提醒

3. 夜间氛围
   - 营区灯光柔和（22:00后调暗）
   - 安静环境维护（提醒喧闹客户）
   - 安全巡查（23:00/1:00各一次）
```

### 五、客户互动与引导

```
1. 服务中的话题引导
   - "今天去摘菜了吗？地里番茄正好熟了"
   - "明早要不要去捡鸡蛋？小朋友都很喜欢"
   - "下周有松林音乐会，感兴趣吗？"

2. 信息传递（非推销式）
   - 告知农场明日活动安排
   - 推荐核心层的采摘体验
   - 推荐自然手作卫星的课程
```

### 六、验收标准

```
□ 客户入住后1小时内已主动问询
□ 服务需求在时限标准内响应
□ 公共区域每2小时巡检并记录
□ 环境和氛围营造到位
□ 客户满意度≥4.5分
□ 未出现24小时未处理的服务请求
□ 客户离场前已传递后续活动信息
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户服务需求超出能力 | 明确告知边界，提供替代方案 |
| 公共区域设施故障 | 立即围挡，张贴提示，报修 |
| 客户醉酒/吵闹 | 劝告→警告→联系同伴/报警 |
| 客户迷路（农场较大） | 指引或陪同送回营位 |
| 客户设备损坏（帐篷/睡袋） | 提供备用设备租赁或替换 |
| 天气突变 | 启动应急预案（转移至庇护所） |

### 八、跨板块协作

- 服务中发现的消费意向（想采摘/想吃饭/想参加活动）即时通知对应板块
- 公共区域问题反馈**运营卫星**纳入巡检清单
- 客户强烈好评记录并反馈给**言渊**

### 九、客户触点

- 露营服务的本质是"让客户在户外过得舒服"，每个服务动作都在传递"你被照顾着"
- 主动服务比被动响应更能创造惊喜感："我还没开口，你就想到了"
- 服务人员的态度比技能更重要——亲切、自然、不打扰
- 夜晚的安全感是露营客户的核心需求，夜间巡查见与不见一样重要
