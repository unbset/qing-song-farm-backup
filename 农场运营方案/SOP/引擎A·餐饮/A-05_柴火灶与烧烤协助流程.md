### 一、使用前准备

```
1. 柴火灶准备
   - 灶台清洁（灰烬清理、灶面擦拭）
   - 柴火准备（干燥木柴，堆放整齐）
   - 点火工具（打火枪/火柴/引火物）
   - 锅具检查（铁锅/砂锅/烤网）是否完好
   - 排烟检查（烟道畅通、排烟正常）

2. 烧烤区准备
   - 烤炉清洁（烤网刷净、残炭清理）
   - 木炭准备（机制碳或果木炭，适量打碎）
   - 点火器/酒精块准备
   - 烧烤工具（夹子/刷子/剪刀/手套）齐全
   - 调料台布置（油/盐/孜然/辣椒/酱料/刷子）

3. 食材准备
   - 已腌制好的肉类（提前30分钟从冷藏取出回温）
   - 已切配好的蔬菜（分类装盘）
   - 蘸料/配菜准备
   - 餐具/一次性手套/湿巾准备
```

### 二、客户到台协助

```
1. 点火协助
   - 为客户点火（或指导客户自行点火）
   - 柴火灶：搭柴架→放引火物→点火→调整通风
   - 烧烤炉：铺设木炭→酒精块助燃→等待炭火均匀

2. 使用指导
   - 柴火灶：火力控制方法（添柴/调整通风口）
   - 烧烤：不同食材的烤制时间和翻烤方法
   - 安全提醒：防烫/防火/儿童看管
```

### 三、使用中服务

```
1. 巡回服务
   - 每15分钟巡查一次
   - 是否需要添柴/加炭
   - 是否需要补充食材/调料
   - 是否需要换烤网（烤网焦糊严重时）

2. 协助需求响应
   - 客户点火失败 → 协助重新点火
   - 火力过猛/过弱 → 协助调整
   - 食材烤焦/不熟 → 指导正确方式
```

### 四、使用后清理

```
1. 火源处理
   - 客户离开后立即处理余火
   - 柴火灶：余烬摊开自然熄灭或用水浇灭
   - 烧烤炉：盖上炉盖隔绝空气灭火
   - 确认无明火后方可离开

2. 场地恢复
   - 烤网/锅具清洗
   - 操作台擦拭消毒
   - 地面清扫（油渍/骨渣/竹签）
   - 剩余食材分类处理（可回收的冷藏/不可回收的丢弃）
   - 垃圾清理

3. 燃料补充
   - 柴火补充至备用标准量
   - 木炭补充至满箱
   - 点火工具归位
```

### 五、燃料管理

```
1. 柴火管理
   - 干燥木柴储备量：不少于5天的使用量
   - 雨天提前遮盖防潮
   - 柴火尺寸：长度30-40cm，直径5-10cm为宜

2. 木炭管理
   - 防潮储存（密封袋或加盖桶）
   - 损耗率控制在15%以内
   - 剩余炭头回收再利用
```

### 六、验收标准

```
□ 使用前柴火灶/烧烤区已清洁，设备完好
□ 燃料储备充足
□ 食材已备好，已提前腌制
□ 点火顺利（客户无需等待超过5分钟）
□ 客户使用过程中无需主动求助
□ 使用后火源已安全处理，无余火
□ 场地已恢复整洁
□ 燃料已补充至标准量
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 柴火潮湿不易点燃 | 使用引火物+小块干柴引火，或切换备用干柴 |
| 排烟不畅 | 检查烟道是否堵塞，调整灶台位置 |
| 客户烫伤/烧伤 | 冷水冲洗15分钟，严重者送医 |
| 烧烤木炭质量差 | 更换供应商，备用不同品牌对比 |
| 客户要求延长使用 | 评估后续预约，有空档可延长（加收费用） |
| 突然下雨 | 启动雨棚/移至可避雨区域 |

### 八、跨板块协作

- 柴火灶/烧烤的食材供应与**A-03备料流程**衔接
- 燃料采购由**运营卫星**统一安排
- 柴火灶使用的蔬菜优先从**核心层**选定品种
- 团建客户使用柴火灶/烧烤与**B-04团建活动**衔接

### 九、客户触点

- 柴火灶和烧烤是农场"自己动手"的体验核心，客户参与感越强、体验越好
- 点火环节是情绪高点，协助但不替代（让客户有"我生着了"的成就感）
- 柴火灶的烟火气和烧烤的香气是天然的"内容素材"，帮客户布置好拍照角度
