[执行人] 引擎A主理人
[替代人] 言渊 / 运营卫星成员（经培训后）
[执行时间] 夏季版 9:00 / 冬季版 9:30，预计耗时40分钟
[适用季节] 全年（分夏冬两版）
[前置条件] 前一日Hermes已确认当日营业；食材供应已确认
[AI接口] Hermes存储开档检查清单和每日食材单；根据天气和预约调整备餐量
[AI提醒] Hermes每日早8:00推送当日菜单、预约人数、食材准备清单

---

### 一、开档前准备

```
1. 查看Hermes当日信息
   - 预约用餐人数（散客/团客）
   - 特殊饮食需求标记
   - 天气情况（影响户外座位安排）
   - 引擎B是否有团建用餐需求

2. 食材验收（与种植养殖主管对接）
   - 确认当日核心层供应的蔬菜/鸡蛋品种和数量
   - 核对Hermes中的食材清单和实际到货
   - 外采食材检查品质和保质期
   - 缺口食材记录并通知外采

3. 环境卫生检查（夏季版/冬季版差异见下方）
```

### 二、夏季版开档检查

```
适用范围：5月-10月（气温25°C以上）

1. 环境检查
   - 室内空调提前30分钟开启，温度设定26°C
   - 户外座位区遮阳伞/遮阳棚已打开
   - 户外座位区蚊虫防控（电蚊香/驱蚊灯）
   - 风扇/冷风机正常运转

2. 食材管理
   - 冷藏柜温度检查（0-4°C）
   - 冷冻柜温度检查（-18°C以下）
   - 易腐食材（肉类/乳制品/叶菜）状态确认
   - 冰块准备充足

3. 设备检查
   - 炉灶点火测试
   - 排烟系统正常运转
   - 饮水机/制冰机状态

4. 物料补充
   - 餐具备足（比预约人数多20%）
   - 纸巾/一次性手套/打包盒
   - 菜单板更新今日推荐
```

### 三、冬季版开档检查

```
适用范围：11月-次年4月（气温25°C以下）

1. 环境检查
   - 室内取暖设备提前30分钟开启
   - 柴火灶/壁炉检查（点火准备）
   - 门窗密封性检查，预防冷风灌入
   - 户外座位区关闭或改为户外篝火锅区域

2. 食材管理
   - 冷藏/冷冻柜温度检查
   - 火锅/柴火灶食材准备（切配）
   - 热饮备料（姜茶/热茶/咖啡）

3. 设备检查
   - 火锅电磁炉/卡式炉数量清点
   - 柴火灶排烟正常
   - 取暖设备安全（一氧化碳报警器检查）

4. 物料补充
   - 火锅餐具/碗碟
   - 冬季菜单板更新
   - 毛毯（备用，户外用餐客户）
```

### 四、通用检查

```
1. 收银准备
   - 验钞机/收款码可用
   - 备用零钱
   - Hermes点餐系统打开

2. 安全通道检查
   - 灭火器位置确认、压力正常
   - 安全出口畅通
   - 急救箱在位

3. 正式开档
   - 以上所有项目确认无误后，在Hermes标记"已开档"
   - 准备就绪迎接客户
```

### 五、验收标准

```
□ 环境温度已调节到位（夏季凉爽/冬季温暖）
□ 当日食材已验收完毕，缺口已处理
□ 设备检查全部正常
□ 餐具和物料充足
□ 安全设备在位有效
□ Hermes已标记开档
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 核心层食材供应不足 | 立即外采，调整菜单标注"今日限量/暂停供应" |
| 设备故障 | 启动备用设备（备用炉/备用冷藏箱） |
| 突然停电 | 启用发电机/使用卡式炉，冷藏食材优先消耗 |
| 恶劣天气 | 切换至室内全封闭模式，取消户外座位 |
| 食材到货品质不合格 | 拍照记录退回，启用备用供应商 |

### 七、跨板块协作

- 每日与**核心层·种植养殖主管**对接食材供应
- 团建用餐提前与**引擎B**确认人数、时间、餐标
- 运营卫星带客户参观结束时，引导客户至引擎A用餐
- 食材缺口通知运营卫星安排外采

### 八、客户触点

- 开档质量决定客户对农场餐饮的"第一印象"
- 夏季注意蚊虫防控，冬季注意取暖体验
- 开档时预留"最佳景观位"给可能到店的散客
