[前置条件] 合作渠道已建立或意向已确认

---

### 一、渠道分类

```
1. 渠道类型

   企业客户类
   - 团建需求企业（IT/金融/教育/制造等行业）
   - 年会/庆典活动企业
   - 员工福利采购企业

   机构合作类
   - 幼儿园/学校（毕业礼/春秋游/自然教育）
   - 培训机构（户外课/亲子活动）
   - 社区组织（社区活动/业主活动）
   - 公益组织（自然教育活动合作）

   平台渠道类
   - 美团/大众点评
   - 小红书/抖音（内容合作）
   - 旅行社/户外俱乐部

   异业合作类
   - 4S店/地产/银行（客户活动合作）
   - 摄影机构（场地合作）
   - 户外品牌（装备展示/体验合作）
```

### 二、渠道拓展

```
1. 新渠道开发流程
   a) 确定目标渠道类型（根据农场当前需求）
   b) 收集目标渠道信息（联系人/规模/需求）
   c) 初步联系（电话/微信/邮件）
   d) 上门拜访或邀请来农场参观
   e) 提供合作方案和报价
   f) 谈判和签约

2. 合作方案模板
   - 合作方式（场地使用/活动定制/分成/推荐返佣）
   - 价格体系（散客价/团队价/年框价）
   - 双方职责（农场提供什么/渠道提供什么）
   - 结算方式（预付/后付/月结）
   - 合作期限
```

### 三、渠道日常维护

```
1. 定期沟通
   - 活跃渠道：每月1次沟通（电话/微信/面谈）
   - 休眠渠道：每季度1次激活沟通
   - 重点渠道（月流水≥5000元）：双周沟通

2. 沟通内容
   - 农场新活动和项目推送
   - 合作数据反馈（送客量/转化率/客户评价）
   - 客户反馈和建议传递
   - 问题协调和处理

3. 渠道支持
   - 提供宣传素材（照片/视频/文案）
   - 合作方来访优先接待
   - 渠道推荐客户到店提供专属服务
   - 联合活动支持（物料/场地/人员）
```

### 四、渠道数据分析

```
1. 月度统计
   - 各渠道送客量
   - 各渠道转化率（送客→实际消费）
   - 各渠道贡献收入
   - 各渠道客户满意度

2. 渠道评级

   A级渠道（月均送客≥50人/月收入≥5000元）
   - 重点维护，专人对接
   - 优先提供优质资源和优惠

   B级渠道（月均送客10-49人/月收入1000-5000元）
   - 常规维护
   - 定期推送活动和优惠

   C级渠道（月均送客<10人/月收入<1000元）
   - 季度触达
   - 观察是否需要终止合作

3. 成本收益分析
   - 渠道佣金/分账成本
   - 渠道维护人力成本
   - 渠道净利润率
```

### 五、渠道结算

```
1. 结算方式
   - 按人头结算：每月初统计上月送客量
   - 按消费金额分成：每月初核算分成比例
   - 年框合作：按合同约定周期性结算

2. 结算流程
   - 每月5日前：汇总上月合作数据
   - 每月10日前：生成结算单并发给渠道确认
   - 每月15日前：完成结算支付

3. 结算记录
   - 所有结算在Hermes中记录
   - 结算凭证存档
```

### 六、渠道终止

```
1. 终止条件
   - 渠道连续3个月无送客
   - 渠道严重违约（虚假宣传/损害农场声誉）
   - 渠道经营异常（倒闭/转让）
   - 农场经营战略调整

2. 终止流程
   - 提前30天书面通知
   - 完成未结算款项
   - 回收合作物料/宣传素材
   - 在Hermes中标记渠道状态
```

### 七、验收标准

```
□ 渠道档案完整（基本信息/合作协议/结算记录）
□ 活跃渠道月度沟通覆盖100%
□ 渠道数据月度统计完成
□ 结算按期完成
□ 渠道送客量月度报告已生成
□ 客户满意度回访渠道推荐客户
□ 休眠渠道季度激活沟通完成
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 渠道投诉客户体验差 | 了解情况，改进服务，安抚渠道 |
| 渠道拖欠结算 | 催款→暂停合作→终止合作 |
| 渠道虚假宣传 | 要求立即改正，严重者终止合作 |
| 渠道推荐客户质量差 | 沟通反馈，调整合作方式 |
| 渠道间冲突（同一客户被多个渠道推荐） | 以首次推荐渠道为准 |

### 九、跨板块协作

- 渠道推荐的团建客户：与**引擎B**对接团建方案
- 渠道推荐的散客：各板块正常接待，标注渠道来源
- 渠道合作活动：与**O-07活动排期**协调
- 渠道推广素材：与**O-06社群运营**共享内容

### 十、客户触点

- 渠道是农场的"外部销售团队"，维护渠道关系就是维护收入来源
- 渠道推荐客户的体验直接影响渠道的合作意愿
- 渠道客户的到店体验不因"是渠道来的"就打折扣——他们也是客户
