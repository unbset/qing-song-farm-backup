[SOP编号] G-02
[SOP名称] 晨会制度
[执行人] 言渊（主持）/ 运营卫星成员（记录）
[替代人] 引擎A主理人（言渊缺席时代理主持）
[执行时间] 每日 8:30-8:50（夏季）/ 9:00-9:20（冬季）
[适用季节] 全年
[前置条件] 无（晨会是每日固定制度，无休日也需进行）
[AI接口] Hermes生成晨会摘要模板，自动录入会议记录；同步当日各板块待办事项
[AI提醒] Hermes在晨会前推送今日重点事项、天气预警、预约提醒

---

### 一、晨会准备（会前5分钟）

```
1. 言渊准备内容
   - 查看Hermes推送的今日重点事项
   - 查看当日预约情况和特殊活动安排
   - 梳理前一日未完成事项

2. 各板块负责人准备
   - 前一日工作总结（一句话）
   - 今日工作重点（一句话）
   - 需要协调的事项
```

### 二、晨会流程（15-20分钟）

```
1. 开场（1分钟）
   言渊简短开场

2. 信息同步（5分钟）
   - 今日预约情况（引擎A用餐/引擎B入住/参观/团建）
   - 今日天气和注意事项
   - 特殊活动提醒

3. 各板块汇报（5分钟）

   核心层·种植养殖主管
   一句话总结前日工作 + 今日重点 + 需要支持

   引擎A主理人
   一句话总结前日工作 + 今日食材情况 + 预约情况

   引擎B主理人
   今日入住/退房情况 + 营位状态

   运营卫星成员
   前日巡检问题反馈 + 今日客户接待计划

   自然手作卫星（若有重点事项）
   今日课程安排

4. 协调事项（3分钟）
   - 跨板块协作需求
   - 人力调配
   - 物资补充

5. 结束（1分钟）
   - 言渊总结今日关键词（一句话）
   - 散会
```

### 三、晨会记录

```
1. 记录内容
   - 参会人员
   - 各板块汇报要点
   - 协调事项和处理方案
   - 待跟进事项和责任人

2. 记录方式
   - 运营卫星成员在Hermes中记录
   - 晨会结束后即时发布至团队群
   - 待跟进事项标记在Hermes中并推送提醒
```

### 四、晨会纪律

```
1. 参会要求
   - 全员参加（除非轮休/病假/紧急情况）
   - 准时到场（迟到者说明原因）
   - 手机静音

2. 发言要求
   - 限时发言（每人不超过2分钟）
   - 简短、具体、可执行
   - 不讨论与当日工作无关的话题

3. 缺席处理
   - 缺席者需提前告知言渊
   - 缺席者当日查看晨会记录
```

### 五、晨会质量评估

```
1. 晨会是否准时开始和结束
2. 各板块信息是否有效传递
3. 协调事项是否明确责任人和时限
4. 前一日待办事项是否跟进
```

### 六、验收标准

```
□ 晨会准时开始（迟到≤2分钟视为准时）
□ 各板块负责人到场或请假
□ 信息同步完成（预约/天气/活动）
□ 协调事项已明确责任人和完成时限
□ 晨会记录已发布至团队群
□ 前一日待办事项已跟进
□ 晨会总时长≤20分钟
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 言渊缺席 | 引擎A主理人代理主持 |
| 多人缺席 | 线上晨会（群消息或语音） |
| 无重要事项 | 缩短至5分钟，快速同步即可 |
| 出现紧急情况 | 优先处理紧急情况，晨会延后或取消 |
| 晨会讨论时间超长 | 线下单独讨论，不占用晨会时间 |
| 周末/节假日 | 缩减为3分钟群消息同步，不召集会议 |

### 八、跨板块协作

- 晨会是跨板块信息同步的唯一固定时间，再忙也需参加
- 各板块的协作需求在晨会上提出，言渊即时协调
- 客户问题和投诉在晨会上通报，推动改进

### 九、客户触点

- 晨会不直接接触客户，但晨会的质量决定了团队一天的工作节奏
- 晨会中清晰的分工让各板块负责人带着明确的目标工作，这种状态最终传递给客户
- 客户体验的顺畅度，很大程度上取决于晨会上信息是否同步到位
