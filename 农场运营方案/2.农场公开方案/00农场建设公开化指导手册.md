## 前言：这是一份什么文档

言渊写了几万字的农场运营方案——从核心层的种养计划，到引擎A的餐饮产品设计，到引擎B的露营住宿、自然手作卫星、运营卫星，再到前面完成的公开化方案总册和五个分册。

方案很完整，但有一个问题：**如果团队的每个人不真正理解"公开化"这三个字到底意味着什么，方案写得再好也落不了地。**

这份指导手册就是为此写的。它不告诉你"哪天做什么活动"（那是分册的事），它回答的是更根本的问题：

- **我们为什么要花精力把农场"公开"给客人看？**
- **这对农场意味着什么？对客人意味着什么？对我自己意味着什么？**
- **公开化跟我每天干的活有什么关系？**
- **我该怎么看待"干着活还要给客人讲解"这件事？**

如果你是新来的同事，建议你先读这一份，再读总册和各分册。如果你是老同事，这份文档也许能帮你把之前零散的感受串起来，变成一个更清晰的理解。

## 第一章：公开化的意义——我们为什么要做这件事

### 1.1 公开化不是"搞活动"，是"还原真实"

青松农场不是一个"景区"，也不是一个"游乐园"。它是一个**真实的农场**——有土地、有作物、有动物、有四季更替、有丰年也有欠收。

但真实的农场，在传统经营模式下，客人是看不到的。

客人来农场，只看到端上桌的菜，看不到菜是怎么种的；只看到树上挂的果，看不到果树全年怎么养护的；只闻到面包的香气，看不到面团在窑炉里膨胀的过程；只坐在木平台上喝咖啡，看不到平台是怎么一块一块搭起来的。

**公开化的第一个意义，就是打破这个"只看到结果，看不到过程"的隔阂。**

让客人看到菜的来源，他会吃得更放心。
让客人看到木头变成了平台，他会坐得更珍惜。
让客人看到面包在窑炉里膨胀，他会觉得这个面包更好吃。
让客人看到鸡在松林里跑着长大，他会觉得这个蛋更有价值。

这不是什么营销技巧。这就是**把真实还原给客人**。

### 1.2 公开化是农场最大的"差异化"

在潍坊，甚至在全国，做农家乐、采摘园、亲子农场的太多了。如果你问客人"青松农场跟别的农场有什么区别"，以前的答案可能是"我们有1000棵松树"、"我们有面包窑"、"我们有露营"——这些别人都能复制。

但**公开化是别人很难复制的**。

因为公开化不是一次性投入，不是买一套设备、建一个设施，而是一种**经营哲学**——它要求农场把"本来关起门做的事"打开给客人看。这需要信任，需要勇气，需要对"公开"这件事有真正的信仰。

一家愿意把堆肥过程开放给客人看的农场，和一家只把最美的一面包装好给客人看的农场，客户感受到的完全是两种东西：

| 传统农场 | 青松农场（公开化后） |
|:---|:---|
| "这是我们的有机菜" | "这是你看着种出来的菜" |
| "这是我们的柴火面包" | "这是你看着在窑炉里烤出来的面包" |
| "这是我们的露营地" | "这是你看着搭起来的露营地" |
| "我们有1000棵松树" | "这棵松树是认领给你的" |
| "我们的食材很新鲜" | "这是早上你捡的蛋" |

**公开化带来的信任，是广告费买不来的。**

### 1.3 公开化是把"成本"变成"资产"

农场有很多"必须做的事"——这些事很真实，但从经营角度看，它们是成本。

育苗是成本。堆肥是成本。除草是成本。搭架是成本。喂鸡是成本。打扫鸡舍是成本。修木平台是成本。备菜是成本。

这些事不做不行，做了又不产生直接收入。传统农场的做法是：关起门来赶紧干完，不让客人看到"脏活累活"。

**公开化的第三个意义，就是把这些"成本"变成"资产"。**

育苗 -> 变成一堂"从种子到幼苗"的自然课 -> 客人付费参加 -> 成本变收入
堆肥 -> 变成一堂"厨余变黑金"的堆肥课 -> 客人付费参加 -> 成本变收入
搭架 -> 变成"一起来给豆角搭架子"的共建活动 -> 客人获得归属感 -> 成本变关系资产
喂鸡 -> 变成"来帮我喂鸡"的劳动换薪 -> 客人获得参与感 -> 成本变体验资产
修木平台 -> 变成"一起建一个观景平台"的共建活动 -> 客人留下名字 -> 成本变品牌资产

**不是所有成本都能变成资产，但农场里大多数"必须做的事"，都有变成资产的潜力。公开化就是那个转化的阀门。**

### 1.4 公开化是农场的"透明度红利"

现在的消费者，特别是城市里的中产家庭，对"食品来源"和"生产方式"的关心程度前所未有。他们愿意花更多的钱，买"看得见"的东西。

公开化就是"看得见"。

当客人看到你的鸡是在松林里散养的，不是关在笼子里的，他愿意为这个蛋付2块钱而不是5毛钱。
当客人看到你的蔬菜是在堆肥改良的土壤里长出来的，不是化肥催出来的，他愿意为这把菜付更高的价格。
当客人看到你的面包是在柴火窑里用手工揉出来的，不是冷冻面团烤的，他愿意等40分钟而不是去便利店买一个。

**公开化不是额外的工作，而是让你的"好"被看见的手段。**

## 第二章：公开化的重要性——不做会怎样，做了会怎样

### 2.1 如果不做公开化

很多农场从开业到倒闭，只用了两年时间。它们不是不努力，也不是东西不好吃，而是死在了同一个问题上：

**客户没有粘性。**

客户来了，吃一顿，走了。下次去哪里吃？不知道，可能是你家，也可能是隔壁新开的那家。农场的餐饮、采摘、住宿，本质上都是在跟全潍坊的同行竞争——你做红烧肉，别人也做。你种草莓，别人也种。你搞露营，别人也搞。

如果不做公开化，青松农场面临的困境：

| 维度 | 不做公开化的情况 |
|:---|:---|
| 客户关系 | 交易关系——我来吃饭，你收钱，吃完走人，下次不一定来 |
| 定价能力 | 受限于市场均价，因为客户无法感知你的产品为什么值这个价 |
| 传播能力 | 靠广告、靠推广、靠烧钱——成本高、效果差 |
| 防御能力 | 同行复制你的产品很容易，你没有护城河 |
| 抗风险能力 | 疫情/淡季/竞争加剧时，客人说走就走，没有任何绑定 |
| 团队状态 | 员工每天重复劳动，感受不到工作的意义和价值 |

### 2.2 如果做了公开化

| 维度 | 做了公开化的情况 |
|:---|:---|
| 客户关系 | 情感关系——"我在那里有一块菜地/一棵树/搭过一个平台" |
| 定价能力 | 客户愿意为"看得见的过程"支付溢价，因为信任已经建立 |
| 传播能力 | 每个参与过活动的客人都是自发传播者——低成本、高信任 |
| 防御能力 | 公开化是一种经营哲学，不是买设备——同行可以抄产品，抄不了信任 |
| 抗风险能力 | 会员体系+认领体系+共建体系——客人跟农场有"财产关系" |
| 团队状态 | 员工的工作从"干活"变成"边干边讲"，有意义感、有成就感 |

### 2.3 公开化对农场各板块的具体重要性

**对核心层（生态种养）**：核心层是农场最"后台"的板块，也是最难被客人感知的板块。不公开化，客人只看到"端上桌的菜"，不知道菜是怎么来的。公开化后，核心层从"成本中心"变成"信任中心"——客人因为看到了种养过程，对农场所有产品都产生了信任。

**对引擎A（餐饮）**：餐饮是农场最直接的收入来源。不公开化，引擎A跟外面餐厅没有本质区别。公开化后，引擎A从"餐厅"变成"剧场"——面包窑是舞台，厨师是演员，客人是观众也是参与者。一顿饭不只是"吃饱"，而是"看了一场关于食物的演出"。

**对引擎B（露营住宿）**：露营住宿的核心竞争力是"氛围感"。不公开化，引擎B只是提供床位。公开化后，引擎B从"住宿"变成"归属"——客人参与搭建的平台、认领的松树、共建的篝火台，让他觉得"这个地方有我的一份"。

**对自然手作卫星**：手作本身已经是课程化产品。不公开化（这里的公开化指"后台透明化"），手作课就是"老师教、学生做"的标准模式。公开化后，客人知道这个手作材料是农场自己种的、自己收的、自己晾晒的——手作的体验深度完全不同。

**对运营卫星**：运营卫星是公开化的"总导演"。不公开化，运营卫星只是"发朋友圈的小编"。公开化后，运营卫星是"把农场的故事讲给大家听的人"——这是一个有创造力、有成就感的位置。

## 第三章：公开化与运营方案的衔接——它不是额外的，它就是运营本身

### 3.1 常见的误解

很多农场在做公开化的时候，第一反应是："我先把农场做好，再考虑公开化。"

这句话听起来有道理，但这是个陷阱。

**"把农场做好"和"公开化"不是先后关系，而是同一件事的两个面。**

种植养殖方案告诉你：什么季节种什么、养什么、怎么管。
餐饮产品方案告诉你：设计什么菜品、怎么定价、怎么出餐。
露营住宿方案告诉你：怎么布置营位、怎么接待过夜客人。
手作课程方案告诉你：做什么手作、收多少钱、怎么教。
运营方案告诉你：怎么招人、怎么排班、怎么算账。

**公开化方案告诉你：这些事情怎么让客人看到、参与、记住。**

所以公开化不是附加在运营方案之上的"额外工作"，而是**嵌入到每一个运营环节中的视角**。

### 3.2 公开化与各运营方案的关系

```
                    ┌─────────────────────┐
                    │   农场整体运营方案    │
                    │（种什么/做什么/怎么卖）│
                    └──────────┬──────────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                ▼                ▼
      ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
      │  种养方案决定  │ │  餐饮方案决定  │ │  住宿方案决定  │
      │  "要种什么"   │ │  "要做什么菜"  │ │  "要搭什么设施"│
      └──────┬───────┘ └──────┬───────┘ └──────┬───────┘
             │                 │                 │
             └─────────┬───────┴───────┬─────────┘
                       ▼               ▼
              ┌───────────────────────────────────┐
              │          公开化方案回答：            │
              │  "这些事怎么让客人看到/参与/记住"    │
              └───────────────────────────────────┘
```

具体来说：

| 运营方案中的工作 | 公开化视角 | 公开化后的呈现 |
|:---|:---|:---|
| 育苗（核心层） | "这个过程有知识含量，客人会想学" | 育苗课堂（课程化） |
| 搭架（核心层） | "这个需要多人协作，客人可以一起干" | 搭架共建（共建化） |
| 喂鸡（核心层） | "这个简单好玩，客人顺便就能做" | 喂鸡劳动换薪（劳动换薪） |
| 面包烘焙（引擎A） | "面包膨胀的过程最有画面感" | 面包出炉时刻开放（课程化） |
| 大席备菜（引擎A） | "备菜过程有仪式感" | 柴火灶开放日（课程化） |
| 木平台建造（引擎B） | "建好之后可以刻名字" | 共建木平台（共建化） |
| 松树养护（引擎B） | "每棵树都可以有主人" | 认领松树（认领化） |

**核心逻辑**：运营方案决定了"我们要做什么"，公开化方案决定了"这些事怎么跟客人产生关系"。两者是咬合的关系，不是附加的关系。

### 3.3 公开化在农场整体节奏中的位置

按照青松农场的整体规划，运营节奏分为三个层面：

```
日常运营（每天）
  ├── 种养工作：浇水/喂鸡/采收（核心层做）
  ├── 餐饮服务：接单/出餐/服务（引擎A做）
  ├── 住宿接待：入住/退房/维护（引擎B做）
  ├── 手作课程：接课/授课/收尾（自然手作做）
  └── 公开化融入：拍一段视频/写一条朋友圈/放一块小黑板（每人顺手做）
```

```
主题活动（每周/每月）
  ├── 课程化活动（按课表执行）
  ├── 共建化活动（按项目执行）
  ├── 劳动换薪（小黑板每日更新）
  ├── 认领化产品（长期在线）
  └── 跨板块联动大事件（每月一次）
```

```
品牌建设（持续）
  ├── 公开化内容的持续产出（运营卫星）
  ├── 客户自发传播的管理（运营卫星）
  ├── 认领人/共建人的关系维护（全团队）
  └── 公开化效果的季度复盘（言渊+全团队）
```

**公开化不是"额外加的一层"，而是"嵌入每一层的一根线"。** 它不需要单独的时间、单独的人手、单独的预算——它只需要在做每一件事的时候，多问一句：**"这件事，客人能看到吗？能参与吗？能记住吗？"**

## 第四章：农场内部人员应如何认识公开化

### 4.1 对不同角色的意义

#### 对言渊（农场主）

公开化是你把农场从"一个人的理想"变成"一群人的共同记忆"的方式。

你投入了四年、几百万，种了1000棵松树，建了面包窑，搭了木平台。这些东西现在是你一个人的。但如果通过公开化，100个、300个、1000个人在这些树上挂过认领牌、在窑炉里烤过面包、在平台上坐过喝茶——那农场就不再是你一个人的农场，而是"我们的农场"。

**公开化是农场从"个人资产"走向"公共记忆"的桥梁。**

#### 对种植养殖主管

你的工作不是"干活"，是"带着客人干活"。

传统农场的种植养殖主管，每天的工作就是种地、养殖、除草、施肥。你做得再好，客人也不知道你是谁。

但在公开化的农场里，你是"老师"——堆肥课是你来讲的、育苗课是你来教的、搭架子是你带着客人一起干的。客人在农场学到的知识，是你给的。客人带回家的那袋堆肥，是你带着他翻的。

**你的价值从"把菜种好"升级为"让客人知道菜是怎么种好的"。**

这不是增加你的工作量，而是让你的工作有了新的意义：你不只是在种菜，你在帮城市里的人重新认识食物的来源。

#### 对引擎A主理人（餐饮负责人）

你的厨房不只是厨房，是剧场。

传统餐厅的厨房是"后场"，客人不能进。但在公开化的农场，厨房是"前台"的一部分。面包窑的火焰、柴火灶的香气、面团膨胀的过程——这些都是"演出"。

客人来农场吃饭，不只是为了吃饱，是为了"看一顿饭是怎么做出来的"。你的工作从"做出好吃的饭"升级为"做出好吃的饭+让客人看到这个好吃的饭是怎么做出来的"。

**你从一个厨师，变成一个"食物故事的讲述者"。**

#### 对引擎B主理人（露营住宿负责人）

你的营地不只是过夜的地方，是"归属感"的载体。

传统营地的客人来了、睡了、走了。他们不会记得营地长什么样。但在公开化的农场，你带着客人一起搭营位、一起布置篝火台、一起挂灯串——这些事做完，营地就不只是你的工作了，也是客人的作品。

下次他再来，会说"这个篝火台是我搭的"、"这棵树是我家的"。

**你的工作从"管好营地"升级为"让客人觉得营地有他的一份"。**

#### 对自然手作主理人

你的课程已经是很成熟的公开化产品。但公开化可以更进一步：不只是"教客人做手作"，而是让客人知道手作材料的来源。

这个松塔是你在松林里捡的。这个干花是你种的。这个树枝是你修剪果树时剪下来的。

**你的课程从"教手艺"升级为"带客人认识农场的四季"。**

#### 对运营卫星

你是公开化的"总导演"和"传声筒"。

你的工作不是"发朋友圈"，而是"把农场的故事讲好"。你发现哪些工作有公开化的潜力 -> 你帮各板块主理人设计互动模式 -> 你写招募文案 -> 你活动现场拍照录像 -> 你把素材做成内容发出去 -> 你统计效果 -> 你帮团队复盘。

5个板块的所有公开化项目，靠你一个人推。你不是"小编"，你是**农场的首席故事官**。

**你的工作从"做内容"升级为"让农场的内容自己有生命力"。**

### 4.2 全员共识：公开化的五个基本认知

#### 认知一：公开化不是"服务客人"，是"分享真实"

不需要刻意讨好客人，不需要把农场包装成"完美目的地"。农场的魅力就在于它的真实——鸡会叫、土会脏、苗会长虫、面包会烤焦。

**不要因为"不完美"就不敢公开，恰恰是"不完美"让农场更真实、更可信。**

#### 认知二：公开化不是"额外工作"，是"换一种方式做原来的工作"

你本来就要喂鸡。公开化只是把"默默喂鸡"变成"边喂鸡边跟客人聊两句"。
你本来就要烤面包。公开化只是把"烤好端出来"变成"让客人看到面团进去、面包出来"。
你本来就要搭平台。公开化只是把"一个人搭"变成"带着客人一起搭"。

**活还是那些活，但做活的方式多了一根线——"分享"。**

#### 认知三：公开化不是"一次性的"，是"持续的习惯"

不是搞一次大活动就叫公开化了。公开化是一种日常——每天的小黑板上写着"今日可帮忙"，每次面包出炉时拍30秒视频发朋友圈，每堂手作课时顺便说一下"这个材料是上周在松林里捡的"。

**公开化不是"做活动"，是"换一种方式过日子"。**

#### 认知四：公开化不是"运营卫星一个人的事"，是"全团队的事"

运营卫星是总导演，但演员是每个板块的主理人。种菜的看到客人有兴趣，顺口说一句"要不要试试"——这就是公开化。烤面包的看到客人盯着炉子看，顺口说一句"刚放进去，40分钟后出炉"——这就是公开化。

**每个人都有公开化的机会，每个人都可以替农场讲故事。**

#### 认知五：公开化的底线是"不影响生产"

公开化的优先级永远低于正常生产。农忙的时候、人手不够的时候、天气不好的时候——不公开化也没关系。种好地、养好鸡、做好饭，永远排在第一位。

**公开化是"锦上添花"，不是"雪中送炭"。先保证农场活着，再考虑怎么让客人参与。**

### 4.3 新员工入职的公开化认知培训

每位新员工入职第一周，需要完成以下三项：

1. **读这份指导手册**（1小时）
   - 理解公开化的意义和重要性
   - 了解自己在公开化中的角色

2. **观摩一次公开化活动**（根据当周安排）
   - 看一次课程化/共建化/劳动换薪的完整流程
   - 结束后跟运营卫星聊15分钟"你觉得这个活动哪里做得好、哪里可以改进"

3. **完成一次"最小的公开化动作"**
   - 比如：拍一段自己工作的10秒视频 -> 发给运营卫星 -> 运营卫星发到社群
   - 比如：在劳动换薪小黑板上写一条今天可以帮忙的工作
   - 比如：在接待客人时说一次"这个菜是今天早上刚从地里摘的"

**目的是让新员工在第一周就体验到：公开化不是一件"大事"，而是工作中随时可以做的事情。**

## 第五章：常见认知误区与纠偏

### 误区一："公开化就是搞活动"

**纠正**：活动只是公开化的一种形式。公开化的核心是"让客人看到、参与、记住"。活动是手段，不是目的。喂鸡时让客人顺手帮忙也是公开化，面包出炉时喊客人看一眼也是公开化。不是非要搞一个"课程"才算公开化。

### 误区二："公开化会降低生产效率"

**纠正**：只有没设计好的公开化才会降低效率。好的公开化设计，是把"客人参与"嵌入到"正常工作流程"中。喂鸡的过程中让客人帮忙撒一把粮食，不需要额外的时间。烤面包的过程中让客人看一眼面包膨胀的过程，不需要额外的操作。关键是**找到"正常工作的间隙"，把公开化塞进去**。

### 误区三："只有好玩的工作才能公开化"

**纠正**：不好玩的工作，换个角度就可能变得好玩。堆肥听起来不好玩，但"厨余变成黑色的、闻起来像森林的土壤"就很好玩。除草不好玩，但"跟客人比赛谁拔得快"就变得好玩。关键是**给工作找到一个"有趣的角度"**。

### 误区四："公开化会让客人觉得我们在让他干活"

**纠正**：前提是"让他觉得是在帮忙还是在被剥削"的分界线——**他有没有选择权**。劳动换薪的核心是"你帮我干这个活，我给你钱/代金券"。客人可以选择干或不干，干了就有回报。这不是剥削，这是交换。课程化的核心是"你有兴趣，我教你，你交学费"。客人付了钱学东西，跟去健身房上私教课是一个逻辑。

### 误区五："公开化做了就行，不需要记录"

**纠正**：不做记录的公开化，做了一年也不知道什么有效、什么无效。每场活动记录数据、每月汇总复盘、每季度深度评估——这是公开化"从凭感觉做变成有意识做"的关键。

### 误区六："公开化就是发朋友圈"

**纠正**：发朋友圈只是传播。公开化包括三个层面：**公开**（让客人看到）-> **参与**（让客人生手）-> **记住**（让客人带走回忆/成果/归属）。发朋友圈只是"公开"层面的事情。如果只发朋友圈不设计参与环节，那就是"云公开化"，不是真正的公开化。

### 误区七："客人不感兴趣怎么办"

**纠正**：客人的兴趣是培养出来的。今天他只看了一眼，明天他可能问一句，后天他可能想试试。不要因为"现在没人感兴趣"就不做，要因为"持续做下去总会有人感兴趣"而坚持做。

## 结语

公开化不是一套流程，不是一本手册，不是一堆模板。

**公开化是一种选择——选择让你的农场不只属于你，也属于每一个来过的人。**

你站在这块120亩的土地上，面对的不是"要不要公开化"的问题，而是"我打算把这份真实分享给多少人"的问题。

每棵松树都可以有一个认领它的人。
每块菜地都可以有一个惦记它的人。
每个面包都可以有一个看着它烤出来的人。
每个平台都可以有一个搭过它的人。

**农场建设公开化，不是把农场"交给别人"，而是让更多人"跟农场有了关系"。**

当你离开农场的那一天，你留下的不只是一个经营实体，而是一群人对一块土地的共同记忆。

这就是公开化的全部意义。
