[SOP编号] G-03
[SOP名称] 客户信息管理流程
[执行人] 运营卫星成员（信息录入与维护）
[替代人] 言渊
[执行时间] 客户到店后24小时内录入 / 每月清理1次
[适用季节] 全年
[前置条件] 客户已到店消费，已获取客户授权（入群/注册即视为同意）
[AI接口] Hermes是客户信息管理核心系统；记录消费记录/偏好/标签/互动记录
[AI提醒] Hermes推送客户生日提醒、沉睡客户唤醒提醒、客户消费习惯变化预警

---

### 一、客户信息来源

```
1. 客户信息来源渠道

   □ 到店消费
   → 引擎A用餐登记 / 引擎B入住登记 / 采摘消费记录

   □ 社群加入
   → 微信/企微自动采集

   □ 线上预约
   → 小程序/美团/大众点评预约记录

   □ B端合作推荐
   → 企业/机构组织的活动参与名单

   □ 公开化平台注册
   → 认领人/共建人登记信息

2. 信息采集授权
   - 所有信息采集前告知客户用途
   - 社群加入视为同意基础信息存储
   - 不采集与经营无关的个人隐私信息
```

### 二、客户信息录入

```
1. 基础信息（必填）
   - 姓名/昵称
   - 手机号（用于到店核销和活动通知）
   - 来源渠道（首次消费渠道）
   - 首次到店日期

2. 消费信息（自动录入）
   - 消费日期、金额、项目
   - 用餐偏好（火锅/烧烤/柴火灶/简餐）
   - 露营偏好（自带装备/租赁/长搭）
   - 采摘和体验参与记录

3. 标签信息（运营卫星标注）

   人群标签
   - 亲子家庭 / 情侣 / 朋友聚会 / 独自
   - 企业团建 / 机构合作 / B端渠道

   兴趣标签
   - 美食爱好者 / 露营发烧友 / 自然教育 / 手作达人
   - 内容创作者 / 拍照打卡型 / 深度体验型

   价值标签
   - 高消费（年≥3000元）/ 中消费 / 潜力客户
   - 高频次（月≥2次）/ 中频次 / 低频次
   - 传播者（经常分享推荐）/ 沉默者
```

### 三、客户信息更新

```
1. 每次到店更新
   - 消费记录自动更新
   - 运营卫星手动补充互动记录
   - 标签更新（客户消费行为和兴趣变化）

2. 定期回访更新
   - 沉睡客户（30天未到店）：回访后更新状态
   - 流失客户（90天未到店）：标记原因

3. 信息修正
   - 客户主动更正的信息24小时内更新
   - 发现信息错误即时修正
```

### 四、客户信息使用

```
1. 到店接待
   - 客户预约时查看历史记录和偏好
   - 老客户到店时能叫出名字（提前准备）
   - 根据历史消费推荐新内容

2. 营销推送
   - 根据客户标签推送精准活动信息
   - 不群发式骚扰，每条推送有针对性
   - 推送频率：会员群每日1条/私信每周≤1条

3. 服务改进
   - 分析客户消费数据，发现趋势和问题
   - 客户流失预警即时跟进
```

### 五、客户隐私保护

```
1. 存储安全
   - 客户信息仅存储在Hermes系统中
   - 不导出至个人电脑/手机
   - 不外传客户信息给第三方

2. 使用边界
   - 客户信息仅用于农场经营和服务
   - 不做与经营无关的分析
   - 不用于广告投放（未经客户同意）

3. 退出机制
   - 客户随时可要求删除个人信息
   - 退出申请24小时内处理
   - 客户退出后不再发送任何信息
```

### 六、信息清理与维护

```
1. 月度清理
   - 重复信息合并
   - 无效信息删除（空号/错号标记2次以上）
   - 标签修正

2. 季度分析
   - 客户结构分析（人群/兴趣/价值分布）
   - 新客增长率和老客流失率
   - 客户生命周期分析

3. 年度归档
   - 年度消费报告（每个客户年度总结）
   - 客户增长趋势和市场变化分析
   - 客户管理策略调整建议
```

### 七、验收标准

```
□ 新客户信息到店后24小时内完成录入
□ 客户信息完整（基础信息+标签+消费记录）
□ 每次到店消费记录已更新
□ 客户标签准确，每月清理无效信息
□ 沉睡/流失客户定期回访并更新状态
□ 客户隐私保护措施到位（无外泄事件）
□ 月度清理已完成
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户信息重复 | 合并为主记录，保留消费汇总 |
| 客户投诉信息被滥用 | 立即删除该客户信息，致歉 |
| 信息录入错误 | 发现后24小时内修正 |
| 系统故障导致信息丢失 | 启用备份恢复（Hermes每日自动备份） |
| 客户要求删除信息 | 24小时内删除并确认 |

### 九、跨板块协作

- 各板块在客户到店时补充信息至运营卫星
- 引擎A和引擎B的消费记录自动同步至Hermes客户档案
- 客户标签信息用于各板块服务时参考（提前了解客户偏好）
- 客户信息用于**O-06社群运营**的精准推送

### 十、客户触点

- 客户信息管理的目标是"让客户在第二次到店时被认出来"
- 叫出客户名字+记得上次的消费，这种熟悉感是建立忠诚度的关键
- 但不是所有客户都喜欢被记住，观察客户对"被记住"的反应，适度调整
