### 一、采收标准

| 品种 | 采收判断标准 | 采收方式 | 储存方式 |
|:---|:---|:---|:---|
| 叶菜类 | 叶片充分展开、未抽薹 | 整株拔起或刀割 | 冷藏（2-4度），当天用完 |
| 番茄 | 转色50%以上 | 手摘，保留果蒂 | 常温存放 |
| 黄瓜 | 长度达品种标准、颜色鲜绿 | 剪刀剪断果柄 | 冷藏，3天内用完 |
| 豆角 | 豆荚饱满、未鼓粒 | 手摘 | 冷藏，2天内用完 |
| 玉米 | 花丝变褐、籽粒饱满 | 手掰 | 当天处理 |
| 花生 | 叶片开始发黄 | 挖取 | 晾晒后储存 |
| 根茎类 | 顶部直径达5cm以上 | 挖取 | 阴凉通风储存 |

### 二、每日执行步骤

```
1. 早晨巡查，确认当日可采收品种和预估量

2. 优先检查客户体验区
   - 预留客户采摘区的品种保持充足挂果
   - 客户采摘前标牌确认（品种/价格/采摘方式）

3. 采收供应引擎A的食材
   - 采收后立即通知引擎A主理人
   - 品质分级：供应引擎A的选最优级
   - 次品留作堆肥或酵素原料

4. 在Hermes中记录
   - 品种/采收量/品质评级
   - 供应去向（引擎A/客户采摘/其他）

5. 采收后即时整理
   - 清理采收后的地块（残枝落叶清理）
   - 采收工具清洗归位
```

### 三、验收标准

```
□ 当日可采收品种已确认，采收计划已录入Hermes
□ 引擎A当日食材需求已满足，或已告知需外采补充
□ 客户采摘区状态良好，标牌清晰
□ 采收记录已完整录入Hermes
□ 采收后地块已清理
```

### 四、异常处理

| 异常 | 响应 |
|:---|:---|
| 产量超过引擎A需求 | 通知运营卫星安排客户采摘或加工储存 |
| 产量不足 | 优先保障客户体验区，引擎A缺口外采 |
| 品质问题 | 不可食用的直接做堆肥 |
| 采收与公开化活动冲突 | 调整采收时间，预留客户体验区 |

### 五、客户触点

本阶段客户可参与的活动：叶菜采摘（劳动换薪）、掰玉米/挖花生（课程化体验）
采收期是全年人流量最大的时段，客户体验和食材供应的优先级需提前一天在Hermes中确认。
