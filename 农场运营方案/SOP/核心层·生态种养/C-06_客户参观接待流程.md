[SOP编号] C-06
[SOP名称] 客户参观接待流程
[执行人] 言渊（主接待）/ 种植养殖主管（协办）
[替代人] 运营卫星成员 / 引擎A主理人
[执行时间] 客户到达前30分钟准备 → 全程陪同 → 结束后30分钟整理
[适用季节] 全年（根据季节调整参观路线）
[前置条件] 客户预约已确认，参观人数/时间/需求已记录在Hermes
[AI接口] Hermes维护客户预约表，自动生成当日参观安排；参观后记录客户标签
[AI提醒] Hermes在客户到达前1小时推送预约信息和客户画像

---

### 一、参观前准备

```
1. 确认预约信息
   - 查看Hermes中客户的预约时间、人数、联系方式
   - 确认客户是否有特殊需求（儿童年龄、老人、饮食禁忌）
   - 了解客户来源（自有渠道/公开化平台/B端合作）

2. 路线规划（根据季节调整）
   - 核心路线：停车场 → 鸡舍/动物区 → 种植区 → 手作区 → 引擎A用餐区
   - 季节支线：春季看播种、秋季看采收
   - 雨天准备室内备用路线（手作棚 → 引擎A）

3. 现场准备
   - 参观路线无障碍清理（路面积水/杂物）
   - 各节点安排到位（鸡舍准备、种植区标牌清晰）
   - 准备接待用品：手写欢迎牌、试吃品（若有）、饮用水
```

### 二、迎接与开场（客户到达时）

```
1. 迎接
   - 客户车辆到达时在停车场迎接
   - 微笑、问候、自我介绍
   - 引导至接待区（或直接开始参观）

2. 开场介绍（3-5分钟）
   - 农场概况：120亩、1000棵松树、生态种植方式
   - 今日参观路线和时长预估
   - 厕所和饮水位置告知

   [客户此时：刚到达、在判断这个地方值不值得、是否放松]
```

### 三、参观引导

```
1. 引导节奏
   - 边走边讲，每个停留点不超过3分钟
   - 留出客户提问和拍照时间
   - 观察客户兴趣点，灵活调整讲解重点

2. 标准化讲解要点
   - 种植区：品种介绍、种植方式（无农药/生态种植）、公开化参与方式
   - 鸡舍：散养方式、产蛋率、"你吃的鸡蛋来自哪只鸡"
   - 松林：历史、生态价值、林下经济
   - 引擎A：食材从田地到餐桌的链条

3. 穿插推荐
   - 根据客户兴趣推荐后续消费
   - 对小朋友重点推荐采摘或捡鸡蛋体验
   - 对成人重点推荐露营或餐饮
```

### 四、参观结束

```
1. 回顾总结
   - 询问客户感受
   - 解答剩余问题

2. 引导下一步
   - 推荐引擎A用餐（提供今日菜单）
   - 推荐引擎B体验（展示露营区域）
   - 引导加入会员社群

3. 送别
   - 送至停车场
   - 送上农场时令伴手小礼（一把青菜/鸡蛋）
   - 邀请再来
```

### 五、参观后跟进

```
1. 当日在Hermes记录
   - 客户标签（亲子/美食/露营/自然教育）
   - 客户兴趣点和反馈
   - 是否有后续消费意向

2. 跟进动作
   - 当日发送感谢短信或微信
   - 3天内推送社群二维码
   - 7天内推送周末活动信息
```

### 六、验收标准

```
□ 客户到达前已完成路线准备
□ 开场介绍完整（农场概况 + 路线 + 基础信息）
□ 参观时长控制在40-60分钟
□ 客户已了解农场各板块功能
□ 客户已明确知道还能做什么（吃/摘/住）
□ Hermes已记录客户标签
□ 客户离开后有跟进动作
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户迟到超过30分钟 | 缩短参观路线，保留核心介绍点 |
| 突然下雨 | 切换室内路线，安排引擎A等候区休息 |
| 客户兴趣低/不愿走路 | 直接引导至引擎A或手作区喝茶聊天 |
| 同时多组客户到达 | 运营卫星支援，分组错时参观 |
| 有小孩哭闹 | 优先引导至动物区或沙坑区安抚 |

### 八、跨板块协作

- 参观中向引擎A预约的客户：参观后直接引导至引擎A用餐
- 参观中对露营感兴趣的客户：参观后引导至引擎B查看场地
- 参观中对采摘感兴趣的客户：运营卫星接手带领
- 多组客户并发时，运营卫星协调各板块人员

### 九、客户触点

- 这场参观是客户对农场的"第一印象"或"全面印象"，接待质量直接影响农场的口碑
- 参观本身不收费，但参观质量决定客户是否产生后续消费
- 参观路线经过公开化展示区，让客户了解农场的透明化运营
