[SOP编号] C-04
[SOP名称] 休耕期与土地改良流程
[执行人] 种植养殖主管
[替代人] 言渊
[执行时间] 冬季休耕期（12月-次年2月）/ 夏季休耕期（7-8月选10天）
[适用季节] 冬季休耕主周期 / 夏季短期休耕补充
[前置条件] 当季作物已全部采收；土地已清理
[AI接口] Hermes记录土壤改良方案和改良效果；跟踪各地块改良周期
[AI提醒] Hermes在休耕期开始时推送土壤改良计划和物资清单

---

### 一、休耕期安排

```
1. 冬季休耕（12月-次年2月，约90天）
   - 主要休耕时段，全年最重要的土壤恢复期
   - 所有露天地块进入休耕状态
   - 大棚区域可缩短休耕期

2. 夏季短期休耕（7-8月，选10天）
   - 选择耗地严重的区域
   - 夏季高温时段休耕，配合高温堆肥
   - 不影响引擎A的夏季食材供应

3. 轮作休耕
   - 同一地块不连续种植同科作物
   - 深根/浅根作物交替种植
   - 地块分区轮作，全年保持部分休耕
```

### 二、休耕前准备

```
1. 采收后清理
   - 作物残体清理（带走的带走/留下的做覆盖）
   - 病株集中深埋或烧毁（不可做堆肥）
   - 石块/杂物清除
   - 灌溉管道排水防冻

2. 土壤检测
   - 采样送检（测pH值、有机质含量、N/P/K含量）
   - 记录在Hermes，与种植前检测数据对比
   - 根据检测结果制定改良方案
```

### 三、休耕期土地改良措施

```
1. 绿肥种植（首选方案）
   - 播种紫云英/油菜/黑麦草（9-10月播种）
   - 休耕期结束时翻压入土（增加有机质）
   - 绿肥用量：2-3kg/亩

2. 有机质补充
   - 腐熟堆肥施用（鸡粪+秸秆堆腐，2-3吨/亩）
   - 冬季翻压入土（深度20-25cm）
   - 蚯蚓养殖区土壤重点补充有机质

3. 土壤改良
   - pH调节：过酸（pH<6.0）撒石灰/过碱（pH>7.5）施硫磺粉
   - 板结土壤：施入粗砂+腐熟有机质+深翻
   - 重茬土壤：使用微生物菌剂

4. 深翻晾晒
   - 深翻深度30-35cm（打破犁底层）
   - 冬季冻垡（自然风化土壤）
   - 春季播种前旋耕整地
```

### 四、休耕期其他工作

```
1. 灌溉系统维护
   - 管道排水防冻
   - 检查维修滴灌/喷灌设备
   - 储水设施清洗

2. 农具保养
   - 所有农具清洗、上油、入库
   - 损坏工具维修或更换
   - 工具清单更新

3. 大棚维护
   - 棚膜检查修补或更换
   - 骨架加固
   - 通风设备保养

4. 年度种植计划更新
   - 根据土壤检测结果调整来年品种
   - 根据引擎A反馈调整种植量和品种结构
   - 在Hermes中生成新一年度的C-00种植日历
```

### 五、休耕期客户活动

```
1. 冬季休耕期间客户可参与的活动
   - 公开化共建：参与堆肥翻转/绿肥播种（劳动换薪）
   - 课程化：土壤改良知识体验课
   - 认领地块的管理和查看
   - 冬季限定：烧草木灰+制炭（增加土壤肥力）

2. 休耕期间引擎A食材来源
   - 大棚蔬菜（冬季温室种植）
   - 储存类蔬菜（土豆/南瓜/萝卜/白菜）
   - 外采补充
```

### 六、验收标准

```
□ 休耕地块已清理（无残体/无杂草/无石块）
□ 土壤检测已完成，检测数据已录入Hermes
□ 绿肥已播种或堆肥已施入
□ 深翻已完成（深度达标）
□ 灌溉系统和农具已保养入库
□ 大棚已检查和维护
□ 来年种植计划已更新
□ 休耕记录已完整录入Hermes
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 绿肥出苗率低 | 补播或增加堆肥用量 |
| 休耕期遇极端低温 | 已深翻地块增加覆盖物防冻 |
| 休耕期大雪 | 积雪融化后增加水分管理，不额外处理 |
| 土壤检测异常 | 针对性改良（如重金属超标需专项治理） |
| 春季种植前整地不及时 | 提前一周解冻后旋耕，抢时播种 |
| 客户想在休耕期采摘 | 引导至大棚区或参观为主 |

### 八、跨板块协作

- 休耕期间向**引擎A**确认来年需求品种和预估用量
- 休耕期结束前与**运营卫星**协调来年公开化活动排期
- 土地改良记录在公开化运营中展示（透明化运营的一部分）
- 休耕期堆肥生产中，鸡粪由核心层收集，协调**引擎A**提供厨余

### 九、客户触点

- 休耕是客户"看不见但很重要"的工作，但通过公开化展示让客户了解土地的恢复过程
- 休耕期的"土壤改良"体验课是很好的教育内容
- 客户认领的地块在休耕期的状态和改良计划，定期同步给认领人
- 休耕的质量决定了来年农作物的品质，这是农场长期经营的基础
