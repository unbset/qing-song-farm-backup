# 劳动换薪机制（V2——适配星形结构）

> **用途**：劳动换薪在农场运营体系中的运行机制
> **版本变化**：V1基于旧6阿米巴结构 → V2适配"1核心+2引擎+N卫星"结构
> **定位**：不是产品，是贯穿所有业务单元的运营机制

---

# 劳动换薪的本质：
劳动换薪有三个目的，一是通过客人的参与，把一些平时客人看不见的东西透明化，倒逼自己品质化、不投机取巧；二是让客人切身感受到农场人的不容易；三是给客户发现金，无套路，增加客户的满足感和对农场的信任感。 
在此基础上，劳动换薪可以贯穿于农场经营的方方面面，哪怕是后厨洗菜、切菜，自然教育的老师助理等等，凡是兼职可以干的工作，都可以拿出一部分来做成劳动换薪。

劳动换薪的真实目的并不是为了替代兼职人员，而是为了增加农场与客户间的相互了解，支付薪酬相当于拓客成本。所以，在设计工作的时候会选择难度相对小的工作，而且不会对质量有严苛要求。在初期，劳动换薪会以小黑板的形式展示给来店客户，自愿参加；到有一定的会员基础后，劳动换薪以预约制对会员开放。 我相信愿意参加劳动换薪的人，并不是为了赚钱，要么喜欢农场的工作，要么其他精神层面的需求。 所以，我认为劳动换薪不是一个产品，而是一个机制，是所有业务单元都可以使用的经营策略。

劳动换薪需要有一定的支撑条件，这个条件就是客人为什么愿意参加这个活动。如果农场的条件不成熟，没有真正的实施生态种养，劳动完没有值得让客人停留的东西，那么劳动换薪就没有吸引力。所以劳动换薪的前提是农场不仅仅只有农业，还要有配套游玩、放松的场景。客户参与2-3个小时的时间参与劳动，剩下的时间可以在农场玩一会，享受一下。

## 一、定位与价值

劳动换薪不是兼职替代方案，也不是慈善活动。它是农场**信任建设的核心手段**，同时兼具**低成本获客**效果。

| 维度       | 价值             | 说明                               |
| :------- | :------------- | :------------------------------- |
| **信任建设** | 把平时客人看不见的运营透明化 | 客人参与了浇水/捡鸡蛋/摘菜→亲眼看到农场在怎么做→信任自然建立 |
| **情感连接** | 让客人切身感受农场人的日常  | "摘菜原来这么累""鸡是这么喂的"——理解了农场的价值      |
| **获客成本** | 支付薪酬相当于拓客投入    | 10-20元的时薪换来一个新客户对农场的好感，比小红书投流便宜  |
| **无套路**  | 发现金，不设消费门槛     | 增加客户满足感和对农场的信任感                  |

## 二、运行原则

### 2.1 三条原则

1. **选择难度低的工作**——不需要技能，任何人都能做。水龙头坏了不能拿来做劳动换薪，但"帮番茄搭架子"可以
2. **对质量不过度要求**——客人做得不好也正常，目的是参与而不是交付。核心主管在旁边做技术指导，不对成品质量做硬性要求
3. **不替代正式岗位**——如果某个工作需要专业技能、或需要每天稳定交付（如后厨备菜），它不适合劳动换薪。劳动换薪的工作应该是"值得做但没那么紧急"的事

### 2.2 适用边界

| 可以做 | 不可以做 |
|:---|:---|
| 采收蔬菜、采摘番茄/辣椒 | 涉及食品安全的环节（后厨切菜/配餐） |
| 捡鸡蛋、喂鸡 | 需要专业技能的工作（窑炉操作/课程带队） |
| 浇水、除草、松土 | 影响客户体验的工作（厕所清洁/垃圾清运） |
| 香草采摘、松针收集 | 可能会让客户受伤的工作（使用刀具/高空作业） |
| 农具整理、种子分装 | 核心层需要稳定交付的工作 |

## 四、运营方式

### 4.1 小黑板制（面向所有到店客户）

在核心区入口或中心厨房附近放一块小黑板，每天更新：

```
今日劳动换薪
━━━━━━━━━━━━━━━
✅ 捡鸡蛋（需2人）——10分钟，5元/人——现在可做
✅ 采收番茄（需3人）——30分钟，10元/人——现在可做
❌ 除草（今日已满）
━━━━━━━━━━━━━━━
参加方式：找核心区的工作人员报名，做完当场发现金
```

**原则**：
- 每天至少保持1-2个可参与项目
- 项目标记"有空缺"还是"已满"，避免客户去了发现不需要人
- 做完当场发现金（不收微信转账——现金的体验感不同）

### 4.2 预约制（面向会员客户）

- 会员客户可提前1天预约劳动换薪项目
- 预约客户可以指定想做的项目（如"我家孩子想捡鸡蛋"）
- 预约制的好处：核心区可以提前安排好指导人员和工作内容

### 4.3 执行流程

```
客户看到小黑板 → 报名 → 工作人员指导怎么做 → 
客户参与（15-30分钟）→ 完成后工作人员确认 → 
支付现金（5-20元）→ 客户自由活动
```

**数据记录**：运营卫星在经营日志中记录：参与人次、项目类型、支付金额、客户反馈。

## 五、预算归属

| 项目 | 归属 |
|:---|:---|
| 劳动换薪支付的薪酬 | 总账→营销费用（作为获客成本） |
| 劳动换薪的指导人工 | 各板块自行承担（本来就是日常工作的一部分） |
| 小黑板+现金零钱 | 运营卫星统一管理 |

**核心原则**：劳动换薪的支出不考核"投入产出比"。它和自然教育引流课的性质一样——花的每一分钱都是获客投入，不是运营成本。

## 六、合规备忘录

> **目的**：劳动换薪涉及客户在农场从事轻度体力劳动，必须明确法律边界和风险覆盖。
> **原则**：保护客户安全、明确双方权责、覆盖意外风险。

### 6.1 法律定位：参与者是"体验者"而非"劳动者"

劳动换薪的核心定性：客户参与农事活动的目的是**体验农场生活**，薪酬是其体验的一部分，而非其劳动的对价。

| 维度 | 劳动换薪的定性 | 正式劳动关系的区别 |
|:---|:---|:---|
| 法律身份 | **体验者/活动参与者** | 劳动者/雇员 |
| 目的 | 体验农场生活、增进对农场的了解和信任 | 以获取劳动报酬为主要目的 |
| 管理方式 | 自愿报名、自由参与、随时可退出 | 接受用人单位管理、遵守劳动纪律 |
| 薪酬性质 | 体验活动的附加回馈（相当于小礼品） | 劳动对价、受最低工资等法律保护 |
| 持续性 | 单次、临时、无长期约定 | 持续性、有劳动合同/事实劳动关系 |

**为什么必须明确这一点？**
- 如果参与者被认定为"事实劳动关系"，农场需要承担社保、工伤等法律责任
- 明确告知"体验者"身份，并在免责协议中注明，可有效规避此风险
- 所有书面/口头招募信息中，使用"体验活动""劳动体验"而非"兼职""招工""帮工"等措辞

### 6.2 招募信息中的必备条款

所有劳动换薪的招募信息（小黑板、公众号、社群、朋友圈）必须包含以下内容：

**基本信息**：
- 活动名称：青松农场劳动体验
- 活动内容：（具体项目名称，如捡鸡蛋、摘菜等）
- 活动时长：XX分钟
- 参与方式：自愿报名，自由参加
- 参与者体验回馈：XX元（标注"体验回馈"而非"薪酬"或"工资"）

**免责与风险提示**（建议使用以下标准化文案）：

> **参与须知：**
> 1. 本活动为农场生活体验项目，参与者以"体验者"身份参与，与农场不构成任何形式的劳动关系。
> 2. 参与者需确认自身身体健康状况适合参与所选活动。患有心脑血管疾病、严重骨质疏松、近期手术史或其他不适宜轻度体力活动的情况，请提前告知农场工作人员。
> 3. 参与活动过程中，请听从工作人员的指导安排，在指定区域和规定时间内进行活动。
> 4. 户外活动存在不可预见的自然风险（滑倒、蚊虫叮咬等），参与即视为已充分了解并自愿承担合理范围内的风险。
> 5. 未成年人参与需有监护人全程陪同，监护人需对未成年人的安全负责。

### 6.3 保险配置

**必须购买的保险**：

| 保险类型 | 保额建议 | 覆盖范围 | 年费参考 | 备注 |
|:---|:---:|:---|:---:|:---|
| 公众责任险（场地险） | 每次事故100万+ | 客户在农场场地范围内发生的意外伤害 | 2,000-5,000元/年 | 这是最基本的保障，必须买 |
| 活动意外险（可选补充） | 每人10-20万 | 特定活动（如劳动换薪、探索营）的参与者 | 按次投保，约2-5元/人 | 可在活动报名时加入费用中 |

**公众责任险的注意事项**：
- 确认保险条款包含"农事体验活动"或"农业观光"类目——普通场地险可能不覆盖农具操作风险
- 保险公司建议：平安、太平洋、人保等大型保险公司均有农业旅游类责任险产品
- 保险范围需明确包含：客户在工作人员指导下参与轻体力农事活动时发生的意外
- 保险区域需覆盖：所有对客户开放的农场区域（不仅仅是餐饮区和服务区）

### 6.4 现场安全管理

| 要求 | 标准 | 执行人 |
|:---|:---|:---|
| 活动前安全告知 | 每个项目参与前，口头说明安全注意事项+请参与者阅读小黑板上的参与须知 | 现场指导的工作人员 |
| 未成年参与要求 | 14岁以下需监护人全程陪同；14-18岁建议监护人知情 | 现场指导的工作人员 |
| 工具使用限制 | 剪刀/镰刀等锋利工具仅在核心主管在场时方可使用，且需提供手套 | 种植养殖主管 |
| 天气限制 | 雷雨、大风、高温（35℃+）天气不安排户外劳动换薪项目 | 运营卫星（当日判断） |
| 急救箱配置 | 核心区、引擎A厨房、引擎B服务台各配1个基础急救箱，含创可贴/碘伏/纱布/冰袋 | 运营卫星每月检查1次 |
| 意外事件记录 | 任何轻伤（即使只是擦破皮）都需记录在经营日志中，注明发生时间、地点、情况、处理方式 | 运营卫星 |

### 6.5 执行节奏

| 时间 | 事项 | 负责 |
|:---|:---|:---|
| 劳动换薪启动前 | 购买公众责任险，确认条款覆盖农事体验活动 | 言渊 |
| 劳动换薪启动前 | 制作免责协议小黑板/纸质确认单 | 运营卫星 |
| 小黑板上线时 | 第一次用小黑板时，由言渊或运营卫星在场示范一次完整的参与流程（包含安全告知环节） | 言渊/运营卫星 |
| 每季度 | 检查保险是否到期，确认续保 | 运营卫星 |
| 每季度 | 检查急救箱物品是否齐全、在有效期内 | 运营卫星 |

## 七、常见问题

### Q：客户做了劳动换薪拿现金，会不会不消费就走了？

不会。愿意参与劳动换薪的客户心理动机：
- 喜欢农场的工作——"很久没干过农活了"
- 让孩子体验——"让孩子知道东西是怎么来的"
- 精神层面的满足——"帮到农场的忙"
- 不是为了赚钱

拿了5-20元现金，他们更可能在农场花50-100元吃饭买面包——"反正这5元是白得的"。

### Q：会不会有客户冲着赚钱来做？

10-20元/次的薪酬，不够覆盖油费。真正想赚钱的人不会来。如果出现"同一个客户天天来干活"，礼貌告知"劳动换薪每人每天限参加1次"即可。
