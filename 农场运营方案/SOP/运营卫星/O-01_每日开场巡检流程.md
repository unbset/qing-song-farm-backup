[SOP名称] 每日开场巡检流程
[执行人] 运营卫星成员（当日值班）
[替代人] 引擎A主理人 / 引擎B主理人
[执行时间] 每日 8:00-9:00（夏季）/ 8:30-9:00（冬季）
[适用季节] 全年
[前置条件] 各板块前一日收档已完成；场地安全
[AI接口] Hermes推送当日巡检清单；记录巡检结果和异常
[AI提醒] Hermes每日8:00推送巡检清单，天气预警和特殊事项提示

---

### 一、巡检前准备

```
1. 查看Hermes当日信息
   - 当日预约情况（引擎A用餐预约 / 引擎B入住 / 参观预约）
   - 特殊活动安排（团建/课程/活动）
   - 天气情况（影响户外布置决策）
   - 前一日异常事件记录（需关注复检项）

2. 准备巡检工具
   - 手机（Hermes巡检清单）
   - 手套、垃圾袋
   - 巡检登记表（备用）
```

### 二、巡检路线与检查项

```
按照以下路线依次巡检，不漏一项：

1. 停车场及入口
   □ 地面清洁（无垃圾/积水）
   □ 指示牌清晰（无破损/掉落）
   □ 入口大门开启状态正常
   □ 停车场车位充足，已整理

2. 公共通道
   □ 主路/步道畅通（无杂物/树枝/工具占道）
   □ 照明设施正常（昨夜有无损坏）
   □ 垃圾桶未满溢（前一日已清理）
   □ 公共休息区整洁（桌椅归位）

3. 卫生间（重点）
   □ 地面清洁、无积水
   □ 便池清洁、无异味
   □ 洗手台清洁、洗手液充足
   □ 纸巾供应充足
   □ 垃圾篓未满
   □ 照明和通风正常

4. 引擎A餐饮区（外部环境）
   □ 户外用餐区桌椅归位
   □ 遮阳伞/雨棚状态正常
   □ 指引牌清晰

5. 引擎B露营区（外部环境）
   □ 当日退房营位已空出
   □ 公共淋浴间清洁
   □ 公共洗漱台清洁、物资充足

6. 核心种植区（环境）
   □ 参观通道畅通
   □ 采摘区标牌清晰
   □ 体验区工具归位

7. 公开化展示区
   □ 公开化信息板更新
   □ 认领牌/记录表状态完好
   □ 劳动换薪登记表整洁
```

### 三、巡检记录与反馈

```
1. 在Hermes中记录巡检结果
   - 勾选已检查项目
   - 标记异常项（拍照上传）
   - 填写整体状态评价（良好/一般/需改善）

2. 异常事项处理
   - 轻微问题（地面垃圾、纸巾缺失）：当场处理
   - 需维修问题（灯光损坏、设施破损）：在Hermes标记并通知言渊
   - 安全问题（路面塌陷、电线裸露）：立即围挡并优先处理
```

### 四、验收标准

```
□ 全路线巡检完毕
□ 所有公共区域整洁、功能正常
□ 卫生间达到可用标准
□ 无安全隐患
□ 各板块开档前环境达标
□ Hermes巡检记录已提交
```

### 五、异常处理

| 异常 | 响应 |
|:---|:---|
| 前一日未收档/未清理 | 优先清理公共区域，其他事项上午完成 |
| 设施损坏 | 围挡并张贴提示，当日安排维修 |
| 公共区域有安全隐患 | 立即围挡，不可营业区域关闭，通知言渊 |
| 卫生间问题 | 立即清洁，严重堵塞通知维修 |
| 发现动物尸体/意外 | 戴手套清理，消毒处理，调查原因并记录 |
| 有前日遗留物 | 拍照记录，联系失主，归入失物招领 |

### 六、跨板块协作

- 巡检发现各板块问题，拍照发群并通知对应负责人
- 引擎A开档时运营卫星巡检结果作为参考
- 巡检后与言渊晨会沟通整体情况（如时间允许，简讯汇报）

### 七、客户触点

- 开场巡检是所有客户体验的"第一道防线"
- 客户看到的第一眼决定了对农场的判断，不被注意的细节（垃圾桶满溢/卫生间脏乱/路面杂物）会降低整体评价
- 检查公开化展示区的信息更新，确保客户能理解农场的透明运营
