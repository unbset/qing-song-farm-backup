# 三层同心圆结构

```
        ┌───────────────────────┐
        │   卫星（费用中心）      │
        │  自然手作/运营/田园摄影  │
        │  ┌───────────────┐   │
        │  │ 引擎（利润中心）  │   │
        │  │ 引擎A餐饮        │   │
        │  │ 引擎B露营住宿     │   │
        │  │ ┌───────┐     │   │
        │  │ │ 核心   │     │   │
        │  │ │生态种养│     │   │
        │  │ │客户参与│     │   │
        │  │ └───────┘     │   │
        │  └───────────────┘   │
        └───────────────────────┘
```

**青松农场经营体系 = 1个核心 + 2个引擎 + N个卫星**

| 层 | 角色 | 考核 |
|:---|:---|:---|
| 核心 | 战略成本中心（信任底座） | 土壤健康度、展示丰富度、客户参观率 |
| 引擎 | 利润中心（造血器官） | 净利润、食材成本率、客户满意度 |
| 卫星 | 费用中心（扩音器） | 获客数、转化率、传播效果 |
