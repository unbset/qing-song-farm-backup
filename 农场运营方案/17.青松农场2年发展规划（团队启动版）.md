# 青松农场2年发展规划（团队启动版）

> **前提**：
> - 言渊（农场主）
> - **运营主管**（第1个月内到岗，月薪5,000元）
> - **种植养殖主管**（第1个月内到岗，月薪5,000元）
> - 引擎A厨师1人（已有）
> - 引擎B帮工兼职（已有）
> - **自然手作卫星主理人**（第6个月到岗，月薪5,000元；有合适人选可提前）
>
> **目标**：2年内会员300人，全部板块启动运营。
>
> **核心变化说明**：原方案基于"单人启动、逐步加人"设计。现调整为运营主管+种植养殖主管第1个月内双到岗，言渊从第1天起即可聚焦战略与产品开发。首年新增人工成本较原方案多约50,000元（前5个月双人重叠期），由言渊负责预算解决。
>
> **原则**：先做已有现金流的、再做需要投入的；先做一个人能干的、再做需要团队的；先做轻量的、再做重的。

---

## 一、核心策略：不是"所有产品一起推"，是"咬合式增长"

每3个月只集中做1-2件事，做出结果再启动下一件。前期的事为后期的事蓄客，后期的事为前期的事增值。

```
第1年：搭骨架 + 跑通基础产品 → 积累第一批种子客户
  ↓
第2年：扩产品线 + 客户裂变 → 300会员
```

---

## 二、阶段规划（6个阶段，每阶段3个月）

### 第一阶段：搭骨架期（第1-3个月）

**3人团队启动**：言渊（战略+产品开发）、运营主管（日常运营）、种植养殖主管（根层建设）。

**各岗位第1个月核心任务**：

**言渊**：
- 制定产品开发路线图（自然教育课程框架、手作产品线）
- 引擎A/B优化方案
- 运营主管+种植主管入职培训与磨合
- 启动第一批自然教育引流课教案开发

**运营主管（到岗第1周）**：
- 跟着言淵走全场——认识人、认识场地、认识流程
- 接管客户信息表格（已有记录→第3个月完成100条）
- 接管品牌内容审核与发布
- 公共环境巡查与问题闭环
- 维护长搭露营客户（续费提醒+日常沟通）

**种植养殖主管（到岗第1周）**：
- 规划种植区域（哪些地块种什么、轮作方案）
- 启动堆肥/酵素制作（收集厨余+落叶+秸秆）
- 搭建或修缮鸡舍
- 翻地、育苗（叶菜类优先）
- 接手展示台"每天有东西"的陈列

| 优先级 | 工作 | 谁负责 | 预期产出 |
|:---|:---|:---|:---|
| P0 | 引擎B散客露营维护 | 运营主管 | 稳定现金流 |
| P0 | 引擎A餐饮（烧烤+中心厨房成品） | 厨师 | 稳定现金流 |
| P0 | 长搭露营客户维护+续费提醒 | 运营主管 | 稳住年费收入 |
| P0 | 种植区域规划+堆肥/酵素制作 | 种植养殖主管 | 根层基础动工 |
| P1 | 松林野餐篮上线 | 厨师+运营主管（上架销售） | 新增引流产品 |
| P1 | 窑炉面包工作日供应 | 厨师 | 新增零售收入 |
| P1 | 自然教育引流课68元教案开发 | 言渊 | 第3个月试跑 |
| P1 | 手作体验产品开发（驱蚊膏/手工皂首款） | 言渊 | 第3个月试跑 |
| P2 | 线上商城基础搭建（微店，先上窑烤面包） | 运营主管 | 第3个月上线 |

**第1-3个月结束时必须达到的状态**：
- 月营收稳定（不低于当前水平），运营主管能独立巡检+闭环
- 松林野餐篮月售≥30篮
- 客户信息表格≥100条
- 核心层有菜有鸡（首批叶菜出苗、鸡入栏）
- 种植区域规划完成，堆肥/酵素已启动≥5桶
- 自然教育引流课教案完成，第3个月试跑≥2场
- 手作体验产品≥2款可带

**关键决策**：确认运营主管已独立运转，确认种植主管工作方向正确，确认自然手作主理人招聘启动或人选锁定。

---

### 第二阶段：跑产品期（第3-6个月）

**关键动作**：产品落地期。言渊从日常运营中完全脱身，集中精力做产品落地和市场拓展。

**人员状态**：3人团队稳定运转（言渊+运营主管+种植主管）。

| 优先级 | 工作 | 谁负责 |
|:---|:---|:---|
| P0 | 自然教育引流课68元正式开跑 | 言渊（自己带课） |
| P0 | 手作体验课上线（驱蚊膏/手工皂首款） | 言渊（自己带） |
| P1 | 引擎A：柴火灶+火锅陆续上线 | 厨师+种植主管（食材对接） |
| P1 | 引擎B：散客活动体验增强（飞盘/篝火/吊床等零成本项目） | 运营主管组织 |
| P1 | 自然教育深度课198元教案开发 | 言渊 |
| P2 | 线上商城运营（窑烤面包+手作零售） | 运营主管 |
| P2 | 节气年卡产品设计 | 言渊 |
| P2 | 引擎B：长搭露营扩招（目标新增5-10人） | 运营主管 |
| P3 | 核心层第一批蔬菜采收，供应引擎A测试 | 种植主管 |

**第3-6个月结束时必须达到的状态**：
- 自然教育引流课月均≥4场，场均≥6人
- 手作体验课月均≥4场
- 核心层第一批叶菜供应引擎A（不考核量，跑通流程即可）
- 引擎A柴火灶/火锅产品稳定运行
- 线上商城≥10个SKU，月均订单≥20单
- 节气年卡产品设计完成，准备发售
- 运营主管能独立管理日常运营（言渊不再需要每日过问）

---

### 第三阶段：扩线期（第6-9个月）

**关键动作**：自然手作卫星主理人到岗，言渊从带课中释放，转向新产品线开发。

**第2位员工——自然手作卫星主理人**（第6个月到岗）

| 项目 | 内容 |
|:---|:---|
| 角色 | 自然手作卫星主理人 |
| 入职后接手 | 自然教育引流课+深度课+手作体验课的全部带课 |
| 言渊腾出的精力 | → 投入引擎B团建/活动策划+自然探索营+成人自然疗愈+田园摄影 |
| 画像要求 | 喜欢孩子、有亲和力、不要求专业教育背景（内部培训教案） |

| 优先级 | 工作 | 谁负责 |
|:---|:---|:---|
| P0 | 自然手作主理人培训+上手指南 | 言渊带 |
| P0 | 自然教育深度课198元上线（设计2-3个主题） | 自然手作主理人 |
| P1 | 节气年卡发售（面向老客优先） | 运营主管+自然手作主理人 |
| P1 | 自然探索营产品开发 | 言渊 |
| P1 | 引擎B：团建/宴会接待流程标准化（活动SOP+分工会+物料清单） | 运营主管+言渊 |
| P2 | 田园摄影试跑（小规模，2-3个场景+合作摄影师测试） | 运营主管 |
| P2 | 核心层种植扩产（种植主管独立规划扩种方案） | 种植主管 |
| P3 | 成人自然疗愈产品设计 | 言渊 |

**第6-9个月结束时必须达到的状态**：
- 自然手作主理人能独立带课
- 节气年卡售出≥15张
- 自然探索营完成设计，试跑≥2场
- 引擎B团建接待流程标准化（接待手册完成）
- 田园摄影试跑跑通（≥10组客户验证）
- 核心层初步实现小规模供应（引擎A蔬菜自供率≥10%）

---

### 第四阶段：加速期（第9-12个月）

**关键动作**：全部产品线均已启动，进入稳定运营和会员裂变阶段。

| 优先级 | 工作 | 谁负责 |
|:---|:---|:---|
| P0 | 自然探索营正式上线 | 自然手作主理人+言渊 |
| P0 | 四季庆典/自然运动会第1场落地（如秋收节） | 运营主管 |
| P1 | 田园摄影正式上线 | 运营主管（合作摄影师模式） |
| P1 | 成人自然疗愈上线 | 言渊（合作疗愈师） |
| P2 | 小院共创启动（言渊先做1个样板小院） | 言渊+种植主管（围栏+绿化） |
| P2 | 引擎A：农村大席产品上线 | 厨师 |
| P3 | 核心层引擎A蔬菜自供率≥30%（平滑切换） | 种植主管 |
| P3 | 劳动换薪机制常态化运行（小黑板展示+会员预约） | 运营主管+各板块配合 |

**第1年结束时必须达到的状态**：
- 月营收稳定增长——对比启动时增长≥50%
- 会员累计≥100人（年卡15张+储值60人+长搭25人）
- 全部产品线已启动（餐饮+露营+自然教育+手作+探索营+生日会+疗愈+摄影+四季庆典）
- 运营主管能独立管理日常运营
- 种植主管能独立规划农事、独立接待参观客户

---

### 第五阶段：裂变期（第12-18个月）

目标：会员从100人→200人

**关键策略**：
- 老客带新客激励机制（推荐有礼）
- 田园摄影带动中老年客群
- 四季庆典扩大品牌曝光
- 节气年卡老客户续费

**人员**：当前4人团队可覆盖（言渊+运营主管+种植主管+自然手作主理人）
**必要时**：引擎B增加1名帮工（兼职，成本约2,000元/月）

---

### 第六阶段：规模期（第18-24个月）

目标：会员从200人→300人

**关键策略**：
- 小院共创自然吸引同频共建者
- 节气年卡扩量
- 田园摄影成为稳定获客渠道
- 品牌内容自媒体矩阵成熟运营

## 四、人员画像

### 第1位：运营主管

| 项目 | 内容 |
|:---|:---|
| 角色 | 办公室主任/副手 |
| 核心能力 | 细心、有条理、能独立推进事情、沟通协调能力强 |
| 不需要的能力 | 不需要懂农业、不需要懂餐饮、不需要会拍照 |
| 日常工作 | 每天全场巡查→发现问题→追闭环；每周审核内容→协调发布；每月更新客户数据 |
| 画像 | 30-45岁，有行政/运营/门店管理经验。做过小企业管理或店长的优先。女性或男性均可 |
| 面试问题 | "你负责过的项目中，出现过什么意外情况？你是怎么处理的？"——考察应变和闭环能力 |
| 到岗后前2周 | 不干活，跟着言淵走一圈——认识人、认识场地、认识流程 |

### 第2位：自然手作卫星主理人

| 项目 | 内容 |
|:---|:---|
| 角色 | 课程老师+手作老师 |
| 核心能力 | 喜欢孩子、有亲和力、当众说话不怯场、动手能力强 |
| 不需要的能力 | 不需要专业教育背景、不需要手作专业背景（教案和配方已标准化） |
| 日常工作 | 带自然教育引流课/深度课、带手作体验课、备课备料 |
| 画像 | 25-40岁，做过幼教/培训/社工/活动策划的优先。喜欢户外工作。女性为主（客户群主要是妈妈和孩子，更容易建立信任） |
| 面试问题 | "带孩子上户外课的时候，有一个孩子哭了不想参与，你会怎么做？"——考察儿童互动能力 |

### 第3位：种植养殖主管

| 项目 | 内容 |
|:---|:---|
| 角色 | 核心层（生态种养）负责人 |
| 核心能力 | 有2年以上生态种植/养殖实操经验（不是理论型）、能独立安排每日农事、能与人沟通（需要接待参观客户） |
| 不需要的能力 | 不需要懂自然教育、不需要做销售 |
| 日常工作 | 种菜/喂鸡/采收/配送引擎A/展示台维护/劳动换薪指导 |
| 画像 | 40-60岁，有实际农场或家庭农场经验。本地或周边人（住农场或附近）。不要求学历 |
| 到岗后前2周 | 言淵带他走一遍：引擎A需要什么菜→每天什么时候要→鸡怎么喂→展示台怎么摆 |
| 注意 | 这个最难招，需提前留意。优先从退休农技员、有经验的种植户中寻找 |

## 五、300会员目标的达成路径

### 会员体系设计（三档）

| 类型 | 门槛 | 权益 | 目标2年累计 |

| **长搭露营**（专属类型） | 3,600元/年 | 100㎡小院使用权 | **30人** |

| **合计付费会员** | | | **≥300人** |

## 六、风险与前提

| 风险 | 可能性 | 影响 | 应对 |
|:---|:---|:---|:---|
| **运营主管招不到** | 中 | 高 | 优先从熟人圈物色，放宽行业经验要求（不做农场经验限制，核心看执行力和细心程度）。2周试岗双向选择 |
| **种植养殖主管招不到** | 中高 | 高 | 这是最难招的岗位。①从退休农技员中找（银发顾问转全职）；②降低全职要求，先招种植顾问+帮工执行；③言淵自己带着帮工干，边干边学边找 |
| **首年人工成本15.5万超出现金流** | 中 | 中 | 运营主管+种植主管双到岗后，若第3个月现金流吃紧，考虑将自然手作主理人延至第8-9个月到岗（节省前2-3个月工资） |
| **自然教育引流课报名不达预期** | 中 | 低 | 68元定价足够低，跑通流程比上量重要。第1个月目标4场，每场≥4人即可 |
| **种植养殖主管到岗后不适应离职** | 中 | 中 | 到岗前招聘银发顾问作为备用兜底；到岗后前2周言渊全程带，建立归属感 |
| **运营主管+种植主管同时磨合压力大** | 中高 | 中 | 第1个月言渊80%精力用于带人+建流程，产品开发暂缓。**宁可慢一点，别让新人"散养"** |
