## 使用说明

成人自然疗愈填补的是现有产品线中**最大的客群空白**——没有孩子的成年人。自然教育面向孩子、手作体验面向妈妈，但农场还有大量"自己来的成年人"没有内容可以消费。

| 维度 | 自然教育/手作体验 | 成人自然疗愈 |
|:---|:---|:---|
| 客群 | 带孩子来的家庭 | 自己来的成年人/朋友结伴 |
| 时间 | 周末 + 节假日 | 周末 + **工作日清晨/傍晚** |
| 消费动机 | "带孩子做点有意义的事" | "为自己花点时间" |
| 与农场其他板块的关系 | 引流转其他板块 | **能引流来新客群（非带娃群体），也能承接其他板块的老客群的休息需求** |

## 1. 飞轮定位

**主定位**：引流入口 + 信任引擎

成人自然疗愈是两个"新客群入口"之一（另一个是自然教育——带孩子的家庭）。它吸引的是**另一种人**：工作压力大、不是没有带娃的家庭、就是想找个地方静一静的城市成年人。

**辅助作用**：
- 复购锚点（疗愈不是一次性的——压力是持续的，需求是持续的）
- 传播杠杆（客户在松林做瑜伽/静坐的画面——社交媒体传播力强）

**与现有产品的内在联动——自然手作卫星的完整客群覆盖**：

```
自然教育 → 带孩子来的家庭（4-10岁孩子）
手作体验 → 妈妈群体
自然疗愈 → 没有孩子的成年人
自然探索营 → 大童/青少年（7-14岁独立参加）
自然生日会 → 所有家庭的"大事件"
                           └── 这四个产品共同覆盖了"一个人从
                                单身→恋爱→结婚→生娃→娃长大"
                                全生命周期的自然体验需求
```

## 2. 目标客群

### 主客群：想在自然中"缓一缓"的城市成年人

- 画像：25-45岁，潍坊城区上班族。白领/自由职业/创业者。日常被工作群、会议、通勤、KPI填满
- 典型场景：
  - **周末版**：周中太累了，周末不想再社交、不想再出门"玩"，但也不想窝在家里。想去一个安静的地方待着但不费劲
  - **工作日清晨版**：周中调休半天，或者自由职业者，早上7点到农场做一个小时的瑜伽再回去上班
  - **闺蜜版**：两个闺蜜一起来，不说话各坐各的，或者做个正念行走后喝杯茶聊聊天
- 痛点：城市里没有"可以安静待着又不觉得孤独"的地方——咖啡馆太吵、公园人多、在家躺着又内疚
- 痒点："去松林里坐一坐"——这个画面本身就有想象的吸引力
- 决策逻辑：在大众点评/小红书看到"松林正念行走"→68元/次→"去试试看"→周末来了→体验后觉得很好→会关注后续活动

### 次客群：农场的"老客户"——那些已经带孩子来过几次的家长

- "每次来都是围着孩子转，从来没在农场为自己待过"
- 自然疗愈给这些家长一个**"把孩子放在自然教育课、自己去做疗愈"**的正当理由
- 此时自然手作卫星内部三个产品形成了完整闭环：**孩子上自然教育课 + 妈妈做手作 + 爸爸去松林做正念行走 = 各得其所的一个上午**

## 3. 核心体验

"不需要说话、不需要社交、不需要做任何事。在松林里慢慢地走一段路，坐下来，呼吸。闻到松针的味道，听到风穿过树梢的声音。一个小时后睁开眼睛——好像没那么累了。"

这不是"治疗"，是**给自己一个可以不说话、不思考的一小时**。

## 4. 产品设计（+扩展：课程体系与合作模式）

### 4.1 三类产品形态

#### A. 松林正念行走（核心产品，即来即走，门槛最低）

| 项目 | 内容 |
|:---|:---|:---|
| 时长 | 60分钟 |
| 定价 | 88元/人/次 |
| 最大容量 | 15人/场（配1位引导师） |
| 时间安排 | 周末上午8:00-9:00 / 周末下午4:00-5:00 / 工作日上午场（视需求） |
| 流程 | 集合（5分钟）→介绍正念行走理念（5分钟）→静默行走，引导师在前慢慢走，每走到一个"停留点"停下来引导观察（40分钟）→回到起点，静坐呼吸（5分钟）→结束，每人一杯香草茶（5分钟） |
| 引导语示例 | "现在把注意力放在脚底——走在松针上的时候和走在土地上的时候，脚底的感觉有什么不同""现在停下来——闭上眼睛，你听到了几种不同的声音？""用鼻子深吸一口气——闻到什么味道？试着分辨松针的味道和泥土的味道" |
| 所需准备 | 1条2-3公里的松林路线（不走回头路，最终回到中心厨房/茶歇区）+ 一个简单的集合点指示牌 |

#### B. 松林颂钵疗愈（深度产品，需预约）

| 项目 | 内容 |
|:---|:---|:---|
| 时长 | 75分钟 |
| 定价 | 88元/人/次 |
| 最大容量 | 10人/场 |
| 时间安排 | 周末下午/工作日晚（日落前） |
| 流程 | 松林里选一棵大树下，铺好瑜伽垫/防潮垫（15张）→引导呼吸放松（10分钟）→颂钵师依次敲钵，参与者躺平/坐姿听音（40分钟）→静默5分钟→引导回归（10分钟）→结束后一杯香草茶（5分钟） |
| 所需准备 | 颂钵（由合作老师自带）、瑜伽垫/防潮垫（农场准备，统一存放）、一处平坦的松林空地 |

#### C. 松林晨间瑜伽/八段锦（周末/节假日轻量产品）

| 项目 | 内容 |
|:---|:---|:---|
| 时长 | 60分钟 |
| 定价 | 88元/人/次 |
| 最大容量 | 20人/场（1位老师） |
| 时间安排 | 周末早上7:30-8:30（做完刚好去中心厨房吃早餐） |
| 流程 | 铺垫→晨间瑜伽/八段锦→结束（无茶歇，想吃的自行去中心厨房） |
| 所需准备 | 瑜伽垫（农场统一存放）、一处平坦松林空地 |

### 4.2 合作模式（农场不自雇老师）

**核心逻辑**：农场的核心能力是提供松林场地+客户流量，不是聘用瑜伽老师/颂钵师。潍坊城区有这个技能的独立老师不少，但他们缺的是"户外教室"和"愿意来的客户"。

| 合作方 | 老师做什么 | 农场做什么 | 分成建议 | 说明 |
|:---|:---|:---|:---|:---|
| 瑜伽老师/颂钵师（自由职业） | 设计课程、现场教学、自带道具（瑜伽垫农场的） | 提供场地+引流（在农场客户群+小红书发布活动信息）+课后一杯茶 | 老师60% / 农场40% | 农场承担获客成本，老师承担教学成本。按场次结算 |
| 潍坊本地瑜伽馆/心理机构（B端合作） | 每周固定开课（比如每周日早8点），自行招募学员 | 提供场地+农场客户优先体验价+品牌露出（"XX瑜伽 x 青松农场"联名） | 按人头结算，农场收取场地费20-30元/人 | 农场不出内容，只出场地+品牌。适合长期稳定合作 |

**为什么选择合作模式而非自雇**：
- 自雇一位全职疗愈老师的成本（月薪+社保）vs 初期频次（可能周末2-3场），经济账算不过来
- 合作模式下，一场课如果有5个人报名，农场净收入 = 5×68×40% = 136元。看起来不高，但**农场的场地坐着也是空着，这136元是纯增量，不占用任何固定成本**
- 合作老师自带客源（忠实学员），等于老师在帮农场引流

### 4.3 借鉴案例

#### 案例一：日本"森林浴"（Shinrin-yoku）——一个国家级的健康工程

日本的森林浴始于1982年，由日本林野厅（Forestry Agency）正式提出。它不是"去森林里走走"，而是一套**标准化的引导流程**——引导师经过认证培训，行走路线经过设计，停留点有明确的功能（第一个点释放紧张、第二个点打开感官、第三个点深度连接）。

至今日本有超过60个"森林浴基地"（Forest Therapy Base），每个基地都有认证的森林浴引导师和散步路线。研究表明：2小时的森林浴可以降低16%的皮质醇水平、提高53%的NK免疫细胞活性。

**可借鉴**：农场的松林正念行走不需要做到认证级别，但应该借鉴它的核心原则——**不是"去松林里走一圈"，是"带着觉知、慢慢走、停下来感受"。** 引导师的作用不是"带路"，是"引导注意力"。

**具体落地**：设计一条2-3公里的松林路线，设3-4个"停留点"——每个点有不同的引导方向。路线图+引导语写在教案里，确保每位客人的体验一致。

#### 案例二：韩国"森林休养"——政府认证的产业化路径

韩国在森林疗愈上比日本走得更商业化。他们开发了"森林休养指南"（Forest Healing Guide）认证体系，有超过1000名持证引导师。森林休养被纳入医保——医生可以开具"森林处方"。

韩国还有"森林体验中心"模式——在森林里建一个简单的木屋，提供茶饮、休息区、引导服务。政府补贴建设费用，运营由本地社区负责。

**可借鉴**：如果潍坊城区有瑜伽馆/心理机构合作，可以在农场设立一个"松林疗愈站点"——一个固定的集合点（可以是一个亭子或一个木平台），铺上木地板、放几个垫子。客户第一次来后就知道位置，下次可以直接来。

**具体落地**：不需急着建。先用一片平坦的松林空地+可移动瑜伽垫试跑。证明有稳定需求后，再考虑建一个固定的"松林疗愈平台"。

#### 案例三：苏格兰"自然处方"（Nature Prescriptions）——医生叫你出门

2018年起，苏格兰NHS（国家医疗服务体系）正式推出了"自然处方"项目——全科医生可以为焦虑、抑郁、高血压患者开具"自然处方"：每周参加一次自然活动（社群园艺、自然行走、环保志愿活动），作为药物治疗的补充或替代。

项目研究表明：自然处方使参与者的焦虑评分平均下降34%，抑郁评分下降28%。很多参与者说"比吃药有用"。

**可借鉴**：虽然中国没有"自然处方"体系，但这个理念可以用来定位产品——**自然疗愈不是"城市里的另一种消费"，是人对自然的真实需求**。在宣传时不需要强调"疗愈"、"治疗"这种词（太重了），而是强调"休息"、"呼吸"、"缓一缓"——把门槛降到最低。

**具体落地**：产品宣传语参考——"周末早上8点，来松林里坐一个小时。不收费心灵鸡汤，不收费冥想课，就只是走走、坐坐、呼吸。"

#### 案例四：莫干山"山中小驻"——短期静修的商业化样本

莫干山的"山中小驻"提供2天1夜的自然静修套餐（正念行走+瑜伽+素食+手工，2000-3000元/人）。客户画像非常明确：30-45岁上海的BAT/外企女白领，年收入30万+，工作强度极高。

为什么她们付2000-3000元来"山里待两天"？不是因为在山里就能治好焦虑，而是**"我来山里了"这个行动本身就是对自己的一种奖励和补偿**——是"我值得被这样对待"的信号。

**可借鉴**：农场的自然疗愈产品不需要做到莫干山那么重（也不需要），但应该传递相似的信号——"花68元，为自己花一个小时"。对城市成年人来说，这笔钱买的不是"课程"，是"允许自己停下来"的许可证。

- 潍坊城区一节瑜伽团课的价格大约在40-80元（瑜伽馆内）

- 客户的心态不是"88元一节瑜伽课"，是"68元去松林里待一小时"——这是两个不同的产品

## 8. 增长路径

### 复购

自然疗愈的复购逻辑和体验课的"用完再买"不同——它的复购驱动是：**压力不会只来一次**。

- 客户第一次来是因为"好奇，试试看"
- 客户第二次来是因为"上次做完感觉挺好，再来一次"
- 客户第十次来是因为"这已经是我的习惯了"

**建议设计**：次卡/月卡 — "晨间瑜伽月卡：4次（每周日一次）原价352元 → 月卡价268元" — 用更低的价格帮客户建立习惯。

### 传播

自然疗愈的场景是天然适合拍照的——但需要注意：**手机和正念是矛盾的**。如果引导师在带正念行走，客户停下来拍照，引导体验就断了。所以传播策略需要设计"拍在开始前、拍在结束后"。

| 时间 | 传播动作 |
|:---|:---|
| 课前（5分钟） | "选一个你觉得好看的位置站好，我帮你们拍一张'上课前的合影'" |
| 课后（茶歇时间） | "刚做完正念，你们可以自己在松林里走走，拍拍照"——这时候客户会自己拍 |
| 课后（老师发群里） | 老师拍3张场景照（不拍正脸）发到活动群——"今天松林的阳光" |

| 项目 | 内容 |
|:---|:---|:---|
| 总体判断 | **做（以合作模式试跑）** |
| 前提条件 | 1. 找到1-2位合作的瑜伽/正念/颂钵老师（潍坊城区一定有，先发朋友圈问问）2. 选定松林正念行走路线（2-3公里，设3-4个停留点）3. 试跑3场，每场不超过8人 |
| 优先级 | **中。** 不是最紧急的产品（不如自然教育双档调整和生日会紧迫），但启动成本极低，试跑不亏。建议在自然教育+手作体验调整完成后、有精力时启动 |
| 启动建议 | **第1步**：找老师——发一条朋友圈或在本地生活群问"有没有认识做正念/瑜伽/颂钵的老师，想合作在松林里开课"——大概率会有朋友推荐 **第2步**：路线踩点——选定一条松林路线，自己走一遍感受节奏 **第3步**：合作老师带第一次试听课（免费，邀请员工+熟人参加）→ 收集反馈 → 调整后正式上线 |
| 退出条件 | 连续3场报名<3人→暂停。合作老师离开后1个月内未找到替代→暂停 |

## +1 多角色验证

### 角色A：第一次来的上班族女性（30岁，广告公司策划）

**体验路线**：小红书刷到"松林正念行走68元"→周末早上开车来→到了发现集合点不太明显→找到了→和其他6个人一起开始走→引导师说"不要说话"→默默地走→走了一会儿开始觉得"松林里真的很安静"→走完了喝了一杯薄荷茶→走了

**加分点**："在松林里走了一个小时没有说话，这个感觉已经很久没有过了"——结束时喝的那杯薄荷茶是意外的小惊喜
**扣分点**：集合点不太好找——第一次来的客户需要更明确的指引（简易路牌+树上的小布条）
**复购意愿**：强。"下个月还想来一次。"
**传播意愿**：中。拍了松林的照片发了小红书，但没有拍自己——"做正念的时候不太想掏手机"
**优化建议**：课前在集合点旁边放一个小黑板"今日松林正念 → 向右走50米"——解决找不到集合点的问题；茶歇用的薄荷摘一片放在杯子里——"这是你自己种的吗？"——这个对话会自然地发生

### 角色B：来参加过自然教育的妈妈（尝试自然疗愈）

**体验路径**：把孩子送进自然教育课→看到隔壁新开了"成人正念行走"→68元/人→正好一个小时，孩子下课的时候她也结束了→报名→走了一个小时→接孩子→一起在农场吃饭

**加分点**："不需要另外安排时间——送孩子来上课的时候顺便就做了"——时间成本几乎为0
**复购意愿**：强。"以后每次送孩子来上课我就报一个。"
**传播意愿**：会。拍了松林的照片发了朋友圈——"他在上课，我在隔壁做正念。各得其乐的周末。"
**优化建议**：这个场景下自然疗愈和自然教育的排课时间需要完全对齐——自然教育课9:00-10:30，自然疗愈也排9:00-10:00（提前30分钟结束，家长走去接）

### 角色C：农场主管（评估合作模式）

**自然疗愈的核心优势不在它自己赚了多少钱，在于它的"激活效应"——它激活了农场的一个时间段（清晨/傍晚）和一个人群（不带孩子的成年人），这两个之前都是空白的。**

合作模式下，农场几乎不需要投入（场地空着也是空着），唯一要解决的是"客户触达"——如何在农场的现有客户群和外部渠道让目标人群知道"农场有松林正念行走"。运营卫星每周发1次小红书+1次朋友圈，成本几乎为零，但需要坚持做。
