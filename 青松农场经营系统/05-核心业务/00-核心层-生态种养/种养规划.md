# 种养规划

## 第一优先级（当年见效，视觉丰富）
| 品类 | 引擎A用途 |
|:---|:---|
| 叶菜类（生菜/菠菜/油菜） | 柴火灶、火锅涮菜 |
| 番茄 | 沙拉、野餐篮 |
| 辣椒/茄子 | 炒菜、配菜 |
| 香草类（薄荷/罗勒/迷迭香） | 面包、饮品、烤肉佐料 |
| 散养蛋鸡（30-50只） | 早餐蛋、面包蛋液 |

## 季节轮作
| 季节 | 主要产出 | 看点 |
|:---|:---|:---|
| 春季 | 叶菜、香草 | 油菜花开 |
| 夏季 | 番茄、辣椒、玉米、鸡蛋 | 满畦挂果 |
| 秋季 | 南瓜、玉米、红薯 | 收获感，适合劳动换薪 |
| 冬季 | 温室叶菜、散养蛋 | 靠鸡和温室体现活力 |
