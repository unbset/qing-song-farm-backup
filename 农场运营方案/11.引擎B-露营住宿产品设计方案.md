# 引擎B（露营住宿）产品设计方案

> **创建日期**：2026-05-28
> **设计原则**：利用松林核心资源，提供差异化的户外停留体验
> **适用场景**：农场营业期间全时段

---

## 一、产品线总览

| 产品线   | 模式              | 目标客群              | 当前状态      |
| :---- | :-------------- | :---------------- | :-------- |
| 散客露营  | 按次收费，提供天幕/帐篷租赁  | 潍坊市区年轻群体、亲子家庭     | 运营中       |
| 长搭露营  | 年费制，客户自搭帐篷常驻    | 自由职业者、退休银发族、有幼儿家庭 | 运营中，已有十几户 |
| 团建/宴会 | 按人头套餐，含场地+活动+餐食 | 本地中小企业、幼儿园、宴会客户   | 运营中       |
| 小院共创  | 长期储备产品          | 热爱乡村生活的人群         | 待启动，缓缓图之  |

## 二、现有产品（运营中）

### 2.1 散客露营

**定位**：农场的引流入口和人气基底。

**模式**：
- 客户按次付费，农场提供租赁装备（帐篷、天幕、睡袋等）
- 客户在划定区域内自由选择营位
- 可叠加购买烧烤食材包

**定价参考**：

| 项目           | 定价       | 说明         |
| :----------- | :------- | :--------- |
| 散客入场（自带装备）   | 10元/位    | 含场地使用+基础服务 |
| 装备租赁（帐篷+防潮垫） | 30元/位    | 按次租赁       |
| 天幕租赁         | 50-80元/个 | 按次租赁       |

**运营要点**：
- 周末和节假日为高峰期，平日以长搭和团建为主
- 下午3点后集中入场，晚上10点后保持安静
- 烧烤区集中设置在远离松林主区域的位置（防火）

---

### 2.2 长搭露营

**定位**：稳定的年度现金流 + 农场人气基底。

**模式**：
- 年费制，客户在划定区域内长期搭设帐篷
- 客户拥有自己的"固定营位"，可随时来
- 农场提供公共设施（卫生间、淋浴、充电、水源）

**定价参考**：

| 档次   | 年费      | 说明           |
| :--- | :------ | :----------- |
| 基础长搭 | 3600元/年 | 月均300元，自己搭帐篷 |
| 升级长搭 | 5000元/年 | 带简易木平台       |

**运营要点**：
- 现有十几户是基础，目标是逐步扩到30-50户
- 每户每月至少巡查一次，了解满意度
- 长搭客户是农场最核心的口碑传播者，维护好他们的体验比拉新更重要

---

### 2.3 团建/宴会

**定位**：工作日现金流的填充器。

**模式**：
- 按人头打包套餐（含场地+活动+餐食）
- 不接定制套餐，只提供固定档位
- 活动内容由引擎B主理人执行（如需自然手作活动，向自然手作卫星采购）

**定价参考**：

| 档次 | 人均 | 内容 | 适用人数 |
|:---|:---|:---|:---|
| 基础团建 | 100-150元 | 松林拓展+自助烧烤 | 15-40人 |
| 标准团建 | 150-250元 | 松林拓展+大锅卤/窑烤+篝火 | 15-40人 |
| 升级团建 | 250-400元 | 含自然手作活动+宴席+住宿（如有） | 15-40人 |

**运营要点**：
- 工作日团建是农场淡季的生命线，需要持续维护企业客户关系
- 团建落地执行需要引擎B主理人全程在场
- 农村大席形式的宴会可作为差异化卖点（一次性上菜，服务成本低）

## 三、长期储备产品：小院共创

**状态**：待启动，缓缓图之。
**定位**：解决农场住宿问题的最终方案，同时吸引深度参与的核心人群。

### 3.1 产品定义

农场划出一定数量的地块（每块约100平米），招募共建共创人，在农场上建造自己的小木屋或土团屋。

每个小院包含：
- 一栋小型居所（木屋/土团屋）
- 户外厨房或烧烤区
- 自行种植的花园或小菜地

### 3.2 使用模式

共建人对小院拥有长久使用权，在使用方式上有双重选择：
- 自己居住：任何时候都可以来，自己打理小院
- 委托经营：自己不住的时候，由农场对外出租，双方按比例分成

### 3.3 启动路径

**不急于求成，按以下节奏推进**：

| 阶段 | 动作 | 目标 |
|:---|:---|:---|
| 第1步 | 言渊自己先建一个样板小院 | 跑通建造流程+做出可展示的成品 |
| 第2步 | 邀请1名内部成员或最活跃的长搭客户共建第二个小院 | 验证共建模式的吸引力 |
| 第3步 | 两个样板院投入运营（自住+对外出租），积累分成模型和运营数据 | 验证商业模型 |
| 第4步 | 通过样板院的传播吸引外部共建人主动询问，逐批增加 | 自然增长，不主动推广 |
| 第5步 | 视需求逐步扩展到10-20个小院，达到稳定规模 | 不追求50个 |

### 3.4 风险控制

- 每个小院的建造标准和安全规范由农场统一制定
- 外观风格可以个性化，但建筑规范和排污标准必须统一
- 委托经营的分成比例需签署正式合同
- 所有小院的建造在启动前必须确认土地使用合规性

### 3.5 这项产品的原因

解决住宿问题不是靠农场自己建客房，而是靠一群热爱乡村生活的人和农场一起建。这群人自己就是最好的内容团队、最好的传播节点、最好的口碑来源。他们不是来消费的客人，他们是农场生态的一部分。

## 四、人员配置

引擎B（露营住宿）现有产品由以下人员运营：

| 岗位 | 人数 | 说明 |
|:---|:---|:---|
| 露营住宿主理人 | 1人 | 全职，负责全部产品的日常运营 |
| 露营帮工/维护员 | 1人 | 全职或兼职，负责场地维护+装备管理 |

小院共创启动后，视规模增加专属管理员。
