[SOP编号] B-08
[SOP名称] 篝火台与用火安全管理
[执行人] 引擎B主理人
[替代人] 言渊
[执行时间] 篝火开始前1小时准备 → 全程监督 → 结束后1小时值守
[适用季节] 全年（禁火期禁止户外明火，须遵守当地防火规定）
[前置条件] 当日无大风预警（风力≥6级禁止篝火）；消防器材在位有效
[AI接口] Hermes对接天气预报API，每日推送火险等级；记录每次用火时间/人数/安全状态
[AI提醒] Hermes在客户预约篝火时推送火险等级和注意事项；点火前推送安全清单

---

### 一、篝火活动前准备

```
1. 环境检查
   - 篝火台区域清理（半径3米内无易燃物）
   - 地面洒水湿润（防火+减少扬尘）
   - 确认风向和风速（现场挂风向标或观察旗）
   - 若风力≥6级或火险等级过高，取消篝火活动

2. 物资准备
   - 防火水桶*2（每个不低于20L，装满水）
   - 灭火器*1（干粉灭火器，检查压力正常）
   - 防火毯*1（备用）
   - 手机满电、应急照明
   - 急救箱在位

3. 篝火台检查
   - 篝火台结构完好（无松动/破损）
   - 防火围挡完整
   - 柴火/木炭准备充足（提前一日的干燥柴火）
   - 点火工具（打火枪/火柴/点火器）
```

### 二、点火与活动期间管理

```
1. 点火
   - 客户到场后由引擎B主理人点火（客户不参与点火）
   - 点火前向客户进行2分钟安全说明：
     - 篝火区域范围，不可超越围挡
     - 不可向火中投掷易燃易爆品
     - 看管好儿童
     - 紧急情况下的疏散路线

2. 活动中监控
   - 引擎B主理人全程在场，不得离岗
   - 每15分钟巡查一次篝火状态
   - 关注客户行为（尤其饮酒客户）
   - 注意火势大小，过大时提示客户后退
   - 随时补充柴火，控制火势均匀

3. 互动节奏
   - 篝火开始：营造仪式感（火光映照下的开场）
   - 篝火中段：自由交流/游戏/唱歌
   - 篝火尾声：逐渐减弱火势
   - 全程保持良好氛围但不喧闹
```

### 三、灭火与清理

```
1. 篝火结束
   - 提前30分钟告知客户篝火即将结束
   - 停止添加柴火
   - 用沙土或水彻底熄灭余烬

2. 灭后确认
   - 用水浇透所有余烬
   - 用棍棒翻搅确认内部无余火
   - 灰烬温度降至手背可触摸（不烫手）
   - 保持篝火台观察30分钟后方可离开

3. 清理
   - 次日清理灰烬（冷却后）
   - 灰烬均匀洒入园土中（草木灰是肥料）
   - 篝火台恢复整洁状态
   - 补充防火物资（若消耗）
```

### 四、设备日常维护

```
1. 每日检查
   - 篝火台结构
   - 防火物资在位有效
   - 柴火干燥程度和储备量

2. 每周维护
   - 篝火台全面检查（焊接点/围挡/地面）
   - 防火物资更换（灭火器压力不足及时更换）
   - 柴火补充和翻晒

3. 季节维护
   - 雨季前加固篝火台防水
   - 秋冬季节前储备足量干柴
   - 禁火期篝火台关闭并张贴公告
```

### 五、验收标准

```
□ 篝火台区域已清理，无易燃物
□ 防火物资在位有效（水桶满/灭火器有效/防火毯在位）
□ 风力/火险等级已确认，符合点火条件
□ 点火前客户安全说明已完
□ 引擎B主理人全程在场
□ 灭火后确认无余火
□ 值守满30分钟后方可离开
□ Hermes已记录本次用火信息
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 篝火中突然刮大风 | 立即灭火，安排客户转移至室内 |
| 火势失控 | 使用灭火器或水桶灭火，疏散客户，拨打119 |
| 客户烧伤 | 冷水冲洗15分钟，严重者送医 |
| 客户酒后失控 | 劝离篝火区，安排同伴陪同回营位 |
| 柴火不足 | 使用备用柴火，控制火势减小或提前结束 |
| 防火物资被误用 | 立即补充 |

### 七、跨板块协作

- 篝火活动前通知**引擎A**准备篝火时段的热饮/小食
- 篝火结束协调**运营卫星**在次日跟进营位清理
- 篝火期间如有团建客户，与引擎B团建活动衔接

### 八、客户触点

- 篝火是露营体验的"高光时刻"，氛围感直接影响客户对农场露营的整体评价
- 篝火的"仪式感"比火本身更重要（开场点亮、围坐、音乐）
- 安全是底线，任何时候不可以牺牲安全换取体验
