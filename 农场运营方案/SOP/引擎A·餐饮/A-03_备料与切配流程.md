### 一、食材验收

```
1. 核心层食材验收
   - 核对种植养殖主管送来的蔬菜/鸡蛋品种和数量
   - 品质检查：叶菜无黄叶烂叶、根茎无腐烂、鸡蛋无破损
   - 称重确认，在Hermes记录入库量

2. 外采食材验收
   - 核对采购清单和实际到货
   - 检查生产日期和保质期
   - 肉类检查色泽/气味/冷藏温度
   - 干货检查包装完整性

3. 不合格品处理
   - 品质不合格的拍照记录，退回供应商或做堆肥
   - 在Hermes标记不合格原因
```

### 二、食材分类储存

```
1. 常温储存（阴凉通风处）
   - 土豆、洋葱、南瓜、大蒜、姜
   - 未开封的干货、调料、粮油

2. 冷藏储存（0-4°C）
   - 叶菜类（用湿厨房纸包裹保鲜）
   - 瓜果类（番茄/黄瓜/茄子）
   - 鸡蛋
   - 肉类（解冻后48小时内用完）
   - 乳制品、豆制品

3. 冷冻储存（-18°C以下）
   - 长期储备的肉类
   - 高汤/骨汤
   - 冷冻蔬菜（玉米粒/青豆）
```

### 三、切配标准

```
1. 蔬菜切配标准

   叶菜类（菠菜/油菜/生菜/韭菜）
   - 去根去黄叶，清水浸泡10分钟去泥沙
   - 沥干水分后切段（长度4-5cm）

   瓜果类（番茄/黄瓜/茄子/辣椒）
   - 清洗表面，去蒂
   - 番茄：切片或切块（厚度1.5cm）
   - 黄瓜：切片或拍碎
   - 茄子：切滚刀块或切片（厚度1cm）

   根茎类（土豆/萝卜/红薯/莲藕）
   - 去皮、清洗
   - 切片（0.3cm）或切块（2cm见方）
   - 土豆切后泡水防氧化

2. 肉类切配标准

   - 猪肉/牛肉：逆纹切薄片（0.3cm）
   - 鸡肉：切块（3cm见方）
   - 切片厚度均匀，确保成熟时间一致

3. 调味料准备
   - 基础调料提前备齐（葱姜蒜/花椒/辣椒/酱油/醋/盐/糖）
   - 火锅蘸料提前调制
   - BBQ腌料提前腌制（至少30分钟）
```

### 四、备料量计算

```
1. 散客备料
   - 根据Hermes预约人数+20%余量
   - 无预约日按基础量备料（如：叶菜5kg/肉类3kg/鸡蛋30个）

2. 团餐备料
   - 团建/宴会按确认人数备料（+10%余量）
   - 按餐标调整食材档次

3. 库存周转原则
   - 核心层食材当日用完优先
   - 外采食材先进先出
   - 每日备料量控制在当日消耗量+10%以内
```

### 五、验收标准

```
□ 所有食材已验收入库，不合格品已处理
□ 食材已按储存标准分类存放
□ 当日所需切配已全部完成
□ 切配规格符合标准
□ 备料量合理（满足当日需求+合理余量）
□ 操作台已清理，刀具砧板已归位消毒
```

### 六、异常处理

| 异常 | 响应 |
|:---|:---|
| 核心层食材供应不足 | 立即外采补充，调整菜单标注"限量供应" |
| 食材品质不合格 | 退回或做堆肥，通知种植养殖主管改进 |
| 备料量超出需求 | 可储存的下次优先使用，不可储存的员工餐消耗 |
| 刀具/设备损坏 | 使用备用刀具，损坏件标记维修 |
| 高峰期备料不足 | 现场紧急补充切配，通知运营卫星支援 |

### 七、跨板块协作

- 每日与**核心层·种植养殖主管**对接次日食材需求
- 切配过程中发现品质问题即时反馈核心层
- 备料量不足时通知**运营卫星**安排紧急外采
- 新菜品试制反馈给言渊和核心层

### 八、客户触点

- 备料和切配质量直接影响菜品口感和出餐速度
- 切配标准统一确保客户每次用餐体验一致
- 食材新鲜度是农场餐饮的核心竞争力
