# 利益共同体与财务透明机制

> **创建日期**：2026-05-29
> **适用阶段**：农场早期（尚未稳定盈利，团队从1人起步逐步扩到4人）
> **核心原则**：用"低底薪+后端分成+非金钱回报"代替高底薪，用财务透明保障分成可信

---

## 第一部分：为什么需要利益共同体

农场早期给不起高底薪。如果只靠底薪招人，招来的人不会把农场当自己的事干。

**解决方案不是"加底薪"——加了你扛不住。方案是：找不需要高底薪的人，用非金钱回报吸引，用真实的后端分成绑定。**

---

## 第二部分：早期找什么人——三条路径

核心思路：不追求"招到最优秀的人"，找到"有退路但想找事做的人"。

### 路径一：运营卫星负责人——找"有副收入的人"

| 画像 | 为什么他能接受低底薪 |
|:---|:---|
| 农场周边的主妇/妈妈——孩子上学后有空闲，家庭有丈夫收入支撑 | 需要"离家近+灵活时间+有点收入"，不是"养家的工资" |
| 退休但闲不住的人——55-65岁，有退休金，身体好 | 退休金够生活了，来做不是因为钱，是因为想做点事 |

**底薪**：2500-3000元/月  
**非金钱回报**：免费午餐 + 弹性时间 + 每月2次带家人来的招待名额  
**后端**：农场月净利润的5-8%（触发条件：月净利润连续3月达标后生效）

### 路径二：自然手作卫星主理人——找"生活方式转换者"

| 画像 | 为什么 |
|:---|:---|
| 想逃离城市坐班的年轻人——25-35岁，不想坐办公室 | 看的不只是钱，还有"这份工作有意思" |
| 孩子大了的妈妈——35-45岁，本地人，孩子上小学了 | 离家近、环境好、做喜欢手作比坐办公室有意思 |

**底薪**：2500-3000元/月  
**非金钱回报**：免费午餐 + 弹性时间 + 在松林里上班的环境  
**后端**：本人所在板块月营收的10-15%（从第1个月开始，不做任何等待）

### 路径三：种植养殖主管——找"本身就在种地的人"

| 画像 | 为什么 |
|:---|:---|
| 农场周边的老农户——50-65岁，自己家里也种菜 | 他本来就要种地的，多管一份地多一份收入 |
| 退休的农业技术员——有种植经验，退休了没事干 | 退休金够生活，来做是因为闲不住+喜欢种东西 |

**底薪**：3500-4000元/月  
**非金钱回报**：免费午餐 + 免费住宿（如有空房）  
**后端**：季度达标奖1000-2000元（考核土壤健康度、展示丰富度、供应达标率）

### 非金钱回报的价值换算

| 你能给的 | 市场价值/月 | 你的成本 |
|:---|:---|:---|
| 员工免费用餐（工作日） | 500-800元 | 极低（食材成本） |
| 免费住宿（如有空房/集装箱房） | 600-1500元 | 一次性投入 |
| 家人免费使用场地 | 几百元 | 场地空着也是空着 |
| 弹性工作制（不打卡） | 无价（尤其对有孩子的人） | 零成本 |
| 在松林里上班 vs 办公室 | 情绪价值高 | 零成本 |
| 可以带孩子/宠物上班 | 对有孩子的人价值极高 | 零成本 |

**"底薪2500+非金钱回报" ≈ 市场价的月薪4500-5500**

## 第三部分：后端分成怎么落地

### 三类人的不同机制

| 角色      | 底薪（元/月）   | 后端机制            | 触发条件            |
| :------ | :-------- | :-------------- | :-------------- |
| 运营卫星负责人 | 2500-3000 | 农场净利润的5-8%      | 月净利润连续3月达标后生效   |
| 自然手作主理人 | 2500-3000 | 本人板块营收的10-15%   | 从第1个月起执行（不做等待）  |
| 种植养殖主管  | 3500-4000 | 季度达标奖1000-2000元 | 按季度考核（土壤/展示/供应） |

### 为什么自然手作主理人从第1个月就分？

因为她直接创造收入。引流课68元×10人=680元，提成10%=68元。前期虽然少，但**"这个月多带了一节课，这个月就多拿了几十块钱"**——这个正向反馈本身就能激励她主动排课。

### 书面协议模板

```
利益共同体协议（摘要）
────────────────────────
参与人：___________
角色：___________

  从第4个月起，每月获得农场净利润的____%（建议5-8%）
  
  [自然手作主理人] 从到岗第1个月起，
  每月获得本人所在板块营收的____%（建议10-15%）

  获得季度奖金______元（建议1000-2000元）

  （预留部分的用途由言渊和主理人共同商议，
  可用于该板块的投入，也可在年底一次性发放）

四、退出：主理人离职后，后端分成自动终止

签署：______ 日期：______
```

## 第四部分：财务透明机制——后端分成可信的基础

后端分成的前提是：每个人能验证"自己的分成数字是对的"。没有财务透明，利益共同体就是空话。

### 三个动作保障可信

**动作1：统一收银系统**
- 所有对外收费走同一个系统（推荐：收钱吧/微信商家等）
- 引擎A、引擎B、手作零售、课程报名——全部从这一个系统出
- 每人每天下班前核对当天流水（5分钟）

**动作2：言渊每月花1小时填表**
- 月初第3个工作日内完成
- 收入部分：收银系统导出（半小时导出+整理）
- 支出部分：人工固定支出是确定的 + 采购有进货单 + 其他有付款记录

**动作3：每月30分钟经营月会**
- 全员参加，言渊念一遍数字
- 解释"这个月收入为什么高了/低了"
- 当场确认每个人的提成/分红金额
- **疑问当面解答**

### 透明与不透明的边界

| 透明 | 不透明 |
|:---|:---|
| 各板块月营收 | 引擎A的利润率详细拆解 |
| 各人工支出合计 | 具体每个人拿多少钱（隐私） |
| 月净利润 | 农场主的个人收入和使用 |
| 提成/分红的计算过程和结果 | 未被采用的预算提案 |

### 一个现实判断

> **早期信任的来源不是"第三方审计"，而是"我每个月的提成/分红都按时、按约定金额打到我账上了"。** 连续3个月按时按额支付，信任自然建立。
>
> 如果这个月亏了——公开。全员知道"这个月亏了，所以没有分红，但底薪照发"。亏损时也透明，信任才能成立。
