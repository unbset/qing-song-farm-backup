### 一、导师来源与招募

```
1. 导师来源渠道
   - 内部培养：农场员工中选拔有兴趣者
   - 社区合作：周边手作达人/退休教师/手工艺人
   - 线上招募：社群/手作爱好者群发布信息
   - 客户转化：在手作课程中发现有天赋的爱好者
   - 专业机构：与当地非遗传承人或手作工作室合作

2. 导师基本要求
   □ 具备至少1项手作技能（提供作品照片或视频）
   □ 有教学意愿和基本表达能力
   □ 喜欢自然环境、认同农场理念
   □ 周末/节假日能稳定出勤（兼职可接受）
   □ 无不良记录

3. 面试与试讲
   - 提交简历和作品集
   - 现场试讲一节30分钟的体验课
   - 评估维度：专业技能/教学能力/亲和力/与农场的契合度
   - 试讲评分≥80分可录用
```

### 二、导师档案管理

```
1. 档案内容
   - 基本信息（姓名/联系方式/身份证号）
   - 技能特长（手作方向/水平等级）
   - 可授课时段
   - 课酬标准
   - 培训记录和评估结果
   - 优秀教案存档

2. 资料管理
   - 所有导师档案在Hermes中建立
   - 资料完整性审核（签约导师需提供身份证复印件）
   - 导师资质证书（如有）存档并跟踪有效期
```

### 三、排课与调度

```
1. 排课原则
   - 周末/节假日优先安排最受欢迎的导师
   - 每位导师每周排课不超过4节（保证授课质量）
   - 新导师前3节课搭配资深导师指导

2. 排课流程
   每周日
   - 查看下周预约情况
   - 根据预约人数安排导师
   - 在Hermes中生成排课表
   - 推送给各导师确认

   课前1天
   - Hermes推送课程提醒给导师
   - 确认导师按时到场
   - 确认材料已备齐

3. 突发调课
   - 导师临时请假→优先安排备选导师
   - 无备选导师→取消课程+通知已预约客户
   - 客户临时取消→提前3小时通知导师取消
```

### 四、课酬与结算

```
1. 课酬标准

   初级导师
   - 课酬：课程定价的30%
   - 适用：新导师/试讲期

   中级导师
   - 课酬：课程定价的35%
   - 适用：授课≥20节/满意度≥4.5分

   高级导师
   - 课酬：课程定价的40%
   - 适用：授课≥50节/满意度≥4.8分/有自主开发课程能力

   资深合作导师（合作分成模式）
   - 农场提供场地+客户+材料，导师提供技术+教学
   - 分成比例：农场60% / 导师40%

2. 结算方式
   - 月结（次月5日前结算上月课酬）
   - 签约导师通过银行转账
   - 兼职导师可通过微信转账
```

### 五、导师培训与评估

```
1. 岗前培训
   - 农场理念和文化介绍
   - 客户服务标准培训
   - 安全注意事项培训
   - Hermes系统基础操作（签到/记录）

2. 月度评估
   评估维度（满分5分）：
   - 客户满意度评分（占比40%）
   - 课程执行准时率（占比20%）
   - 材料损耗控制（占比20%）
   - 团队协作满意度（占比20%）

3. 晋升机制
   - 连续3个月评估≥4.5分的导师晋升一级
   - 月度评估≤4.0分的导师给予改进建议
   - 连续2个月评估≤4.0分解除合作
```

### 六、导师关系维护

```
1. 日常沟通
   - 建立导师微信群
   - 每周同步农场活动信息
   - 及时解答问题和反馈

2. 季度活动
   - 每季度1次导师交流会
   - 新课程共创工作坊
   - 导师作品联展

3. 年度优秀导师评选
   - 年度授课最多/满意度最高/课程最受欢迎
   - 奖励：奖金+农场产品礼包
```

### 七、验收标准

```
□ 导师档案完整（基本信息+技能+排课+课酬）
□ 排课表准时发布，导师确认率100%
□ 导师按时到课率≥95%
□ 客户满意度评分≥4.5分
□ 课酬按期结算
□ 月度评估按时完成
□ 导师无投诉/冲突记录
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 导师临时请假 | 安排备选导师或取消课程并致歉客户 |
| 导师授课质量下降 | 面谈了解原因，提供培训或调整岗位 |
| 导师与客户冲突 | 即时调解，记录事件，评估是否继续合作 |
| 导师要求提高课酬 | 根据评估结果和农场预算协商 |
| 导师流失 | 分析原因，启动招募储备 |

### 九、跨板块协作

- 导师课程中的特殊材料需求：与**H-02材料管理**协调
- 团建客户需要定制课程：与**引擎B**对接课程方案
- 导师档期与农场活动冲突：与**O-07活动排期**协调
- 导师推荐给其他板块（如带领客户参观）：与**运营卫星**共享人才资源

### 十、客户触点

- 导师是手作体验的核心，导师的水平和态度直接决定课程价值
- 一个好的导师能让客户从"随便玩玩"变成"我想再来学"
- 导师的"故事"（退休教师/手工艺人/本地匠人）本身也是农场内容的一部分
