[SOP编号] O-08
[SOP名称] 客户满意度调查流程
[执行人] 运营卫星成员
[替代人] 言渊
[执行时间] 每次消费后24小时内推送 / 月度汇总分析 / 季度全面报告
[适用季节] 全年
[前置条件] 客户已完成消费或活动
[AI接口] Hermes生成调查问卷、自动收集和分析数据、生成满意度报告
[AI提醒] Hermes在客户离场后24小时推送调查邀请；月度分析报告自动生成提醒

---

### 一、调查方式

```
1. 调查渠道
   - 小程序推送（首选方式，自动触发）
   - 微信私聊（大客户/团建客户/深度体验客户）
   - 社群内公开征集（月度/季度）
   - 现场口头收集（引擎A/引擎B消费后）

2. 调查时机
   - 引擎A用餐：结账后+1小时推送
   - 引擎B住宿：退房后+1小时推送
   - 手作课程：课程结束后即时推送
   - 团建活动：活动结束后当天推送
   - 参观体验：离场后推送
```

### 二、调查内容

```
1. 通用问题（每项1-5分）

   整体评价
   - 本次在农场的整体体验如何？
   - 是否会推荐给朋友？
   - 是否愿意再次到访？

   服务评价
   - 服务人员的态度和响应速度
   - 服务人员的专业度

   环境评价
   - 农场环境整洁度
   - 设施使用便利性

2. 板块专项问题

   引擎A·餐饮
   - 菜品口味
   - 出餐速度
   - 食材新鲜度
   - 价格合理性

   引擎B·露营
   - 入住/退房效率
   - 营位环境和设施
   - 公共区域清洁度
   - 夜间安静程度

   自然手作
   - 课程趣味性
   - 导师专业度
   - 作品效果
   - 课程时长

   核心层·体验
   - 采摘体验满意度
   - 讲解/引导质量
   - 农产品品质

3. 开放性问题（非必填）
   - 本场最满意的是什么？
   - 有什么需要改进的地方？
   - 你希望在农场体验到什么？
```

### 三、数据收集

```
1. 自动收集
   - Hermes自动推送调查问卷
   - 自动回收和统计评分
   - 自动关联客户档案和消费记录

2. 手动收集
   - 现场口头反馈（运营卫星在服务中收集）
   - 社群内意见和建议
   - 平台评价（大众点评/美团/小红书）

3. 收集目标
   - 月度回收率：到店客户的30%以上
   - 每次活动/消费都有对应的评价
```

### 四、数据分析

```
1. 每日关注
   - 低于3分的评价即时查看
   - 发现问题即时反馈对应板块

2. 月度分析（月度最后1天）
   - 整体满意度评分（均值）
   - 各板块评分排名
   - 高于4.8分的亮点分析
   - 低于4.0分的问题分析
   - 客户常见建议汇总
   - 投诉处理结果跟踪

3. 季度报告（季度最后1周）
   - 满意度变化趋势（与往期对比）
   - 各板块提升/下降分析
   - 客户需求变化洞察
   - 改进措施效果评估
   - 下季度改进重点
```

### 五、反馈闭环

```
1. 差评处理
   - 低于3分：运营卫星24小时内联系客户
   - 了解具体原因
   - 给出改进承诺或补偿
   - 在Hermes记录处理结果

2. 好评利用
   - 4.5分以上：征得客户同意后用于宣传
   - 真实好评截图在社群/朋友圈传播
   - 优秀员工在晨会上通报表扬

3. 建议落实
   - 可行建议：明确责任人和完成时限
   - 不可行建议：记录在案，定期重新评估
   - 进度同步给提出建议的客户
```

### 六、验收标准

```
□ 满意度调查在客户离场后24小时内推送
□ 月度回收率≥到店客户30%
□ 低于3分的评价24小时内跟进处理
□ 月度分析报告按时完成
□ 差评100%回访并记录
□ 客户建议有落实或回复
□ 满意度季度趋势分析完成
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 客户拒绝填写调查 | 不强求，口头收集一句话评价 |
| 连续差评同一板块 | 该板块全面复盘和整改 |
| 调查回收率过低 | 增加现场引导/提供小礼品激励 |
| 客户差评后在平台发布 | 公开回复+私聊跟进 |
| 调查数据与感知不符 | 交叉验证（现场观察+员工反馈） |
| 客户在评价中提具体人名 | 正面评价表扬、负面评价私聊该员工 |

### 八、跨板块协作

- 月度满意度报告同步至各板块负责人
- 差评反馈推送至对应板块主理人
- 改进措施纳入**G-02晨会**跟踪
- 好评用于**O-06社群运营**内容素材

### 九、客户触点

- 满意度调查不是"完成任务"，而是"我在认真听你说"
- 客户填写了调查就期待被回应，差评没有回访就是二次伤害
- 让客户看到"上次的建议这次来已经改了"，信任感倍增
