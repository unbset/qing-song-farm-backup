# 青松农场启动阶段与闸门设计

> **创建日期**：2026-05-28
> **基于**：星形结构（核心+引擎+卫星）
> **适用状态**：引擎（餐饮+露营）和卫星（自然手作）已运行且有客户基础；核心（生态种养）尚未启动，无负责人

---

## 阶段总览

```
                      ┌─ 闸门① ─┐                  ┌─ 闸门② ─┐
  ────── R0 ──────→   │         │  ──── R1 ────→   │         │  ──── R2 ────→  R3
  核心到岗+物理准备    │  → R1  │  核心播种+可参观   │  → R2  │  核心小规模供应   │  核心扩产+升级
                      └─────────┘                  └─────────┘
```

**时间说明**：不设硬性时间节点。各阶段过关条件达到即进入下一阶段，未达到则继续做。1个月达到最好，3个月还达不到则需要排查结构性问题，找到原因并进行调整。

---

## 阶段R0：核心搭建期
**前提**：引擎A/B和卫星正常运营，核心为零。种植养殖主管+运营主管招聘已启动，目标第1个月内双到岗。
**目标**：种植养殖主管+运营主管到岗并完成交接，核心物理空间准备就绪。

### 核心任务

| 任务           | 说明                        | 执行人   |
| :----------- | :------------------------ | :---- |
| 种植养殖主管入职交接+初步培训 | 到岗前2周言渊全程带：认识场地、认识流程、认识人 | 言渊 |
| 划定种植区+鸡舍位置   | 20亩种植区+鸡舍，确定围栏和参观路线       | 言渊+帮工 |
| 启动堆肥         | 收集厨余+落叶+秸秆，开始堆肥（周期长，越早越好） | 帮工    |
| 启动首批酵素       | 至少5桶，贴上日期标签和配方，放在显眼位置     | 言渊或帮工 |
| 招聘银发种植顾问（备用） | 退休农技员，每周来1-2次，在种植主管适应期兜底 | 言渊 |
| 运营主管入职交接+初步培训 | 到岗前2周言渊全程带：认识人、认识场地、认识流程 | 言渊 |

### 闸门①：R0→R1

**全部达标后方可进入R1**：

| 指标           | 达标线              | 为什么                    |
| :----------- | :--------------- | :--------------------- |
| 种植养殖主管到岗+完成交接 | 已入职，完成场地/流程/人员交接 | 无人则无法开始 |
| 银发顾问到位       | 已找到可兜底的人选        | 防止种植养殖主管到岗后因不适应迅速离职，出现空窗 |
| 种植区+鸡舍物理准备完成 | 地块划定/翻土完成/鸡舍打扫可用 | 人到就能直接开工               |
| 第一批酵素已启动     | 至少5桶，贴上日期标签      | 3个月后才能用，越早越好           |

## 阶段R1：核心播种期（到岗后前3个月）

**目标**：核心有东西可看，但不考核产出量。

### 核心任务

| 任务 | 说明 | 执行人 |
|:---|:---|:---|
| 5-8个易成活品种下种 | 叶菜为主，追求"客户能看到菜在长"而非产量 | 种植养殖主管 |
| 鸡舍启动 | 首批50-80只，先跑通流程 | 种植养殖主管 |
| 可参观路线成型 | 菜地→鸡舍→酵素桶→堆肥区，走一圈看完 | 种植养殖主管+言渊确认 |
| 引擎A继续外采蔬菜 | 这3个月不要求核心供应达标 | 引擎A主理人 |

### 闸门②：R1→R2

**全部达标后方可进入R2**：

| 指标 | 达标线 | 低于达标线怎么办 |
|:---|:---|:---|
| 可展示参观点 | ≥5处（菜地区+鸡舍+酵素桶+堆肥区+至少1个其他） | 投入不足→追加展示投入；品种过少→加种 |
| 第一批蔬菜可采收 | 至少1个品种已进入采收期 | 种植计划有误→调整品种和时序 |
| 客户自主参观率 | 连续两周，到店客户中主动走向种植区的比例≥20% | 参观路线不吸引人→优化路线引导和视觉 |
| 种植养殖主管可独立接待参观 | 无需言渊陪同，能独立讲解+答疑 | 培训不足→安排模拟演练+话术整理 |

---

## 阶段R2：核心验证期（第4-8个月）

**目标**：核心开始小规模供应引擎，客户对"生态"的感知真实落地。

### 核心任务

| 任务 | 说明 | 执行人 |
|:---|:---|:---|
| 引擎A蔬菜自供率逐步提升 | 从0→10%→20%→30%，平滑过渡 | 种植养殖主管+引擎A主理人 |
| 引擎B烧烤食材包部分自供 | 核心供应部分蔬菜/蛋，不足部分外采 | 种植养殖主管+引擎B主理人 |
| 首批5桶酵素投入使用 | 3个月已到，效果可见 | 种植养殖主管 |
| 劳动换薪启动测试 | 邀请2-3组老客户参与堆肥/喂鸡/摘菜 | 卫星+种植养殖主管 |

### 闸门③：R2→R3

| 指标 | 达标线 | 低于达标线怎么办 |
|:---|:---|:---|
| 引擎A蔬菜自供率 | ≥30%且稳定，客户无负面反馈 | 不能一次性切换，口味差异需平滑过渡 |
| 客户参观率 | ≥30%的到店客户参观了种植区 | 展示区不够吸引→加互动环节（可触摸/可拍照） |
| 种植养殖主管独立接待能力 | 可独立完成参观讲解+答疑+劳动换薪引导 | 培训不足→增加模拟接待频次 |
| 劳动换薪测试完成 | 至少完成2组接待，有纸质或口头反馈 | 流程未跑通→简化流程，降低执行门槛 |

---

## 阶段R3：常态化运营期（第9个月起）

**目标**：核心扩产，卫星课程升级，农场进入三层协同运转。

**核心任务**：

| 任务 | 说明 |
|:---|:---|:---|
| 核心扩产 | 增加蔬菜品种至10种以上；鸡群规模视引擎需求逐步增加至150只左右 |
| 卫星课程升级 | 推出含核心深度参与环节的升级课程（如"半日农耕体验"、"酵素制作全流程课"等） |
| 统一销售渠道正式上线 | 小程序商城+会员体系，由卫星运营 |
| 月度复盘制度化 | 各单元月度经营简报+言渊汇总 |

**R3不再设硬性闸门，进入常态化运营。此后所有迭代通过周反馈+月度复盘完成。**

---

## 各阶段提醒事项

### R0阶段
- 种植养殖主管的到岗是核心层启动的前提。到岗前不要为了"让核心看起来有东西"而随意种点什么——客户看到杂乱的菜地反而会减分。但言渊可以启动堆肥+酵素制作（不依赖种植主管即可开工）。
- 酵素和堆肥不需要等人，先启动。主管到岗时直接有可用的酵素
- 银发顾问是为"全职到岗后不适应而离职"这个大概率事件兜底的，不是可选项

### R1阶段
- 前2个月不主动宣传"我们有生态种植了"——等第一批菜长起来、视觉上可看了再纳入参观路线
- 不要追求产量，追求"客户看到后愿意拍照"。菜地好不好看的判断标准是：客户走过去了会不会掏出手机

### R2阶段
- 引擎A的供应切换要平滑。不要某周一突然用核心蔬菜完全替代外采——客户会尝出差异，可能误以为品质下降。逐步提高自供比例，让口味过渡自然
- 建议R2初期让引擎A的帮工每天去种植区自己摘菜（而不是核心配送）——通过"自己去摘"建立对新供应方式的体验和信任
- 劳动换薪第一轮测试选老客户（参加过课程、对农场已有信任的人），不用面对完全陌生的人增加执行难度

### R3阶段
- 进入常态化后，核心的预算依然作为固定项优先划出，不可被其他单元挪用
- 言渊在月度复盘中持续关注三个先行指标：客户参观率、感恩续约率、老带新占比。这三个指标只要在缓慢上升，就说明方向没错

# 前期业务的衔接

## 一、露营住宿

### 核心到岗前（当前 → R0/R1期间）

露营住宿保持现有运营节奏。核心启动带来的变化还没有产生，不做额外变动。

| 工作方向 | 具体做什么 | 备注 |
|:---|:---|:---|
| **维持现有客户** | 长搭客户月度问候持续做，散客周末服务照常，团建订单照接 | 长搭是当前农场的"人气基底"和稳定现金流，不能失守 |
| **优化团建产品** | 在现有套餐基础上，试增1-2个不需要核心支撑的新活动环节 | 比如：松林寻宝、篝火故事会、露天电影——利用现有松林资源，不依赖核心 |
| **内容产出** | 每周1条短视频，以松林场景为主 | 账号持续更新，积累素材和粉丝 |
| **观察和记录** | 记录客户闲聊中提到的"农场缺什么"、"如果有了什么就更好了" | 这些信息是对核心建设方向很有价值的参考 |

**关键提醒**：不要在这个阶段给客户承诺"以后会有生态种养"。种植养殖主管还没到、种植还没开始，说了但做不到的情况对信任的伤害很大。

---

### 核心到岗后（R1中后期开始）

核心有了可看的东西之后，露营住宿逐步把核心融入体验。

| 工作方向 | 具体做什么 | 备注 |
|:---|:---|:---|
| **烧烤食材包升级** | 从全部外采，逐步将蔬菜/蛋替换为核心产品 | 替换节奏跟随R2阶段的供应能力，不平滑切换 |
| **长搭客户增值** | 向长搭客户开放种植区优先参观权——"你是长搭客户，所以可以优先预约" | 让长搭客户感到"专属感"，增强续约意愿 |
| **新增体验选项** | 在团建套餐中增加一个可选环节："清晨菜园唤醒体验"（早起摘菜+简单农事） | 作为团建套餐的增值选项，不是标配，不增加基础套餐复杂度 |
| **卖点升级** | 对外宣传口径从"松林露营"逐步过渡到"在真正的农场里露营" | 话术随核心进展自然变化，不要一次全换 |

## 二、自然手作卫星（自然教育/手作体验）

### 核心到岗前（当前 → R0/R1期间）

当前的课程（松针纯露、松塔香、松针皂等）已形成自己的特色，继续做。同时为核心启动后的课程升级做准备。

| 工作方向 | 具体做什么 | 备注 |
|:---|:---|:---|
| **现有课程继续跑** | 引流课（68元/人）持续排课，周末+假期正常开班 | 保持课程节奏，不要因为核心没起来就不开课。客户在就行 |
| **积累种子客户** | 每次课记录报名家长的联系方式 | 这些人未来是核心课程的第一批体验者 |
| **优化现有课程内容** | 在纯露/松塔香等课程中，不动声色地增加一小段关于"生态种植"的讲解 | 不需要提"我们以后会有"，只需要说"好的植物来自好的土壤"——先给客户埋下认知种子 |
| **观察课程素材需求** | 记录"如果有了种植区，我可以在课程里增加什么环节" | 等核心建好时，可以直接落地，不需要重新规划 |

**关键提醒**：不要在这个阶段为了"看起来有生态"而临时设置菜地参观——没有真正在种的东西时，带客户去看一片空地反而不好。让课程靠现有松针资源维持即可。

---

### 核心到岗后（R1中后期开始）

核心有了可看的东西之后，自然手作卫星可以推出含核心环节的升级课程。

| 工作方向 | 具体做什么 | 备注 |
|:---|:---|:---|
| **课程升级：增加核心环节** | 引流课增加15-20分钟的"农场参观"环节——带学员走到种植区，看看正在生长的蔬菜和鸡群 | 这个环节不改变课程定价，只是提升体验丰富度，为后续深度课做铺垫 |
| **推出新的引流课方向** | 基于核心素材推出新课程方向，如："酵素探秘课"、"小农夫的半天"、"从种子到餐桌"等 | 与现有松针课程并列，不替换。增加引流课的多样性 |
| **深度课升级** | 深度课（198元/人，2-3小时，不含餐）增加"亲手劳动"环节——让学员在种植区体验15-20分钟的农事操作（移栽、覆盖、制作酵素等） | 这是自然手作卫星"拉长停留时间、增加信任深度"的关键手段 |
| **劳动换薪衔接** | 深度课结束后，自然手作卫星主理人可在课后跟进中提及劳动换薪，作为后续推荐 | 不需要当场推销，只需要让客户知道有这个选项。课后3天微信里带一句即可 |
| **课程定价调整** | 引流课保持68元不变（依然不是利润中心），但深度课可适当上调价格（增加了核心体验环节，价值感提升） | 调整幅度不超过20%，保持竞争力 |

## 四、关于餐饮的简要说明

用户未要求展开餐饮计划，仅简要记录其当前状态供参考：
- 目前1位厨师在岗，日常出餐能维持
- 食材全部外采
- 核心到岗前：维持当前运营和外采模式，不做变动
- 核心到岗后：逐步纳入核心供应的蔬菜和蛋（跟随R2阶段的供应进度，不平滑切换）
