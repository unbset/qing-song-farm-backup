# 青松农场组织架构设计方案（V2.0）

> **基于**：星形结构模型（核心/引擎/卫星）
> **设计日期**：2026-05-28
> **替代**：旧的"6个平铺阿米巴"结构
> **核心原则**：不同层级的单元承担不同角色，用不同的考核标准，不以利润为唯一标尺

## 二、各单元详细定义

### 第1层：核心 — 战略成本中心

**定位**：农场的信任底座，所有上层业务差异化的来源。

**负责人**：种植养殖主管

**核心职责**：
1. 生态生产（种植、养殖、酵素、堆肥）——保证农场有"真实的东西可看"
2. 可展示度——不是关门种地，而是"任何时候客户走进农场都能看到生态生产的某个环节"
3. 客户参与通道——劳动换薪的执行接口（客户来农场做什么、怎么参与、谁带领）

**考核指标（不是收入）**：

| 指标      | 说明             | 目标参考        |
| ------- | -------------- | ----------- |
| 土壤健康度   | 有机质含量、蚯蚓密度、pH值 | 每季度可量化检测    |
| 展示丰富度   | 种植品种数量+可参观环节数  | ≥8种作物+5个参观点 |
| 客户参观率   | 到店客户中主动参观种植区比例 | ≥40%        |
| 内部供应达标率 | 餐饮/露营下单的供应满足率  | ≥80%        |
| 信任转化率   | 参观后购买农产品/认养的比例 | ≥15%        |
**成本来源**：由引擎按比例分摊基础设施费覆盖。

**为什么这样设计**：核心最容易被利润考核扭曲——一旦要求它盈利，就会砍掉"不赚钱但需要展示"的品种，减少可参观的环节。把利润压力拿掉，它才能专心做好信任底座这个本职工作。

---

### 第2层：引擎 — 利润中心

**定位**：农场的造血器官，养活自己和核心。

#### 单元A：餐饮

**负责人**：餐饮主理人

**核心职责**：
1. 室内餐运营（日常现金流基本盘）
2. 室外餐（中心厨房自取+DIY体验）
3. 窑炉产品（面包+披萨）
4. 向其他单元供应餐食（露营烧烤食材包、自然体验课午餐）

**考核指标**：
- 月/季度净利润
- 食材成本率 ≤ 35%
- 客户满意度 ≥ 4.5/5
- 内部供应响应时效

**协作备注**：减脂餐和伴手礼的销售归卫星，引擎A只负责生产。卫星定方案和定价，引擎A按标准制作。

#### 单元B：露营住宿

**负责人**：露营住宿主理人

**核心职责**：
1. 散客露营（引流+现金流）——模式A 9.9元（自带装备）/ 模式B拎包入住（农场提供装备+食材）
2. 长搭露营（锁客+稳定收入）——年费3600元/100㎡小院
3. 团建/宴会（工作日填充+高客单价）——获客+接待+回访全流程
4. 小院共创（长期储备产品）——先建样本，等人来找，缓缓图之
5. 活动策划（四季庆典+自然运动会）——每季度1次大型活动，全农场协同

**考核指标**：
- 月/季度净利润
- 长搭续约率 ≥ 80%
- 旺季周末场地利用率 ≥ 70%
- 团建客户满意度 ≥ 4.5/5

**利润分配**：每个季度，两个引擎各自净利润的10%-15%（预估值，测算方案见附件3：[[6.3组织架构设计方案--附件3：基础设施费比例的计算方法]]）划拨为"基础设施基金"，用于覆盖核心成本+农场公共维护费用。剩余净利润由各单元主理人与农场按规则分配。

---

### 第3层：卫星 — 费用中心

**定位**：不追求独立盈利，考核获客数、转化率、传播效果。

**卫星一：自然手作卫星**

**负责人**：自然手作卫星主理人（初期可由言渊兼任）

**产品线**：
1. 自然教育（引流课68元/深度课198元/节气年卡1280-1680元）——均不含餐，课后客户自行在引擎A消费
2. 手作体验（驱蚊膏/手工皂/洗发液/松塔香/纯露/合香珠等）——体验课+零售复购
3. 自然探索营（7-14岁独立营，半日198-298元/全日398-598元）
4. 自然生日会（4-10岁亲子派对，980-1680元/场）
5. 成人自然疗愈（合作模式：松林正念行走/颂钵/晨间瑜伽，68-168元/人）

**内部协作**：自然教育课（孩子上课）与成人疗愈（家长参加）同步排课，实现"孩子上课+家长疗愈+课后一起吃饭"的组合。

**考核指标**：引流课转化率、年卡续费率、手作零售复购率

**卫星二：运营卫星**

**负责人**：运营卫星负责人（办公室主任/副总角色）——1人

**六大职能**：
1. 公共环境管理（P0）：停车场/公厕/步道/垃圾桶的每日巡查+问题闭环
2. 安全与应急（P0）：急救箱/灭火器/防火巡查/应急预案/意外事件到场协调
3. 品牌内容（P0）：统一账号运营、各板块内容审核发布、品牌调性标准、月度数据汇总
4. 客户关系管理CRM（P1）：客户信息统一记录、交叉推荐、老客户维护、投诉受理
5. 线上零售与商城（P1）：微店运营、各板块零售产品上架销售与配送
6. 行政协调（兜底）：资质维护、采购协调、活动排班

**工作方式**：协调多于执行。发现问题→通知责任人→追踪闭环。不直接执行各板块的业务。

**考核指标**：问题闭环时效、品牌内容执行率、客户数据完整度

**卫星三：田园摄影卫星（项目制，合作模式）**

**负责人**：不设专职岗，由运营卫星对接合作摄影师

**产品形态**：
1. 跟拍服务（客户活动时跟拍，398-698元/组，摄影师50%/农场50%）
2. 场景快拍（大型活动中设拍照点，19.9元/张或98元/5张）
3. 内容生产（对内：客户授权后照片入库，作宣传素材）

**核心客群**：两类并行——① 已在农场的客户（亲子/情侣顺手拍一组）；② 55-70岁中老年女性（专程来圆田园梦，工作日为主）。凡朴农场模式证明中老年群体是田园摄影最大市场，工作日为主要客流时段，填补农场平日空白。

**启动原则**：不自雇摄影师，找潍坊城区自由亲子摄影师合作分成。有单再约，零固定成本。现有客户中自然转化，积累20组作品后正式宣传。

**考核指标**：合作摄影师满意度、月均接单量、客户授权照片入库量

**为什么不能是利润中心**：卫星的核心价值不在赚钱。如果考核利润，自然体验就会涨价（客户减少），内容预算就会砍掉（传播下降），田园摄影就会追求客单价（口碑变差）。让它专心做"把更多人拉进来"这件事。

## 三、内部成本核算与资源流转规则

### 4.1 总账原则

农场只有一个财务口径。所有收入进入同一个账户，所有支出从同一个账户出。不做内部结算、不做资金划转、不做独立核算。

### 4.2 引擎管理台账

利润中心的两个引擎分别记录两张台账：

**收入台账**：引擎A（餐饮）和引擎B（露营住宿）各自统计自己的直接对外销售收入，按周或月汇总。

**直接成本台账**：各自统计自己能直接决定的成本——食材采购、人工排班、装备维护、小型物料等。不含核心供应品（菜、蛋等）的"内部价"——核心的农产品直接计入总账生产成本，不从引擎成本走。

这两张台账的作用只有一个：**评估引擎的经营表现，作为定目标和分奖金的管理参考。** 不需要对账、不需要结算、不需要月底划账。

### 4.3 非利润单元的成本归属

| 科目 | 归属 |
|:---|:---|
| 核心全部成本（人工+种子+饲料+维护等） | 总账→生产成本 |
| 卫星全部成本（课程物料+推广费用等） | 总账→营销费用 |
| 共享职能成本（工具订阅+商城费用等） | 总账→管理费用 |
| 言渊薪酬+场地公共水电+保险+税费 | 总账→管理费用 |

所有成本最终都从利润池（引擎创造的利润）中支付。不需要分摊比例，不需要计提公式。

### 4.4 管理工具

初期用一本简单的收支台账即可：

| 月份  | 总收入 | 引擎A收入 | 引擎B收入 | 总成本 | 生产成本 | 营销费用 | 管理费用 | 净利润 | 备注  |

## 四、协作规则

### 5.1 冲突优先级

当多个单元争夺同一资源时：
```
核心展示需求 > 引擎客户接待 > 卫星引流活动
```

### 5.2 仲裁机制

两个负责人无法达成一致时：
1. 先自行协商一次（24小时内）
2. 无法解决→提交言渊裁决
3. 裁决以"核心优先"为第一原则
4. 裁决结果写入文件，作为后续类似场景的参考依据
