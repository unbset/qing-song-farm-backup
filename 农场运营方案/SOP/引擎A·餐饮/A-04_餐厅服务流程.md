### 一、客户到店接待

```
1. 迎接入座
   - 微笑迎接，询问人数
   - 引导至合适座位（家庭→靠窗/宽敞位；情侣→安静位；团建→长桌区）
   - 提供菜单和饮用水
   - 告知今日推荐和时令特色

2. 特殊需求确认
   - 是否有儿童（提供儿童座椅）
   - 是否有饮食禁忌（素食/过敏/忌口）
   - 是否赶时间（调整出餐优先级）

   [客户此时：饿了/好奇/在判断这家店怎么样]
```

### 二、点餐服务

```
1. 点餐推荐
   - 先推荐招牌菜和时令菜（来自核心层当日食材）
   - 根据人数推荐合适份量（减少浪费）
   - 荤素搭配建议
   - 饮品推荐（夏季推荐农场凉茶/冬季推荐热饮）

2. 点餐确认
   - 复述菜单确认无误
   - 告知预计等候时间
   - 询问是否需先上饮品/小食
```

### 三、用餐中服务

```
1. 上菜服务
   - 凉菜/饮品尽快上（5分钟内）
   - 主菜按顺序上（先素后荤/先淡后重）
   - 上菜时报菜名
   - 火锅类：先上锅底和蘸料 → 再上荤菜 → 再上素菜
   - BBQ/柴火灶：开火指导→提供基础调料→后续补充

2. 巡台服务
   - 每10分钟巡台一次
   - 观察：茶水是否需要加/菜是否上齐/是否有招手需求
   - 换骨碟（如有需要）
   - 询问口味是否合适

3. 特殊场景服务
   - 儿童：优先出餐（儿童不耐饿）/提供儿童餐具
   - 老人：推荐软烂菜品/提醒菜品烫口
   - 生日：配合客户安排庆祝环节
```

### 四、结账与送别

```
1. 结账
   - 确认所有菜品已上齐
   - 询问用餐体验（一句话）
   - 主动提供会员优惠/折扣提醒
   - 提供付款码或现金结算

2. 送别
   - 感谢光临
   - 提醒带好随身物品
   - 送别语："欢迎下次再来，下周有新菜品"
```

### 五、翻台准备

```
1. 翻台清理
   - 桌面餐具收拾（先收大盘、再收小盘、最后收杯子）
   - 桌面擦拭消毒
   - 地面清扫（明显垃圾/油渍）
   - 补充纸巾和调料

2. 翻台标准
   - 翻台时间不超过8分钟
   - 下一桌客人入座前桌面已干爽
```

### 六、验收标准

```
□ 客户到店2分钟内完成引导入座
□ 点餐后5分钟内上饮品
□ 凉菜15分钟内上齐/热菜30分钟内上齐
□ 巡台频率达标（每10分钟）
□ 客户未主动招手即获得服务
□ 结账过程顺畅无差错
□ 客户评价≥4.5分
```

### 七、异常处理

| 异常 | 响应 |
|:---|:---|
| 出餐时间过长 | 先上小食安抚，告知预计时间，致歉 |
| 菜品口味问题 | 无条件更换，回收菜品记录问题原因 |
| 客户催单 | 确认订单，告知优先处理进度 |
| 儿童哭闹 | 提供小玩具或画笔，加速该桌出餐 |
| 客户醉酒 | 停止供酒，提供茶水/蜂蜜水，联系同伴 |
| 高峰期产能不足 | 限流或延长等候时间，排队客户提供饮品 |

### 八、跨板块协作

- 向**核心层**反馈菜品受欢迎程度，指导种植优先级
- 向**运营卫星**通报翻台情况，便于引导新客户
- 团建/宴会餐标准提前与**引擎B**对接
- 食材品质问题即时反馈**种植养殖主管**

### 九、客户触点

- 餐厅服务是引擎A的"产品交付"环节，服务温度决定客户对农场餐饮的最终评价
- 等待时间是客户最敏感的环节，不要让客户"空等"
- 巡台时一句"今天的菜还合口味吗"比任何标准化话术都有效
- 儿童和老人的体验影响家庭客户的复购决策
