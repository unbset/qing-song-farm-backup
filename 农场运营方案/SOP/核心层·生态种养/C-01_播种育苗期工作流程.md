[SOP编号] C-01
[SOP名称] 播种育苗期工作流程
[执行人] 种植养殖主管
[替代人] 言渊
[执行时间] 每天（2-3月 / 8-9月）
[适用季节] 春播期2-3月 / 秋播期8-9月
[前置条件] 全年种植计划（C-00）已制定，种子/育苗土/育苗盘已备齐
[AI接口] 每天在Hermes中记录播种育苗进度和出苗情况
[AI提醒] Hermes根据C-00种植计划，在每批播种前3天推送备种提醒；播种后每日推送检查提醒

---

### 一、本阶段工作节奏

| 时间 | 工作内容 | 标准 |
|:---:|:---|:---|
| 播种前3天 | 备种/备土/备育苗盘 | 种子无霉变、育苗土消毒、育苗盘清洁 |
| 播种当天 | 装土/播种/覆土/浇水 | 播种深度为种子直径2-3倍 |
| 播种后3-5天 | 检查出苗情况 | 出苗率大于80%为正常 |
| 苗期 | 浇水/通风 | 见干见湿，不积水 |
| 定植前7天 | 炼苗 | 逐渐增加通风和光照，减少浇水 |

### 二、每日执行步骤

```
1. 早晨到农场后，首先检查育苗区
   [客户此时：如果有早到的客人，看到你在育苗区工作，可能产生好奇]
   检查内容：温度/湿度/出苗情况/是否有病虫害

2. 根据检查结果决定当天的操作
   正常 → 常规浇水（上午10点前完成）
   异常 → 按异常处理执行

3. 完成当天操作后，在Hermes中记录：
   - 各品种出苗率和生长状态
   - 浇水/施肥记录
   - 异常情况（如有）

4. 确认展示区状态
   如果育苗盘移到了可见区域，确认标牌清晰（品种名称+播种日期）
```

### 三、验收标准

```
□ 各品种出苗率已记录在Hermes
□ 育苗区无杂草、无异味
□ 展示区标牌清晰（品种+播种日期）
□ 如有异常已在Hermes记录并处理
□ 明日工作计划已列出
```

### 四、异常处理

| 异常 | 判断标准 | 响应 |
|:---|:---|:---|
| 出苗率低 | 小于60% | 检查种子质量/育苗土/温湿度，必要时重新播种 |
| 徒长 | 苗细长、叶片色淡 | 增加光照、减少浇水、降低温度 |
| 猝倒病 | 苗茎基部缢缩倒伏 | 立即移除病株，停止浇水2-3天，加强通风 |

### 五、客户触点

本阶段客户能看到的内容：育苗盘上的嫩芽（客户会拍照）、播种过程（可邀请参与）
对应公开化方案：育苗课堂——从种子到幼苗的自然课
