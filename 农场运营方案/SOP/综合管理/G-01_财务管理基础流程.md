[执行人] 言渊（总负责）
[替代人] 运营卫星成员（协助记录和统计）

[前置条件] 财务记账系统（Hermes财务模块）已就位

[AI提醒] Hermes推送月度结算提醒、异常收支预警、预算超支提醒

---

### 一、日常收支记录

```
1. 收入记录（各板块每日录入Hermes）

   引擎A·餐饮收入
   - 每单结账后记录：消费项目/金额/支付方式
   - 分类：火锅/烧烤/柴火灶/饮品/其他

   引擎B·露营收入
   - 入住时记录：房费/装备租赁/附加消费
   - 退房时结算：额外消费/押金退还

   核心层·体验收入
   - 采摘收入（按品种/重量）
   - 农产品销售
   - 认领收入

   自然手作收入
   - 课程收入（按课程类型）
   - 材料包销售

   其他收入
   - 会员卡销售
   - 活动报名费
   - 渠道佣金收入

2. 支出记录
   - 食材外采：品种/数量/金额/供应商
   - 物料采购：品种/数量/金额/用途
   - 人力成本：工资/兼职/导师课酬
   - 运营成本：水电/燃料/维修/运输
   - 营销成本：平台佣金/推广费用
   - 固定支出：土地租金/设备折旧
```

### 二、每日财务动作

```
1. 营业结束前（各板块）
   - 确认当日收入已全部录入Hermes
   - 确认当日支出已记录（含票据拍照存档）
   - 现金收入清点并存放入保险柜

2. 营业结束后（言渊或运营卫星）
   - 核对各板块收入记录与实收金额
   - 差异即时查明原因
   - 在Hermes中确认日结
```

### 三、每周核对

```
1. 每周一核对上周
   - 收入汇总与各板块记录一致性
   - 支出票据核对
   - 现金/账户余额核对
   - 应收/应付款项跟进

2. 核对发现的问题
   - 差异≤50元：记录差异原因
   - 差异>50元：追溯每笔记录，查明原因
```

### 四、月度结算

```
1. 月度财务报表（每月最后1天生成）

   收入报表
   - 各板块收入明细和占比
   - 收入环比/同比分析
   - 收入结构变化

   支出报表
   - 各板块支出明细
   - 支出分类占比（食材/人力/运营）
   - 支出环比分析

   利润报表
   - 总收入-总支出=毛利润
   - 各板块利润率
   - 净利润

2. 月度结算
   - 供应商货款结算
   - 兼职/导师课酬结算
   - 渠道佣金结算
```

### 五、预算管理

```
1. 年度预算（每年12月制定次年预算）
   - 收入预算（各板块预期收入）
   - 支出预算（固定支出+变动支出）
   - 利润目标

2. 月度预算跟踪
   - 实际支出与预算对比
   - 偏差≥20%的标注原因
   - 预算调整申请（言渊审批）

3. 成本控制红线
   - 食材成本率：≤营业收入的35%
   - 人力成本率：≤营业收入的30%
   - 营销费用率：≤营业收入的10%
   - 综合运营成本率：≤营业收入的15%
```

### 六、资金管理

```
1. 资金保管
   - 每日现金收入存入保险柜
   - 超过2000元的现金当日存入银行
   - 电子支付收入即时到账

2. 备用金管理
   - 日常备用金：1000元（用于小额采购/找零）
   - 备用金使用后即时补充
   - 每月盘点备用金

3. 大额支出审批
   - 单笔≥2000元：言渊审批
   - 单笔≥5000元：需提供比价单（至少2家）
```

### 七、税务与合规

```
1. 发票管理
   - 客户要求开票时即时开具
   - 发票登记（客户名称/金额/日期）
   - 月度发票汇总

2. 税务申报
   - 按期完成税务申报（言渊负责）
   - 所有收支凭证存档备查
   - 年度财务审计（如有需要）
```

### 八、验收标准

```
□ 每日收入/支出记录完整准确
□ 每周核对无差异或差异已处理
□ 月度财务报表按时生成
□ 成本率在控制红线内
□ 预算偏差≤20%（超预算有说明）
□ 资金管理合规（现金/备用金/大额审批）
□ 税务申报按期完成
□ 财务凭证完整存档
```

### 九、异常处理

| 异常 | 响应 |
|:---|:---|
| 收支记录与实际不符 | 追溯当日各笔记录，查明差异原因 |
| 成本率超标 | 分析超标原因，调整采购/定价策略 |
| 客户退款/纠纷 | 按O-05投诉处理流程+财务冲正 |
| 现金流紧张 | 控制支出/催收账款/短期周转方案 |
| 税务问题 | 咨询专业财税人员 |
| 票据丢失 | 补开/情况说明+双人签字确认 |

### 十、跨板块协作

- 各板块每日收入记录需准确录入Hermes
- 采购支出需与**各板块物资管理**核对
- 人力成本月度数据来源于**G-06员工培训**的考勤和考核记录
- 财务报表用于**言渊**的经营决策

### 十一、客户触点（间接）

- 财务管理不直接接触客户，但决定了农场的定价能力和服务投入
- 健康的财务状况是农场持续运营的基础，也是公开化运营中向客户展示"透明经营"的底气
- 财务数据（如各项成本构成、利润分配）可在公开化中适度展示，建立客户信任
