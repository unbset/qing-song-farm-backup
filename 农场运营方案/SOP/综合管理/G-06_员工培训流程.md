[SOP编号] G-06
[SOP名称] 员工培训流程
[执行人] 言渊（培训总负责人）
[替代人] 各板块主理人（负责本板块培训）
[执行时间] 新人入职第1周集中培训 / 在岗每月1次专题培训 / 每季度1次全员培训
[适用季节] 全年
[前置条件] 培训资料已在Hermes中归档；各板块SOP已就位
[AI接口] Hermes管理培训资料库、考核题库、培训记录
[AI提醒] Hermes推送月度培训提醒、SOP更新后推送重新学习提醒

---

### 一、新人入职培训（第1周）

```
1. 第1天：农场基础认知
   上午（3小时）
   - 农场参观（全板块走一遍）
   - 农场理念和定位介绍（言渊主讲）
   - 组织结构讲解（核心层+双引擎+运营卫星+自然手作）
   - 公开化运营理念介绍

   下午（3小时）
   - 各板块主理人见面
   - 各板块基础功能讲解
   - 岗位职责说明书确认
   - Hermes系统基础操作培训

2. 第2-3天：板块专项培训
   各板块主理人负责：

   核心层新员工
   - 种植日历和年度种植计划
   - 播种/生长期/采收期操作规范
   - 鸡舍日常管理
   - 客户参观接待

   引擎A新员工
   - 开档/收档流程
   - 备料与切配标准
   - 餐厅服务流程
   - 食材安全管理

   引擎B新员工
   - 入住/退房流程
   - 散客露营服务
   - 团建活动接待
   - 篝火安全管理

   运营卫星新员工
   - 每日开场巡检
   - 客户接待和引导
   - 社群运营维护
   - 客户投诉处理

3. 第4天：综合技能培训
   - 公开化运营实操（如何引导客户参与）
   - AI助手（Hermes）全功能操作
   - 紧急情况处理（急救/火灾/恶劣天气）
   - 客户沟通技巧

4. 第5天：考核与上岗
   - 笔试（SOP核心内容）
   - 实操考核（各板块主理人现场评分）
   - 综合评分≥80分方可独立上岗
   - <80分继续培训至达标
```

### 二、在岗持续培训

```
1. 每月1次专题培训（2小时）

   培训内容来源：
   - 本月SOP执行中发现的问题
   - 客户投诉反馈的高频问题
   - 新活动/新项目上线前的培训
   - 技能提升（烹饪技巧/服务礼仪/急救知识）

   培训形式：
   - 现场演示+实操
   - 案例复盘（真实投诉/优秀服务案例）
   - 模拟演练

2. SOP更新培训
   - SOP更新后7天内完成相关岗位培训
   - 更新内容重点标注，签字确认已学习
```

### 三、季度全员培训

```
1. 每季度1次（4小时）
   - 农场运营情况通报（言渊主讲）
   - 优秀员工表彰和经验分享
   - 客户反馈和投诉案例复盘
   - 新季度重点工作部署
   - 团建活动（增强团队凝聚力）

2. 季度考核
   - SOP知识抽查
   - 岗位技能考核
   - 客户服务情景模拟
```

### 四、培训资料管理

```
1. 培训资料库（Hermes中）
   - 各板块SOP文档
   - 新人培训手册
   - 常见问题FAQ
   - 客户沟通话术参考
   - Hermes操作指南

2. 资料更新
   - SOP更新同时更新培训资料
   - 每季度全面审查培训资料完整性
   - 培训资料设版本号
```

### 五、考核与认证

```
1. 岗位认证
   - 每个岗位设置初级/中级/高级三级认证
   - 初级：独立完成岗位工作（80分）
   - 中级：独立完成+指导新人（90分）
   - 高级：优化流程+跨板块协作（95分）

2. 认证晋升
   - 每季度可申请晋升认证
   - 考核通过后调整薪资
   - 连续两次考核不通过安排再培训
```

### 六、培训记录

```
1. 个人培训档案
   - 参加过的培训课程和时间
   - 考核成绩
   - 岗位认证等级
   - 培训师评价

2. 培训效果评估
   - 培训后1个月：工作表现是否提升
   - 客户满意度是否因培训而改善
   - 投诉率是否下降
```

### 七、验收标准

```
□ 新员工入职培训完成率100%
□ 新人考核通过率≥90%（未通过者再培训）
□ 月度培训按计划执行
□ 季度培训全员参与率≥90%
□ 培训资料完整（所有SOP均对应培训资料）
□ 个人培训档案齐全
□ SOP更新后7天内完成培训
```

### 八、异常处理

| 异常 | 响应 |
|:---|:---|
| 新人快速流失 | 分析离职原因，优化入职培训和岗位适应 |
| 培训参与率低 | 调整培训时间（规避高峰时段），录制培训视频 |
| SOP更新频繁 | 集中更新后统一培训，不单独每次培训 |
| 考核通过但实操差 | 增加在岗带教时间，延长试用期 |
| 老员工抵触培训 | 差异化培训内容，提升实用性和针对性 |

### 九、跨板块协作

- 培训内容由各板块主理人提供并负责本板块部分
- 跨板块协作内容在全员培训中统一宣讲
- 优秀员工跨板块轮岗培训（培养全面型人才）
- 培训考核结果反馈至言渊，用于人员调配和晋升

### 十、客户触点（间接）

- 培训质量最终体现在客户体验上：训练有素的员工是优质服务的保障
- 客户能感受到员工是"熟练的"还是"生疏的"，培训决定这个差异
- 公开化运营中，员工对农场理念的理解深度直接影响客户对农场信任感
